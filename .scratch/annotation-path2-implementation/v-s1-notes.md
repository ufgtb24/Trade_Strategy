# V-S1 记录：第一段标注工具的试用反馈

本文件中所有项目内路径均相对 repo root。

V-S1 是第一段实施票 01～11 全部合回后，用户和会话一起手工走的验证，做法和通过标准见 [spec](../annotation-path2/spec.md) 第 7 节「V-S1 第一段验证」。本文件随走随记，记三类东西：

- **界面改进**：用起来别扭、要改的地方。V-S1 走完后统一整理，再决定拆成实施票还是回头改 spec。
- **装不下的意思**：哪句话只能写进 `note`（spec 第 7 节要求会话记下）。
- **只能靠猜的翻译**：会话把标注翻成 app 时，哪一层只能靠猜（同上）。

## 界面改进

### 1. 加属性的地方写不了属性词的定义

- **现状**：在 `selection` 页用 `+ attr` 加一个新属性词后，这个词进了词表，但 `selection` 页只给框的特征名留了定义格（spec 5.4 第 354 行「新特征第一次用时，`selection` 页留一格请用户写定义」只落到了特征名上）。要写属性词的定义，得切到 `features` 页找到这个词再写。
- **影响**：标注时被打断；新属性词容易漏写定义，几周后就想不起它指什么（spec 第 187 行的用户故事）。
- **可能的改法**（待定）：新属性词第一次用时，在 `selection` 页属性那一行旁边同样留一格定义，可以先空着。
- **来源**：用户 2026-11-03 试用时提出。

### 2. `rally` 清单看不出哪些已经标过

- **现状**：`rally` 清单只有 `symbol`、`date`、`rise` 三列，看不出哪一行的图已经标过。想回头检查、修改标注时，只能逐行点开看。替代办法是侧栏 `pattern` 页（或 `unsorted` 页）的样本卡，点卡能挨个打开，但只列放了样本的图；只画了框、还没放样本的图不在里面。
- **影响**：回头检查和修改标注时要一张张点开；也分不清哪些大涨段还没看过。
- **可能的改法**（待定）：清单每行标出这只股票、这段涨附近有没有标注（例如框数、样本数），并能按「已标 / 未标」筛选或排序。注意 spec 5.3「看过什么一律不记」：这里只显示用户存下的标注，不记看图记录。
- **来源**：用户 2026-11-03 试用时提出。

### 3. 删框要有快捷键

- **现状**：删一个画错的框，要先选中它，再点 `selection` 页里的 `delete` 按钮。没有键盘快捷键。标注里也没有撤销。
- **影响**：画错框是常事，每次都要移到侧栏去点，打断标注。
- **已改（2026-11-03，用户要求当场加）**：在 `annotate` 和 `compare` 下，选中框时按 `Delete` 就删，和 `delete` 按钮是同一个动作；光标在输入框里时不触发。不认 `Backspace`，免得误触。e2e 测试在 `path2_web_ui/e2e/annotate-boxes.spec.ts`。
- **还没做**：撤销。删掉的框如果是某个样本的成员，成员关系也一起没了。要不要做「删后短暂提示并给一个撤回」，V-S1 走完后再定。
- **来源**：用户 2026-11-03 试用时提出。
