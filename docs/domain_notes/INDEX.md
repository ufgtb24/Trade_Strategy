# 领域方法论笔记索引

## 分类维度
按概念回答的方法论问题分（区分度/相关性/归一化/时间过程/不确定性/金融算法）。查阅时按「想干什么」直接定位：想筛特征→区分度与排序；想查共线→相关与关联；想统一量纲→归一化与量纲。多面概念（如 Mann-Whitney U 既是检验又是排序量度）取主功能归属，在辨析小节里提另一面。

## 分类与笔记

### 区分度与排序
衡量「一个量把两组分开 / 给样本排序」的能力。
- [discrimination-ranking.md](discrimination-ranking.md) — AUC 及同族排序质量概念

### 相关与关联
衡量「两个变量一起变动」的程度与方向。
- [correlation-association.md](correlation-association.md) — Spearman ρ 及同族关联度量

### 归一化与量纲
把不同尺度的量拉到可比口径的方法（TR/ATR 归一、对数收益、z-score 等）。

### 时间过程量
描述时间演化/随机过程的量（first passage、自相关、波动率估计等）。

### 抽样与不确定性
从样本推断总体的工具（置信区间、bootstrap、p 值、置换检验等）。

### 金融与交易算法（预留）
计算流程类算法：技术指标算法、组合/风险计算、定价模型。首个概念落位时启用。
