# 续跑：上一轮断在哪

第 0 步发现「有 round 文件、没有同名 `.report.md`」时读。记号同 SKILL.md：`<R>` 是那个 round 文件。**不重新定格。**

先看断在哪：

```bash
uv run python .claude/skills/annotation-round/scripts/round_state.py <R>
```

它打印：定格时的 app 与指纹、现在的 app 与「指纹: 变了 / 没变」、「快照已写进会话段: True / False」、会话段里 conditions 与 tags 各几条、这一轮有没有处理清单（`.plan.md`）、没注册上的 app。从上往下对，停在第一条对得上的：

| 看到的 | 从哪接着做 |
|---|---|
| 「现在 app」读不出，并且多出一行「注意: app … 的 mapping.yaml 读不出它对哪个 pattern」 | `mapping.yaml` 写坏了（多半是写快照或记账时弄坏了格式）：把它修到读得出（只动它），重跑本命令再往下对 |
| 「现在 app」读不出，并且多出一行「磁盘上有 mapping、app 却没注册上 …」 | 有 `.plan.md`：app 是这一轮改（或新建）到一半、导入不了——回第 5 步，按末行的报错修到它能导入，再照 `.plan.md` 把没做完的做完，修好后重跑本命令往下对。没有 `.plan.md`：这一轮还没动过 app，不是你改坏的——把末行的报错告诉用户（末行没有它的原因时，就说这个目录的 app 没被认出来），停下 |
| 「定格时 app」有、「现在 app」没有，上面两种行都没出现（可能多出一行「定格时的 app … 现在的 mapping 写的 pattern 是 …」） | `mapping.yaml` 里的 pattern 名和这一轮的对不上：跑不带参数的总览看那个 app 那一行，只改 `mapping.yaml`（把 `pattern` 那一行改回这一轮的名字），修好重跑本命令再往下对。总览里也找不到定格时的那个 app（`mapping.yaml` 整个被删了，或 app 目录改了名、挪走了）→ 告诉用户，停下。这种情形下「把快照写进去」是变不成 True 的，不要在下一行打转 |
| 「定格时 app」没有、「现在 app」也没有（没有上面两种多出来的行） | 定格时还没有 app，app 还没建：没有 `.plan.md` 从第 2 步，有就从第 5 步 |
| 快照已写进会话段: False | 把 `<R>` 里 `snapshot` 那一项照第 1 步写进 `mapping.yaml` 的会话段（只动 `snapshot`；还没有 `.plan.md` 时连第 1 步的「先存一份、写完 `diff`」一起做），重跑本命令确认变成 True，再接着往下对 |
| 「定格时 app」没有、现在有 app 了 | 第一版 app 已经建出来：第 6 步 |
| 指纹没变、没有 `.plan.md` | 第 2 步（题要重新问） |
| 指纹没变、有 `.plan.md` | 第 5 步，照 `.plan.md` 改 |
| 指纹变了 | 第 6 步 |

从第 6 步接着做之前，先对照 `.plan.md` 逐条看 app 现在的声明（`dag_spec.py`、`params.yaml`、`mapping.yaml`）：清单里要改的每一条做了没有。有没做的就回第 5 步补完，再做第 6 步。`git diff path2_apps/<app>` 只作参考——这一轮新建的 app 还没进 git，diff 是空的。

- 指纹只看 app 包里的 `.py` 和默认参数文件，不含 `mapping.yaml`：指纹没变不等于 mapping 没动，从第 5 步接着做时先对照 `.plan.md` 看一眼 `mapping.yaml` 现在的 `features`、`notes`。
- 第 2 步的摘要、`look.py` 随时可以重跑：摘要固定按 `<R>` 定格时的标注和改之前的买点出，不受中断影响；`look.py` 跑的是现在的 app，app 已经改过时它给的是新版。
- 用户在中断期间又改的标注不进这一轮（摘要里看不到），照常留给下一轮；他问起时告诉他「这一轮先收尾，你后来改的下一轮处理」。
- 报告只在记完账之后才存成 `.report.md`。所以「指纹变了」那一行也包括「报告已经出过、账没记完」的情形：照样从第 6 步走，报告重出一遍、`lost` 行重填，再记账、存报告。
- 续跑走到第 8 步时，会话段里可能已经有这一轮记了一半的行和标签。重记之前先看 `mapping.yaml` 现有的 `conditions`、`tags`，对照 `.plan.md` 找出已经记了哪些，只补缺的、改不对的；同一条条件不要记成两行（两行都合规、页面不报错，但下一轮的摘要里会重复）。
- 用户说「新一轮」而这一轮还没走完，也是先把这一轮收尾（出完报告、记完账），再新开。
