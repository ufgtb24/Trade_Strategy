# 计算方法与边界

本文对应随 skill 提供的收盘方向实现。默认数值是工程初值，不是已证明最优的交易配置；本轮开始前固定，不能因候选成绩不好临时调整。

## 逐日标签

按事件实际 `sample_bar_indices()` 取买点，排除事件确认前及候选所需回看不足的日期，同股同日去重。每股标签仅算一次。检测输入止于买入结束日，标签输入止于该阶段允许的未来尾部。正式入口按冻结交易日历要求每股实际数据末端到齐；系统日期已过而文件未更新时，在标签计算前失败，不凭一部分旧标签得出采用结论。

买点收盘价 P；当日及之前最近 `FP_ATR_WINDOW` 根的 `TR/close` 中位数为 M；TR 是当日高低差、高价与昨收之差绝对值、低价与昨收之差绝对值三者最大值。沿用框架尺度和几何上下线：

- 上线 `P*(1+k*M)`，下线 `P/(1+k*M)`，买入时固定。
- 从次日起到第 H 个交易日，按 close 最早达到或越过的线判先上/先下；都未到则未触线。使用完整 H 日，不因已经触线允许截短历史尾部。
- 三态方向值分别为 +1、−1、0。表中保留 `both` 列但恒为0，评分拒绝盘中双触标签。
- 空间 `max(high[t+1..t+H])/P-1`；盘中回撤 `min(low[t+1..t+H])/P-1`。两者为带符号幅度，保留中位数；回撤另报较差10%处数值。它们不是实际持有收益。
- 缺少完整未来、价格非法或 M 不可算时不产生标签，另报不可评估数；正常的未触线必须保留。

空间、回撤使用滚动最大/最小；M 使用等价滚动中位数。首穿按未来偏移批量比较尚未分出结果的起点，已触线起点退出后续比较；最坏O(NH)、额外O(N)，不造整个起点×未来日期矩阵。

## 时段内与时段间

普通股票池所有可评价日期共同组成按交易日排序的日历。默认每个连续21交易日为一个窗口，枚举全部合法起点。窗口内 N 为真实买点数，U/D 为先上/先下数量：

`z=(U-D)/N`。

未触线留在 N 中；没有买点的窗口无成绩。有买点但全未触线则 z=0。窗口末端距最新可评价日期为 age，时间权重 `a=2^(-age/252)`；只在该候选非空窗口上归一：`Z=sum(a*z)/sum(a)`。没有任何非空窗口则不可评分。

外层不按窗口买点数再加权。默认半衰252交易日与21日窗口可以在配置中预先改，但不作为 Optuna 参数。主分评价“有机会的时段里，偏重近期后的方向表现”，不是全年资金回报。窗口重叠不增加独立证据；首尾日期参与的完整窗口少于内部日期，也不等于全部日历日等权。另报最后完整窗口及覆盖率。

报告同时保留：合并买点方向均值、条件先上比例 `U/(U+D)`、触线比例、窗口中位数和主分Z。前两者不能冒充Z，方向分0.2也不能写成收益20%。此度量没有完全消除未来波动变化的影响，也不奖励更快触线。

## 普通买入与固定 bo

普通对照为同股票池同日期的全部可评价股票日，包含候选自身，不刻意排除pattern。每日期按已知M切至最多五个档，同M不拆开。一次预计算每档三态均值与股票日索引，trial只按所选股票日查询其档位均值，不重新扫描全池。

候选窗口有几个某日期某档的买点，就给该档对照对应次数的权重。窗口内汇总得到 b；用候选同一批非空窗口和相同时间权重算B，差异为Δ=Z−B。这保留窗口内股票日等权，不偷换为每日等权。候选等于全池时Δ应为0（允许机器精度误差）。候选与池子有共同数据，不能当独立样本。普通对照的空间中位数未用档内中位数近似，字段明确为空。

固定 bo 使用 `bo_only`，默认冻结现役 app 的 bo 参数段；app 无该段时冻结 `bo_only.load_params()`。允许在搜索前显式指定完整 `bo_params`，不随候选改动。买点用其自身定义，方向标签与pattern相同，数据和标签缓存共用。bo的买入日期可能不同，所以成绩差异也含择时，不自动成为逐窗口门槛。必须报告其突破判断方式和完整参数；close方向标签不等于所有信号都必须由close突破产生。

## 搜索与入选的同一要求

| 规则 | 默认 | 含义 |
|---|---:|---|
| 总买点数 | ≥30 | 同股同日只计一次，超过不额外奖励 |
| 相对原参数总数 | ≥一半 | 保留基本供给 |
| 最近126交易日买点数 | ≥1 | 短评价段用实际全部日期，不强迫每月出手 |
| 相对原参数近期数 | ≥一半 | 不靠已经消失的机会维持主分 |
| Z | 严格>0 | 全未触线不算有效向上 |
| 同配比普通对照差Δ | ≥0 | 观察值要求，不是统计不劣证明 |
| 买点空间中位数 | 默认不设 | 显式设置后搜索/入选都执行 |
| 买点回撤中位数 | 默认不设 | 带符号值下限，例如≥−0.2；不是尾部损失保证 |

对应键在 `scoring.DEFAULT_POLICY`。股票数、活跃日期数、时间覆盖只作证据描述，不直接变成独立样本数。约束值>0表示违反；等于0通过，方向严格下限单独处理。搜索和最终训练选参都在同一合格集合最大化本轮冻结的主分（默认Z，启用折扣时为S）；没有额外空间改善资格。机器精度范围的差异不算改善，平分保留先出现者。

## 可选的统计折扣

默认 `shrinkage.enabled=false`，排名仍为Z且不计算工作误差。显式开启时，对所有候选使用同一算法：

`S = B + λ × Δ`，`Δ = Z − B`，`λ = τ² / (τ² + V)`。

Z、B先完成同窗口同权重汇总，再调整整体差异。τ默认0.1，是搜索前固定的差异尺度，尚未经市场校准，不由Optuna逐候选挑选。V是整体配对差的工作误差刻度，保留候选和普通买入的共同变化，不把它们视为两份独立样本。

在按交易日顺序排列的所有窗口起点s上，有交易时令 `ψ_s=ω_s[(z_s−b_s)−Δ]`；空窗口直接令ψ=0，不能执行0乘NaN，也不能删掉空位置压缩日历。相关跨度q默认80：

`V = Σψ_s² + 2Σ(lag=1..min(q,窗口总数−1)) (1−lag/(q+1)) Σ_s ψ_sψ_(s+lag)`。

q=0时只保留首项。循环只用窗口数组，不重新检测、不扫描整个股票池；开关启用后的附加时间O(窗口数×有效跨度)，额外空间O(窗口数)。窗口重叠、长H及持续市场影响仍可能让这个V低估不确定性；λ不是结论为真的概率，B本身未来是否可靠也没有被该公式解决。它只是有理论动机、尚未验证本项目选参收益的实验性选项，不生成置信区间。

明确的边界处理：

- 没有买点时仍无分数；不能用B补出交易。
- 若观察差Δ在1e−12机器精度容差内为零，令S=B、λ=0并标 `zero_observed_difference`。这不意味着真实差异已被证明为零。
- 非零差但只有一个活跃窗口、活跃窗口差值变化≤1e−12、或算出的V无法与数值舍入区分时，令λ=0、S=B，标 `unidentified_variance_full_shrinkage`。这是事前固定的保守规则，可能压低真实且稳定的优势；不让V=0自动等于完全信任，也不悄悄改用Z。
- Bartlett相关和的极小负舍入可归零；明显负值或非有限结果作为计算错误报告，不吞为一个漂亮分数。

启用与否都保留原始Z/B/Δ和全部供给/方向要求；约束检查原始观察，排名才用S。因此折扣抬高了某个原始差成绩也不能使其绕过要求。输出并列实际主分、原始方向分、V、λ、开关配置及状态。开关与τ/q一轮冻结，搜索、入选、最后检查、复核使用同一模式；各阶段基于各自数据重新算V，不沿用训练的候选特定λ。

## 采用的实际能力

`comparison` 比较新旧本轮主分及同一要求；`score_difference` 是S之差（关闭时为Z之差），`new_direction_score/reference_direction_score` 始终为原始Z。折扣详情分候选/原参数保存，空间差仅作诊断。开启也保持 `evidence_sufficient=False`、改善上下界为空；不能把折扣数值自动变成统计确认。

因此当前自动流程：最后观察改善且要求通过→暂用；否则不采用；预定复核仍缺确认依据→撤回。`adoption` 保留确认分支，但评分模块尚无经过验证的证据规则能自动到达它。不能宣称本版能自动确认，也不能临时填误差下限触发确认。未来引入规则须先做训练内部开发比较，统一冻结后才能用于新一轮，不修改已冻结轮次。

两段数据比较用来改公式时都属于开发。开发结果不能代替最后一次未参与改方法的数据检查；只有一个冻结候选进入最后检查，不依据检查结果重选第二名。

## 缓存、隔离与使用记录

- 每评价器固定股票、日期、标签定义和数据快照；固定bo共用标签。精确完整参数+源码+数据摘要决定候选缓存，不对浮点取整。
- `WindowPlan` 复制并冻结普通池。传入原表仅作句柄；外部原表后来变化不会改变该计划。更换标签或池必须建新计划；候选标签须与快照一致。
- pickle反序列化会读取整文件字节，然后立即裁切。隔离指进入检测和标签的日期范围，不声称操作系统没读取后段字节。需要物理隔离时先准备分期文件。
- 事件确认检查不能代替祖先/边/where因果审查。对具体app用代码与逐日前缀核查；没有覆盖全部参数范围的测试时如实限定。
- 正式搜索预留final/review并先记training；方法开发用同账本 `claim_development` 记录，不虚设最终验证。开发暴露永久阻止相同范围被当最终未见数据，`abandon` 不清除记录。
- 固定股票池和完整数据研究不消除存续股票筛选偏差、交易成本、成交约束或历史参数开发的影响。
- Optuna建议参数，评分模块定义好坏；SQLite记录不是随机搜索器全状态备份，不支持精确续搜。
