# FC-001「买点日 ATR%(20)」换样本验证 + feature-study skill 首次完整跑通

## 背景

`docs/feature_candidates.md` 的 FC-001 登记了一条待验证假说：bb_v1 买点当日的 ATR% 越低，未来收益 (`forward_return`) 越高。发现样本是 2025-09..12 窗口的 112 行买点，且该样本在当前代码上已不可精确复现（36/107）。本轮任务有双重目的：

1. **验证 FC-001**：换一份完全不同的样本（全 2025 年窗、458 条 match、317 只股票）重新检验这条假说是否成立。
2. **验收 `feature-study` skill 本身**：这个 skill 自 2026-08-20 建立以来，`docs/research/` 下没有任何 `*feature-study*` 目录——完整六步流程从未真正跑过一遍。骨架 (`extract.py`) 也刚从「硬编码单个 app」改造为「任意声明了 adapter 的 app 可用」，本轮同时是这次重构后的第一次真实使用。

**条件宇宙**：样本 = bb_v1 pattern 已成立的 match（tb/burst/bo 闸全部通过），不是宽进池。这一点决定了本报告的结论不能与 `docs/research/2026-09-07_dag-scoring-vs-hard-gates/` 那种宽进池研究直接对齐。

**底座**：`outputs/path2_web/scans/20260908T113225.json` —— bb_v1 / 扫描 8325 只 / 命中 317 只 / 458 条 match / `label_horizon=40` / 严格窗 2025-01-01..2026-01-01 / 切窗 2024-09-19..2026-03-08 / filters price 0.5~30、volume_min 10000。

样本约 450 行 / 317 股——**够跑机制验收，不足以下强统计结论**，这一点贯穿全篇局限声明。

## 口径表（≥3 种，公式级）

FC-001 登记的原始口径与骨架自动注入的通用波动率控制列 `c0_atr_pct` 同源（都是 ATR/close 类波动率地板），这是本轮最大的方法论陷阱，见下节「两轮电池」。

| 列名 | 口径 | 公式 | 换的是什么 |
|---|---|---|---|
| `v_median20` | 登记簿原口径 | `rolling_atr_pct_nanmedian(high, low, close, 20)`，买点当日 `entry_idx` 取值 = median_{i=t-19..t}(TR_i / close_i) | 基线 |
| `v_wilder20` | 换平滑方式 | `calculate_atr(high, low, close, 20)`（Wilder RMA）在 `entry_idx` / close_t | median → Wilder RMA |
| `v_median10` | 换窗口长度 | `rolling_atr_pct_nanmedian(high, low, close, 10)`，买点当日取值 | 窗 20 → 10 |

三个口径均只用 `t` 及之前的 high/low/close（`TR_t` 用 `t` 日 high/low + `t-1` 日 close），买点日收盘决策时刻均已知、无前瞻，**均不加 `posthoc_` 前缀**。

**比值口径的分子/分母原始量**（供归因诊断，不进三关判定）：

| 列名 | 含义 | 对应哪个比值口径的分子 |
|---|---|---|
| `tr_median_raw_20` | median_{i=t-19..t}(TR_i)，美元级 | `v_median20` |
| `tr_median_raw_10` | median_{i=t-9..t}(TR_i)，美元级 | `v_median10` |
| `atr_wilder_raw_20` | Wilder RMA(TR,20)_t，美元级 | `v_wilder20` |
| `c_close_t` | close_t（三者共享的分母） | 全部三个 |

## 两轮电池：为什么要跑两次

骨架自动注入的 `c0_atr_pct`（买点前一根的 ATR/close，Wilder 窗14）是一个通用波动率地板，进默认控制集。FC-001 的三个口径本质上都是波动率的另一种量法，**与 `c0_atr_pct` 同源**——默认配置下关 2 秩回归几乎必然把 FC-001 判成「代理」，但这是**控制列自我吸收**的产物，不是关于 FC-001 独立性的真实发现。

- **A 轮（默认路径）**：`controls = ["c0_atr_pct"] + adapter.KNOWN_SIGNALS`（`KNOWN_SIGNALS = [m1_burst_runup, m2_depth_rel]`）。目的是验证默认路径能跑通、关 2 不因空控制集整体跳过。**FC-001 在这一轮被判成「代理」是预期内的结果，不是失败。**
- **B 轮（移出地板）**：`controls = adapter.KNOWN_SIGNALS`（不含 `c0_atr_pct`）。这才是排除同源控制列自我吸收之后，FC-001 相对于两个已知业务信号的真实独立性判定。

## 电池结果

### 关 1：原始关联（Spearman + BH-FDR，两轮相同）

| 口径 | spearman | p | q_fdr |
|---|---|---|---|
| `v_median20` | +0.189 | 4.7e-05 | <0.001 |
| `v_wilder20` | +0.200 | 1.7e-05 | <0.001 |
| `v_median10` | +0.165 | 3.8e-04 | <0.001 |

电池打印的形状注记（`_shape_note`，判形状用的是 `mean_lab`）：`v_median20` 单调升、`v_wilder20` 单调升、`v_median10` 非单调。**这只是均值形状**——本仓评估纪律的核心指标是 `median(forward_return)`，均值形状不能替中位数形状说话，两者在 `v_median20` 上不一致，见下方「与登记簿方向对照」按 `med_lab` 重新核对的真实分箱形状（fix 轮补，完整 stdout 见归档的 `battery_output.txt`）。

### 关 2：控制后独立贡献

| 口径 | A 轮 t（含 c0_atr_pct） | B 轮 t（不含 c0_atr_pct） |
|---|---|---|
| `v_median20` | +1.60 | +1.82 |
| `v_wilder20` | +1.91 | +1.43 |
| `v_median10` | −0.04 | +0.72 |

三口径两轮 `\|t\|` 全部 < 2，**均未过关 2**。

**口径间的 t 值排序不稳定，不作为机制证据**（fix 轮改判）：B 轮排序是 `v_median20`(+1.82) > `v_wilder20`(+1.43) > `v_median10`(+0.72)，但 **A 轮前两名对调**（`v_wilder20`(+1.91) > `v_median20`(+1.60)），`v_median10` 还从 −0.04 翻到 +0.72。三个 t 全部低于判定门槛、彼此差距在噪声量级内，任何单一排序都撑不住「机制证据」这个分量。

排序不稳定的根源可从 Spearman 矩阵读出：A 轮里 `v_wilder20` 与骨架控制列 `c0_atr_pct` 的相关高达 **0.992**（`v_median20` 对它是 0.884、`v_median10` 是 0.903），两根近乎同一的列被劈成一对大小相当、符号相反的系数（A 轮实测 `v_wilder20: t=+1.91` 配 `c0_atr_pct: t=−1.62`）——这是共线性方差膨胀的典型形状，不是「`v_wilder20` 被地板吸收得更彻底」。所以「A 轮代理判定 = c0_atr_pct 自我吸收」这个解释对 `v_wilder20` 并不成立，也就谈不上用它去解释口径间的强弱。三个口径的独立贡献应读作「均在噪声内，彼此不可分辨」，而不是一条可解读的排序。

### 关 3（诊断参考，未作为正式 verdict 依据）

关 2 已判死（`\|t\|<2`），按电池判定逻辑直接给出「代理」、不再消费关 3 结果，但电池仍打印了关 3 的数值，可作诊断参考：

- 关 3a 股内去簇（n=317）：三口径 p 值 0.0043 / 0.00072 / 0.011，均 <0.05 且同号——个股维度稳健，不是少数股票反复观测刷出来的。
- 关 3b 时间去簇（桶宽 40，**n=8**）：三口径 p 值 0.42 / 0.69 / 0.78，全部不显著——但时间桶数量仅 8，该检验在本轮无功效，「真实信号被时间去簇后消失」与「本来就没有独立信号」两个方向都不可解释，不构成额外的负面证据，也不能反过来当正面证据。

### 判据 2 / 3 核对

- `dataset.csv` 同时含 `c0_atr_pct` / `m1_burst_runup` / `m2_depth_rel` 三列（实测核对：均存在，NaN 计数均为 0）；A 轮电池打印中**没有**出现「⚠ 无 controls:关2 跳过」。
- 电池打印出了「== 关3b 时间去簇(每时间桶首条,桶宽=40,n=8) ==」这一段，**没有**「缺列 / 时间维跳过」的降级警告——`entry_idx` 列名回归测试通过，`run_battery.py` 未发生静默降级。

| 口径 | A 轮 | B 轮 |
|---|---|---|
| `v_median20` | 代理（被控制集吸收） | 代理（被控制集吸收） |
| `v_wilder20` | 代理（被控制集吸收） | 代理（被控制集吸收） |
| `v_median10` | 代理（被控制集吸收） | 代理（被控制集吸收） |

**FC-001 三个口径在 A/B 两轮均判定为「代理」**——A 轮的代理判定预期内（`c0_atr_pct` 同源控制列导致的判定降级，`v_wilder20` 一项还叠加了 0.992 共线的方差膨胀，见上节）；B 轮移出该地板后，FC-001 仍然被已知信号 `m2_depth_rel`（回撤深度）吸收，说明 FC-001 测到的关联主要不是独立于已知信号的新增信息，而是 `m2_depth_rel` 这一波动率/回撤深度族信号的又一种量法。**落点方向与登记簿 FC-009「bb_v1 上 forward_return 的优势可能全是波动率读数」的预期相同，是符合预期的机制性结果，不是验证失败**——但 FC-009 的发现报告样本宇宙是宽进池（含被闸拦下的样本），本轮是 pattern 已成立的 match，两者宇宙不同，不构成互证，只是方向一致的独立观察。

## 与登记簿方向对照 + 真实分箱形状（med_lab）

登记簿 FC-001 原描述「低波动 → fr 更高」，本轮三个口径的关 1 相关方向（Spearman）均为**正**（ATR% 越高 → label 越高），表面上与登记簿方向相反——这是特征与 label 的秩相关本身的符号，与分箱顺序无关。

按 `median(forward_return)`（本仓核心指标，非电池默认展示的 `mean_lab`）重新核对五分位分箱，三口径**形状并不一致**：

| 口径 | med_lab（q0→q4） | 真实形状 |
|---|---|---|
| `v_median20` | 0.164 / 0.159 / 0.275 / 0.352 / 0.336 | 低两箱持平微跌 → 中高抬升 → **尾箱回落**，甜点在 q3 |
| `v_wilder20` | 0.155 / 0.233 / 0.269 / 0.287 / 0.416 | 单调升 |
| `v_median10` | 0.164 / 0.253 / 0.218 / 0.286 / 0.478 | q2 回落，非单调 |

只有 `v_wilder20` 在 med_lab 口径下真正单调升；`v_median20`（登记簿原口径）实际是**尾箱回落、甜点在 q3**，`v_median10` 在 q2 回落。**本样本下，高波动分位数的中位 forward_return 总体更高，与登记簿「低波动→更高」的方向相反**（q0 到高分位普遍升，只是升法各口径不同）。这属于「换样本」应当暴露的差异之一，不强行调和；本轮的判定重点在「代理」而非方向本身，故不深挖方向反转的原因，仅如实记录供后续研究参照。分箱形状对 tune-gates 后续定硬闸的形状选择（单档阈值 vs 甜点区间）有直接影响，见结论段。

## 结论

- **FC-001 判定：代理（被控制集吸收）**，A/B 两轮一致。三种口径（原始 median-TR 窗20 / Wilder RMA 窗20 / median-TR 窗10）在关 1 全部显著（q_fdr<0.001），但控制已知信号后独立贡献均未过 `\|t\|≥2` 门槛，且三者的 t 值排序在 A/B 两轮不一致，不可读作口径间的强弱排序。
- **分箱形状（med_lab）三口径不一致**：`v_wilder20` 单调升；登记簿原口径 `v_median20` 实际是尾箱回落、甜点在 q3；`v_median10` 在 q2 回落。若后续要交给 tune-gates 定硬闸，形状差异意味着不能默认套单档阈值——单调升适合下限闸，尾箱回落/甜点型适合区间闸，两者硬闸行为不同。
- **本轮不向 tune-gates 交付任何候选信号**——三口径判定均为「代理」，没有「有信号」结论可交。
- 本轮同时验证了 `feature-study` skill 重构后骨架（`extract.py`/`run_battery.py`）在新 app（bb_v1）+ 新 scan 上的完整可用性：两道自检门、五个通用列、A/B 双控制集切换、关 3b 时间去簇列名回归（`tb_start`→`entry_idx`）均按预期工作。

## 局限（逐条声明）

- **单窗样本内**：2025-01-01..2026-01-01 严格窗，非跨期 holdout，未做样本外验证。
- **label 口径上偏**：本样本 label 中位数 0.234、均值 0.473，这是 bb_v1 买点已过全部闸限（tb/burst/bo）的条件化样本本身的正偏性，不可当作无条件收益预期（本轮未计算随机日基线做对照，不下「高/低于基线」的判断，仅陈述数值本身）。
- **458 行 ≠ 458 个独立买点**：按 `(symbol, entry_date)` 去重后只有 **374** 个独立买点（299 个 1 行、68 个 2 行、5 个 3 行、2 个 4 行——75 个买点重复计入，多出 84 行）；同一买点内三个特征值完全相同（同一天同一根 K 线算出），关 1/关 2 的名义 n=458 因此高于独立买点数。这不是去重键写错——`DEDUP_COLS=(symbol, tb_id, bo_id)` 本就允许同一天出现多个合法的 tb/bo 实例——但读者不应把 458 当成 458 个独立观测。**这条局限对判定有实质影响**：按买点日去重（每买点取数据原序首条，n=374）重跑 B 轮秩回归：

  | 口径 | B 轮 t（n=458） | B 轮 t（n=374，按买点日去重） |
  |---|---|---|
  | `v_median20` | +1.82 | +1.70 |
  | `v_wilder20` | +1.43 | **+2.02** |
  | `v_median10` | +0.72 | +0.81 |

  `v_wilder20` 在去重口径下会跨过 `\|t\|≥2`，但它的关 3b（n=458 口径）p=0.69 过不了，去重口径下判定会从「代理」变成「**不稳**」而非「有信号」；`v_median20`/`v_median10` 两个口径判定不变。FC-001 的总判定（三口径在 B 轮均未拿到稳定的独立贡献）方向上仍然站得住，但 `v_wilder20` 一项对去重口径敏感，读者需知悉。
- **观测非独立，双维去簇已检**：关 3a 股内维度三口径均显著（个股驱动已排除）；关 3b 时间维度因桶数过少（n=8）功效不足，未能给出有效判断，但由于关 2 已先判死，未纳入正式 verdict，不构成额外负面证据。
- **口径族已 FDR**：三个口径同一族做了 BH-FDR 校正（q_fdr 全部 <0.001，通过关 1）。
- **样本量**：458 行 / 317 股，够跑机制验收，不足以支撑强统计结论（尤其关 3b 的 8 桶诊断）。
- **相关 ≠ 可交易**：本报告最高产出是候选信号的排除性判定，不构成任何交易建议。
- **c0_atr_pct NaN 计数 = 0**：本轮无该项缺失导致的有效 n 衰减，无需进一步声明。
- **不与 `2026-09-07_dag-scoring-vs-hard-gates` 对齐**：该轮样本宇宙是宽进池（含被闸拦下的样本），本轮是 pattern 已成立的 match，两者不可比。
