## 0. 锚点:解耦为了什么

解耦不是为形式而形式。它的目的是**让每个评估回答一个清晰的问题,从而支持独立的归因与独立的迭代**。

- feedback §0 的解耦,服务于「自动优化循环能独立迭代 pattern」——尺子一旦混入**可调**交易参数,分数下降时分不清该改 pattern 还是改交易,两层都失去独立迭代能力。
- web UI 人工分析场景的解耦,服务于「人能独立归因选股 vs 交易」——人脑不会被一把耦合尺子机械误导,但若两个问题被合成一个数字,人就**失去"区分选股贡献 vs 交易规则贡献"的能力**。

形式(指标分开呈现)相同,目的(独立归因/迭代)同源,但**紧迫性与"移出"的具体含义随场景改变**。

## 1. 场景差异如何改变解耦的必要性【必答 a】

### feedback §0 的解耦是机械保护
自动优化器单尺度、机械、不能自归因:只认一个 score,掉就调参。score 耦合 pattern+交易 ⟹ 无法分辨该改哪层 ⟹ 优化失去方向。所以那里的解耦是**必须**的(防崩)。

### 人工场景:人会混淆吗?
人看 K 线能同时持有"方向对不对"与"能赚多少"两个视角而不混淆——这是人与自动优化器的本质差别。所以 feedback §0 那种"机械防错向"动机**大幅减弱**。

但解耦在人工场景**仍有价值**,价值换了一层:

| 维度 | feedback §0(自动 score) | web UI 人工分析 |
|---|---|---|
| 解耦动机 | 防止优化器机械错向(崩) | 让人能独立归因(清晰) |
| 紧迫性 | 必须,否则优化无方向 | 有益,否则归因能力受损 |
| 受益对象 | 优化循环(pattern 能独立迭代) | 人(能区分选股贡献 vs 交易贡献) |

### 裁定
用户确认"人工场景也希望解耦"——**合理,但理由不是 feedback 的理由**。人工分析的核心动作是**归因**,归因的前提是"选股效果"和"交易效果"作为**两个独立维度**分别给出。合并成综合指标 ⟹ 归因能力丢失(哪怕人不会机械错向,也会因信息被压缩而**无法定位问题层**)。必要性从"机械必须"降为"认知必须",但仍然"必须"。

## 2. 两 label 职责分工 + 精确分界线【必答 b】

### 职责定义

| label | 回答的决策问题 | 维度身份 | 是否含交易参数 |
|---|---|---|---|
| **方向性 label**(正负对称) | "选股对未来**方向**有没有预测力?" | **诊断指标**(diagnostic) | 否,纯统计 |
| **模拟交易 label**(非对称变现) | "选股**配上我的交易规则**,能变现多少?" | **实战指标**(operational) | 是,联合体利润 |

共享同一输入(买点),解耦在**解读层**(各自回答独立问题),不在输入层。

### 精确分界线:可调交易参数(回应 directional)

"选股评估"与"交易评估"的分界线 = **是否引入可调交易参数(止损 / 止盈 / 择时规则)**。

- **选股评估层**:只依赖"信号发出时刻 + 之后价格路径";horizon 是**全局固定口径**(所有 match 同一个 N),不引入 per-pattern 可调交易参数。
- **交易评估层**:引入可调交易参数(止损止盈),结果随交易规则变化。
- **端点收益 / 方向 label**:horizon 固定、无干预 ⟹ 无可调交易参数 ⟹ **选股侧**。
- **mfr**:无干预(只量上行天花板)⟹ 无可调交易参数 ⟹ **选股侧**。
- **sim(strategy_return)**:有可调止损止盈 ⟹ **交易侧**。

**为什么是"可调"而非"任何交易假设"**:端点收益隐含"被动持有 N 日",严格说也是一种交易规则,但 horizon 全局固定、不可 per-pattern 调,不会诱发"搜交易参数"的优化错向。feedback §0 反对的是**可调交易参数耦合**进评估(诱发参数搜索),不是反对任何持有假设。固定 horizon 的被动持有属中性口径——但它仍是"一种交易规则(持有到期)的结果",这点要知道,不是完全无假设。

**horizon 的元口径身份(精度澄清,v5 采纳 skeptic 终审)**:horizon 不是交易参数——它是**所有 label(mfr/min_low/端点收益/sim)共享的全局元口径**,横跨选股与交易两层、**不破坏层边界**(别因「扫参禁令适用于它」就误归交易层)。「扫 horizon 选最优 label」被禁,是因为**前瞻偏差原理参数无关**(skeptic H10 泛化:参数选择程序不得在样本上对 label argmax,适用于任何 label 所依赖的参数,交易参数 + horizon 都在内),不是因为它属交易层。用法区分:报 horizon 敏感性(配基线,如 feedback b 项 ρ_null)= 合法诊断;据结果 argmax 选 horizon 当口径 = 禁。与项目已有铁律(label_horizon 全局单值、eval_meta head_buffer 取 max)方向一致,是已有原则的显式化、非新约束。

**更深的本质:决策的有无,而非是否持有(回应 directional,裁定无分歧)。** 交易层的本质是"基于价格路径**做决策**"(止损/止盈触发),固定 horizon 持有是"**不做决策**、到固定时间点看价格"。mfr 也"持有"(看窗口内 max),从不被视为交易层。端点收益的"持有 N 日"与 mfr 同性质——是评估的时间框架,不是交易。⟹ directional 的"N 是评估窗口不是交易策略"论证成立,端点收益判入选股侧,双方无分歧。

### 2×2 正交归因(解耦的真正红利)

两个维度正交,作为独立维度分别给出,人才能做下面这种归因:

| | sim 好 | sim 差 |
|---|---|---|
| **方向性好** | 选股有 alpha 且交易规则兑现了它(理想) | 选股有 alpha,交易规则在浪费它 → **改交易规则,别动选股** |
| **方向性差** | 交易规则在弥补选股不足,或纯波动率红利(警惕:别误记成选股功劳) | 选股无 alpha,交易规则也救不了 → **放弃** |

四个象限各指向**不同后续动作**。合成综合分 ⟹ 四种区分全部消失。**这是用户要解耦的务实理由。**

**⚠ 方向轴的可靠性边界(吸收 skeptic 批判):** 2×2 是**概念归因框架,不是定量工具**。"方向性好/差"这一轴若用端点收益量,有两个污染——(i) 单 match 实现值方差随 σ 放大,排序顶部仍是高波动股("期望中性"只在集合期望成立、个案不成立);(ii) 单 match 端点收益混市场漂移。⟹ **方向轴不是可靠定量轴**。建议:**集合级**用首次穿越比例(feedback c 项口径,干净)定方向轴读数;**个案级**用肉眼读 K 线 + 端点收益(辅助,带折扣读)。别让读者把 2×2 的方向轴当成可定量比较的轴。

### 深化:用户说的「交易策略评估」不在单个 label 里

直觉陷阱:把 sim 直接当「交易策略评估」。但 sim 评的是**选股+交易联合体**利润,同时混着选股贡献与交易贡献,**无法单独读出交易策略好坏**。

真正的「交易策略评估」= sim 中**无法被方向性 label 解释的部分**:
- 方向性强 + sim 弱 ⟹ 交易规则摧毁价值(边际贡献负)。
- 方向性弱 + sim 强 ⟹ 交易规则创造价值(边际贡献正,但很可能波动率红利,见 §6)。

量纲上不可直接相减,**这是定性的概念归因,不是可定量计算的数值减法**(吸收 skeptic)。但它揭示:**「交易策略评估」必须在两个 label 联合解读中完成,不存在独立的"纯交易 label"**。把 sim 单独当"交易评估"= 把联合体利润错记成交易功劳。

**调和 payoff §6.3/§6.5 的措辞矛盾(skeptic 与 payoff 共提):** "方向差也能赚"与"方向不对一定不赚"的区别在"赚"的定义——方向差 → sim 显示正数**可能**(波动率红利),但那是警报(见 §6),不是真赚;方向差 → **真实方向 alpha 的利润不可能**(这才是"方向不对一定不赚")。本 draft 的"方向差 → 警报"表述站得住:"警报"≠"sim 一定为负",而是"sim 若为正,那也是虚假的"。已请 payoff 修订时把"赚"拆成"sim 正数(可能虚假)"vs"真实 alpha(方向差则无)"。

**且与 payoff 对齐:directional 对 sim 既非必要也非充分**——方向差+sim 正(波动率红利)= 非必要,方向好+sim 差(交易浪费)= 非充分(正对应 §2 2×2 四象限)。"directional 是真实 alpha 利润的必要条件"只是定义性同义反复,不用来约束 sim 的好坏。本 draft 不在表述上暗含"方向性是 sim 的必要条件"。

### 裁定
两 label **各自必要、职责不重叠、天然解耦**,前提是并列呈现且可配对解读,而非二选一。

## 3. 端到端类比的归属【必答 c】

用户原话:"端到端训练一个由两个模型(选股+交易)组成的神经网络,输出是利润。"

- **形式上归属 sim**:联合体 + 输出利润 + 两者一起决定效果,全部对应 sim。方向 label 只评选股单模型,谈不上"两个模型组网"。
- **它暗示的耦合是想要的**:端到端训练本质是联合优化(梯度从利润反传,选股为交易服务),这是想要的耦合,且**与 feedback §0 不冲突**——§0 管"怎么优化选股 pattern",端到端管"怎么评估最终变现效果"。「评估变现」让两模型联合,「优化选股」让选股独立,两者并行不悖。
- **必须澄清的边界**:类比是**训练**语境(梯度反传),web UI 是**评估**语境(不训练、只看)。类比的形式(联合评估)适用 sim,但它的**优化含义**(梯度回流选股)在人工场景**没有对应物**——人不做梯度反传,选股改进由人看两 label 对比手动完成。**写进 final_report**:避免误以为"端到端"= web UI 自动反向优化选股。

## 4. web UI 呈现建议 + payoff 的视觉隔离【必答 d + skeptic ★】

### 核心裁定:sim 不应作为"与 mfr 同级的 label"参与选股排名

这是对 skeptic ★ 与 payoff §3.3"信息 vs 目标"的统一回答。

payoff 的"信息 vs 目标"区分概念上正确:人类**可以**把 sim 当信息(反事实投影)而非目标(挑 sim 高的 pattern)。但 skeptic 的担忧实在——**人类会本能把"可排序的列"当目标**。视觉上的"可排序 + 等权重"强烈暗示"这是目标"。光有概念边界不够,须有 UI 闸门。

### 落地原则

1. **并列而非合并**:选股评估指标(mfr / 方向 / min_low)与 sim 分列,**绝不合成综合分**(综合分会抹掉 §2 的 2×2 归因)。
2. **语义标注一眼可读**:sim 列明确标「交易联合利润 · 选股+当前交易规则 · 非选股评估」;选股层指标标「方向预测力 · 与交易规则无关」。
3. **默认排序键不是 sim**:match 主排名依据 = 选股评估指标(方向 / mfr),**sim 不作默认排序键**。用户可**主动**按 sim 排序(信息用途),但默认不诱导。
4. **无"按 sim 综合打分选 pattern"入口**:堵掉"目标"用法,只留"信息"用法。这是把 payoff 的"不正当用途"(用 sim 给 pattern 排名)在 UI 层物理阻断。
5. **sim 的交易参数显式可调,且只联动 sim**:改止损止盈只重算 sim、不影响选股评估指标——这条交互不变式就是"解耦"在 UI 层的可操作定义。一旦改交易参数会带动方向数字跳,解耦就破了。**已确认代码天然保证**:`match_forward_returns`(eval.py)签名只接 `(match, end_node, df, horizons)`,不接止损止盈 ⟹ directional/mfr 数值物理上不随交易参数变。"参数只联动 sim"几乎免费地成立,UI 层只需守住"默认排序键不是 sim"。
6. **mfr 降级为"上行天花板披露项"**(见 §7):保留但非主决策依据。

### 原 plan 定位的修订

原 plan 把 strategy_return 当"与 mfr 同级的 label"——**这个定位要改**。同级 label 在 UI 等权重,会诱导用户拿 sim 排名选股、据此调 dag(= feedback §0 的耦合错误从自动 score 搬到人工 UI)。修订:sim 是**独立交易层 readout**,视觉隔离,不进选股主排名,可按需排序(信息),无综合分入口。

### 2×2 散点(可选增强,非必须)
以方向性为 x、sim 为 y,每个买点/配置一个点。**MVP = 第 1、2 条(分列 + 语义标注);散点是锦上添花**,买点量大、需看整体分布时才显价值,不作为 v1 硬性要求——避免 over-engineering。

## 5. 与 feedback §0 的异同

### 同(精神一致)
- **选股评估绝不含交易参数**:方向 label 与 §0 的 score 一样,只依赖"信号时刻 + 之后价格路径",不含持仓/止损/止盈决策。
- **交易层是独立的一层,该存在但不进选股评估**:§0"止损止盈期望值完全移出(到交易层)"——"移出"≠"删除"。web UI 里 sim 就是那个被移出的交易层,以独立 readout 呈现。
- **基线对照(bo_only)在选股层依然适用**:方向 label 应相对 bo_only 扣掉突破本身的贡献。

### 异(场景不同)
| | feedback §0 | web UI 人工场景 |
|---|---|---|
| 交易层去向 | 完全移出 score(自动优化不需要它) | **保留为独立 readout**(人需要看它) |
| "移出"的体现 | 不进 score 数字 | 不混入选股评估指标,作并列独立维度 |
| 解耦动机 | 防止自动优化机械错向 | 让人能独立归因 |

一句话:§0 把交易层移出 score 是因为"自动优化不该背交易的锅";web UI 把交易层做成独立 readout 是因为"人需要单独看交易的锅有多大"。**方向一致(选股不含交易参数),落地不同(人工场景交易层以独立 readout 存在,而非消失)。**

## 6. 警示:sim 的"虚假 alpha"陷阱

sim 的"非对称"(止损截断跌、逐利涨)可能**制造虚假 alpha**:

- feedback §0 已证:**`bo_only` 的 +72% lift 控制波动率后完全归零**(A.1);命中集波动率是全宇宙 1.83–2.13 倍,主体是先在属性。
- feedback §0 的 c 项已证:**现有 pattern 方向无优势**——先涨比例并不高于随机日。
- 合起来:一个方向无优势、纯靠高波动率的策略,套上"止损截断回撤 + 逐利 max-price"非对称规则后,sim 完全可能显示正期望——**但这个正期望纯来自波动率红利,不是方向 alpha**。

**裁定:sim 绝不能单独下"选股有 alpha"的结论**,必须与方向 label 配对解读(对应 §2 的 2×2 左上象限警惕)。两个 label 都在场,才识破 sim 单独制造的假象——这也反过来说明 mfr(只看涨)与 sim(逐利)都不足以单独评估选股,须有方向 label 制衡。

**解耦的纯洁性原则(吸收 payoff):每个 label 忠于自己语义,不在内部修正对方维度的问题。** 给 sim 加"波动率惩罚项"会把选股评估(σ归一)反向塞进交易层 label = 再次耦合(feedback §0 同病,只是方向反过来)。sim 的职责是**诚实报告联合体利润**(含波动率红利是它的诚实);directional 的职责是**路径无关的方向位移披露**——**非 σ 中性**(directional v3 已撤回:per-match 实现值方差仍被 σ 支配,directional 只去掉了 mfr 的选择偏差、并未消除方差对单 match 的支配)。各自信实,虚假 alpha 不能在任何单数内部"修掉"。**识破 sim 的虚假 alpha = 三层(skeptic H8 / payoff §6.7),不是「靠 directional 共读」一句**:① per-match 共读(directional+sim)识破肉眼可见的背离——**必要但不充分**(per-match 层两 label 都带 σ 噪声);② **集合级统计闸才是主力**(命中集波动率倍数 / 控 σ 后 sim 条件百分位 / 首次穿越方向检验,归选股评估层,复用 feedback c/g 体检口径);③ UI 标注 sim 的波动率暴露(诚实披露)。三层各司其职——共读是 web UI 自带、统计闸属选股评估层、UI 标注是 sim 面板的披露;**payoff 不内置统计闸**(在内部做选股层归因 = 再次耦合,与「给 payoff 加波动率惩罚项」同病)。

**统计闸的归属(payoff 裁定,解耦审计认可 = 上一原则的直接推论):集合级统计闸(波动率倍数 / 控 σ 后 sim 百分位 / 首次穿越)归选股评估层**,复用 feedback §0 体检口径,不进 payoff 内部。理由:它们检验的是"pattern 是否在 surf 波动率",是**选股维度的诊断**;payoff 内置它们就是在内部做选股层归因 = 再次耦合(与"给 payoff 加波动率惩罚项"同病)。payoff 只在 UI **标注**波动率暴露(事实披露:"命中集波动率是全宇宙 X 倍",让用户警惕 sim 可能含红利),**不做统计闸**。关键区分:**标注(披露)payoff 可做,统计闸(诊断)归选股层**——标注是诚实报告的一部分,诊断是选股评估层的事。

## 7. mfr 的去留裁定【回应 skeptic 3】

**保留。** 理由:

- **§0 已为 mfr 背书**(median 增量 + 顺序闸 + 因果闸都基于 max_high)。替换 mfr 要重做整条 score 链,成本高且动已定案的东西。

- **mfr 的"只看涨"缺陷,用 min_low 伴随量补**(让 per-match 方向诚实),而不是替换。

裁定:**mfr 保留,补而非换**。与 directional(选股评估层)、skeptic(保留)共识。

## 8. 方向性 label:最小实现 vs 完整框架【回应 skeptic 1】

skeptic 问:完整的"方向性 label 框架"是否必要,还是 min_low 伴随量就够?

裁定:

- **解耦层面中立**:只要一个量"无交易参数 + 正负对称 + 服务方向判断",就归选股评估层,满足解耦。min_low 伴随量与端点收益都满足。
- **奥卡姆层面倾向 skeptic 的 min_low 伴随量作最小起步**:它与现有 mfr 同构(只需加 `min(low)/close-1`),零框架成本,且直接修 mfr"只看涨"的诚实性缺陷。这是"让 mfr 在 per-match 层方向诚实"的最廉价路径。
- **但端点收益(directional)不是 min_low 的冗余,而是回答不同问题**:min_low+mfr = 上下行极值幅度(路径天花板/地板);端点收益 = 终点净方向。度量维度不同。
- **最小集建议**:`mfr`(上行天花板,保留)+ `min_low`(下行地板,补诚实)+ `sim`(交易层独立 readout)。端点收益作为"净方向"的可选增强,在 min_low 不足以回答方向问题时再加。
- **min_low 的精确定义(directional 给出,解耦审计认可)**:`min_forward_drawdown = mean over 买点窗 t of [ min(low[t+1..t+N]) / close[t] - 1 ]`,即 `path2/eval.py:39` 的 mfr 把 `high.max()` 换成 `low.min()`,买点窗逐点均值、t+N 越界跳过,与 mfr 完全同构、零框架成本。无可调交易参数 ⟹ 选股侧(符合 §2 分界线)。与 mfr 两列独立并列(不合成,像 OHLC 极值切片)。
- **v1 实施粒度(directional + decoupling 共识)**:**先只上 min_low**,端点收益作可选增强不上 v1。理由:min_low 已满足"正负对称披露"的诚实性目标(下行可见,不被 mfr 只看涨粉饰);端点收益的"净终点方向"语义是锦上添花,YAGNI——等用户实际需要"最终涨跌"度量时再加。

诚实警示给 directional:端点收益若与 mfr 并列,必须明确"mfr=天花板、端点收益=净终点",否则会被当冗余;且端点收益隐含"持有 N 日"假设(horizon 固定、中性,但要知其在,见 §2 分界线)。

## 9. 选股层能诚实表达的有限(诚实项,呼应 skeptic)

feedback 已证:现有 pattern 方向无优势(c 项)、控制波动率后 bo_only +72% lift 归零(A.1)、label R²=0.92≈波动率。即"选股评估层"诚实表达的,很可能是"本 pattern 在方向上无优势、收益靠波动率"。

但这**不是不做方向 label 的理由**——正相反:正因为有限,更需要诚实的方向 label 让"无优势"可见。mfr 只看涨会把"无方向优势"粉饰成"+72% 涨幅";方向 label / min_low 让真相暴露。**解耦的价值之一,就是不让交易层或波动率粉饰选股层的真相。** 诚实地显示"没有",比漂亮地显示"有(但其实是波动率)"更有用。

## 附:核心结论速览(供 leader)

1. **精确分界线**:选股评估 vs 交易评估 = 是否引入**可调交易参数**。方向 label/mfr 无可调参数→选股侧;sim 有可调止损止盈→交易侧。端点收益"持有 N 日"是中性固定口径,仍属选股侧。
2. **解耦动机随场景换层**:从"机械必须(防优化崩)"降为"认知必须(让人能归因)",但仍必须。
3. **两 label 职责正交**:方向=诊断(选股有无方向 alpha)、sim=实战(联合体能变现多少);天然解耦,前提是并列呈现可配对解读。"交易策略评估"在两者联合解读中,不在单个 label 里。
4. **sim 的 UI 视觉隔离(skeptic ★)**:不进默认选股排名、独立 readout 面板、明确标注"交易联合利润·非选股评估"、可按需排序(信息)、无"按 sim 选 pattern"入口、参数只联动 sim。**原 plan"同级 label"定位要改。**
5. **端到端类比**:归 sim 的"评估端",人工场景无"训练端"对应物,选股改进仍由人完成。
6. **mfr 保留**(§0 背书 + 波动率读数诊断价值),**补而非换**(min_low 补方向诚实)。
7. **方向 label 最小起步 = min_low 伴随量**(奥卡姆,与 mfr 同构、修只看涨缺陷);端点收益是可选净方向增强,非冗余但优先级靠后。
8. **最重要警示**:sim 单独可造虚假 alpha(波动率红利),必须与方向 label 配对解读——这是解耦的终极价值与警示。
9. **诚实项**:选股层诚实表达有限(pattern 方向无优势),但正因此更需方向 label 让"无优势"可见,不被 mfr/波动率粉饰。
