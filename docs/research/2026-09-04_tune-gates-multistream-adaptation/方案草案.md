## 二、根因判断（草案主张，可被推翻）

引擎 `path2/dag/engine.py:run_streams` 的物化键是 **一次 detect 调用** = `(id(detector), consumes_stream)`，
用 `run_bundle()` 一次取回整包流，再按 `produces_stream` 分给同组兄弟 node，各自用自己的 node_id 标注。

tune-gates 反转循环 `multivar_core.py:300-315` 自己重写了这套阶段-1，但物化单位是 **node**：
缓存键 `(nid, 影响维取值)`，且调的是单流 `run()`。

多流 detector 的定义就是"一个 detector 实例被 ≥2 个 node 认领"，于是撞上工具当年为
`down`/`side` 共享 `TrendSegmentDetector` 立的拒绝闸。

**闸拦错了对象**：它用 `id(detector)` 去重这个过粗判据，去表达一个更窄的禁令。
- 别名场景（两 node 拿**同一条**流）：引擎折叠标注，第二个 node 的事件带的是第一个 node 的 node_id，
  反转循环复刻不了 → 该禁。
- 多流场景（两 node 拿**不同**流）：两条流各自独立列表、各自标注，引擎与反转循环本可对齐 → 不该禁。

## 四、修改方案（草案）

### 4.1 核心：把工具的产流单位从 node 换成「detect 调用」

```python
siblings = {}
for n in spec0.nodes:
    if n.detector is not None:
        siblings.setdefault((id(n.detector), n.consumes_stream), []).append(n)
infl_group = {k: tuple(sorted(set().union(*(infl[s.node_id] for s in g))))
              for k, g in siblings.items()}

for nid in order:
    node = by_id[nid]
    if node.detector is None or nid in streams:      # 已被兄弟那趟填好
        continue
    gkey = (id(node.detector), node.consumes_stream)
    ckey = (gkey, tuple(combo[d] for d in infl_group[gkey]))
    if ckey not in stream_cache:
        src = (win,) if node.consumes_stream is None else (streams[node.consumes_stream], win)
        bundle = run_bundle(node.detector, *src)
        got = {}
        for sib in siblings[gkey]:
            got[sib.node_id] = bundle[sib.produces_stream]
            annotate_stream(counts, sib.node_id, got[sib.node_id], children_of)
        stream_cache[ckey] = got
    streams.update(stream_cache[ckey])
```

三个要点：① 缓存值必须是整组 `{nid: events}`；② 每个 detect 调用只跑一次；
③ `annotate_stream` 只在缓存未命中时调一次，跨 combo 复用已标注事件。

### 4.2 两道闸：从禁「共享 detector」改为禁「共享同一条流」

判据从 `id(detector)` 去重换成 `(id(detector), consumes_stream, produces_stream)` 去重。
多流兄弟放行；同流别名继续拒绝（错误信息换语义）。

### 4.3 `compare_longtable.py:144`：`fixed` 的推导改成按物化组比较

从 `detector_nodes[d] == [first]` 改成 `set(detector_nodes[d])` 恰好等于 `first` 所在物化组的 node 集合。

### 4.4 F 维判据：本轮**不放宽**，只把降级理由记进 `classification.json`

理由：今天没有任何多流 detector 声明 `filter_params`，放宽等于为零消费者写代码（奥卡姆）。

### 4.5 可选但推荐：把分组抽成引擎的纯函数

在 `path2/dag/engine.py` 把 4 行分组抽成 `stream_groups(nodes)`，`run_streams` 与工具共用。
零行为变化，消灭「工具猜引擎物化键」这一类漂移。
