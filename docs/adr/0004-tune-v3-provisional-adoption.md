# v3 允许证据不足但看起来改善的候选暂用，并安排复核

2026-10-01 用户明确选择：最后独立验证中，新参数看起来改善，但证据尚不足以确认是真实改善时，允许暂用新参数，之后复核。这一选择为了尽早利用可能的改善，接受暂用结果可能来自偶然高分的风险；暂用状态不能表述为已证明改善。

最后检查的结局是暂用或不采用；复核沿用最后检查的同一条规则，通过为继续使用，否则撤回。暂用限于预先规定的要求仍满足、排名分高过原参数的候选；允许暂用不绕过这些要求。训练阶段仍固定一个候选及采用规则，打开最后验证数据后不更换候选、调整评分或另试第二名。即使结果只支持暂用，这份验证数据也已经被使用。

暂用前固定后续复核的数据与时机。复核使用后来积累且未参与选择的新数据，到期按同一规则检查一次，不延长观察、不反复查看。保存改前参数、暂用参数及证据状态，使撤回有明确依据。继续使用表示两次独立观察都改善，不是统计确认。

暂用后的复核不自动创建定时任务，需要运行 skill 时按任务范围安排执行。

实施入口：`.agents/skills/tune-gates-v3/SKILL.md`。已完成合成数据下的行为验证，未据此宣称真实市场效果或优于旧版。
