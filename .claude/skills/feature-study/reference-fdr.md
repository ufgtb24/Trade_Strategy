# 批量特征筛选的 p 与 BH-FDR 操作卡

电池关 1（原始显著性 + 同族 BH-FDR）的执行细节。单特征深究用不到本卡；批量候选筛必读。

## p 怎么算（每特征一个）

```python
from scipy.stats import mannwhitneyu
U, p = mannwhitneyu(坏样本特征值, 好样本特征值, alternative="greater")  # 单侧
AUC = U / (n * m)
```

- `alternative` 由方向假设决定；方向假设**在动数据前写死**——看了数据再挑方向 = p 再砍半，隐性多试一次。
- **AUC 与 p 必须并报**：AUC 是效应量（多强），p 是可信度（多不像随机）。p 由 (AUC, n, m) 联合决定——同一个 AUC，样本越多 p 越小；只报 p 会把大样本下的芝麻效应当宝贝，只报 AUC 会在小样本下收进运气冲高。
- 样本极端少或并列很多时，用置换检验代替解析 p：把特征与 label 的配对随机重洗 N 次（N≥5000），数 ≥ 实测 AUC 的比例。
- z 的手工核对：z = (U − nm/2) / √(nm(n+m+1)/12)。

## BH-FDR 四步（q=0.05）

1. m 个 p 从小到大排序 p(1)…p(m)；
2. 第 i 名门槛 = (i/m)·q；
3. 找**最大的** i 使 p(i) ≤ 门槛；
4. 宣布前 i 个（过关者把前面的全带上）。

**意义直译**：判定等价于 m·p(i) ≤ i·q——左边 = 全噪声世界期望混入个数（p 均匀撒，落在 [0, p(i)] 期望 m·p(i) 个），右边 = 按 q 比例这 i 个里容许的假货数。即在每个切割点问「假如全是假的，混入速度是否超过 5% 配额」，取承诺仍成立的最慷慨切割。

**关键性质**：门槛自适应真信号密度——真信号越多（前排名次被顶满），i 越大门槛越宽；全噪声时与 Bonferroni 同严（m=10 时第 1 名门槛同为 0.005）。

## m 与门槛速查

| 特征数 m | 第 1 名门槛 | 期望假阳性 (m·q) |
|---|---|---|
| 1 | 0.05（=裸检验，BH 自动退化） | 0.05 |
| 3 | 0.017 | 0.15 |
| 5 | 0.010 | 0.25 |
| 10 | 0.005 | 0.50 |

## 数字例（m=10）

p 排序：0.001, 0.008, 0.012, **0.028**, 0.040, 0.11, …
i=3：0.012 ≤ 0.015 ✓；i=4：0.028 > 0.020 ✗ → 宣布前 3。
注意 0.028 单看 <0.05 达标、批量下出局——**同一 p 的命运取决于 m**（换算：m·p = 0.28 个期望混入 > 容许 4×0.05=0.2）。
