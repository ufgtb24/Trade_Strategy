# tune-pattern-strength:pattern 全局调参

## Overview

把「让 pattern 更强」固化为:建对照 → 定判据 → 消融找瓶颈 → 坐标扫描确认平台 → 诚实性检验 → 多窗口复核 → 定案。

**核心原则:没有对照的"更强"是幻觉。** 绝对 label 会把市场平移当成绩;唯一有意义的量是相对平凡对照的 lift。

本目录自带两个已实测的脚本,**用它们,不要重写评估代码**:
- `eval_skeleton.py` — 评估管线(双端缓冲切窗 / 按买点窗去重 / 双 label 列 / 自检门)
- `sweep.py` — 扫描 + score 排序 + 多窗口最差分排序

## 与 authoring-path2-app 的分工

`authoring-path2-app` 的 Step 0 入口分诊第三路(**纯调参**:只动阈值数值、不碰结构)
短路到的就是本 skill。反向也成立:**若发现需要改的是结构**(节点集/边集/detector 选型),
停下回 `authoring-path2-app` 走三层 gate,别在参数空间里硬凑。

判断信号:单因子消融里没有任何旋钮能过硬门、或最优点仍远低于对照 ⟹ 大概率是结构问题。

**逻辑改造也不在本 skill 内**。本 skill 只搜参数;逻辑改动仅作为**诊断**出现在
诚实性检验的极限测试里(把某道判据关掉看 score 动不动),用来判断它值不值钱,
不作为候选方案实施。要真改判据逻辑,回 `authoring-path2-app` 层②。

## 三道强制关卡

**任何搜索开始之前**,这三关必须先过。跳过其中任何一关,后面所有数字都不可信。

### 关卡 1 · 先建平凡对照,先问"现状到底有没有优势"

对照 = **同上游参数、去掉待评估的那几层过滤**的退化版 app(如 bottom_burst 的对照是 bo_only)。
对照必须**逐窗重算**(市场本身在不同时间窗有平移,2024 与 2025 的基线差 0.0075)。

先把现状与对照并排跑一次。若现状 lift ≤ 0,如实说出来——这改变任务性质:
不是"保住质量的同时加量",而是"先做到能测出有无优势,再看优势是否存在"。

**别拿绝对指标当成绩**:高胜率往往是基率复读。20 日 max-high 口径下随机买点胜率就有 93.6%,
所以"胜率 94.7%"什么都没证明。任何绝对量都要先问"对照是多少"。

### 关卡 2 · 找出能被参数操纵的量,并列对照列

label 常依赖某个由参数决定的区间(如 tb 的买点窗宽由 phase2 收窗规则定)。
缩窗就能在窗数不变的情况下白拿一截 label——这是刷分,不是变强。

堵法两步:① 搜索期间**冻结**决定该区间的那一段,只动筛选段;
② 每个配置**并报**一个区间无关的 label 列(如"只取买点窗第一天")。排序一律用后者。

若两列排序不一致,以区间无关列为准,并在报告中点名该配置的窗宽假象。

### 关卡 3 · 硬门取 n ≥ n₀,不是 n ≥ 30

n=30 是统计学惯例,不是这个问题的答案:此时中位数抽样 SE≈0.037,
能认出的最小 lift 要 +0.074(基线的 60%)。硬门取在收缩权重 w=0.5 处(即 n=n₀),
含义是「能进排序的配置至少一半信得过自己的观测值」。

## 判据(写死,不现场发明)

```
score = w · (median_配置 − median_对照)
w     = n / (n + n₀)          n₀ = 200(沿用 BreakoutStrategy/mining/pipeline.py)
n     = 买点窗数(按 end_node event_id 去重)
median= 区间无关口径的 label 中位数
硬门  = n ≥ n₀  且  q25 ≥ 0
```

- **用 median 不用 mean**:mean 被尾部极值主导。
- **q25 ≥ 0** 挡住"抬中位数、养亏损尾巴"的配置。
- **收缩而非硬切**:n 越大越拿得住自己的观测值,不设悬崖。
- 全放开退化成对照时 lift 恒为 0 ⟹ 摆烂刷不到分。

## 流程

1. **搭管线 + 自检**。复制 `eval_skeleton.py`,填 app 名/窗口/对照。
   自检门 = 与已有 web 扫描结果对齐(命中数与中位数量级一致,差异要能被口径解释干净)。
   **自检不过不进搜索**——索引错位时所有统计静默全错。
2. **过三道关卡**(见上)。
3. **单因子消融**:每个旋钮各动一次,看谁能撬动局面。通常只有 1-2 个能过硬门。
4. **坐标扫描**:以最优点为中心逐维扫描。要确认落在**平台**上(邻域 score 接近)
   而非尖峰——这是抗过拟合最实在的证据。副产品是识别 non-binding 参数
   (改它结果逐字不变 ⟹ 该约束根本没在起作用,报告里要写出来)。
5. **诚实性三检查**(见下)。
6. **多窗口复核**:至少两个不相交时间窗各跑一次,按**两年最差 score** 排序。
   默认开启;要关必须显式说明理由。
7. **误伤审查**(定案前最后一关):用 `path2_web.eval_runner.run_regress` 对拍改前 baseline。
   ```python
   from path2_web.eval_runner import run_eval, run_regress
   run_eval(module_path="path2_apps.<app>", start=..., end=...,
            out_path="outputs/path2_eval/<app>_baseline.json")          # 改参数之前先存
   r = run_regress(baseline_path="outputs/path2_eval/<app>_baseline.json",
                   param_overrides=定案配置)                              # 候选侧参数
   ```
   按 (symbol, buy_date) 对拍,`removed` 行带**改前收益**。DIFF≠0 不一律算回归。

   **判读要对比 added 与 removed 的分布,别只看 removed 的最高值**——放宽型改动几乎
   必然丢掉几个原有的大牛股,单看"丢了一个 ret20=1.05"会误判成回归。正确读法:
   两侧的 n / median / 高收益票数量并排看。实测例:removed 39 个(med 0.108,>0.5 的 4 个)
   vs added 421 个(med 0.231,>0.5 的 114 个)⟹ 误伤真实但被压倒性淹没。

   **必看 `unchanged_count`**:它是"新旧配置的交集"。unchanged 极小(实测这次 = **2**,
   旧配置 41 个买点窗只留下 2 个)意味着这不是"原 pattern 的增强版"而是**几乎换了一批
   买点**。这不否定 score 的结论(对照与口径都同),但改变结论的措辞——报告里必须写成
   "换成了一个不同且更好的配置",不能写成"改进了原策略"。
8. **定案 + 端到端复现**:差异小于抽样误差时按奥卡姆取改动更少的。
   改完配置后**重跑一次**确认数字逐字复现(防止改的地方和跑的地方不是同一处),
   并跑回归测试。

## 诚实性三检查(每轮必做)

| 检查 | 做法 | 这次实测到的 |
|---|---|---|
| **极限测试** | 把某道判据完全关掉,看 score 动不动 | "完全不要求止跌信号"只差 1% ⟹ 该判据是装饰品 |
| **前瞻偏差** | 逐字段问"这个量在买点当天是否已知" | `outcome` 能把 score 推到 0.087,但它是买点之后才定的 ⟹ 不可用 |
| **算术效应** | lift 里有多少不是"选得更准"而是别的 | 一部分来自"买得更低"(对照买在突破日高位) ⟹ 是入场时机不是选股能力 |

## 常见坑

| 坑 | 现实 |
|---|---|
| 直接优化绝对 median | 把市场平移当成绩;必须减对照 |
| 用胜率证明质量 | 该 label 口径下基率就有 93.6% |
| 硬门取 n≥30 | 中位数都算不稳;取 n≥n₀ |
| 只看窗均值 label | 缩窗可白拿分;必须并报区间无关列 |
| 相关字段拿来当筛选条件 | 先问它在买点当天是否已知(前瞻偏差) |
| 只跑一个时间窗 | 现状在 2024/2025 之间符号翻转过;多窗口是唯一的稳健性证据 |
| 采纳未做 label 验证的历史建议 | 稀缺信号池那条建议使 score 从 0.072 崩到 0.015 |
| 改完配置不重跑 | 改的地方与跑的地方可能不是同一处(yaml SSoT vs dataclass default) |

## 归档

按 write-user-doc 规范落 `docs/research/<日期>_<slug>/final_report.md`,结构:
TL;DR(改动表 + 前后对照表)→ 判据怎么定的 → 根因 → 消融证据 → 定案与多窗口验证
→ 诚实性发现 → 局限 → 复现方式。

**局限必须逐条写**:label 口径上偏、搜索了 N 个配置的选择偏差(用平台证据缓解)、
复核窗也不是真样本外、观测非独立、未探索的自由度。
