# v3 按买点日评价，机会数量只作下限

2026-10-01 在设计访谈中确定：本次 v3 面向每个符合条件的股票与买点日都允许等额新增买入的场景，连续几天符合条件可以连续买入，资金不限制这项评价。在此假设下，买入机会按“股票＋交易日”去重计数，同一股票同一天被多个事件或走势组合重复找到只计一次；同一事件持续多个买点日则有多个机会。事件数量不能代替机会数量。

上涨空间逐买点日计算前瞻收益，再对这些买点日的结果取中位数；方向表现逐买点日计算首次穿越并按统一规则汇总。沿用前瞻收益与首次穿越在 `path2/CONTEXT.md` 中的定义，随机日基线和原参数采用相同的按日统计方式。未触线、同日触及两线及后续数据不足的处理必须预先固定并单独报告；可识别的机会数量与实际能完成表现评估的数量分开记录。每个事件内部先取平均、再让事件等权的方式，不作为本次 v3 的主要评价。

业务目标是在机会数量达到下限、方向表现符合要求的前提下，提高典型买点日的上涨空间。数量达到下限后不因更多机会额外加分，也不直接将数量乘进空间成绩。机会下限须在相同股票范围与时间长度下定义，并在比较候选之前固定；具体确定方式由实现者研究和验证，不要求用户指定数值。机会下限与证据是否足够是两项要求，不能相互替代。

这一选择使评价对应实际允许执行的逐日买入，同时允许筛掉质量较低的机会，只要仍满足数量下限。代价是持续较长的事件会贡献更多买点日、对整体成绩产生更大影响；同一股票与相近日期的表现可能高度相关。判断可信程度时仍考虑股票和时间上的关联，不能把所有买点日当成独立证据，也不通过把每个事件改成等权来消除这些实际买入机会。事件信息保留用于追溯、复用计算及分析关联。

前瞻收益是上涨潜力，本次目标不等同于最大化实盘累计利润；实际利润另需明确卖出规则与交易成本。本决策也不承诺 v3 已优于现有方法。
