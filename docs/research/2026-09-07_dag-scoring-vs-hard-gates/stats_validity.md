# 打分制的统计合理性

**日期**：2026-09-07 · **角色**：`stats`（agent team 统计路）
**问题**：`path2_apps/bb_v1` 的 burst node 挂着 4 道硬 where 闸（`first_drought` / `distinct_pk` / `vol_spike` / `peak_age`），全 AND。用户想改成打分制（加权求和过总阈值），让单项特别优秀的样本不被其他项拖死。这个思路的**统计前提**成不成立？

---

## 结论先行

**可补偿性不成立**——而且用户举的那个例子方向正好相反：「`vol_spike` 很大但 `distinct_pk` 不够」这一格，是四格里唯一**测不出任何优势**的一格；反过来「`distinct_pk` 够但 `vol_spike` 不够」那一格，优势已经跟双高格一样大。

再往下一层，**真正的病根既不是 AND 这个结构，也不是某道闸「定得离谱」**：四道闸里只有 `distinct_pk` 在两个独立年份上都量得出方向优势，`vol_spike` 沿整条阈值轴全平（放在任何位置都不产生区分度），`first_drought` 在 2025 窗上是负贡献，`peak_age` 的优势是 2025 这一年特有的。把它们做成可补偿的加权项，等于让三个没信号的量买通唯一一个有信号的量。

配套的三条量化读数：

| 问题 | 答案 |
|---|---|
| 「利好因素」前提成立吗 | 部分成立。四个量在 `forward_return` 上的「越大越好」**全部是波动率读数**——按买点日 ATR% 分层匹配后，Δmed_fr 全线贴 0 或转负。只有 `distinct_pk` 在首次穿越率上留下真实的方向优势 |
| 打分制值不值 | 同准入量下点估计一致优于现有 AND 闸（4/4 组合为正，Δ +0.027~+0.070），但**配对自助 CI 四个全跨 0**，按项目及格线不能宣称更好。且优势来自绕开定坏的固定阈值，不是来自「放进单项优秀的样本」 |
| 放宽的代价 | 打分曲线是**越收紧越好**。2024 窗上准入量一旦超过宽进总体的约 15%，相对基线的优势整体归零。用户想要的方向恰是掉分方向 |
| 过拟合预算 | 4 个权重不可辨识：单个配置的 ΔFPR 自助 CI 半宽 **0.084**，而 255 组权重在调参窗上的 max−p50 只有 **0.062**。排名差异全在噪声内，拟合权重买不到东西 |
| 阈值处的「人为不连续」 | 用户的直觉对了一半：**四道闸没有一道在阈值处存在可测的收益断层**（§7.1）。但正因为线两侧本来就相同，把阶跃换成平滑过渡同样拿不到东西——软阈值要有价值，前提是两侧确实不同、只是切得生硬 |
| 「看最强项还是看最弱项」 | 两个都不成立：四量分位秩的 `max` 与 `min` 对 label 的 Spearman 全部 \|ρ\|<0.07，配对差全跨 0，`min` 还跨年翻号（§7.3）。选人类比预设四项都是真本事，而实测只有一项是 |
| 附带：锚语义放宽 | 表面上新增买点大幅更好（ΔFPR +0.18、Δmed_fr +0.13），但**优势 100% 来自一个前瞻偏差**——43% 的新增买点配的是买点之后才确认的 burst（§8）。约束住因果性后，新增买点与原有**质量无法区分**，价值主张应改为「买点 ×1.44~1.45、质量不变」 |
| 「亏欠一点点」值不值得救 | **不足以判定**（§7.6）：沿总亏欠的梯度 `w2025` −0.022 / `w2024` +0.048，符号相反、都在噪声内；「擦线被拦下」与「四闸全过」两窗都无法区分。这是截断加权和相对「删闸」的唯一增量来源，落在一个测不出来的地方 |

## 0. 一个必须先纠正的口径

**团队前期引用的「bb_v1 默认参数」不是现役配置。**

- `first_drought_min=20 / distinct_pk_min=4 / vol_spike_min=8.0 / peak_age_min=125` 来自 `path2_apps/bb_v1/params.py` 里 dataclass 的字段默认值。`app.analyze(df)` 不传 params 时走 `Params.default()`，拿到的是这一套。
- **现役是 `path2_apps/bb_v1/params.yaml`：`40 / 3 / 3 / 60`**（另有 `gap_max=8`、`min_bos=1`，dataclass 是 5 / 2）。`params.py` 的 docstring 写明 yaml 是 web 入口的 SSoT；`path2_web/scan.py` 走 `load_params()` 读它。今天早上那次生产扫描 `outputs/path2_web/scans/20260907T051628.json`（8325 只、2025 全年、253 只命中）用的就是 yaml 这套。

所以「`vol_spike≥8.0` 在 734 个样本里只放行 9 个」描述的是一个**没人在跑的配置**。本报告两套阈值都测，结论不受影响，但对外说数时口径必须写清。

## 1. 口径与底座自检

### 样本

| 项 | 取值 |
|---|---|
| 股票池 | `datasets/pkls/` 全宇宙 **8325 只**（不是随机 800 只） |
| 窗口 | `w2025` = 2025-01-01..2026-01-01（与生产扫描同窗）；`w2024` = 2024-01-01..2025-01-01（独立复核窗） |
| 缓冲窗 | `[start − 104 日, end + 66 日]`（`head_buffer=63` 交易日 × 1.65、`label_horizon=40` × 1.65），与 `path2_web/scan.py:276` 同一公式 |
| 参数底座 | `params.yaml`，**只把 4 道 burst 闸放到最松**（`first_drought_min=0 / distinct_pk_min=1 / vol_spike_min=0 / peak_age_min=0`）。`tb.max_day_drop_pct` 保持 0.2——它不在本轮 4 道闸内，放松它会换掉总体 |
| 过滤 | `volume_min=10000`（股票级，判定窗 = scan 区间）、`price ∈ [0.5, 30]`（match 级，锚 end_node 事件起点日收盘价），与生产扫描逐项一致 |
| **样本单位** | **一个 match**（= 一个 burst 前缀 × 它锚定的 tb），去重键 `(symbol, tb_instance_id, anchor_bo_id)` |
| 样本量 | `w2025` n=5846 / 2232 票 / 3645 个 burst 前缀族；`w2024` n=4357 / 1734 票 / 2804 族 |

**为什么用 match 而不是 burst**：burst 不是买点。bb_v1 的买点 node 是 `tb`，label 必须锚在 tb 的买点日上。把闸放松、跑完整 pattern、再把 burst 四量挂到每个 match 上，才是「这道闸拦掉的样本到底好不好」的正确问法——直接在 burst 层看，测的是一批永远不会被买入的东西。

**前缀族的相关性**：`BurstDetector` 用 all_ends 前缀族物化，同一簇的多个前缀各产一个 burst，`first_drought` 在族内恒等、其余三量随前缀变长单调增。所以同族的多行高度相关。本报告所有 CI 都按 **symbol 整簇自助**（比按族更保守），报表里同时给 `n` / `n_sym` / `n_clu` 三个规模数。

### label 与基线

- **前瞻收益 `fr`** = `path2.eval.match_forward_returns(m, "tb", win, [40], sample_window=(lo,hi))`——tb 买点窗内逐买点日 `max(high[t+1..t+40])/close[t]−1` 的均值。报中位数。
- **首次穿越率 `FPR`** = `match_first_passage(..., horizon=40, k=5.0)` 四态计数池化后的 `up/(up+down)`。分母是买点日，不是 match 数。
- **前瞻回撤 `dd`** = `match_forward_drawdowns(...)`，只用来甄别「这个量是不是只是波动率读数」。
- **随机日基线**：每票在 scan 区间内抽 20 个交易日（候选日筛选与抽样复刻 `random_day_first_passage`，seed 走 `_ticker_seed`），同时算 FP 四态与 fr / dd。`w2025` 129407 日 / 6667 票，`w2024` 116372 日 / 6002 票。
- **波动率层匹配基线**（关键）：`docs/feature_candidates.md` FC-004 明确记着——bb 与随机日的任何比较**必须按波动率层匹配**，否则会被 artifact 骗。做法：用基线池的买点日 ATR%（`rolling_atr_pct_nanmedian(h,l,c,20)`）三分位定层，每个子集按它自己的层分布对基线三层重加权。全文的 **ΔFPR / Δmed_fr = 子集读数 − 该子集的层匹配基线**。

无条件基线（供参考，**不用于下结论**）：`w2025` med_fr +0.1162 / FPR 0.5103；`w2024` med_fr +0.1084 / FPR 0.5408。分层后差异极大（w2025 三层 med_fr = 0.054 / 0.131 / 0.272，FPR = 0.551 / 0.503 / 0.477），这正是不做层匹配就会出错的原因。

### 底座等价自检（硬闸）

把宽进结果按现役 yaml 四闸过滤，与生产扫描 `20260907T051628` 逐 match 对比：

- **缺失 0 个**（scan 有、我没有：0）
- **label 逐 match 重算 358/358 全部 `<1e-12`**
- **多出 100 个** —— 100/100 全部是「簇首 bo 无前序（`drought is None`）」的 burst。原因已定位：commit `ed9a9a8f`（今日 06:13:51）把 `first_drought` 从 `drought or 0` 改成 `drought_floor`，而那次扫描跑在 05:16:28、用的是旧码。旧码下这批 burst 的 `first_drought=0`、被 `≥40` 拦掉，新码下拿到真实的沉寂下界、通过。**这是已知代码变更，不是漂移；差异 0 个无法解释。**

随机日基线复刻自检：官方 `random_day_first_passage(n_days=3)` 的四态计数 vs 本地复刻，`w2025` 6688 票全等、0 例不符（`w2024` 6059 票同）。

### 分箱形状（`w2025`，五分位）

**`vol_spike` 是纯波动率读数**——这是全文最该记住的一条：

| 分箱 | n | med_fr | 层匹配基线 | FPR | med_dd |
|---|---|---|---|---|---|
| ≤1.06 | 1170 | +0.150 | +0.178 | 0.594 | −0.119 |
| 1.06–1.64 | 1169 | +0.164 | +0.179 | 0.556 | −0.126 |
| 1.64–2.61 | 1169 | +0.196 | +0.204 | 0.555 | −0.156 |
| 2.61–5.13 | 1169 | +0.215 | +0.221 | 0.538 | −0.174 |
| >5.13 | 1169 | +0.234 | +0.241 | 0.548 | −0.226 |

`med_fr` 从 0.150 单调涨到 0.234，看着漂亮；但**层匹配基线以完全相同的斜率一起涨**（0.178 → 0.241），而 `med_dd` 从 −0.119 恶化到 −0.226。也就是说 `vol_spike` 越大，涨得多也跌得多，两边同比例放大——它测的是波动率，不是方向。真正剥离波动率的 FPR 一栏，从 0.594 走到 0.548，**方向上是轻微递减的**。Spearman：`fr` +0.105 / `|dd|` +0.188——与回撤的相关强于与收益的相关，是波动率成分的直接签名。

**`distinct_pk` 是唯一形状干净的**：FPR 0.549 → 0.571 → 0.607 单调递增，Δmed_fr 也是唯一从负转正的（−0.022 → +0.004 → +0.009）。

三档 k 稳健性（`w2025`，ΔFPR vs 层匹配基线）：

| 子集 | k=4 | k=5 | k=6 |
|---|---|---|---|
| 全体宽进 | +0.0599 [+0.035, +0.084] | +0.0664 [+0.039, +0.093] | +0.0734 [+0.045, +0.104] |
| `distinct_pk≥3` | +0.0966 [+0.046, +0.144] | +0.1001 [+0.047, +0.150] | +0.1114 [+0.057, +0.165] |

三档 k 同向、CI 均不跨 0，且随 k 增大而增强。`w2024` 三档 k 同样全正（`≥3`：+0.031 / +0.045 / +0.047），但 CI 全跨 0。

### `distinct_pk` 是不是 `burst_count` 的马甲

同一簇的前缀越长，`distinct_pk` 与 `count` 一起涨，所以必须分开。用固定阈值 3 做 2×2（`w2025`）：

| 格 | n | ΔFPR |
|---|---|---|
| **`pk≥3` & `count<3`** | 648 | **+0.1424** [+0.0811, +0.2019] |
| `pk≥3` & `count≥3` | 743 | +0.0650 [−0.0037, +0.1318] |
| `pk<3` & `count≥3` | 255 | +0.0955 [−0.0155, +0.1971] |
| `pk<3` & `count<3` | 4200 | +0.0534 [+0.0261, +0.0826] |

最强的一格是**「bo 根数少、但突破的不同 pk 多」**——即少数几根 bo 各自吃掉多个阻力位。这与「`distinct_pk` 只是 burst 更长的代理」正好相反。`w2024` 排序一致（+0.053 / +0.039 / −0.004 / −0.018），但幅度小、CI 全跨 0。

需要说清的一处不复现：在 `count=2` 层内按阈值 **2** 切 `distinct_pk`，`w2025` 上反了（`pk≥2` +0.070 vs `pk<2` +0.094，CI 重叠）。这与边际扫描一致——`≥1→≥2` 那一档本来就几乎没有增量（+0.067 → +0.072），信息集中在 `≥3` 这一档往上。低档位的切分没有区分力，不是矛盾。

**`peak_age` 在 2025 上近似平坦**（FPR 0.549/0.569/0.540/0.541/0.593，Spearman(fr) −0.013），只在最高分位有一个抬头；`w2024` 上全程平。

**`first_drought` 非单调**：FPR 呈 U 形（0.605 / 0.539 / 0.498 / 0.551 / 0.610），`med_fr` 随它单调**下降**（0.221 → 0.136），Spearman(fr) −0.092。现役阈值 40 恰好落在 U 形的谷底附近。

> 这一节的结论对上了 memory 里那条「bb 的现有 score 类量更像波动率读数而非方向性优势」。差别是：本轮把四个量拆开测，发现**并非全部如此**——`distinct_pk` 在层匹配后仍留下方向优势，它不是波动率的马甲。

## 3. Q2 · 可补偿性直测（核心）

**读法**：`(vol 高, pk 低)` 与 `(vol 低, pk 高)` 是两个「单项优秀」格。如果打分制的前提成立，它们应该都接近 `(高,高)`；如果它们接近 `(低,低)`，补偿逻辑当场判死。

### 现役 yaml 阈值：`vol_spike≥3.0 × distinct_pk≥3`

**`w2025`**

| 格 | n | n_sym | ΔFPR | Δmed_fr |
|---|---|---|---|---|
| 双高 | 882 | 582 | **+0.1017** [+0.0377, +0.1638] ✔ | +0.0089 [−0.0239, +0.0466] |
| **vol 高 · pk 低** | 1168 | 827 | **+0.0290** [−0.0242, +0.0778] ✘ 跨 0 | −0.0107 [−0.0400, +0.0178] |

| 窗 | 双高 | vol 高·pk 低 | vol 低·pk 高 | 双低 |
|---|---|---|---|---|
| `w2025` | +0.1038 (n=204) | +0.0438 (n=522) | **+0.1308** [+0.0277, +0.2167] (n=375) | +0.0622 (n=4745) |
| `w2024` | +0.1850 (n=148) | **−0.0406** (n=398) | −0.0150 (n=235) | −0.0043 (n=3576) |

### 判读

1. **两个单项优秀格完全不对称。** 四组读数（2 窗 × 2 套阈值）里，`vol 低·pk 高` 有 3 组 ≥ 双高格或与之持平；`vol 高·pk 低` 有 3 组 ≤ 双低格。用户设想的对称补偿——「哪一项特别好都能顶上」——在数据里不存在。
2. **用户点名的那一侧恰恰是最差的一侧。** `w2025` 现役阈值下 `vol 高·pk 低` 的 ΔFPR = +0.029，是四格里唯一 CI 跨 0 的；`w2024` 下它是 −0.004（dataclass 阈值下 −0.041，四格最低）。「`vol_spike` 很大但 `distinct_pk` 不够就被筛掉，很可惜」——数据说不可惜。
3. **`distinct_pk` 单独就撑得起全部优势。** `vol 低·pk 高` 在 `w2025` 拿到 +0.098，与双高的 +0.102 在统计上无法区分；这意味着 `vol_spike` 那一维**没有增量贡献**。
4. **`forward_return` 上的差异全是波动率。** 四格的 Δmed_fr 分别是 +0.009 / −0.011 / −0.005 / −0.019——全部贴 0 或为负，而未做层匹配的原始 med_fr 排序（0.251 > 0.216 > 0.209 > 0.166）看起来完美可加。**任何用 `median(forward_return)` 当打分目标的加权方案，实际上是在给波动率打分。**
5. 其余五对（`vol×drought` / `vol×peak` / `pk×drought` / `pk×peak` / `drought×peak`）在 `repro/factorial_ci.py` 输出里全在，形状一致：只要一格里含 `distinct_pk 高`，ΔFPR 就抬到 +0.09 以上；只含 `vol_spike 高` 或 `first_drought 高` 的格子都回落到全体水平。

### 同准入量下的三路对照（配对自助）

把准入量对齐后比「AND 硬闸 / 等权分 / 只用 `distinct_pk`」。配对做法：每次自助重抽同一批 symbol，三种规则在同一批票上各自重算 ΔFPR 再取差——票级噪声被抵消。

| 窗 · 阈值套 | 准入量 | AND 硬闸 | 等权分 | 只用 `distinct_pk` | 配对差（等权分 − AND） |
|---|---|---|---|---|---|
| `w2025` · yaml | 458 (317 票) | +0.0983 | +0.1249 | +0.1264 | **+0.0274** [−0.0292, +0.0862] P(>0)=0.84 |
| `w2024` · yaml | 395 (279 票) | +0.0650 | +0.1059 | +0.0537 | **+0.0373** [−0.0369, +0.1086] P(>0)=0.84 |
| `w2025` · dataclass | 94 (74 票) | +0.1040 | +0.1586 | +0.0923 | +0.0380 [−0.1120, +0.1952] P(>0)=0.69 |

## 5. Q4 · 过拟合预算

打分制把 4 个阈值超参换成 4 权重 + 1 总阈值。用**权重可辨识性**回答这个问题比用样本/参数比更直接：

| # | 量 | 值 |
|---|---|---|
| ① | 单个配置的 ΔFPR 自助 95% CI **半宽**（等权分 @ `w2025`，n=537，按票整簇自助 2000 次） | **0.0836** |
| ② | `w2024` 上 255 组权重（网格 {0,1,2,3}⁴ 去零，准入量固定 400）的 ΔFPR 分布：min −0.015 / p50 +0.060 / max +0.122 | **max − p50 = 0.0616** |
| ③ | 选择偏差实测：`w2024` 择优权重 `(2,3,3,2)`（2024 ΔFPR +0.1217）拿到 `w2025` → +0.1295，落在 2025 全部 255 组结果分布的**第 74 分位** | — |

**① > ②：权重不可辨识。** 「换一组权重能提升多少」的整个可观测幅度（0.062），比「同一组权重测量本身的不确定度」（0.084）还小。也就是说 255 组权重在调参窗上的排名，绝大部分是噪声排出来的。

直接验证：等权 `(1,1,1,1)` 在 `w2024` 只排到 ΔFPR +0.0962（255 组里中上），拿到 `w2025` 是 +0.1207；`w2024` 择优权重拿到 `w2025` 是 +0.1295。**同在 2025、同批重抽票的配对差 = +0.0037 [−0.0297, +0.0338]，P(>0)=0.61** —— 拟合出来的权重与等权**统计上无法区分**。

**有效样本**：AND 闸的工作点上 `w2025` 是 458 个 match / 317 只票 / 329 个前缀族；打分制 P92 附近是 537 match / 364 票 / 379 族。**有效 n 是票数不是 match 数**（FC-003 记着 bb 买点的 ICC ≈ 0.87），所以 4 个自由超参（4 权重尺度不变 ⟹ 3 自由，加 1 总阈值）对应约 **90 只票 / 参数**。在一个效应量 ≈ 0.12、测量噪声 ≈ 0.084 的问题上，这个预算只够定「用不用某个量」，不够定「它该占多少权重」。

**时间外推的意外读数**：2024→2025 没有明显衰减（+0.122 → +0.130）。但这**不是**「权重学到了东西」的证据——因为等权同样不衰减（+0.096 → +0.121），而两者的配对差贴 0。真实的解读是：这套量的可用信息很粗，粗到怎么加权都差不多；换句话说，**衰减小是因为本来就没学到什么可衰减的东西**。

## 7. 边界行为、组合规则、聚合口径

用户后来把论点精化成：「一个 `vol_spike` 远大于阈值、但 `peak_age` 仅仅只比阈值小一点点的 event，在刚性判断中会被过滤掉」，并给了一个选人的类比——有人有明显特长、有人有致命短板、有人各项都不错但无突出优势，该按什么选。这一节直接回答它。脚本 `repro/boundary_and_aggregation.py`，全部以现役 SSoT 阈值（40 / 3 / 3 / 60）为中心。

### 7.1 阈值处有没有收益断层

在每个量自身的轴上取阈值两侧的窄带（带宽 = 该列在宽进池上的 0.25σ 与 0.5σ 两档），比「刚过线」与「刚没过线」。配对自助：同批重抽票，两侧各自重算再取差。

| 量（阈值） | `w2025` 配对差 ΔFPR（刚过 − 刚没过） | `w2024` | 判读 |
|---|---|---|---|
| `first_drought` (40) | −0.0870 [−0.193, +0.023] · −0.0637 [−0.139, +0.012] | +0.0949 [−0.028, +0.212] · +0.0793 [−0.003, +0.161] | **符号跨年翻转**，无稳定台阶 |
| `distinct_pk` (3) | 阈值下侧窄带 **n=0** | n=0 | **整数计数，不存在邻域**——没有可平滑的连续统 |
| `vol_spike` (3) | −0.0084 · −0.0104 | +0.0233 · +0.0261 | 贴 0，无断层 |
| `peak_age` (60) | +0.0297 [−0.060, +0.127] · −0.0097 [−0.082, +0.064] | +0.0681 [−0.053, +0.190] · +0.0318 [−0.051, +0.113] | 全部跨 0，无断层 |

（每格两个数分别是 ±0.25σ 与 ±0.5σ 两档带宽。）

**四道闸没有一道在阈值处存在可测的收益断层。** 用户「阈值造成人为不连续」的直觉在这一点上是对的——线两侧确实是同一批东西。但这把结论是双刃的：**正因为线两侧没有差别，把阶跃换成平滑过渡也拿不到任何东西**。软阈值要有价值，前提是「两侧确实不同、只是切得生硬」；实测是两侧本来就相同，平滑一个不存在的台阶只是把噪声换个位置。

### 7.2 只差一闸的天然对照组

比上一节更干净的设计（由 team-lead 提出）：取「其余三闸都过、仅被这一闸拦下」的 match，唯一变量就是那一道闸，与「四闸全过」比。

`w2025`（四闸全过 n=458，ΔFPR +0.0983）：

| 组 | n | ΔFPR | 配对差（本组 − 四闸全过） |
|---|---|---|---|
| 只差 `peak_age` | 100 | +0.1399 | **+0.0416** [−0.134, +0.190] |
| 只差 `first_drought` | 310 | +0.0908 | −0.0075 [−0.145, +0.124] |
| 只差 `vol_spike` | 200 | +0.0567 | −0.0417 [−0.190, +0.106] |
| 只差 `distinct_pk` | 148 | +0.0239 | −0.0744 [−0.240, +0.081] |

`w2024`（四闸全过 n=395，ΔFPR +0.0650）：只差 `peak_age` n=72 **+0.1297**（配对差 **+0.0647**）· 只差 `distinct_pk` n=165 +0.0793（+0.0143）· 只差 `first_drought` n=172 −0.0449（−0.1099）· 只差 `vol_spike` n=153 −0.0242（−0.0893）。

### 7.3 产出由最强项还是最弱项决定

四个量各取分位秩，比 `max`（最强项，对应 OR / 取最优）、`min`（最弱项，对应 AND / 短板决定）、`mean` 三个统计量对 label 的解释力。

| 统计量 | Spearman(fr) `w2025` / `w2024` | 三分位高低配对差 ΔFPR `w2025` | `w2024` |
|---|---|---|---|
| `max`（最强项） | −0.025 / +0.042 | +0.0162 [−0.044, +0.078] | +0.0545 [−0.015, +0.125] |
| `min`（最弱项） | +0.026 / +0.056 | **−0.0511** [−0.111, +0.003] | **+0.0557** [−0.009, +0.122] |
| `mean` | +0.038 / +0.063 | +0.0039 [−0.049, +0.061] | +0.0500 [−0.013, +0.112] |

**数据既不支持「看最强项」也不支持「看最弱项」。** 三个统计量的 Spearman 全部 |ρ| < 0.07；配对差全部跨 0；`min` 这一条还**跨年翻号**（−0.051 → +0.056）。

这个结果是 §2 的必然推论，不是另一个独立事实：四条轴里三条不带信号，那么任何对四条轴取序统计量的规则（max / min / 加权和），读到的主要都是那三条轴上的噪声。选人类比之所以套不上，是因为它预设了四项都是真本事——而实测只有一项是。**所以正解不是换聚合方式，是减轴。**

### 7.4 `peak_age` 的聚合口径

`peak_age_max` 是簇内各 bo 的 **max** 聚合（存在性语义：任一根 bo 突破陈旧峰即满足）。对照 `median` 与 `min`（全员语义）：

| 聚合 | Spearman(fr) `w2025` / `w2024` | 三分位高低配对差 ΔFPR `w2025` / `w2024` |
|---|---|---|
| `max`（现役） | −0.013 / −0.008 | +0.0070 [−0.050, +0.063] / +0.0474 [−0.016, +0.109] |
| `median` | −0.040 / −0.031 | +0.0216 [−0.035, +0.075] / +0.0275 [−0.034, +0.098] |
| `min` | −0.090 / — | +0.0054 [−0.058, +0.072] / — |

三种聚合彼此无可测差别，全部跨 0。**换聚合口径救不了 `peak_age`**——问题不在「max 把一次偶然深突破误判成结构性突破」，而在这条轴本身在两个窗上都没有稳定的方向信息。

### 7.5 `peak_age` 定性

**建议删或大幅放松**，三条证据同向：① 被它单独拦下的样本两年都不比四闸全过的差（§7.2，唯一两年同号的一道）；② 阈值 60 处没有可测断层（§7.1）；③ 换聚合口径无差别（§7.4）。反向证据是 §6 的边际扫描——`w2025` 上 `peak_age≥125` 有 +0.139，但 `w2024` 同一阈值只有 +0.017，是典型的单年驱动，不足以支撑保留。

### 7.6 亏欠幅度带不带信息（截断加权和的判据）

一个具体的替代形式：各项封顶 μᵢ = min(1, xᵢ/tᵢ)，准入条件 Σμᵢ ≥ θ，等价于**总亏欠** S = Σ(1−μᵢ) ≤ 4−θ。它相对「直接删掉那道闸」的**全部增量，都在「S 小的样本比 S 大的样本好」这个假设上**——若沿 S 没有梯度，它放进来的和删闸放进来的是同一批样本，只是换个说法。

**沿总亏欠 S 的梯度**（未全过样本内，比亏欠小的三分之一与亏欠大的三分之一，配对自助）：`w2025` **−0.0218** [−0.076, +0.034]（符号是反的）· `w2024` **+0.0478** [−0.016, +0.113]。Spearman(S, fr) = −0.053 / −0.067。分档也不单调——`w2025` 的 `S>2.0` 那档（+0.083）比 `0.1<S≤0.5` 两档（−0.009 / +0.039）还好。

**只差一闸的组，按该闸自身相对亏欠分档**（`w2025` n=758、`w2024` n=562）：

| 亏欠档 | `w2025` ΔFPR (n) | `w2024` ΔFPR (n) |
|---|---|---|
| <10% | +0.153 (99) | +0.120 (67) |
| 10~25% | **−0.028** (117) | +0.182 (80) |
| 25~50% | +0.072 (318) | −0.039 (244) |
| >50% | **+0.122** (224) | −0.028 (171) |

`w2024` 大致单调递减（近 ≤25% − 远 >25% 配对差 **+0.188** [+0.029, +0.321]，是唯一 CI 不跨 0 的读数）；`w2025` 非单调且反号（**−0.047** [−0.193, +0.096]）。

**最关键的一格**：「只差一闸·近（≤25%）」与「四闸全过」比——`w2025` −0.054 [−0.199, +0.092]，`w2024` +0.089 [−0.070, +0.230]，**两窗都跨 0**。擦线被拦下的样本与四闸全过的样本在两个窗上都无法区分。

**判定：不足以判定。** 各档 n 在 67~318、CI 半宽约 0.15，而要分辨的效应量级是 0.05~0.10。两个窗给出相反的符号，既不能说梯度存在，也不能说它被证伪。但可以说的是：这个形式相对「删闸」的唯一增量来源，落在一个本轮测不出来的地方，而它要付 4 个 μ 映射 + 1 个 θ 的超参代价——在 §5 那个预算下（单配置 CI 半宽 0.084 已经大于 255 组权重的全部可观测幅度 0.062），这笔账买不到东西。另外它会把准入量从 458 扩到 758（2.6 倍），而 §4 的曲线显示放宽方向单调衰减、`w2024` 上超过宽进总体 15% 优势即归零。

## 8. 锚语义放宽的 label 质量（附带评估，含一个前瞻偏差）

`framework` 提出一条零框架改动的写法：把 bb_v1 的边从「tb 锚簇末 bo」放宽成「tb 锚簇内任一 bo」（`ContainmentEdge(burst, bo)` + `TemporalEdge(bo, tb, anchor_field=...)`），治的是一条结构性连坐——burst 被闸拦下，它的 tb 就彻底无主。它不放宽任何判据，与本报告主线（组合规则）正交，但用的是同一套 label 机器，故一并评估。

**口径**：全宇宙 8325 只 × 两窗，SSoT 参数（四道闸照常开着），**样本单位 = 买点（tb 实例）**——放宽后一个 tb 会同时配上多个 burst 前缀，按 match 计会把同一个买点重复计，而 label 只与 tb 有关。自检：现状 spec 的买点 100% 出现在放宽 spec 里（两窗全宇宙，丢失 0），放宽确实是超集。买点数 `w2025` 458 → 817（新增 359），`w2024` 395 → 681（新增 286）。

### 8.1 表面结果

| `w2025` | n | ΔFPR | Δmed_fr | med_dd |
|---|---|---|---|---|
| 原有 | 458 | +0.0983 [+0.008, +0.184] | −0.0070 | −0.204 |
| 新增 | 359 | **+0.1819** [+0.087, +0.272] | **+0.1327** [+0.058, +0.200] | −0.152 |

配对差 新增 − 原有：ΔFPR +0.0836 [−0.005, +0.172]、Δmed_fr +0.1397 [+0.062, +0.210]。`w2024` 同向且 ΔFPR 的 CI 不跨 0（+0.1146 [+0.030, +0.199]）。看起来是本轮最强的读数。

### 8.2 这个优势是前瞻偏差

`burst` 是**回顾型**事件，`confirm_idx = end_idx`（`path2/CONTEXT.md`：区段走完回头才能确认）。现状 spec 锚簇末 bo 且 `min_gap≥1`，所以恒有 `burst.end_idx < tb.start_idx`——买点当天 burst 已确认。**放宽之后没有任何东西约束这一点**：一个 tb 可以配上买点之后才成形的 burst。按确认根的定义（「站在这一根收盘、只读它及之前的数据就足以断定事件已经发生」），逐日跑的扫描器在买点当天产不出这条 match。

规模：`w2025` 新增 359 里 **156 个（43%）** 非因果，`w2024` 286 里 109 个（38%）。

| `w2025` 拆分 | n | ΔFPR | Δmed_fr |
|---|---|---|---|
| 原有 | 458 | +0.0983 | −0.0070 |
| 新增·**因果**（买点时已确认） | 203 | +0.0953 [−0.034, +0.218] | +0.0054 |
| 新增·**非因果**（买点后才确认） | 156 | **+0.3036** [+0.166, +0.430] | **+0.3296** [+0.189, +0.523] |

- 配对差 **非因果 − 因果**：ΔFPR **+0.2083** [+0.028, +0.391]、Δmed_fr **+0.3242** [+0.174, +0.538]，**CI 都不跨 0**
- 配对差 **新增·因果 − 原有**：ΔFPR **−0.0030** [−0.103, +0.102]、Δmed_fr +0.0124 [−0.055, +0.066]——**归零**
- `w2024` 同构：因果 − 原有 +0.0592 [−0.036, +0.158]（跨 0）；非因果 − 因果 +0.1597 [−0.022, +0.351]

一个佐证视角：`n_bo_after`（买点当日或之后仍有几根成员 bo，按**最长**匹配前缀算）——`w2025` 有后续 bo 的 ΔFPR +0.3174、无后续 bo 的 +0.0603，配对差 +0.2571 [+0.074, +0.438]。**但这个视角依赖「取哪个前缀当代表」，不独立于因果性判据**：若改取最早确认的那个前缀，因果买点的 `n_bo_after` 恒为 0，这一拆分就退化成因果拆分本身。所以**可作结论依据的是 `causal`**（= 存在至少一个在买点前已确认的合格 burst，等价于 `burst_end_min < tb_start`，已逐行验证），`n_bo_after` 只作佐证。

**读法**：新增买点 label 好看，是因为它们坐在「后面还会继续突破」的位置上——而「后面还会突破」**正是它们能被匹配上的原因**（`framework` 独立查证：新增买点 359/359 都是「自带前缀存在但没过闸」，救回它们的必然是一个更长的前缀）。这是选择在了未来收益上，不是这批走势更好。它同时解释了「新增那批 dd 反而更浅」（非因果组 med_dd −0.096 vs 原有 −0.204）：那是「买在一段仍在延续的上涨中段」的特征，不是波动率下降。

### 8.3 修正后仍然成立

约束住「burst 须在买点之前确认」之后，**全部 203 个因果新增买点都保留**（`w2024` 177 个）：

| 窗 | 原有 | + 因果新增 | 召回倍数 | 不设约束（含偏差） |
|---|---|---|---|---|
| `w2025` | 458 | **661** | **1.44×** | 817（1.78×） |
| `w2024` | 395 | **572** | **1.45×** | 681（1.72×） |

质量与原有**统计上无法区分**：配对差 新增·因果 − 原有 = ΔFPR −0.0030 [−0.103, +0.102]（`w2025`）/ +0.0592 [−0.036, +0.158]（`w2024`），两窗都跨 0；三档 k 也都落在原有附近。

所以这条路的正确价值主张是「**零框架改动、买点 ×1.44~1.45、质量不变**」，不是「买点更多且更好」。§8.1 那组数（+0.084 / +0.115）是偏差的读数，**不应引用**。

### 8.4 与 `framework` 的独立实现对拍

### 8.5 加了因果闸的 spec：修法验证与入场时点控制

`framework` 把修法落成第三条边 `TemporalEdge("burst", "tb", min_gap=1, max_gap=tb.max_span)`——`min_gap=1` 不是新拍的数，它复刻的正是现状 spec 本来就隐含的因果纪律（现状锚 `last_bo` 且 `burst.end_idx == last_bo.end_idx`，那条 `min_gap=1` 同时管着身份与因果两件事；换端点时只放开了身份，因果是搭在同一条边上顺带丢掉的）。

**修法验证**（`repro/causal_spec_check.py`）：

- **spec 级修法与我的事后因果过滤产出同一批买点**：`w2025` 661 vs 661、`w2024` 572 vs 572，两侧各自独有 **0** 个
- 加闸变体内 `causal_gap = tb.start_idx − burst.end_idx` 最小值 = **1**（须 ≥1）、`n_bo_after` 最大值 = **0**（须 =0），约束确实生效
- 原有买点丢失 0

**质量**（ΔFPR vs 波动率层匹配基线，三档 k，配对自助）：

| 组 | n | k=4 | k=5 | k=6 | Δmed_fr | med_dd |
|---|---|---|---|---|---|---|

## 9. 局限（逐条）

1. **单一 label 口径**：`fr` 是买点窗内逐日 `max(high)` 的均值，天然上偏，不能当收益预期；`FPR` 只看 k=5 一档、horizon=40 一档，未做 k∈{4,6} 的稳健性。
2. **两个窗都是样本内**：`w2024` / `w2025` 是两个不重叠的年份，可以互为复现，但都不是预注册的 holdout。所有「跨年一致」的说法只是两次观测同向，不是 out-of-sample 验证。
3. **观测非独立，只做了单维去簇**：CI 按 symbol 整簇自助（比按 burst 前缀族更保守），但**没做时间桶去簇**——「那几周小盘股集体反弹」这种同期跨股聚集是 symbol 单维的盲区，名义 n 可能仍虚高。feature-study 电池的双维去簇本轮没跑。
4. **未做 FDR 校正**：本轮报了 4 个量 × 2 窗 × 多个阈值档，属于口径族批量比较，没做多重比较校正。所以单个「CI 不跨 0」的读数（如 `peak_age≥125` @ `w2025` 的 +0.139）**不能单独当作发现**——这也是我在结论里只依赖「两窗同向 + 形状单调」的 `distinct_pk` 的原因。
5. **`w2025` 的宽进总体本身就有优势（+0.067），`w2024` 没有（−0.003）**。这个跨年落差比任何一道闸的效应都大，说明整个 pattern 的表现高度依赖市况。本报告所有「闸有没有用」的判断都是相对同窗的不设闸对照说的，不受这个落差影响；但任何绝对水平的数字都不可外推。
6. **`vol_spike` 的极端右尾**：`max_bar_vol_ratio` 最大到 18686，分布重尾。分位秩打分对它不敏感（用的是秩），但硬闸扫描在右尾档样本稀薄，`≥9.8` 以上未报。
7. **前缀族内的量不独立**：`distinct_pk` / `vol_spike` / `peak_age` 随前缀变长单调增，`first_drought` 族内恒等。`distinct_pk` 与 `burst_count` 的分离已做（§2 末），结论是不构成代理；但 `vol_spike` / `peak_age` 与 `count` 的分离**没做**——这两个量本轮判为无信号，所以没有进一步归因的动机，但若后续要用它们，这一步不能省。
8. **底座自检的 100 个差异**已定位到 `ed9a9a8f`，但那次代码变更本身**放宽了 `first_drought` 闸的实际效果**（把一批原本被记成 0 的 burst 抬到真实沉寂下界）。所有结论跑在修复后的代码上；如果参考的是修复前的扫描文件，数字对不上是预期的。
