# 调参判据卡

这份文档只回答一件事：**Claude 给你的调参结果，什么时候能信、什么时候不能信。**
怎么跑、跑什么，都不用你管。

几个贯穿全文的词：
- **首次穿越率**：买入后在前瞻期内，先涨到上方目标线、而不是先跌到下方止损线的比例（两条线按这只股票近期的波动幅度定）。它是判断好坏的主指标。
- **最小关心改进**：改进不到几个点你就不在乎，默认 2 个点。开工确认时由你定，开跑后不改。它同时用在三处：判「没有底子」、判「没用」、判「删了不亏」。
- **同一段买点只计一次**：同一段买点常被好几条命中共享，所有计数、比例、误差都按「一段买点」算，不按命中的条数算。
- **误差按股票算**：同一只股票的多段买点彼此牵连，不当成互相独立的样本。所以真正独立的样本比表面上少得多。

---

## 一、优势检查怎么读

优势检查排在一切调参之前，回答两件事：这个走势的买点比随机买入好不好；手上的样本能分辨多小的改进。没有底子时，调参挑出来的好成绩多半是运气。

**比的是什么**：每个买点日只和**同一天、同样波动水平**的随机买入日比首次穿越率。「同样波动水平」= 当天全部股票按波动高低分成三档，落在同一档。这样差值读到的是走势本身，而不是它碰巧落在哪段行情、落在多高波动的股票上。

**两种口径**各给一个结论：
- **闸全部放开**：只看走势检测本身；
- **按现在的正式参数**：各道闸按现在的值。

**四种结论**（逐年各一个，另有全部年份合并）：

| 结论 | 意思 |
|---|---|
| 有底子 | 差值的 95% 区间整体在 0 以上。区间下沿刚过 0 时，读作「有底子，但不厚」 |
| 没有 | 区间上沿不到最小关心改进：就算有好处，也小到你不在乎 |
| 还不能确定 | 其余情况：区间里既有 0 以下的值，也有最小关心改进以上的值。两年数据下这很常见 |
| 比不了 | 同一天找不到足够多同样波动水平的随机买入日来比（每一档至少要 20 个分出涨跌的随机日），这一口径没有结论。通常是只扫了一小部分股票 |

注意「还不能确定」不等于「就是 0」，只是「还不能排除是 0」。

**怎么用这些结论**：
- 按现在的正式参数判「没有」→ 继续调参之前，先想清楚这个走势值不值得调，更可能该回去改结构。
- 判「还不能确定」→ 可以继续，但后面所有结论都带着「底子未证实」。
- **闸全部放开时没有、按现在的正式参数有** → 这点底子来自现在开着的闸，不是走势检测本身带来的。删闸时要格外小心。
- **覆盖率提醒**：明细表里「比得上的买点日占比」低于 80% 时，报告会单独提醒。那一栏的结论只代表比得上的那部分买点，不代表全部。

**「样本能分辨多小的改进」一节**（标「估计」）：
- 事先写好的单个改动，能分辨出几个点以上的改进；
- 筛选阶段要同时比很多组改动，门槛会更高；
- 两个参数一起调，能不能分辨出最小关心改进那么大的差别；
- 要分辨最小关心改进，每年需要多少个买点日、现在有多少、够不够；
- 按现在的样本量，噪声本身最多能造出多大的假差值。

标「估计」的原因：「改一个参数之后大约还保留多少买点」用的是事先标定的经验比例，要比几组改动也是预估数；真正筛选之后会换成实测值重算。样本本身的离散程度是这次实测的。

## 二、筛选结论怎么读

筛选在现在这套参数附近逐个改一处：每个检测参数试松一档、紧一档，每道开着的闸试关掉。每个改动在「现在这套闸」和「闸全关掉」两种情况下各比一次。

**开头那句「一共比了 N 个改动，k 个分辨得出」**：
- 「分辨得出」= 算上这一轮一共比了 N 个改动之后，这个差别仍然超出噪声。N 越大，单个改动要过的门槛越高——这就是范围必须在看结果之前定死的原因。
- 标了**「刚过线」**的：把这道门槛再收紧一半就过不了。它是分辨得出里最弱的一档，别和明显过线的等量齐观。

**「分辨不出」≠「没用」**：它只说明差别没大到这份样本看得出来。报告末尾「现在这套参数的分辨力」给出误差有多大、这些买点 bar 大约只相当于多少个互不相关的样本——效果小于这个量级，就算真有也看不出来。离门槛只差一点的改动会列进「需要留意」，写明「差一点没过线，先不动」。

**开着的闸：删了亏不亏**（最多能容忍差出最小关心改进那么多）：

| 结论 | 意思 |
|---|---|
| 删了不亏 | 关掉之后，首次穿越率的**最坏情况**（单侧 95% 下沿）也只差在容忍范围以内 |
| 有用 | 没过「删了不亏」，而且关掉之后明显变差，保留 |
| 说不清 | 关掉最坏可能差出容忍范围，又分辨不出这道闸确实有用，维持现值 |

看的是最坏情况，**不是估计值的正负**：关掉后估计值是正的，最坏情况照样可能差出容忍范围；估计值是负的，也可能完全在容忍范围内。筛选里的「删了不亏」是按调参数据得出的初步结论，最终要经过没碰过的数据验证。

**「需要留意」里的几类提示**：
- **两年明显不一样**：两年效果之差超过误差的两倍。结论多半是某一年的特有现象撑起来的。
- **时好时坏**：把训练期按标签前瞻期那么长切成若干段，各段效果的差别超出误差。反过来，没标出这一条也不等于「各时期效果都一样」——这项检查对小的时期差异不敏感。
- **效果依赖其他闸开不开**：写成「现在这套闸下 x 点，闸全关掉时 y 点」。这是只在某一种底座上有效的改动：它和开着的闸有交互，单独拿出来说「有用」不成立。
- **买点少了超过三成**：改进伴随买点大量减少，质量和数量之间要你来取舍。
- **可能换成了另一批波动或行情的股票**：改动之后买点池的构成变了，首次穿越率的变化可能只是换了股票。
- **一起改时会互相影响**：两处一起改，比两处各自的效果相加明显多出一截（超过误差两倍）。其中一个已经分辨得出时，另一个也会被一并带进「几个参数一起调」。

**效果靠多少段买点撑着**：分辨得出的改动会写明「某年掉出 N 段、新增 M 段」和「买点数是改前的 x%」。如果改进只靠每年几十段买点的进出撑着，一两段的运气就能左右结论，要打折看。

**稳不稳**：把股票重新抽几百次、每次重做一遍筛选，看各参数被选入的比例，以及选入的参数和这次完全一样的比例。比例低，说明这次选中谁有很大的偶然性。

## 三、几个参数一起调：三个分数怎么读

只把筛选里分辨得出的参数（以及和它们一起改会互相影响的参数）放在一起调，找「自己好、相邻组合也好」的组合：每个组合在各年分别和现在这套参数比，取最差的一年，再和只差一档的相邻组合取最差。结果同时给三个分数，**并列呈报、不折中**：

- **朴素分数**：挑出来那一组自己的分数。它一定偏乐观——「挑」这个动作本身就会挑中运气好的。只作参考。
- **扣掉挑选偏差后的分数**：把股票重新抽几百次，每次连筛选一起重做、再重新挑，估出挑选带来的虚高并扣掉。**这个扣减只会少扣**：重抽股票只模拟了「换一批股票」，没模拟「换一段行情」，扣完的数仍然偏乐观，只能当上界看。偏差估出来是负数时，扣完的数不能当保守的数读。
- **对半分验证**：一半股票挑、另一半股票打分。它对怎么分很敏感，**只看方向**，不要拿单次数值当下界。

**判据**：
- 朴素分数为正、扣掉偏差后翻负 → 不构成推荐；
- 三个分数互相矛盾 → 以最保守的那个为准；
- 扣完仍为正，也只说明值得花掉留作最后验证的数据，**不能代替验证**。

**组合样本不够时**：一个组合每年至少要有一定数量的买点 bar（由最小关心改进和优势检查实测的样本牵连程度推出），而且至少 30 段买点，才下结论；不够的标「这个组合买点太少，评估不了」。评估不了 ≠ 坏：它不参与比较，也不当别人的相邻组合；不许为了凑数降低门槛。收紧一档的闸一个买点都没多筛掉时，那个组合和放松一档是同一批样本，也不单独算。

整体样本不够时会直接说：
- **「样本只够一次改一个参数」**：同时改两个及以上参数的组合，没有一个样本够分辨最小关心改进，只在单个改动里挑；
- **「样本只够维持现值」**：改动任何一个参数的组合，样本都不够。

## 四、独立验证怎么读

调参结束后，候选改动要在**两段没碰过的数据**上各检验一次：训练期之前留出的一段（下称「往前那段」），和训练期之后到数据末尾的一段（下称「之后那段」）。两段都和训练期隔开一个前瞻期，在开局核对时就划好，调参期间谁都不看。检验什么、按什么顺序、怎么判，都在打开之前冻结成一份清单。

**往前那段的检验**。按事先定好的顺序逐个检验，选出第一个确认下来的配置。默认顺序是：先这一整套改动，再按训练数据上各改动单独贡献从强到弱逐项退，最后维持改前。含检测参数的配置要确认「比改前好」；只含删闸的，要确认「不比改前差出容忍范围」。这里已经算上了「这次一共验几套」的校正。选出了记**「显著」**，一个都没确认下来记**「不显著」**。

**之后那段：核对**。只核对往前那段选出的配置（没选出就核对整套改动），看它相对改前**有没有差出容忍范围**、**方向和训练期是否一致**。

**两段合起来的六种结论**：

| 往前那段 | 之后那段 | 结论 | 意思 |
|---|---|---|---|
| 显著 | 差出了容忍范围 | 撤回 | 往前那段确认了改进，但最近的新数据上比改前差出了容忍范围 |
| 显著 | 没变差，方向一致 | 采纳 | 两段都站得住，写进正式参数 |
| 显著 | 没变差，方向相反 | 暂定采纳 | 写进正式参数但标暂定，等之后的新数据攒满一年再复验 |
| 不显著 | 差出了容忍范围 | 撤回 | 往前那段没能确认，最近的数据上又变差了 |
| 不显著 | 没变差，方向一致 | 暂定采纳 | 写进正式参数但标暂定，等没碰过的数据攒够再确认 |
| 不显著 | 没变差，方向相反 | 不写进正式参数 | 已经在正式参数里的维持暂定、不撤回，等之后的新数据攒满一年再复验 |

之后那段差出容忍范围时不看方向，一律撤回。

**幸存者偏差**：往前那段的股票池里，没有那些之后退市的股票。开窗前会用训练期里「日后陷入困境」的股票，估一下这会让往前那段的读数偏多少；超过 1 个点，往前那段的确认只按「暂定」算（记为「不显著」），以之后那段为准。

**预期把握**：开窗前，按训练期的效应（扣掉挑选带来的虚高）和那段数据里的买点量，估出「这次验证能把改进确认下来的概率」。**把握不到一半时，会先停下来问你**：
- 往前那段只能开一次，也不会随时间变长。把握不足时打开，大概率得到「不显著」，这段数据就白白用掉了；
- 之后那段会随新数据积累变长，等一等，把握会上升；
- 现在开还是等，是业务决定。你没有明确同意之前，不会打开。

**两段数据用掉之后**：
- 两段各只能按这份清单开一次。开过就记为已用——哪怕定案时你整体否决、维持现状，也照样算用过。
- **不能在同一段数据上换别的候选再验**：看过一次结果再换候选，挑选偏差又回来了，结论会偏乐观。
- 两段检验的不是同一个配置时（例如先开了之后那段、它核对的是整套改动，往前那段后来选出的却是单项改动），给不出合并结论。
- 定案时只能确认写入，或者整体不写、维持现在这套；不能换成别的配置，也不能只写一部分。

## 五、什么时候不该信结果

1. **一致性验证没通过** —— 硬红线。一次扫描的结果按参数事后归类，和每种参数组合单独重跑的结果，必须按「同一段买点只计一次」逐项对上。对不上，所有读数都没有意义。
2. **底子没证实** —— 优势检查判「还不能确定」时，后面每个「有用」都要带着这句。
3. **只在一个时间段成立** —— 标了「两年明显不一样」「时好时坏」的，多半是那段时间的特有现象。
4. **扫描结果再生不出来** —— 当前代码已经产不出那份数据，基于它的结论没法复现，我会主动告诉你。
5. **这一轮中途代码、底座或衡量尺子变过** —— 从变动那一步开始的结论要重做，我会告诉你是哪几步、大约要多久。

## 六、哪些数字只是估计

- **优势检查里「能分辨多小的改进」**：改一个检测参数后大约还保留多少买点，用的是只在一个走势上标定过的经验比例；筛选之后会换成实测值。
- **幸存者偏差的大小**：「往前那段里之后退市的股票占多少」是事先定下的取值，不是实测。

## 七、什么时候该推翻我的结论

- 我说「找到稳健区域」但三个分数互相矛盾 —— 以最保守的那个为准。
- 我给的参数值落在扫描范围的边缘 —— 说明真正的好区域可能在这个范围外面，该重新扫一个更宽的范围。
- 我报的提升幅度没有随机日基线对照 —— 孤立数字不能下结论，问我基线是多少。
- **同一批数据已经挑过很多轮** —— 挑得越多，最终数字越乐观。定案时我会告诉你这组参数在训练数据上一共被比较过几次。
