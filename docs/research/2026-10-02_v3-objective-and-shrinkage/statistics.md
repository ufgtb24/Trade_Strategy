# 统计证据怎样进入 v3 的优化目标

日期：2026-10-02。范围：目标与证据的分工、重抽窗口的含义、回拉评分的适用范围。只做方法研究与代码核对，没有读取真实验证数据、运行真实参数搜索或修改算法。

## 核心结论

Optuna 应寻找“根据现有证据，预计最有使用价值”的参数。使用价值决定要估计什么，统计方法帮助避免高估这个价值。它们不是两个各占一半、随手加权的独立目标。

买点数量有两种作用：能否给有限资金提供足够可用机会，以及我们有多少证据判断买点质量。前一种会饱和，后一种也取决于新增信息是否相关、是否重复。不能把总行数直接当成无限加分项。

用户提出的“单月窗口内中位数，再取窗口中位数”是有明确含义的时间聚合方式：不让买点密集的少数月份仅靠数量支配分数。但它不等于估计误差已经得到处理，也不等于从两年数据生成了 200 次独立市场经历。

建议采用“一项明确业务主量 + 对该主量的一次可靠性校正 + 少数真正不能妥协的底线”。两种基线都要参与评估，是否进入主分则由它们代表的实际选择决定；不建议把空间、方向、数量、两种超额表现与若干置信度全加成一个大公式。

## 1. “统计上所有指标都是多多益善”需要怎样修正

在研究同一个目标、数据仍适用、测量方式一致的前提下，更多独立信息通常让判断更精确。这里的对象是“信息”，不是“所有指标”：

| 增加的东西 | 为什么可能有帮助 | 为什么不保证更好 |
| --- | --- | --- |
| 新买点记录 | 可能帮助判断这类买点平均怎样 | 同股连续买点、同日同类股票、重叠后续区间常携带重复信息 |
| 新历史月份 | 可能增加不同市场经历 | 很久以前的规律可能不适合未来，混合后也可能改变原来要估计的目标 |
| 重抽次数 | 让给定历史上的数值计算更稳定 | 重复利用同一批历史，不增加市场证据 |
| 方向比例、上涨空间 | 可能表示实际表现更好 | 一个只是方向，一个是潜力；不能仅因某一个更高便断言组合赚钱更多 |
| 显著程度或“更有把握” | 可能表示更容易排除无差别 | 很有把握的小改善仍可能没有多少使用价值 |

统计效力是一个检测程序发现指定大小差异的能力，不是策略收益本身。它受差异大小、噪声、样本规模和比较次数共同影响。不能让 Optuna 通过追求“最容易证明”替代追求“最值得使用”。有关样本量和精度的关系可参照 [NIST 样本量说明](https://www.itl.nist.gov/div898/handbook/prc/section2/prc222.htm)；低信息量下被挑出的漂亮结果可能同时夸大改善幅度、甚至方向错误，参照 [Gelman 与 Carlin 原文](https://stat.columbia.edu/~gelman/research/published/retropower_final.pdf)。这些是方法依据，不是对当前市场数据做出的检验结论。

一个简单推论：把“优势 / 估计误差”作为主分，会倾向选择非常确定但极小的优势，而不是一定选择预期使用价值最大的参数。这种分数适合回答“多容易识别”，不自动适合回答“应该买哪一种”。

## 2. 四种不同问题不能用一个“稳定性”笼统代替

1. **真实表现随时期变化。** 同一种买点在某些月份本来就更有效；是否接受这种专门化是业务选择。月度中位数偏好大多数时期有效，可能不奖励只在少数机会期非常有价值的规则。
2. **估计不准。** 一个窗口只有少量买点，算出的窗口中位数可能偏离该类机会的真实水平。这不是数据损坏，完整数据也有这个问题。
3. **历史不再适用。** 同样准确描述旧数据的参数，对接下来的市场也可能失效。加大旧样本或反复重抽不能自动解决。
4. **随机计算的不稳定。** 随机选 200 个窗口而不是枚举全部合法起点，结果会随种子变化。增加抽取次数可以减少这一项，但不能直接改善前三项。

因此不能把 200 个窗口分数的离散程度直接解释为“当前参数估计有多不准”：里面既有真实时段差异，也有各窗口样本少产生的误差，还有大量重叠。若要推断未来，仍须说明历史与未来有什么关系；若目标只是描述固定两年数据，随机抽窗口主要是在近似这个有限历史量。

保留相邻日期联系来估计误差有理论依据，但相应方法存在平稳性、相关长度等条件，不能把任意窗口重抽都视为已有保证。参照 Künsch 的原始论文 [The Jackknife and the Bootstrap for General Stationary Observations](https://doi.org/10.1214/aos/1176347265)（作者上传摘要和正文入口：[作者原文页](https://www.researchgate.net/publication/2355926_The_Jackknife_And_The_Bootstrap_For_General_Stationary_Observations)）。本研究没有验证这些条件对项目数据成立。

## 3. 对选中 shrinkage_score 的统计解释

`BreakoutStrategy/mining/threshold_optimizer.py:60–115` 对组合分组，先按原始中位数取前几名，然后把各组中位数向全局基线回拉。简化后为：

```text
调整后成绩 = 基线 + 证据权重 × (观察成绩 - 基线)
证据权重   = 样本数 / (样本数 + 固定常量)
```

含义是“样本少时，不充分相信它与普通水平有很大差别”，不是“收益和数量分别加分”。若观察成绩高于基线，证据增加会提高调整后成绩；若低于基线，证据增加反而降低成绩，因为我们更确信它差。样本数的效果本就不应永远向上。

这个思路有价值，但这段实现只能被称为一种工程化回拉规则：

- 它没有使用标签噪声大小、相关结构、时段覆盖或近期适用程度；相同记录数会得到相同权重，不代表实际可靠度相同。
- 它回拉的是中位数，没有在这里给出使该公式成为中位数最优估计的模型或推导。注释写着 James–Stein 不构成理论保证。
- 它先按未经校正的中位数挑前几名，可能把校正后应当胜出的组提前丢掉。对搜索与最终选择应使用同一真正目标。
- 全局基线也是由样本估出来的，不是天然无误差的常数；而该流水线数据语义还决定它究竟是哪种“普通水平”，不能直接挪作新 v3 的同日普通买入对照。
- 200 个重抽窗口不能充当这里的样本数。换种子重复同一历史，也不能提高权重。

收缩极端估计以缓解挑选偏高结果有扎实统计动机，但它依赖哪些案例可以相互借用信息等假设；不能把“用过回拉”理解为“搜索偏差已消失”。参照 [Efron：Tweedie’s Formula and Selection Bias](https://pmc.ncbi.nlm.nih.gov/articles/PMC3325056/)。本文针对具体分布模型推导的方法不能未经验证直接移植给当前重叠窗口中位数。

## 4. 回拉、取较保守的下界、设底线，是不同事情

**回拉**试图给“真实价值是多少”一个较少被噪声夸大的估计。若设计为对没有特异优势的回拉，零应对应“相对选定对照没有额外优势”；不能不辨单位就把正的上涨空间直接向零压。

**取较保守的下界**是在估计之外再偏好“即使有误差也较少失望”的参数。这反映如何看待不确定性；比用点估计更谨慎，不代表在所有业务损失下都更正确。它不等于以前“附近最差参数”的评分，但也不该未经说明就变成另一种过强保守。

**设底线**表示低于某条件便不能采用，即使别的成绩高也不能补偿。例如确实无法支持使用的机会不足、方向明显恶化。应分清业务底线与证据底线：一个决定能不能用，一个决定当前能知道多少。

这些机制可组合，但每层必须有单独理由。不要先因记录少把主分回拉，再因同一记录少减一遍分，最后又要求所有对照的保守下界都过关，称之为“没有代价的全面”。这可能主要偏好常见、变化小的规则。

## 5. 两种对照怎样参与，才不会把目标偷偷换掉

普通买入回答“同样市场背景下，筛选股票是否增加了价值”；固定 BO 对照回答“这个复杂 pattern 相比一种简单策略是否值得”。两者都值得算，但不是两份独立加分凭证。

若候选参数改变买点日期，普通买入的同期成绩也会变化。此时绝对表现与相对表现可能排序相反：候选 A 表现 12%、同期普通买入 10%，候选 B 表现 8%、同期普通买入 3%。A 的绝对空间更大，B 的筛选增量更大。哪个更应优先取决于要保留市场时机收益还是更强调筛选贡献，统计学不会替用户决定。

因此，不能同时说“绝对空间仍然是原来的目标”又将相对优势加进主分而不承认目标改变。也不宜无理由相加两种对照优势；两者共享 pattern 表现及部分市场背景，会重复计量。

比较应尽量在共同的时间窗口、相同股票池准入、标签口径与成本假设下进行，并保留相互对应关系。应先在每个对应窗口算比较量，再聚合；一般不能把两个全局中位数相减当成“典型窗口差”。基线无 BO 买点时，相关条件买点统计未定义，不能默认对照为零或判 pattern 自动获胜。

不能每个窗口事后挑普通买入和 BO 中成绩更好的一个作为部署基线，除非真实部署也有只用当时信息决定二者的规则；否则创建了看完未来才知道选谁的过强对照。

## 6. 最简可解释架构建议

1. **先定义业务主量。** 有完整资金、持仓和出场规则时，用规则真正能获得的表现评估。尚无完整交易规则时，明确当前是在优化买点潜力，而非已兑现收益。前瞻收益的项目定义见 `path2/CONTEXT.md:141`。
2. **确定需要回答的比较。** 两种对照统一计算。若主任务是选股规则的增量价值，可以将对照后的价值作为主量；若主任务是带择时的整体交易效果，使用整体交易价值，同时把对照作为替代方案比较。避免临时混成一个没有业务解释的加权分。
3. **只对选定主量做一次可靠性校正。** 保留日期与股票相关关系，考虑真实覆盖和结果噪声；回拉依据在训练范围内预先校准。具体公式尚待验证，不能用重抽次数或任意等价记录数替代实际误差。
4. **保留少量真正不可补偿的约束。** 机会是否足够、风险或方向是否不可接受。通过后的额外机会数不自动无限加分。若更大的实际供给确有价值，由容量和持仓规则反映。
5. **所有候选都以同一评分与约束搜索、选定。** 明确训练内这是带选择偏好的优化，不把训练内很稳定当作已经证明未来有效。完整流程仍可能从大量候选中挑到运气成分；搜索以外的新证据才承担最终检验作用。

空窗口要依主量处理：若主量为“命中买点的上涨空间”，无买点就是未定义，不能当零收益；若主量为“这一时期按明确交易规则产生的组合收益”，无交易可以自然记录持币收益，仍需明确定义现金表现与成本。两者不能混用。

### 当前阶段可审议的具体候选

在还没有完整退出及资金分配规则的阶段，可以暂以“证据校正后的绝对上涨潜力”为主分：每个窗口把 pattern 观察到的潜力，按可靠程度向同期普通买入水平回拉，再对这些校正后的窗口分数取中位数。固定 BO 用于判断增加复杂 pattern 是否值得，作为替代方案或有业务依据的底线，而不再与普通对照的差值一起无限加分。

```text
窗口校正分 = 同期普通买入水平
           + 可靠程度 × (pattern 观察潜力 - 同期普通买入水平)
主分       = 各个可评价窗口的校正分中位数
```

这里的可靠程度尚未校准，不能直接等同于窗口买点数，也不能让 Optuna 选择“少打折就高分”。该候选比先汇总再回拉多了一层明确判断：每个窗口的观察精度不同，先分别处理，避免少量买点的偶然成绩在外层得到完整一票。

同时必须标清其限度：

- 它是“先校正窗口、再取典型表现”的工程预测分，不是已证明无偏的原始双中位数改良；“各窗口后验均值的中位数”一般不等于“窗口真实中位数的后验均值”。
- 回退水平和 pattern 观察潜力都存在估计误差，且可能相关，需在成对比较里一起考虑；不能把股票池很大解释成所有日期背景都确定。
- 同期普通买入因候选命中日期不同而变化，会保留一部分市场时机收益，甚至偏向牛月；这是绝对潜力目标允许的结果，不是消除了市场影响后的纯增量。
- 若观察潜力低于普通水平，回拉会抬高它的分数；这符合“不充分相信弱证据的差异”，但说明回拉并非只向下惩罚幸运。
- 无买点窗口不能填入普通买入水平并当作 pattern 的成绩。少量有效窗的中位数仍须连同真实覆盖报告。

以上可作为新 v3 的研究起点，尚不足以直接替换正式实现。

## 7. 当前证据界限与团队交叉核对

- 以上是第一性原理推导、代码核对和一手统计资料支撑的设计评估，不是已经跑通的新评分算法。
- 未证明双中位数优于其他聚合，未定回拉常量、窗口长度或机会地板，没有把数字决定交给用户。
- 与应用研究员一致：有限资金使机会价值饱和；缺出场与分配规则时不能把潜力说成实盘效用。已直接交流空窗口和重复惩罚问题。
- 与公式研究员一致：选中的旧公式有正确的“证据弱时少相信极端值”直觉；原始记录数、原始中位数先筛选及基线语义妨碍直接复用。已直接交流回拉次数、基线排序反转与双重计量问题。
- 没有真实市场副产品达到预设登记线，因此不向 `docs/feature_candidates.md` 添加推测。
