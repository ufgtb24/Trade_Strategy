# 研究副产品登记簿（feature 候选队列）

> **性质**：跨任务、持久、只追加。与 `docs/research/`（临时、可删）相反——本文件是 feature-study 的假设队列，
> 报告可以丢，登记不能丢。**登记 ≠ 结论**：每条在被换样本验证前，状态一律 `exploratory`。

## 规则

- **登记触发**（写在 CLAUDE.md）：研究任何任务时，凡是**过了预设判据、但不属于本轮主假设**的发现——新变量、方向反了的闸、错的基线——都登记；不限于"上涨规律"。登记前先 grep 本文件防重复。
- **谁关闭**：只由**换了样本**的验证（feature-study / tune-gates）回写状态与报告链接；**登记人不得关闭自己的条目**（发现样本对该条目已烧掉）。
- **不删只压缩**：关闭的条目压成一行移到「已关闭」段；积多了整段挪到 `docs/feature_candidates_archive.md`。**待验证段不删。**
- **自包含**：口径必须写到**公式级**（`pos = close[t]/max(high[t-20..t])`，不是"价格位置"），报告链接失效后仍能判断"新发现是不是它"。（教训：`2026-07-19_tb-geometry-label` 报告已丢，只剩"回撤相对深度"一句，与 `pos` 是否同一个量已无法核对。）
- **合并**：`.gitattributes` 已设 `merge=union`，多分支并行追加不冲突；已有条目不要回头改（改状态走"关闭"流程新写一行）。

## 字段

`ID · 名称 · 口径（公式级）· 方向 · 效应量 + 过了哪些门槛 · 发现样本（哪批 / 窗口 / n）· 原构造目的 · 已知纠缠/反驳 · 状态 · 发现报告 · 验证报告`

## 待验证

### FC-001 · 买点日 ATR%(20)
- **口径**：`rolling_atr_pct_nanmedian(high, low, close, 20)` 在 buy_date 当日取值（与 FPR 阈值同源）
- **方向**：低波动 → fr 更高（按三分位：低 0.533 / 中 0.212 / 高 0.156）
- **效应量**：低−高 Δfr median **+0.378**，bootstrap 95% CI [+0.075, +0.463]；FPR_k6 Δ +0.422 CI [+0.156, +0.667]，k=4/5 同向；标记率 33%
- **发现样本**：bb_v1 112 行买点，2025-09..12（`2026-08-16_news-sentiment-path2-integration/repro/full_metrics_20260816-193657.json`）。⚠ 该样本在当前代码上**不可精确复现**（36/107）
- **原构造目的**：红队给外部通道定"增量"门槛（陷阱 4-4 波动率混杂实测），不是找 feature
- **已知纠缠/反驳**：与 FC-002 纠缠（Spearman −0.324），控制 pos 后 CI 跨 0 但子样本 n=28、MDE≈0.5 ⟹ **本样本无法分离二者**；已排除机械分母解释（换分母 +0.368 几乎不变）
- **状态**：`exploratory`（事后、未预注册、跑了 6+ 个对照）
- **发现报告**：`docs/research/2026-08-26_unpriced-catalyst-channels/final_report.md` §3.3；细节 `red_team_review.md` §4-4b~d；脚本 `repro/vol_confound_on_112.py`

### FC-002 · 买点相对近期高点位置 pos
- **口径**：`pos = close[t] / max(high[t-20..t])`（锚**滚动 21 日最高价**，不是形态 peak）
- **方向**：贴近高点 → fr 更高（三分位：深回撤 0.139 / 中 0.345 / 贴近高点 0.559）
- **效应量**：贴近高点−深回撤 Δfr median **+0.420**，CI [+0.125, +0.900]；标记率 33%
- **发现样本**：同 FC-001
- **原构造目的**：为**杀死** FC-001 而造的机械替代解释的操作化（假说：ATR% 高 ⟹ close 在局部高位 ⟹ 分母大 ⟹ fr 天然低），结果方向相反、杀不掉，顺手量了它自己
- **已知纠缠/反驳**：与 FC-001 纠缠；可能只是 **tb 企稳判据松紧的代理**（bb_v1 买点即 tb 节点）——但 FinChannel 实测买点距 burst 终点中位 2 bar、上限 7，tb 已贴上限、无收紧余量，故更可能来自 burst 自身几何。⚠ 与已丢失的 `2026-07-19_tb-geometry-label`（"回撤相对深度主信号 +0.279，26–38% 甜点"）**表面相反、无法核对**：二分 vs 倒 U / 锚点不同 / 测量对象不同，三条理由指向不矛盾但未证实
- **若成立的行动项**：改 pattern 内部（pos 纳入 where / 调 tb 企稳），**不是**外接数据源
- **状态**：`exploratory`
- **发现报告**：同 FC-001；脚本 `repro/atr_mechanical_check.py`

### FC-003 · burst 量能闸 `vol_spike_min` 可能过紧（10 → 6）
- **口径**：`bb_v1` params `burst.vol_spike_min`：至少一根 bar 量能 ≥ 63 日均量 × N；比较 N=10（现行）vs N=6 新增买点
- **方向**：放宽后**新增**的买点 FPR **高于**基线（0.588 vs 0.461）——闸拦掉的那批比留下的还好
- **效应量**：Δ +0.118，CI (+0.011, +0.221)；9 个 (k, h) 组合全正、4 年全正、2024+ 通过
- **对照**：同轮 `first_drought_min` 40→25 放宽新增买点 FPR 0.407（9 组合全负）——**旱期闸是好闸别松**，两道闸方向相反
- **发现样本**：bb_v1 五年全量扫描，窗口 2022-09-01..2026-06-19，基线 789 买点 / 481 票；松闸为纯增量（789 → 超集，基线一天没动）
- **原构造目的**：TrackC 测"松 where 闸能否**提前**买点"（结论：结构上不可能，where 只在 solve 阶段生效，松闸只能多买不能早买）
- **已知纠缠/反驳**：⚠ FPR 有效 n 是票数不是买点数（ICC 0.87），CI 是否 cluster-aware 需回查；单 pattern、单参数、未与其它 where 阈值联动扫
- **若成立的行动项**：交 tune-gates 重扫该闸（报告原话："交还 tune 线，不建议直接改参数"）
- **状态**：`exploratory`
- **发现报告**：`docs/research/2026-08-26_fundamental-gate-vs-anchor/final_report.md` §4.1

### FC-004 · [对照基线] bb_v1 相对随机日：非匹配对照下更差，同波动率层匹配后更好
- **口径**：随机日基线按买点日 ATR% 分三层匹配后，层内 Δ(bb − 随机) FPR
- **方向**：非匹配 bb 0.444–0.461 < 随机 0.510（表面无优势）；**匹配后最高波动层**（bb 103/110 行在此）Δ = +0.030 / +0.017 / +0.071（k=4/5/6 三 k 全正）
- **效应量**：幅度 +0.02~0.07，与营收信号同量级、远小于 FC-003；低两层 bb 仅 2 行 / 5 行，CI 未算 ⟹ **方向性证据非定量**
- **发现样本**：bb_v1 110 行 + 24,975 随机抽样日
- **原构造目的**：TrackB 构造随机日基线（本意是给外部通道当对照）；TrackA 复核
- **登记理由**：不是 feature，是**基线口径**——记下来防止下次再用非匹配对照得出"bb 无方向优势"（本轮两轨同时被这个 artifact 骗过，摘要里已带限定句仍误读）。任何 bb vs 基线的比较**必须按波动率层匹配**
- **状态**：`方法结论，不进 feature-study`；待有人算 CI 后可升级为定量
- **发现报告**：同 FC-003，§4.2

### FC-005 · [bb 特有] 买点前有无 XBRL 财务读数（「财报序列厚度」）
- **口径**：buy_date 前是否存在任何 point-in-time 可见的 XBRL 季度财务值（营收/CFO/净利润任一）；三分 `G_ok`（全有）/ `G_partial` / `G_none`（全无，占 23.8%）
- **方向**：有读数 → FPR 更高
- **效应量**：有 − 无，年 × 波动率层内：FPR k4 **+0.184** [+0.066, +0.301] · k5 +0.201 [+0.061, +0.333] · k6 **+0.236** [+0.084, +0.377]；三 k 同号排除 0；逐年 2023–2026 全正；2024+ 一致 k6 +0.182 [+0.008, +0.350]；作用面 23.8%
- **不是马甲**：G_none 与 G_ok 的 ATR%/pos 几乎同分布（0.079 vs 0.082 / 0.924 vs 0.923）；四层全控 +0.240 [+0.074, +0.412]；只用价格 k6 −0.001、只用成交额 −0.143 都跨 0
- **发现样本**：bb_v1 五年扫描 789 买点 / 481 票（同 FC-003）
- **原构造目的**：TrackB 预注册要求「无财务读数样本单独归类并报告其 FPR 与基率对照」——是**处置策略**不是候选；量出来过了线
- **已知纠缠/反驳**：⚠ **全宇宙复核符号相反**（TrackA：k4/5/6 = −0.026 / −0.023 / −0.024）⟹ **bb 池内特有的选择效应，不是「有财报的公司表现更好」**，措辞禁止外推。⚠ 「无读数」内部异质（TrackC 五类拆分）：真 pre-revenue（1059 票）方向最好幅度最差；年报-only 外国申报人（572 票）方向一般幅度最好；`rev_no_shares` / `not_yet`（正常报营收的美国公司、序列薄）FPR 0.380 / 0.390 与无读数侧一样低 ⟹ 测的是**财报序列厚度**而非公司种类。**跟进须双轴（种类 × 厚度）拆开，不做二值闸。** 两轨在 `no_facts` 格逐位吻合（202 行 / 56 票 / 0.3670）
- **若成立的行动项**：砍 23.8% 信号换约 +0.05 方向率，划算与否取决于仓位周转约束（报告不拍板）
- **状态**：`exploratory`（bb 池内；差值+CI 类，本轮四次撤回全是此类读数）
- **发现报告**：`docs/research/2026-08-26_fundamental-gate-vs-anchor/final_report.md` §2.3；细节 `track_B_gate.md` §5、`track_C_anchor.md` §9.1、`track_A_calibration.md` 跨轨复核

### FC-006 · bo 当根「收盘越过前高的幅度」excess_h
- **口径**：`excess_h = close[t] / max(high[t-20 .. t-1]) - 1`（分母窗**不含当根 t**，长度 = bb_v1 的 `bo.total_window=20`）；回归前 winsorize 到 1%/99%
- **方向**：**负** —— 突破幅度越大，未来 40 日 first-passage 方向越偏下行（追高受罚）
- **效应量**：控制 `drought` / `peak_age_max` / `pk_count` / `log M` 后 beta = **−0.269**（因变量 fp_score∈{−1,0,1}，k=5、horizon=40），cluster-robust t：股内簇 **−7.00**、40 交易日桶 **−4.79**（两维同号且 |t|>2）。分箱亦单调：excess_h 高分位组 FP(up−dn) −0.110 vs 低分位组 −0.064。基线对照：全宇宙随机日 FP(up−dn) −0.023（同一 M、同一 k、同一 horizon）
- **发现样本**：bb_v1 现役 bo 流（`peak_measure=high`、`breakout_measure=close`，params.yaml 实参），2000 只股票 / 2021-01-01~2026-03-08 / n=24662 bo（`docs/research/2026-08-31_pk-as-event-and-multi-measure/repro/s5_shared.csv`）
- **原构造目的**：不是找 feature——它是为回答「`shared`（两个 pk_measure 都触发）组的优势是不是只在复读突破幅度」而造的 **measure-free 控制变量**；主假设（多 pk_measure 有无增量）判定为**无**，这个对照变量自己过了线
- **已知纠缠/反驳**：⚠ 与 **FC-002**（`pos = close[t]/max(high[t-20..t])`，方向为**正**：贴近高点 → fr 更高）口径高度相似但**分母窗含当根**、**label 不同**（fr median vs FP 方向）、**样本对象不同**（bb_v1 的 tb 买点 110~112 行 vs bo 全流 24662 行）。两者符号相反，**未核对是否同一个量**——追这条必须先把 (含当根 / 不含当根) × (fr / FP) 四格拆开量，否则会把口径差当成发现。⚠ 同一回归里 `log M` 亦强负（t −10.79 / −5.03），与 FC-001 同向，excess_h 与波动率的分离未做专门检验
- **状态**：`exploratory`（事后、单窗、样本内；发现样本已烧掉，验证须换样本）
- **发现报告**：`docs/research/2026-08-31_pk-as-event-and-multi-measure/q2_measure.md` §2.3 §6；脚本 `repro/s5_shared_is_new_info.py`
