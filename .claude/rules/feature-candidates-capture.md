# 研究副产品登记

每次研究都有一个主假设，和一条判断它成不成立的及格线（例如「CI 不跨 0 且三个 k 同向」）。研究过程中还会顺手量到很多**不是主假设的东西**——用来做对照的变量、要排除的混杂因素、为了反驳某个结果而造出来的变量、某道现有的闸、某个基线口径。**其中任何一个如果也过了这条及格线**，就是副产品，必须追加登记到 `docs/feature_candidates.md`（不新建文档、不只写在本轮报告里；登记前先 grep 防重复）。

两条限制：及格线必须是量它**之前**就定好的，不能事后为它现编一条；本轮没明确定过及格线的，用最低线——有基线对照，且 FPR k∈[4,6] 或 fr median 的 CI 不跨 0。

每条必带：**公式级口径 / 方向 / 效应量与过了哪条线 / 发现样本 / 原本是为了什么目的量它的 / 状态=exploratory**。登记的人不关闭自己的条目——只由换样本的验证（feature-study）回写状态。登记 ≠ 结论。

副产品为什么会出现：因为把对照变量当候选一样认真量、把「也许其实是 X 在起作用」的 X 真的造出来量了——坚持这两个习惯就够了，不要为找 feature 单独立项。
