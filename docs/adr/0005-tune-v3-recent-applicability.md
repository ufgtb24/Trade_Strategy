# v3 选参优先服务近期交易

2026-10-01 用户明确选择近期适用优先：较早的数据可以提供支持，但不能主要靠过去的好成绩掩盖近期优势减弱。代价是可用于判断近期效果的证据更少，更容易得到尚不能确定的结论。

近期优先必须进入事先固定的选参和采用规则，而不只是报告中的补充说明。主要成绩是近期加权的方向成绩相对同日普通买入对照的优势，机会数量保留相对原参数的下限；较早与较近时段的范围及作用须在比较候选前规定，不能根据某组参数在哪段时间表现更好再改变。具体历史长度、近期安排、下限和复核时机由实现者研究并核对，用户不负责确定数值。

近期训练数据与最后验证数据分开，不能因为强调近期就把最后留出的最新数据提前用于选择参数。

实施入口：`.agents/skills/tune-gates-v3/SKILL.md`。已完成合成数据下的行为验证，未据此宣称真实市场效果或优于旧版。
