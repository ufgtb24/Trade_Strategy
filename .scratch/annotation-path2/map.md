# 用看图标注做出 path2 pattern

## Destination

用户能通过看图标注得到较好的 path2 pattern：在没碰过的数据（2026 年起）上胜过同日普通买入。本地图终于一份规格加拆好的开发任务，覆盖结构化标注、app 盲看清单、串起「图 → 代码」循环的技能、现有技能改成以标注为输入、没碰过的数据上的检查与数据墙、两台机器的同步、「至少 k 条成立」组合子与复合事件写法约定、旧看图工作流代码的搬与拆；用这套工具做出第一个 pattern、写具体的 detector 都不在图上。

## Notes

- 总原则（2026-10-23 用户定）：结构化标注今后是构建 path2 pattern 的唯一方式，一切为结构化标注服务。各票拿不准时，按「怎样让标注直接变成 pattern、让 pattern 直接对回标注」来取舍。
  - 语言仍然需要，但只作为挂在图上某个位置的附注：新概念第一次出现时的一句话、盲看点「不是」的理由、pattern 想抓什么的一句话。脱离图的语言不能直接改 pattern：技能要反问「在哪几张图上看到的」，转去标注或指出已有标注。防的是：改动没有对应的例子，改完无法检验，以后的改动把它改坏也查不出。只调参数取值（tune-gates-v3）不受影响。
- 起点：`docs/research/2026-10-23_annotation-path2-direction/方向讨论.md`（下称「方向文档」），2026-10-20～10-23 与用户谈定的结论全在里面，各票按它来，不重新论证。要点：
  - 训练段不记账、随便看；2026 年以后的数据永远不给看；只有没碰过的数据上的检查要记次数（方向文档第 2 节）。
  - 七步流程：找图 → 标注 → 写 app → 拿 app 对标注 → 盲看 app 抓出来的图 → 调参数 → 最后检查；只有最后一步判输赢（第 3 节）。

  - 一个 node 包容多种特征用复合事件，path2 现有机制够用（第 7 节）。
  - 结构化标注：用用户自己的词画框和放样本，会话翻成 path2 的 node / where / 边写进 mapping；对照时和显示用同一套画法；一次标注可以有多个 pattern，先看特征和先定目标分阶段配合，合不合并看骨架（第 8 节；细则见票「结构化标注：存什么、界面和主视图怎么合」）。

## Decisions so far

- [在要用的地方量一条特征：现有工具能不能直接做](issues/05-measure-in-context.md): 复用 tune-gates-v3 的计算代码（不用其调参命令），同一评价器带 / 不带各跑一遍、多出来的和同日对照比；四选一报结论，「看不出」附样本量与能分辨的最小差别，「看得出没多大用」默认不并；k 不变；约 300 行待补
- [训练段用多长：样本多，还是和现在的市场像](issues/02-training-range.md): 默认 2021-10-08～2025-12-31 全部，不切；保留 v3 的近期加权；各工具读同一个训练段设置；成绩按半年拆开、最近半年单列；改训练段须有证据，不许按行情像不像或成绩好看来挑

- [标注、mapping、app 产出与对照：各环节东西的命名](issues/14-naming.md): 一名一格；sample（positive / negative）、box、dag、node / where、hit、event；match 改指 hit 与 sample 的比较、全仓改名另立；买点只留 app 一侧；英文为规范名，起名规则在 GLOSSARY-MAP；成员框须在样本日或之前结束
- [界面显示的对称与统一](issues/15-display-consistency.md): 计数一律数样本、正负对偶写 `pos k/N · neg m/M`；汇总写比例、点开分排写个数；凡数样本的数都能点开；样本卡在哪都挂同一组 tag；数为 0 也显示
- [结构化标注：存什么、界面和主视图怎么合](issues/01-structured-annotation.md): 标注是主视图的一个模式（annotate / compare / app）；框用用户自己的词、词表跨图共用；样本标 pos / neg，依据是样本日或之前结束的成员框、换样本后冻结；会话写 mapping、翻译与定级归会话；对照三层只给状态（tier / link / match tag），不比起止、不给数字
- [旧看图工作流代码搬什么、拆什么](issues/10-old-code.md): 2026-11-02 用户改定：不搬，整体删除、不要账本；path2_web 调试视图只读训练段副本、硬截到 2025-12-31；截副本改成独立脚本；新工具要用的旧做法从提交 79a379a 找参照重写
