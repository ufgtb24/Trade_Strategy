# 数据使用记录

本实验使用现有本地股票文件，但不把这次开发检查称为新鲜最终验证。

1. 在任何行情读取之前，已检查 `docs/sample_usage/bb_v1.jsonl`，并写入固定协议和33组参数。虽然当前 app 是 bottom_burst，仍沿同谱系保留旧 bb_v1 的2022–2023及2026确认范围。
2. 全部价格运算先裁切到2024-01-01..2025-12-31，各段再裁到它自己的标签尾部；检测进一步裁到买点截止日。2024上半年供回看，首个买点日期2024-07-01。没有用旧保留区间作预热。
3. 本地 pickle 整文件反序列化不能避免内存读取后段字节；本报告只能保证后段没有进入检测、价格指标、标签或成绩统计。
4. 首次单股载入只检查了列名与索引类型。股票结构筛选后，8只股票曾在正式 `claim_development` 入口登记之前做纯计时试算，已计算标签和买点但没有查看其成绩。对此不能声称“所有标签均先登记”；这8只数据一样视为已开发。正式全池比较之前，已在 `docs/sample_usage/bottom_burst.v3.jsonl` 登记2024-01-01..2025-12-31完整开发暴露。
5. 按固定hash序选取256只；依次检查308只，40只缺完整交易日期、12只OHLC边界异常被排除。排除仅按数据完整性，不因策略表现。通过者的价格快照摘要见 `sample_manifest.json`。
6. 2024–2025价格已在旧bb_v1研究大量使用，本轮两个后段也将用于选择评分实现。因此即使后段表现提高，也不能按独立最终验证解释；未创建最终验证/复核虚假预留。
7. 两个搜索段存在重叠、参数之间高度相关、各月窗口大量重叠。同股票同日和相同买点集合已去重，但不因此获得独立样本量。没有将256股票、33候选或数百窗口直接当成独立证据数。
