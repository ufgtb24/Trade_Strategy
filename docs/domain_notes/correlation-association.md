## Spearman 秩相关（ρ / Spearman's rank correlation）

**一句话本质**：把两个变量各自换成排名（秩），再对排名算普通 Pearson 相关——衡量**单调关系**的强度与方向：一个变大时另一个是否稳定地也变大（或变小），不要求直线、不关心幅度。

**怎么算**：每个变量各自从小到大排名次（并列取平均秩）→ 丢掉原始数值，对两列名次算 Pearson 相关系数。等价读法：ρ≈排名贴合度——ρ=1 表示 n 个样本在两个变量上的名次完全一致，ρ=0 表示名次互不相干。

**数值怎么读**：+1 完全单调递增；0 无单调关系（注意 0 ≠ 无关系，U 形这类非单调结构它看不见）；-1 完全单调递减。经验上 |ρ|>0.8 就当作「同一个维度的两种刻度」。

**何时用 / 为何用它**：分布偏斜、离群值极端、或数据本来就是名次/等级时，Pearson 会被极端值拉走，ρ 只看名次、天然稳健——如收益分布带 8 倍尾巴、连阴天数只有 0-5 几个离散值这类场景。

**局限**：丢掉间距信息，说不了「升多快」（排序对幅度不敏感）；看不见非单调结构（先升后降记 0）。

**典型用法（研究语境）**：共线性诊断——两个特征 ρ=0.86 意味着一个的信息几乎被另一个覆盖，同时放进过滤规则没有额外收益（2026-08-18 tb revert 研究：连阴天数与回踩时长 ρ=0.86，连阴假设的高分大半是时长借来的）；反之两个低相关维度（跌幅烈度 vs 量能比）才值得做 AND 组合。判定特征的独立信息量，比判定特征与标签的关联更常用它。
