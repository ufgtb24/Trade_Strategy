# v3 的评分方法实验与正式调参分开

已被 [0007](0007-tune-v3-ranking-shrunk-matched-lead.md) 取代：排名不再使用重抽，改为按证据打折的相对同日普通买入对照的优势；按股票重抽只用于报告偶然波动。下文保留为历史记录。

2026-10-01 修订的 v3 设计边界：固定候选参数后重抽训练样本、复用逐日结果并重新汇总，可用于评估候选对样本变化的敏感程度，不以先运行对半分实验为前提。用于比较搜索评分方法的对半分属于开发 v3 时的可选实验，不是每轮正式调参前后必经的步骤，也不是允许启用重抽的门槛。正式调参使用已固定的评分规则与 Optuna 搜索，最终采用另用未参与方法开发或参数挑选的数据验证。

重抽的评估用途与把重抽信息纳入排名是两件事：前者不要求对半分实验许可；后者仍需明确评分含义、固定抽样安排、核对样本是否足够及计算是否稳定，不能仅凭能反映样本敏感程度就声称必然选得更好。当前实现用固定重抽空间中位数的较低分位参与排名，原始空间另报；默认值是工程起点，尚未证明最优。需要实测比较评分方法时，可在一部分方法开发数据内搜索、在另一部分比较选出的参数；也可使用预先安排的时间拆分或已知真实效果的模拟。反复指导方法修改的数据不再提供最终独立证明。

这一边界保留了重抽的直接用途，避免把一个有明确评价意义的操作变成依赖先导实验才能启用的流程；代价是仍须单独研究怎样把不确定性转成排名，不能以理论用途代替搜索效果证据。若开展方法比较，应明确实验预算与数据用途。将来修改评分方法可重新开展开发实验，不能复用其成绩作为最终独立验证。

实施入口：`.agents/skills/tune-gates-v3/SKILL.md`。已完成合成数据下的行为验证，未据此宣称真实市场效果或优于旧版。
