# 找一个能选股的优秀 pattern

## Destination

得到一个 path2 pattern 及其配套买卖规则：每天盘后在用户的目标股票池（中小盘、价位偏低）里扫出一份候选名单，用户看图挑（约每周买一只），按配套规则买卖。整套交易的结果——典型的一笔和平均的一笔——都明显胜过同一池子里同日随便买、按同一套规则买卖的对照（大优势，默认值见「照这份数据的分辨力，判优标准和终点要不要调」），在训练段成立，并在只用一次的验证段上看得出；之后靠每日名单存档在新数据上接着核对。本地图终于一份可交给实施的规格——做哪个 pattern、它的走势语义、配套买卖规则、判优的尺子、验证与后续核对方案（含没过时回到哪个决定）；建 app、调参、跑验证归实施票（看图工作流的最小工具是例外，见 Notes），仓位不在图上。

## Notes

- 领域：path2 走势 pattern 的选股能力。用词以 `path2/CONTEXT.md` 为准（查词用 grep 定位后只读那一段）；对用户说话按项目 CLAUDE.md「白话解释」的约定。用户是策略方向的决策者：阈值、窗口这类数值先取默认并标「待验证」，不交给用户定。
- 判优尺子（2026-10-07 改定，见「照这份数据的分辨力，判优标准和终点要不要调」）：判整套——pattern 加配套买卖规则，按规则算每笔交易实际赚多少，典型的一笔（中位数）和平均的一笔都要明显赢对照；对照 = 同一天、同一目标池里随便买，按同一套规则买卖（同日普通买入对照 `path2/CONTEXT.md:155` 的推广）。起点价格一律用次日开盘价（名单盘后才出）。首次穿越（`path2/CONTEXT.md:148`）与前瞻收益（`path2/CONTEXT.md:141`）两把尺子保留作体检，不当门槛；随机日基线和收益绝对值只报告、不判优。大优势在验证段上算数的六个条件见那张票结论第六节。
- 想法来源（已定）：文献里有记录的量价规律 + 用户看图时信的形态 + 从数据里系统地挖（2026-10-07 加入：用户认为公开的规律和常见形态里的优势多半已被做掉）。用户不信任文献，文献只作低权重参考，重点在用户的形态和挖数据。挖数据守三条纪律：①挖之前先定好最后检查用的数据，挖时绝不碰；②事先列清要试哪些、试了几条都记账；③只认最后检查那段数据上的结果。只在目标股票池里挖，素材是现有 detector 产出的走势事件与日线量价特征（含登记簿里已有的候选）。K 线以外的信息（如新闻）也可以融合（2026-10-07）。现有 pattern（bottom_burst、bb_v1、bo_only 等 app）已废弃，不当起点也不当参照；框架与底层 detector 可当零件。看图找规律按「看图找规律的工作流怎么设计」定下的流程做。
- 目标股票池（方向已定，具体口径由「候选名单的规格」定）：中小盘、价位偏低。用户的理由四条都有——价格高了买不起几股、觉得这类票涨得猛、觉得大资金少碰机会没被做掉、习惯熟悉。落到口径上：低价是一条价格上限（默认 20 美元，待验证），不刻意往更低价钻；数据里没有市值，中小盘只能拿成交额近似，并用成交额下限去掉买卖困难的微型股；「涨得猛」由池子本身满足，判优尺子照样扣掉波动带来的成绩，不因此改尺子。事实：2026-10-05 价格低于 10 美元的约 2300 只，其中约 1400 只日成交额不到 100 万美元。历史上的「当时价格」：数据文件只存复权价，按复权价设价格上限会把后来反向拆股的股票错放进来或挡出去，要靠拆合股记录还原（下载脚本取到过但没存）。
- 范围（2026-10-07 改定）：任何走势都可以，可以新写 detector、改框架；可以融合 K 线以外的信息（如新闻，来源见「能接哪些外部信息：从哪来、历史多长、会不会偷看未来、花多少」）；每个 pattern 配自己的买卖规则；仓位不在范围内；不补退市数据或更长历史（用户决定）。
- 图内建造的例外（2026-10-07 用户同意）：「走哪条路」要靠看图找规律的工作流才选得出，所以「做出最小可用的看图工作流」这张任务票在图内动手做；其余建造仍归实施。
- 按需调用的 skill：涉及评估或下好坏结论 → 照项目 CLAUDE.md「编码规范」里的评估纪律（它提到的 eval-discipline skill 并不存在）；验证某个特征 / 形态与后续涨跌的关系 → `feature-study`；走势结构设计 → `authoring-path2-app` / `authoring-path2-detector`；调参相关的输出照 `tune-gates-v3` 第三节的人话译法表说。
- 数据纪律：凡是读 pattern 成绩或特征之后涨跌的实验（包括挖数据），都不得碰「最后检查用哪段留着没碰过的数据」划定的时段；那张票解决之前，只做不读任何 pattern 成绩的计算。bb_v1 已废弃，它预留的两段确认窗不再单独保护，由「最后检查用哪段留着没碰过的数据」统一安排。看图也算读涨跌：那张票定稿前，看图只看训练段（默认 2024-01..2025-12，见「看图找规律的工作流怎么设计」）。
- 报告规矩：任何 pattern 或特征的成绩，都同时报一份去掉 2022 年的版本（2021～2025 年价量信号的成绩主要靠 2022 一年撑着，见「文献里哪些量价规律扣掉波动率和大盘后仍能选股」）。
- 数据现状：`datasets/pkls/` 共 5778 只美股，2021-10 至 2026-10-05，全是仍在交易的股票（没有退市股）。
- 研究中顺手发现、过了及格线的副产品，写进所在票的 Answer，经用户批准后再登记到 `docs/feature_candidates.md`（规则见 `.claude/rules/feature-candidates-capture.md`）。
- 过往研究给的背景（现有 pattern 已废弃，以下只作教训）：bb 系过去的好成绩大多是在读波动率；bottom_burst 现在这套参数对同日对照的方向领先约 +0.006，偶然波动约 ±0.04，看不出选股能力；bb_v1 的研究结论是现有几个条件怎么组合都提不上去，要更准得找新判据。

## Decisions so far

- [这份数据能分辨多大的选股优势](issues/02-resolution.md): 分辨力看命中了多少只不同股票，而非买点数；照 bb 的扎堆程度、每年 1000 个买点、用满 4 年，方向领先要约 0.12、幅度约 4 个百分点才看得出，0.05 以下怎么都看不出；只有买点分散到上千只不同股票时门槛才降到 0.03～0.05。全市场口径，目标池另算。
- [文献里哪些量价规律扣掉波动率和大盘后仍能选股](issues/03-literature-patterns.md): 文献效果放到本项目尺子上普遍偏小，2010 年后多半减半，近年剩下的主要靠 2022 一年；几条与 bb「底部 + 暴涨」直接相反；候选清单交「走哪条路」，用户不信任文献，只作低权重参考。
- [幸存者偏差会把哪类 pattern 的成绩抬多高](issues/04-survivorship.md): 落在「要限定股票池」一档；底部类贴着「要补数据」的边，创新高类可忽略；池子按成交额和当时价格定、不按复权价；越近的数据越干净；留一条实施阶段验证项。
- [目标池里的分辨力和幸存者偏差有多大](issues/09-target-pool-resolution.md): 池子够大，门槛与全市场相同、仍看买点长相（4 年：扎堆约 0.12，分散约 0.03）；池子挡不住底部类的幸存者偏差，挖数据落在「要补数据」一档（一个简单组合就白得约 0.10）；推荐默认池为普通股、当时价格 ≤20 美元、日成交额 200 万～1 亿美元（待验证）。
- [照这份数据的分辨力，判优标准和终点要不要调](issues/12-criterion-vs-resolution.md): 优秀要能被证实；不补数据；目标改大优势（默认典型一笔每月多赚 3 个百分点以上，待验证）；废弃现有 pattern；外部信息与配套买卖规则进范围、仓位不进；判整套，对照用同一套规则，起点次日开盘；验证段只用一次，名单每日存档。
- [能接哪些外部信息：从哪来、历史多长、会不会偷看未来、花多少](issues/13-external-info.md): 先接三类免费信息——SEC 公告事件、SEC 财务数字、FINRA 空头持仓；一律按信息被接收的那一刻用；新闻免费的取不回训练段、社交讨论有删帖偏差，暂不接；大盘涨跌在同日对照下单独造不出领先，只能当「什么时候用」的条件。
- [看图找规律的工作流怎么设计](issues/14-chart-workflow.md): 最小可用、尽快转起来；圈＝找大涨段（按拿得到的涨幅相对自身波动排、显示原值、自动分组）→ 在 path2_web 多图标注里标出形态 → 会话生成的对照页（数表加赢输并排图集）→ 收紧或放弃并记账 → 训练段达到大优势默认值且逐年同号才毕业；所有页面只显示训练段。

## Not yet specified

- **选中方向的结构设计**：拓扑、要用和要新写的 detector、where、参数初值；要等「走哪条路：选哪个方向进入设计」定下来。可能需要一张原型票，在看图工具里看命中是否符合用户的意图。
- **动手建之前的便宜验证**：选中方向的核心假设（比如某个特征和先涨方向有没有关系）先用一次小实验检查，决定值不值得建；具体检什么取决于方向。
- **最后检查方案**：比几次、怎么判过、没过时回到哪个决定重来；取决于留哪段数据和选中的方向。
- **每日候选名单怎么产出**：扫最新一天、名单格式、怎么接到看图工具；取决于名单规格和 pattern，可能现有扫描就够用。
- **实施阶段待验证：幸存者偏差**——完整条目（验什么、何时触发、怎么判、验证前能做什么、没过怎么办）在「幸存者偏差会把哪类 pattern 的成绩抬多高」的 Answer「留待实施阶段验证」一节，进规格时整条带上。「目标池里的分辨力和幸存者偏差有多大」修正了其中两点：限定股票池消不掉这份偏差，兜底只能靠最近一段数据的最后检查，或补退市数据；触发条件扩大到挖数据（挖数据整体落在「要补数据」一档）。是否补数据由「照这份数据的分辨力，判优标准和终点要不要调」决定。
- **配套买卖规则怎么设计**：选定方向之后，按那个 pattern 的长处配买卖规则；规则里引用 pattern 自身结构的部分怎么让对照也能套用，见「同日对照怎么配对才挡得住白得的领先」。
- **外部信息怎么接进 path2**：现在 path2 只读单只股票的 K 线。先接的三类（SEC 公告事件、SEC 财务数字、FINRA 空头持仓）和接入规矩（按接收时刻、公告类特征只对本土公司定义、SEC 数据按公司编号取）见「能接哪些外部信息：从哪来、历史多长、会不会偷看未来、花多少」；框架怎么改，等选定方向确实用到时再定。

## Out of scope

- 仓位、同时持有几只：买卖规则已纳入（2026-10-07），仓位仍不在图上，每只买多少由用户自己定。
- 补退市数据或更长历史（Sharadar 5 年档 / 全历史档）：用户 2026-10-07 决定不买，证实靠没碰过的历史数据加以后的新数据；外部信息本身已移进范围。
- 以随机日基线（含择时）或收益绝对高低判优：尺子定为整套对同日对照。
- [现有 pattern 在判优尺子下的底子](issues/07-existing-baseline.md)：现有 pattern 已废弃（见「照这份数据的分辨力，判优标准和终点要不要调」），盘点它们的底子不再服务终点，按范围外关闭。
