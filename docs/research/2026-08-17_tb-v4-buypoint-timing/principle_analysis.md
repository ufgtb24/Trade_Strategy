## 1. 推演一:burst 积累了什么?回踩深度与卖压存量的关系(用户质疑 ①)

### 1.1 burst 结束时刻的持仓者结构

burst = 底部区域放量突破前高(ABOS:1.2x→1.77,broken peaks,量比 ~10x)。此刻持股者分四层:

1. **底部获利盘**(1.2-1.4 买入):浮盈 30-50%。持有久、成本低,止盈动机随浮盈放大(处置效应;且对这类低位股,理性上「解套/翻倍减半」是常规纪律)。这是**最大的存量卖压**,但触发条件是心理价位,不急。
2. **解套盘**:burst 打破的前期高点套牢者,在突破位上方解套——供给墙在突破位上方密集分布,**触发位集中**。
3. **burst 追高盘**(bo 根附近买入):浮盈薄、止损紧,是回踩第一波急卖压的来源,量小但速度快(决定回踩第一根的斜率)。
4. **波动率状态切换**:底部低波 → burst 高波(巨量长实体)。高波态吸引短线资金(他们的离场是后续卖压)、放大价格对任何信息的反应幅度。

「回踩深度」度量的是其中 **3 类(急卖)已被释放的部分 + 1/2 类被触发释放的部分**。

### 1.2 「惯性」的正确微观含义

用户说「大幅下跌有惯性要消化」。从微观结构翻译:**卖压释放有正反馈性**——下跌触发追高盘止损,止损制造更深的下跌,再触发更高成本层的止盈/解套,即「下跌-止损」级联。深回踩 ⟹ 级联已运行 ⟹ 已释放卖压多。

由此可得用户度量(跌幅/涨幅比)的原理依据与它的边界:

- **成立的部分**:跌幅/涨幅比 ≈ 已释放卖压占获利盘深度的比例的代理。比例高 ⟹ 级联已走过 ⟹ 残余卖压趋薄 ⟹ 「企稳等待」有真实对象(等级联熄火:不刷新计数、量能萎缩)。比例极低 ⟹ 没有级联可等 ⟹ K 根不刷新的等待是在等一个不存在的过程——**用户直觉「浅震荡不该被强制等待」在「等待语义」上成立**。
- **失效的部分(关键)**:浅回撤有两种微观解释,(a) 卖方主动单规模持续小于买方承接,卖压被时间缓慢吸收(真稳);(b) **卖压存量完全未触发,双方观望,价格没跌到任何心理触发位**(假稳)。跌幅/涨幅比区分不了 (a) 和 (b)。而 (b) 的存量一点没少,触发器只需时间或一次反弹到供给密集区。**ABOS 正是 (b)**:258-263 浅震荡(存量未动)→ 264 反弹到 2.25(进入解套/止盈供给区)→ 10 月下旬派发崩塌到 1.55,涨幅全部回吐。
- **推论**:「浅回撤 ⟹ 无惯性 ⟹ 可直接买」作为无条件规则不成立;成立的形式应该是条件式的——浅回撤的「稳」需要**别的证据通道**补位(见 §3 清单 B/C/D),否则浅回撤只是「下跌被推迟」而非「下跌不存在」。
- **失效场景清单**(什么走势浅回撤但仍有大跌风险):①存量未触发型(ABOS 型:浅震荡后反弹入供给区再崩);②消息驱动型(利空未落地,横盘是暴风雨前);③低流通/庄控型(无量横盘,出货靠后置)。共同点:**浅回撤时,已释放≈0,风险完全取决于未观测的存量与触发器**。

### 1.3 对 UP→DOWN 刚性触发的原理判定

现状:任何阴线或收跌都转 DOWN,DOWN 内做「滚 trough + 衰竭计数」。用户观察的正确内核:**DOWN 态的全部功能(找底 + 等衰竭)对浅震荡是空转**——浅震荡的 trough 不断被 -0.5% 级别的碎步微刷新(刷新即清零 count),或等值徘徊,机器把预算花在数一根根「可忽略」的 bar 上。

但注意柔性化的正确变量不是「跳过等待」,而是**承认浅回撤需要不同的确认路径**:深回踩的企稳证据是「级联熄火」(不刷新计数——现状逻辑),浅回踩的企稳证据只能是「横盘本身 + 承接/量能信号」(幅度带内直接判稳)。这不是放松标准,是**换证据类型**——因为浅回踩语境下「不刷新计数」这个证据的语义是空的(没有级联,谈不上熄火)。风险闸门:浅回撤直接可买的正当性完全依赖 empiricist 验证 §4-P2/P3(浅回撤买点的 fwd 分布不劣于深回撤企稳后),否则它就是把 (b) 型假稳放进买点。

## 2. 推演二:V 反弹(DOWN→UP)何时是企稳证据(用户质疑 ②)

### 2.1 反弹根度量的是流量,不是存量

DOWN→UP 不产段的裁决理由是「未经卖压衰竭证据的反弹不给买点」。原理层拆开:

一根长实体阳线带下影无上影(ABOS 261)度量的**当日买卖力对比**:低位有承接(下影 = 买方在低位接走卖压)、收盘无回落(无上影 = 收盘前没有新的供给压制)。这是**流量证据**——它说明「这一天买方赢了」。

企稳需要的是**存量证据**——卖压存量已被释放或确证枯竭。流量强 ≠ 存量空。反弹的两种成因在当根 K 线上不可区分:(a) 承接资金主动建仓(买方强);(b) 卖压暂时停顿 + 空头回补/短线抢反弹(供给只是歇了)。

**单根形态的信息量是条件性的**:在深回撤语境(级联已运行、存量已释放大半)下,强承接根是「衰竭后需求出现」的确认 → 高信息量(右侧信号);在浅回撤语境(存量未动)下,它只证明当日买方强,对存量无推断力 → 低信息量,甚至偏负面(反弹把价格推向供给区,下一个买点的位置更差;ABOS 261 反弹后 262 立即回落,264 再冲高后崩)。

用户问「261 这根难道不是稳定住的标志吗」——**是「当日稳」的标志,不是「卖压已消化」的标志**。二者在深回撤语境下高度相关,在浅回撤语境下脱钩。

### 2.2 mtr 阈值(max_rise_k=1.5)过严吗

原理上,1.5×median-TR 的反弹臂是一个「流量显著性」阈值(这根阳线是否超出噪音)。它不过严——它甚至经常不够严(F3:vol 抬高后阈值失真)。真正的问题不在阈值水平,在**rise 臂触发后的处置**:转 UP + 不产段 + 等待全部归零,把一次有信息量的强承接事件完全丢弃。261→262→263 的空转(反弹、回落、重新数一根)是纯等待损耗。

### 2.3 左侧 vs 右侧的代价结构(「STABLE 才可买」vs「STABLE+UP 都可买」)

- **STABLE-only(现状,右侧确认)**:代价 = ①价格成本(确认花时间,时间 = 价格漂移;ABOS 263 段已是 +12% 位,267 段是 +36% 位);②机会成本(反弹足够快时 rise 臂抢道,整轮错过——t1 时代 rise-before-confirm 杀 30.6% 召回的历史教训,t4 已把「判死」修成「不产段」,但那一轮的买点仍然没了)。收益 = 过滤直接破位的 burst(83-93% 机器最终 break——企稳等待的真正价值在**否决**,不在**买得更安全**)。
- **STABLE+UP(用户方向,左侧/更早)**:省价格成本与机会成本,付假阳风险(存量未释放的反弹被当买点)。适用面:追求 first_passage 早兑现、能承受路径回撤的风险偏好。
- **原理层关键(ABOS 单案例坐实的结构)**:确认机制的回撤保护来自「否决掉 83-93% 的破位机器」,**不来自「确认后的买点本身更抗跌」**。一旦确认发生在反弹半山腰(F3 的 267 型段),价格成本直接吞掉全部回撤保护——确认得越晚、位置越高,「右侧」的伪安全越强。即:**右侧确认的保护是事前的(过滤),不是事后的(入场位)**;入场位由「enter 价相对 trough 的偏移」决定,这是一个独立于确认逻辑的量,现状状态机对它无任何约束。
- 由此推论:**「STABLE 才可买 vs STABLE+UP 都可买」可能是个伪二分**。真正该控制的是买点的价格位置与证据充分度的组合:低位(贴近 trough)+ 流量证据即可买;高位(远离 trough)必须存量证据(深回撤+衰竭)才可买。低位早买在 ABOS 上同时赢了 max 和 min——因为它的风险敞口本来就由低位界定。

## 4. 可检验预测(供 empiricist 验证;按证伪价值排序)

用 t4 已产出的机器/段为样本(20260817T142145.json 全量 214 命中,窗内;B2 去重纪律按 (symbol,date)):

- **P1(存量→风险)**:机器级,burst 涨幅(burst span 涨幅或 burst 量能累计)与 machine_outcome=break 概率正相关;与段级 fwd40_min 深度负相关。〔原理 §1.1-A〕
- **P2(浅回撤买点的分布——用户命题的正面检验)**:把「段 enter 时回踩深度/burst 涨幅 < 0.2」的浅组 vs ≥0.5 的深组对比 fwd40_max / fwd40_min / 首越+5% 率。用户命题预测浅组不劣;我的原理预测(a/b 分解)预测浅组内部方差大、若能加「横盘期量能萎缩」子条件则浅组显著改善。〔§1.2〕
- **P3(V 反弹根的条件信息量——质疑②核心)**:所有 rise 臂触发根(DOWN→UP 不产段的那些 bar)作为虚拟买点,按此前「回踩深度/burst 涨幅」分浅/深两组比 fwd。深组(V 反弹 = 衰竭后需求)应显著优于浅组(存量未动的反抽);若无差异,则「V 反弹一律不产段」的裁决失去原理支撑,「STABLE+UP 都可买」在数据上复活。〔§2.1〕
- **P4(买点价格位置——F3 漏洞的普遍性)**:段 enter 根 close 相对 trough 的偏移与段 fwd40_min 负相关;偏移高位段(267 型)与偏移≈0 段(263 型)分层后 max/min/破段率差异显著。**归一尺度(2026-08-17 与 architect 裁定后修订):burst_gain 归一(θ_e = (close[enter]−trough)/burst_gain)为主、vol 归一双尺度对照**——理由:vol(i) 尺度与 F3 污染源(vol 被反弹后大 TR 抬高)同窗同参数、闸随污染同向松弛(267 偏移/vol=1.05、rise 臂阈值 2.42>2.33 坐实同窗失灵),burst_gain 机器常数后窗不可污染;且闸的保护量(fwd min,百分比浮亏)与百分比输入直接同构;与 B 通道 θ 同尺度族。数值裁决归 empiricist 双尺度对照。〔§2.3〕
- **P5(等待的语义空转度)**:浅回撤语境(跌幅/涨幅<0.2)的机器,DOWN 态内「刷新幅度 < 0.3×vol 的微刷新」占全部刷新的比例——量化「count 反复清零、预算空转」的普遍性;若占比高,UP→DOWN 柔性化(幅度带判稳)有真实收益面。〔§1.3〕

P2/P3 是用户两个质疑的数据化核心:P2 成立 ⟹ 柔性化①正当;P3 成立 ⟹ 柔性化②正当;P1/P4 是与用户方向无关、但原理层要求的独立风险闸(A/F 通道)。

### 4.1 θ(消化度)基准裁定(应 architect 之问,2026-08-17 补)

浅回撤度量有两个候选基准,裁定为**双层结构、各司其职,不是二选一**:

1. **burst 涨幅基准 = 消化度 θ,用于换轨判定**(浅/深回撤分流,即用户质疑①的判据)。原理:vol 只标定噪音尺度、不标定存量;同样 -3% 回撤在 +35% burst 后(θ=0.09,几乎没消化)与 +8% burst 后(θ=0.37)存量意义完全不同,vol 基准下二者无差。θ 语义 = 已释放卖压占存量代理的比例,分母必须是存量本身(burst 涨幅 = 获利盘深度代理,§1.1-A)。
2. **vol 基准 = 动作真实性闸,用于噪音过滤**(P5 的 <0.3×vol 微刷新识别)。回答「是不是真动作」,不回答「消化了多少」。
3. **消化度定义建议累计口径**:θ = (peak − trough)/burst_gain,peak 用全程累计口径(INV-2 已裁决的单调 peak,零新状态);burst_gain 用 measure 口径(spec §5/Q4 一致)。避免引入「本 DOWN 轮起点」类新状态——用户语义是「burst 后累计经历的大跌」,累计口径天然匹配。

3. **P2 部分对+量能方向反**:(i) 拐点在 dd≥0.5×burst 涨幅(浅 <0.2:−0.9% / 0.2-0.5:−0.8% / ≥0.5:−10.9% ep_med)——浅/中回撤段不差,换轨(浅回撤快通)数据正当;(ii) §1.2 的 (a)/(b) 识别猜想**方向反**:浅组内按回踩期均量/burst 期量中位 0.781 分半,**未萎缩组 +2.2% 优于萎缩组 −3.6%**(fp_down 17.6% vs 26.8%)——不是「量能萎缩=卖压枯竭(改善浅组)」,而是**浅回撤+缩量=无承接横盘((b) 型标记)、浅回撤+量能未萎缩=有承接横盘((a) 型)**。bb 池横盘期缩量更可能是关注度退潮(投机资金离场)——没有买方的稳不是稳。此为 post-hoc 反向发现,按 G5 定位零先验新假设,待前向验证。
4. **P1 证伪——burst 涨幅作为「存量风险预测器」无效**:break 率按 burst 涨幅四桶 88.6/92.8/91.1/92.0%(spearman 0.04)、相对量能 −0.05——「burst 后跌破 burst 底」是该池基率特征,与 burst 强度无关。**标尺/预测器分离**:burst_gain 作为消化度分母(标尺,P2 分层有效)成立,作为预测自变量(P1)无效——量纲语义必须分开;与 skeptic「θ₀ 一参多用」警惕同构(burst_gain 也在两用,一用成一用败)。
5. **P5 坐实**:1806 次刷新中 38.4% 为 <0.3vol 微刷新——柔性化①收益面真实、规模约四成。
6. **P3′ 数据中性**:次根(浅 +2.7%)与当根同级,armed+次根版(architect 形式化)的选择按语义定、数据不构成偏好。

**修正后的原理立场汇总**(取代 §5 中被证伪部分):换轨架构三分支全部有数据支撑——浅回撤快通(P2 浅组不差+P3 浅组等值+P5 收益面四成)、深回撤维持熄火确认(P3 深组段根优于 V 根)、θ_e 闸待分桶定生死(普适版已死,尾部版待决);A 通道(存量定价)失去 burst 涨幅代理,(a)/(b) 识别改由量能未萎缩标记(零先验新假设)。

**补记(P4 元教训,skeptic §8.9 提出、本文采纳)**:反向幸存者偏差第二实例——用户从 ABOS 自疑「不满可能是幸存者偏差」,分析师从同一个 267 诱导出「位置失控需修复」,结构同构、方向相反。精确化:机制分析只回答「能不能拦」(267 上偏移闸确实拦得住),全量数据才回答「该不该拦」(拦掉的 38% 恰是更好样本)——**机制可行性与筛选价值是独立问题,单案例机制分析天然给不出后者**。与止跌池证伪的类同:共同根因是单一观测维度对质量的预测力弱;相异:P4 连方向都反了(止跌池只是无增量),教训更重。分桶补查定位:仅档内假说记录,极端档若单独差只复活「p90+ 尾部假说」进 G2 观察,不复活普适闸、不动 final_report「不实施」定案。

## 9. 诚实边界

- §1/§2 是机制推演(微观结构逻辑自洽),非实证;ABOS 数字是单案例展示,幸存者偏差风险用户自己已点明——分布层结论全部押在 §4 的 P1-P5 上。
- 「浅回撤的 (a)/(b) 二分」中,(b) 型假稳的识别(量能萎缩、横盘时长、供给区位)我在原理层只能给方向,有效性未经任何数据检验,且 2026-07 调参曾证伪过「止跌 K 线信号池」——量能通道有被证伪的前科,引入需谨慎。
- 本分析未触碰 t4 六参数的数值域(K/max_rise_k/vol_window),只讨论判据结构;参数级微调(如 mtr 阈值放松)在原理层不解决任何上述问题。
