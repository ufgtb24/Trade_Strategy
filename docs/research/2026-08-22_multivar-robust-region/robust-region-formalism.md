# 多维稳健区的可计算形式化

> 角色：region-formalizer（agent team 成员）。目标：把「多维稳健区」从直觉提升为可计算数学对象——这是整个方法的地基，直接决定 optuna 怎么用。

## 0. 一个统一框架：外推保持 = 对扰动稳健

先立一个贯穿全文的等价关系，它是所有定义的锚：

> **外推 = 训练窗的一个「新扰动样本」。** 未来数据就是训练数据再采样一次（regime 漂移、新股票、新噪声）。因此「外推保持成绩」在数学上等价于「指标对扰动稳健」——对数据扰动、对参数扰动、对时间扰动都稳健的东西，才是外推能保持的东西。

这解释了为什么「找平台/找稳健区」能服务外推：**平台和稳健区都是「对扰动不敏感」的几何对象**。找它们，就是在训练窗上找「对外推扰动免疫」的东西。

由此，「多维稳健区」的三个性质——有体积（反参数扰动）、时间一致（反时间扰动）、中心代表点（反估计误差）——各对应一类扰动，统一在「稳健」一个词下。

## 1. 稳健区的严格定义

设 θ ∈ Θ 是「必须真扫参数」向量（2-4 维，已归一化到各维分辨率），f(θ) 是主指标（FP，越大越好，训练窗完整检测口径）。

**核心洞察：区分「真信号」和「噪声尖峰」的量是体积，不是平坦性。** 一个噪声尖峰可以局部平坦（尖峰顶端），但它的「好区」体积 ≈ 0；噪声要造出一个「大体积的连通好区」，需要同时抬起一整片区域，概率随体积指数下降。所以：

```
稳健区 R = superlevel set 的大体积连通分量
         = 连通分量 of {θ : f_robust(θ) ≥ τ}，满足 体积(R) ≥ V_min
```

其中 f_robust 是「逐点时间一致化的稳健指标」（§2）。**τ 的锚点**：用基线（宽进配置）的指标作 τ——区域 = 「比基线好的一片连通区域」，而不是「比全局峰值略低的一片」。

三种候选定义为何这个最好：

| 定义 | 优点 | 缺点 | 对服务外推 |
|---|---|---|---|
| 水平集 `{f≥τ}`（+连通+体积） | 直接刻画「处处好」，体积直接反噪声 | τ 敏感 | **最好**——体积是反偶然的核心量 |
| 平坦区 `{‖∇f‖<ε}` | 是「平台」的直接推广 | 平坦≠好（低洼也平坦）；尖峰顶端也平坦 | 次——平坦不区分信号/噪声 |
| 等值区 `{diam(f)≤ε}` | 介于两者 | 既不保证好也不保证体积 | 弱 |

**结论**：稳健区 = 水平集（superlevel set）的**大体积连通分量**。平坦性降级为次要校验（§6 后验），不作为区域的定义判据。

## 2. 时间一致性：逐点 min 并入（min-fold 的几何化）

时间一致性的最干净并入方式，不是「先各年取区域再求交集」（那是繁琐的两步），而是**逐点取各年最小值，再取 superlevel set**：

```
f_robust(θ) = min_{y ∈ years} f_y(θ)      # 逐点最差年
R = 连通分量 of {θ : f_robust(θ) ≥ τ}
```

数学等价性（关键，让形式化极简）：
```
{θ : min_y f_y(θ) ≥ τ}  =  ∩_y {θ : f_y(θ) ≥ τ}  =  ∩_y R_y
```
即「逐点 min 再取区域」≡「各年区域求交集」。一个式子同时表达了「区域有体积」和「时间一致」——**f_robust 的 superlevel 大体积连通分量，就是「每年都好、且年年重叠在同一片」的区域**。

这就是上一轮 optuna-designer 的「min-fold」objective 的几何升级：min-fold 是在「单点」上取 min，这里是在「区域」上取 min——后者多了一个「这片区域每年都连成一片」的要求，比单点 min 更强，因为它排除「每年各有一个好点但位置漂移」的情形（那种情形各年区域交集是空的、体积≈0，自动被排除）。

## 3. 体积与形状：为什么各向同性圆区 > 细长区

**体积度量**：连续意义是 Lebesgue 测度；离散采样下用「采样覆盖数」（区域内好点数）或其 r-ball 并集体积近似。

**形状的关键**：一个「细长」区域（沿某参数方向长、其他方向薄）体积可以很大，但它的「有效稳健性」差——沿薄方向扰动一下就掉出区域。所以单看体积不够，需要形状信息。

**正确的不变量 = 最大内切球半径（inradius）**，即区域切比雪夫中心的半径：

```
inradius(R) = max_{θ∈R} min_{θ'∈∂R} ‖θ−θ'‖   # 到边界最远点的距离
```

- 圆区：inradius ≈ 半径（大）
- 细长区：inradius ≈ 薄方向半宽（小，尽管体积大）

**判据：稳健区 = superlevel 连通分量，且 inradius ≥ r_min**（而非仅体积 ≥ V_min）。inradius 同时惩罚「薄」和「小」——它要求区域在每个参数方向都有足够厚度，这正是「对各方向扰动都稳健」的形式化。

（注意：参数空间必须先归一化——每维除以该维的分辨率/step，否则「距离」「体积」「半径」在量纲不同的参数间无意义。）

## 4. 区域代表点：切比雪夫中心，不是重心

代表点（最终采用的参数）应是**切比雪夫中心**：

```
θ* = argmax_{θ∈R} min_{θ'∈∂R} ‖θ−θ'‖    # 到边界最远的点 = 最大内切球圆心
```

- **切比雪夫中心 > 重心**：重心对形状敏感（细长区域重心可能落在「薄」处）；切比雪夫中心定义就是「到边界最远」，对参数估计误差 + 未来参数有效值漂移的容忍最大。
- **为什么中心 > 边缘**：我们估计的 f(θ) 有噪声，未来 regime 会漂移参数的有效最优位置。中心到边界距离最大 = 能容忍最大的「真实最优 vs 估计最优」偏差。这是「选平台中点不选边缘」的多维推广。
- 离散采样下切比雪夫中心难精确算，用「区域内点的重心」近似（区域足够圆时两者接近）。

## 5. 从采样点识别区域：两阶段，optuna 只负责「填空间」

**根本约束**：optuna 只有 20-40 个 trial（每个一次全量 scan），这个密度**不足以刻画区域形状**。所以区域识别必须两阶段：

```
阶段1（optuna 采样填空间）：QMC / 拉丁超立方均匀覆盖搜索域 → 30-50 点，每点算 f_robust(θ)
    → 标出「好点」{θ : f_robust(θ) ≥ τ}
阶段2（候选区加密 + 识别）：
    → 对好点做图连通分量：好点按参数距离 < r 连边，找连通分量，每个分量估 inradius
    → 对 inradius ≥ r_min 的分量，在分量内部加密采样（局部随机/网格）确认「片状」非「散点」
    → 取加密确认后仍连成一片的分量 = 稳健区，代表点 = 重心
```

**识别算法选型**（规模 2-4 维、30-50 点 + 加密后 ~100 点）：

| 候选 | 适用性 |
|---|---|
| **图连通分量**（好点建图，距离 < r 连边） | ✅ **首选**——最简单、对几十点规模稳健、直接给出「连通」「体积（点数）」「inradius 可估」 |
| DBSCAN 聚类 | ⚠️ 对 20-40 点 + 高噪声不稳定，ε 参数敏感 |
| 网格化 + 形态学膨胀腐蚀 | ⚠️ 2-4 维可行但分辨率受限，维数再高爆炸 |
| persistent homology | ❌ 对这个规模 overkill，且需要专家解释 |

**关键洞察（重新构思 optuna 用法的核心）**：

> **optuna 的优化能力（TPE/NSGA-II 找最优）恰恰是我们要放弃的；我们只用它的采样能力（QMC 空间填充）。** 因为「找最优」是在找点，而点是偶然的；「均匀填空间」才能让我们看见「区域」。optuna 作为 QMC 采样器（`sampler=QMCSampler`）的价值远大于它作为优化器的价值——它给我们一个「无偏地覆盖搜索域」的采样网格，区域识别在网格上进行。

这是对「optuna 用法」的彻底重构：**从「优化器」降格为「空间采样器」**。上一轮方案的 objective 还在优化标量（哪怕加了 min-fold/SE 惩罚），本质仍是「找点」；本方案把 optuna 当「均匀采样器」，找的是「区域」。

## 6. 与「选平台不选峰值」的关系 + 平坦性降级

- **一维平台 = 多维稳健区在该方向的投影宽度**。一维切档找平台，是在「其他维固定」的投影切线上找区间；多维稳健区找的是「全空间的一片区域」。前者依赖「其他维固定」，后者不依赖——所以**多维区域从机制上根治切片漂移**（OAT 的切片漂移，本质是「固定其他维」这个前提在参数变化时不成立）。
- **多维区域不自动蕴含「每个一维切片都是平台」**——只有凸/单调区域才保证。但多维区域保证的是更强的、我们真正要的：**区域内任意一点，沿任意方向扰动都还在区域内（或至少不掉太远）**。这是「各向稳健」，比「每个切片是平台」更直接服务外推。
- **平坦性降级为后验校验**：对识别出的稳健区，抽 2-3 个内部点 + 边界点做邻域扰动（真 scan），确认「片状平坦」而非「大体积但是抖出来的」——这是上一轮 flatness 的用法，从「搜索内循环」降为「区域后验确认」，成本可控。

## 7. 未解决的开放点（诚实声明）

1. **τ 锚点**：τ = 基线指标（宽进配置 FP）是自然锚，但「比基线好」的强弱（τ 要不要加边际）需首轮实战校准。
2. **r_min / V_min 阈值**：inradius 下限、「片状」的加密确认标准，都需要在真实 pattern 上标定——纯形式化给不出数值。
3. **采样密度是根本约束**：每点一次全量 scan，30-50 点 + 加密 ~100 点 = 全流程数天量级，仍是成本天花板。这也是「为什么 optuna 该降格为采样器」的另一个理由——采样器只需要「覆盖」，不需要「收敛」，trials 预算直接花在「覆盖」上更划算。
4. **f_robust 的 min 太苛刻**：弱年主导（某年天然低 FP）会让 f_robust 全被弱年压低。缓解：用「各年相对基线的增量」的 min（`min_y (f_y(θ) − baseline_y)`）而非绝对值的 min——这正好对应上一轮的「方向一致」判据，留作区域定义的变体。
