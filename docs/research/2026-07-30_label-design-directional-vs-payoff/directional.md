# directional 立场(v2 · 吸收 skeptic/decoupling 批判后的最终版)

> **本版撤回第一稿的核心论证错误**(§1)。经 skeptic §2.1/§2.2、decoupling §2/§8、H3/H4/H7 批判后重写。立场收敛:方向 label 需要,但理由从「剔除波动率」换成「补 mfr 跌盲区 + 让方向在个案层可见」;v1 主推从「端点收益」换成「min_low」(奥卡姆,与 mfr 同构)。

## 1. 撤回声明:第一稿的核心支柱是偷换概念(诚实认错)

第一稿的论证支柱是「端点收益 span 均值期望中性 ⟹ 剔除波动率混淆」。**这是偷换,必须撤回。** skeptic §2.1 精准点出我混了两个命题:

- **我证明了的**:端点收益对 σ **期望中性**——去掉 mfr 的选择偏差(`max` 选上端,`E[max]≥E[close]`,被 σ 单调抬高),鞅假设下 `E[close[t+N]]≈close[t]`,σ 只移动方差不移动期望。技术正确。
- **我没证明、却当成已证的**:期望中性 ⟹ **单 match 排序不被波动率支配**。这是偷换。

**为什么是偷换**:用户在 web UI 看的是**单个 match 的实现值**并按它排序。单 match 实现值 = `E + 噪声`,噪声的**幅度随 σ 放大**(我第一稿 §2 候选 A 自己写过「σ 决定 close[t+N] 的离散程度」,却没意识到这正好反驳了我的支柱)。高波动股的端点收益实现值散布更大(既出 +30% 也出 −30%),低波动股挤在 0 附近。⟹ **用户排序时,数值大/极端的仍然系统性是高波动股——和 mfr 一样的病,只是病灶从「均值被选择偏差抬高」换成「方差放大致极值更极端」**。

feedback g 项(A.1)的真正内核正是「label 的**方差**由 σ 解释」(R²=0.919),不是均值。端点收益去掉了 `max` 的选择偏差,会让那个 R² 系数变小,但**绝不会到 0**——因为单 match 实现值的散布仍由 σ 决定。

**诚实表述**:端点收益去掉了 mfr 的**选择偏差**(max 选上端),但**没有**去掉波动率尺度对单 match 实现值的支配。波动率混淆的干净解法仍是 feedback 的路子(集合级首次穿越 + 随机日基线 + 波动率倍数披露,不打分),不是 per-match 端点收益。

**这条不否决方向 label 本身**(补跌盲区的价值仍在),只否决它的论证支柱。

## 2. 第一稿另一处低估:漂移漏洞(skeptic §2.2)

第一稿 §3 把单 match 端点收益当「选股纯度诊断」。**这不纯**。单 match 端点收益 +0.10,用户分不清「pattern 选对了」还是「这只股本来就在漂移上行」。这和 payoff 被 feedback §0 批的「联合体」问题**同构**——payoff 混交易参数,端点收益在单 match 层混**市场漂移**。集合级配随机日基线扣漂移 OK,但 per-match 层没有基线,漂移污染无法在单点读数里消除。

⟹ 端点收益是 per-match 层「退而求其次」的方向读数,带折扣,不是纯净的方向诊断。

## 3. 方向 label 的真价值(重新定位,对应 H3)

撤回错误支柱后,方向 label 的价值不靠「剔除波动率」,而靠两条**真实且成立的**贡献:

1. **补 mfr 的跌盲区**:mfr 只读 `high`,值域恒 ≥ 0,看不到负半轴。XAGE 暴跌 −83%、mfr 却 +1.3%(因 40 日内盘中摸过 +1.3% 峰值)——这是 mfr **正确量了它该量的**(上涨触碰潜力,feedback §0 已定案是特性),但用户拿它回答了它不该回答的问题(持有收益/方向)。方向 label 把负半轴还回来,让「暴跌」在数值上可见。
2. **让 feedback 的方向结论在个案层可见**:feedback c 项已证 pattern 方向无优势(首穿 8 单元 7 个低于随机日)——这是**集合级**结论。方向 label 让用户在**单个 match** 上也能看见「涨跌参半、净位移不偏涨」。**这是集合级结论的个案层复显,不是新信息**(skeptic 审查项 5,我接受)。

**绝不能宣称**:方向 label 能产出「pattern 有方向优势」的新结论。feedback 已证没有。方向 label 只会让「没有方向优势」这件事在个案层更清楚,不会推翻它(对应 H7)。

## 4. v1 度量主推:从「端点收益」改为「min_low」(奥卡姆)

这是吸收 decoupling §8 + skeptic 审查项 3 后的核心修正。我第一稿主推端点收益、弃 min_low(候选 B,理由「双极值合成丢顺序」)。**这个弃法有漏洞**:若**不合成、两列独立并列**(像 OHLC 的 high/low),就没有合成问题,各自保留极值语义。

**min_low 作 v1 主推的理由**:
- **零框架成本**:与 mfr 完全同构——`path2/eval.py:39` 的 `high.iloc[...].max()` 换成 `low.iloc[...].min()`,其余(锚 end_node、horizon、span 遍历 `range(start_idx,end_idx+1)`、t+N 越界跳过)逐字不变。
- **解决 XAGE 可见性**:min_low ≈ −83%,与 mfr +1.3% 并列,暴跌不被粉饰。
- **保留过程极值,不丢信息**:min_low 是「路径地板」(区间内最低),不像端点收益只看「落点」(终点)丢掉中间路径。
- **(mfr, min_low) 双端极值的「背离即信号」有 triage 价值**:批量扫描时用数值快速捞出「mfr 高 + min_low 深」的灾难型 match(高波动尖刺),这是逐个点开 K 线做不到的。

**端点收益降为可选净方向增强(YAGNI,v1 不上)**:
- 它回答的是不同问题:min_low+mfr = 上下行极值幅度(路径天花板/地板);端点收益 = 终点净方向。度量维度不同,端点收益**不是 min_low 的冗余**。
- 但 v1 上 min_low 已满足「正负对称披露」的诚实性目标(下行可见);端点收益的「净终点方向」是锦上添花,等用户实际需要「最终涨跌」度量时再加(decoupling §8 共识)。

**精确定义(decoupling §8 认可)**:
```
min_forward_drawdown = mean over 买点窗 t of [ min(low[t+1..t+N]) / close[t] − 1 ]
```
即 mfr 把 `high.max()` 换 `low.min()`,与 mfr 完全同构。无可调交易参数 ⟹ 选股侧(decoupling §2 分界线)。与 mfr 两列独立并列,不合成。

## 5. 与 feedback / c 项的关系:冲突时以 c 项为准(对应 H4)

- **集合级方向判据 = feedback c 项(首次穿越)**:它与幅度解耦、与随机日比,是干净的方向检验。pattern 方向有无优势,以此为准。
- **per-match 方向 label(min_low / 端点收益)= 个案层辅助,带折扣读**:它混了漂移(§2)+ 幅度,是集合级结论在个案层的可视化,不是独立的方向判据。
- **冲突裁定**:per-match 方向 label 与 c 项结论矛盾时(例如某 match 端点收益为正),**以 c 项为准**。单 match 正不等于方向有优势——可能是漂移、可能是少数大涨样本的长尾。

## 6. 与 payoff 的关系:不同层,接受 sim 作交易层 readout

完全接受 payoff 的分层,以及 decoupling/skeptic 对 sim 的硬约束:

- **方向 label(min_low)选股侧,sim(strategy_return)交易侧**,分界线 = 是否引入可调交易参数(decoupling §2)。
- **sim 作独立交易层 readout**,不进选股排名(decoupling §4 / H9)、参数外生固定(H2/H10)、禁扫参(payoff §5.2 红线)、必须与方向 label 配对解读(H1)。
- **识破 sim 的虚假 alpha = 三层(H8),不只靠方向 label 共读**:① per-match 共读(必要不充分,因 per-match 两 label 都带 σ 噪声);② **集合级统计闸是主力**(命中集波动率倍数 + 控 σ 后 sim 条件百分位 + 首次穿越,归选股评估层,复用 feedback c/g);③ UI 标注 sim 的波动率暴露。

**我撤回第一稿对 payoff 的「端到端两模型」反驳中过强的部分**:第一稿说「方向 label 更基础,是 sim 的上游」——这在「真实方向 alpha 利润」意义上对,但不能用来约束 sim 好坏(decoupling §2 裁定:directional 对 sim 既非必要也非充分,§6.3/§6.5 矛盾以「既非必要也非充分」收口)。

## 7. 诚实框定(对应 H7,skeptic 唯一不放的红线)

**本次 label 设计不改变 feedback 的核心负面结论**——pattern 在方向上无优势(c 项)、lift 是波动率而非方向优势(A.1/g)。

新 label 的作用,且**都是负向的诚实化,不是创造 alpha**:
- **止住 mfr 对「无优势」的粉饰**:mfr 只看涨会把无优势粉饰成 +72%;min_low 让「涨跌参半、下行很深」在个案层可见(feedback 负面结论的可视化)。
- **给交易层一个外生投影**:sim 让交易层从抽象变具体。

**绝不是「换把尺子去量出 alpha」**。任何措辞若让用户产生「新 label 可能反转 pattern 评价」的预期,就是给虚假希望、重蹈 feedback §0 警告的「换尺子找 alpha」循环。lead 写 final_report 时,这条应作框定不作脚注(skeptic §7.3)。

## 8. 给 lead 的可执行建议(收敛后)

按怀疑论/奥卡姆排序(边际收益 ÷ 复杂度成本),与 skeptic §7.4、decoupling §8 一致:

1. **先做 min_low**(最小、最高性价比):`min_forward_drawdown`,与 mfr 同构、零框架成本、补 mfr 跌盲区、批量 triage 灾难 match、诚实化「无优势」。**这是唯一该立即实施的**。
   - 实现:`path2/eval.py` 新增 `match_forward_drawdowns`(或复用 `match_forward_returns` 加参数),与 mfr 同签名;注入 `serialize_per_pattern_result` 与 `forward_return` 并列(如 `forward_drawdown`),per-match + per-symbol 聚合用 **min**(最差下行)而非 max。
2. **strategy_return 后做、克制定位**:独立交易层 readout、UI 隔离、参数外生固定、禁扫参、必须与 min_low 共读。不追求独立决策列。
3. **端点收益暂缓(YAGNI)**:min_low 不足以回答「净终点方向」时再补;v1 不上。
4. **mfr 保留不动**:feedback §0 背书 + R²=0.92 诊断价值,补而非换。

## 9. 诚实的局限(收敛后)

- **min_low 与 mfr 同构地继承 σ 方差污染**:min_low 的 per-match 实现值方差同样随 σ 放大(高波动股上下行都深)。它去掉了 mfr 的「只看涨」盲区,但没去掉波动率对实现值散布的支配——这点与 mfr 同病,诚实承认。
- **min_low + mfr 不解决方向判据**:「pattern 有没有方向优势」仍由集合级首次穿越(c 项)判,不由 per-match 极值判。min_low 只让个案可见。
- **方向 label 无法回答「能不能赚钱」**:那是 sim 的领域;sim 也无法回答「策略有没有独立方向 alpha」(虚假 alpha 陷阱)。两者不可互替,须配对解读。
