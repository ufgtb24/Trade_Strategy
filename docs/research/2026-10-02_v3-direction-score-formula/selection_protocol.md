# 选最高分的反例实验：预先写下的协议

日期：2026-10-02。研究用合成估计，不是行情回测，不读取训练或验证数据。

## 问题

对一个候选估计得更合理，不自动意味着在许多候选里选最高分也可靠。本实验检验不同证据强度的候选共同竞争时，回拉是否会改变排名，以及什么情况下它完全不改变排名。

## 比较前冻结的设计

- 使用抽象的方向增量估计：各候选真实增量独立服从均值 0、标准差 0.08 的正态分布；观测分数是该真值加估计误差。它是便于检查机制的连续近似，不声称就是有限股票日三态的完整分布。
- 候选一半误差标准差 0.04，另一半 0.16；每轮随机排列。这里误差强弱已知，不用实际买点数冒充独立样本量。
- 比较预算 20、100、500 个候选，各 5000 次重复，固定种子 2026100204。
- 候选公式：原始观测分；统一乘以 0.5；按候选误差与已知真实差异幅度回拉；把真实差异幅度误设为一半或两倍后的回拉。
- 回拉权重为 `tau² / (tau² + error_variance)`。同一轮候选共有固定基线，本实验取 0，所以绝对成绩与增量排名一致。它不比较“绝对目标”和“增量目标”的业务偏好。
- 另作全无优势 `tau=0` 情景，比较原分、正确回到 0 的模型、错误假设 tau=0.08 的模型。

## 事先规定的检查与报告

1. 同一基线、统一正系数回拉必须与原分逐次选中相同候选；不满足则实现有错。
2. 在所设模型为真、误差已知时，逐候选回拉是对应条件均值；观察其平均选中真值是否高于直接选观测最大。只作该合成机制范围内的证据。
3. 报告赢家真实增量、显示分数与真实增量之差、选中高误差候选比例，以及相对该轮真实最佳候选的损失；不只报告表面最高分。
4. 全无优势时不能通过挑最高分获得正的真实优势。正确模型的全部零分只表示无法在这些候选间分辨，并不保证实际中能知道 tau=0。
5. 使用错误强度的效果必须如实保留。即便已知参数的回拉有效，也不能据此宣称本项目已经能从两年相关历史中准确估计这些参数。
