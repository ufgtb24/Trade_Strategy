# simulator：调参挑选流程的有真值蒙特卡洛

> 本文所有项目内路径相对 repo root。脚本在 `docs/research/2026-09-15_tune-gates-crossfit-simplification-review/repro/`（下称 `repro/`），完整结果表在 `repro/results/*.md`。数据全部合成，没有碰真实长表（`outputs/tune_gates/` 下没有现成长表）。

## 0. 结论

**一句话**：在 bb_v1 量级（效应小于噪声、单参数配对差的年交互约 1 点）下，挑选规则怎么换（朴素取最大 / 现行规则 / 交叉拟合 / 各种收缩排序），对选中点真实增益的影响在 0.3 点以内；真正决定未来表现的是「写不写」这道门。草案的交叉拟合块结构会泄漏行情，「两规则都跑取更高」相当于抛硬币；而「往前那段 + 往后那段按精度合并的单侧优效门」在 N0/N1 下所有曲面都不差于、多数优于现行 validate 的非劣效门。

要点（口径：Q = 首次穿越率点数，U = (首次穿越率 − 基线)·n/(n+n0) 点数；「增益」都是相对维持工作点，真值用平稳真值或独立新抽行情的部署年真值；N0/N1/N2 见 §2）：

1. **选点本身差别小**（§4.1）。Q N1、1～2 点小效应（oracle +1.50）：朴素取最大 +0.83～0.90、草案交叉拟合 +0.72、现行规则 +0.58、一倍标准误 +0.53；4～8 点大效应（oracle +5.99）：+4.47 / +4.24 / +3.67 / +3.43。工作点本身最优时方向反过来：−1.85 / −1.52 / −1.23 / −0.57。U 口径小效应下所有「总会换」的规则都 ≈0（oracle +0.43）。规则之间的差距主要来自「多常离开工作点」，也就是隐含的门控强弱。
2. **草案块结构泄漏**（§4.3）。单一规则的交叉拟合报数减部署年真值：留「股票折 × 年」、其余全训练 Q N0 −0.0 / N1 +2.1 / N2 +4.5 点，只按股票折同样漏；整年留出 −0.2 / −0.2 / −0.3，训练取「其它年 ∩ 其它股票」−0.2 / −0.2 / −0.4，walk-forward −0.1 / −0.2 / −0.3。泄漏占朴素虚高的 28%（N1）/ 49%（N2），与 extrapolation 的闭式预测一致。
3. **「两规则都跑、取交叉拟合更高」应删**（§4.4）。它给报数再加 +1.0～+1.9 点，且选对规则的概率 T=2 为 0.50～0.54、T=3 为 0.52～0.57，是抛硬币。
4. **交叉拟合当「>0 才换」门区分力弱**（§4.4）：有真改进与无真改进时的通过率之比 q1/q0，N1 下留一格 1.4、整年留出 1.8、walk-forward 1.6，不如现行规则的 bootstrap 校正门（2.5）和 ρ·d̄>δ（2.1）。
5. **剪枝必须放进交叉拟合循环**（§4.8 S3）。全数据先剪枝再整年留出，零效应下报数 +0.7 / +1.2 / +2.8 点（τ=0/0.9/1.8），换点率 22%/35%/59%；折内剪枝 ≈0、14%/23%/37%。草案「剪枝不是发现、不需多重校正」在剪枝放循环外时不成立。
6. **半年块只在行情冲击半年内独立时才免费**（S6）。同年两个半年共享比例 r=1、τ=1.8 时半年 4 折报数偏高 +1.9，整年 2 折 −0.1；r=0 两者等价。
7. **U 的数量因子压住了薄格赢家诅咒，但没有带来可得增益**（§4.1）：朴素取最大选中「买点 <0.35×工作点」薄格的概率 Q 55% → U 0～3%。
8. **报数诚实度普遍差**（§4.2）。现行规则的邻域分在 T=2 时近乎无偏（−0.4 / +0.1 / +0.9）纯属两重「取最差」恰好抵掉取最大虚高，T=3 就变成 −1.8；bootstrap 校正过度（−2.6 / −2.1 / −1.1）；对半分约 −7；朴素 +5.7 / +7.1 / +9.0。所有报数与部署年真值的相关，N1 下不超过 0.49、N2 下不超过 0.25——单次报数几乎不含「这次选的点到底好不好」的信息，诚实只能在平均意义上做到。
9. **写入门是主杠杆**（§4.5，v3，Q N1）。合并确认优效门（A1）大效应 +2.05、小效应 +0.17、工作点最优 −0.11；现行 validate（朴素取最大 + 往后段非劣效）+1.31 / +0.12 / −0.17；草案 + 往后段 +1.37 / +0.12 / −0.15。ρ·d̄>δ 直接换（不开确认窗）大效应最高 +2.94，但工作点最优时 −0.32、全平误写 26%。CV 门叠在合并门上只减误写、不增收益。AND 写法（合并优效且往后段 ≥ −δ）比只合并少约 10% 收益，并没有低于现行。N2（强行情切换）下合并门在工作点最优时变差（−0.27 vs 现行 −0.19）。
10. **可信度排序 ρ·d̄ 在嵌套网格上不如朴素取最大**（§4.7）：它系统性偏爱配对 SE 小的格（与工作点共享买点多、或更松），Q 口径 peak 曲面选中格买点数中位 1.33×工作点（朴素 0.26×、oracle 0.19×），平稳增益 +0.51 vs +1.66；mono +1.23 vs +3.18。U 口径两者持平。
11. **写入时报数**（§4.6）：通过显著性门的原始合并估计 Q N1 偏高 +4.5（V2）～+6.5（A1）；截断正态中位无偏校正把均值拉到 +1.2～+1.7，N0 下反而过度（−0.7～−0.8），N2 仍 +4.8～+5.0——校正用的 SE 只含抽样误差，不含行情交互方差。
12. **收缩类在稀疏真效应下丢一半收益**（S7，相加结构）：12 个方向里只有 1 个 +3 点时，ρ·d̄>δ 保留 48%、尖峰加平板 >δ 54%，argmax + 整年留出门 74%；尖峰加平板没能「两头都拿」（工作点近最优时损失是 ρ 版的两倍多）。一旦再叠前向确认窗（SE 2.7），各规则近最优损失都 ≈0、一维 +3 的保留率都跌到 14～25%。

## 3. 对比的流程

| 名字 | 定义 |
|---|---|
| 维持现行参数（K0） | 永远选工作点 |
| 朴素取最大 | 两年合并相对工作点增益最大的格 |
| 现行规则 | 每年相对工作点增益 → 两年取较差 → r=1 邻域取最小（可评估格之间）→ 最高；报邻域分，另报按股 bootstrap（B=40）optimism 校正值、3 种子对半分 |
| 现行规则 校正后>0 | 邻域分 >0 且 bootstrap 校正后 >0 才换 |
| 一倍标准误 | 在「最优 − 其按股 SE」内选离工作点最近的格 |
| 草案交叉拟合 | 块 = 年 × 5 股票折，留一块、其余全训练；峰值 / 平台两规则各算交叉拟合估计，取高者，最终点 = 该规则全数据选点，报该估计 |
| 只按股票折 / 整年留出 / 双向剔除 / walk-forward | 块结构变体：留出股票所有年 / 留一整年 / 训练 = 其它年 ∩ 其它股票 / 用前 o 年挑、第 o 年打分 |
| … + X>0 才换 | 相应估计 >0 才写，否则留工作点 |
| 平滑先验后验（核平滑） | 按股线性化全协方差 + 线性趋势核 + 指数核先验（工作点处条件为 0），边际似然定超参，取后验均值最大；另一版噪声加入由两年分歧估出的时段方差 |
| 两向随机效应 / 配对收缩（ρ·d̄） | unifier 方向 E：σ_μ² = 跨格 Cov(d̂_1, d̂_2)，σ_ξ² = max(0, [Var(d̂_1−d̂_2) − mean(s_1²+s_2²)]/2)，v = σ_ξ²/T + mean s²/T，ρ = σ_μ²/(σ_μ²+v)，d̃ = m + ρ(d̄ − m)，m = 0（工作点中心，即最终版 ρ·d̄）或格均值；逐格水平版工作点也被收缩 |
| 尖峰加平板 | d ~ (1−w)·δ0 + w·N(0,s²)，(w,s) 边际似然取，后验均值排序 |
| 往后段非劣效（现行 validate，「+前向窗」） | 往后段估计 >0 且 估计 − 1.645·SE ≥ −δ（δ：Q 2 点、U 1 点） |
| 合并确认优效（A1 / V2 等 `_m`） | 往前段（含幸存者平移）与往后段按精度合并，合并估计 − 1.645·SE > 0；AND 版另要求往后段点估计 ≥ −δ |
| A2 | 朴素取最大 + 整年留出 >0 + 往后段非劣效 |
| V2cv | ρ·d̄ 排序 + 整年留出（朴素取最大的）>0 + 合并确认优效 |
| E3 | ρ·d̄ >δ 直接换，不开确认窗 |
| oracle | 平稳真值最大的格 |

### 4.11 选候选与开窗前门用不用同一把尺子（v6，设定同 v5，Q 口径，按曲面分开报）

**做了什么。** 推荐形态里，选候选用原始增益 d̄ 取最大，开窗前门却看 ρ·d̄ > δ，两步尺子不一样。这一节把「一把尺子」的完整组合补跑出来，和现有写法在同一批随机数上逐次对比，并新加了一种「真改进在更松、买点更多的格」的曲面，检验旧结论是不是只在「改进伴随买点变少」时成立。

**说明什么。** ①两种写法谁也压不过谁：改用 ρ·d̄ 排序，在「越严越好」和「薄角尖峰」上少拿 0.1～0.2 点，在宽平台和「放松更好」上多拿 0.2～0.7 点（松侧平台版 1.1 点），工作点即最优时亏损一样、开窗率高 3 个百分点。②预先定的「最差落差不超过 0.2 点就换」这条线，判据量正好压在线上（−0.20±0.03），口径自己裁不出来。③终审担心的「取最大挑中薄格、过不了前门、白白空转」确实存在，但只占 1%～6% 的轮次，把它们救回来最多多拿 0.05 点（松侧平台 0.2 点）；两种写法的差别主要来自「两边都开窗、但送去确认的格不同」。④取最大 vs ρ·d̄ 排序的优劣在新曲面上**反转**了，三个层次（不过门 / 只过写入门 / 前门 + 写入门）方向一致。

**不说明什么。** 反转的幅度依赖新曲面的形状：主版本（镜像单调）里紧侧薄格真值很差，取最大本来就不太会选它们，过门后只差 +0.2 点；敏感性版本（松侧平台、紧侧薄格真值为 0）差 +1.1 点。真实世界更像哪一种，模拟回答不了。

**臂。** 四个 R 臂的写入门统一为推荐全式：往前段（含幸存者平移）与往后段按精度合并、每段方差加 τ̂²，合并估计的单侧 95% 下界 > 0，且往后段点估计 ≥ −δ。

| 臂 | 选候选 | 开窗前门 |
|---|---|---|
| R0 | d̄ 取最大 | 无 |
| R1 | d̄ 取最大 | 选中格 ρ·d̄ > δ（= §4.10 的 G1，写入门多了「往后段点估计 ≥ −δ」） |
| R2 | ρ·d̄ 取最大 | 该最大值 > δ |
| R3 | 在 ρ·d̄ > δ 的格里 d̄ 取最大 | 没有这样的格则维持工作点 |
| 现行 validate | d̄ 取最大 | 无；写入门 = 往后段估计 > 0 且非劣效下界 ≥ −δ |

**实现说明。**
- ρ·d̄ 对全部候选格逐格算，公式与 `eb_paired(center="zero")` 完全相同；冒烟时断言过 R2 的候选格与最大值逐次等于 `eb_paired` 的输出，R1 的开窗与 v5 的 G1 逐次相同，R1 开窗时 R3 与 R1 逐次相同，全式写入是 v5 写入门的子集。候选资格沿用现有 mask（每年定向数 ≥ 200、排除工作点）。
- 「d̄ 取最大」的 d̄ 沿用 `rule_peak` 的两年合并增益；ρ·d̄ 里的 d̄ 沿用 `eb_paired` 的两年逐年增益取平均。两者只差年内买点数加权，R3 在过线格里取最大用的是前者。
- 结构上 R1 开窗 ⊂ R2 开窗 = R3 开窗（R1 要求取最大那一格过线，R2 / R3 只要有任一格过线）；R1 开窗时 R3 ≡ R1，所以 R3 = R1 + 「空转时改送过线格里 d̄ 最大者」。
- 新曲面的 sid 接在原 51 个场景之后，原场景随机种子不变：v6 parquet 里 v5 的列与 §4.10 逐数相同（核对过 N1 的 G1 开窗率 22% / 59% / 18%）。`report2.band` 把新曲面单列，旧报告的「小 / 大效应」不受影响。
- 「_c」行记录候选格本身（不过写入门）与是否开窗，用于买点数比与「不过门」层次的对比。

**新曲面「放松更好」。** 网格坐标：where1 档 0→4、where2 档 0→3 都是从松到紧（保留比例 1/.8/.6/.42/.28 与 1/.75/.55/.40），检测轴 5 档买点数相同。工作点 (1,1,2) 在每个 where 维度上只有一档可松，比工作点买点多的格只有 15 个（(0,0,·) 1.67×、(1,0,·) 1.33×、(0,1,·) 1.25×）。
- 主版本 `relax`（进裁决）：mono 的镜像，h = −(z1 + z2)，where1、where2 越松越好；最好格 = 最松角 (0,0,·)，幅度定义同 mono（最好格 − 工作点 = A 点）。A=8 时 (1,0,2) +4.5、(0,1,2) +3.5，最紧角 −15.4。
- 敏感性版本 `relaxp`（松侧平台，不进裁决）：只有 where1 最松一档新纳入的原子更好，其余全平；where1 = 0 的 20 格同为最大值（买点 0.67～1.67×），where1 ≥ 1 的格真增益恒为 0，紧侧薄格是纯噪声干扰项。

**其他读法。**
- 前门把排序之争压扁了：同样是「ρ·d̄ 排序 − 取最大」，只接写入门时单调·大差 −0.70，加上 ρ·d̄ > δ 前门后只差 −0.20。原因是 R1 只在取最大那一格本身可信时才开窗，最离谱的薄格候选已经被前门拦掉。
- 终审担心的空转：N1 下「R1 不开窗、但有别的格过线」占 1.5%～6%，救回这部分的收益 ≤ +0.05 点（松侧平台·大 +0.2）。R2 与 R1 的差别主要不在这里，而在两边都开窗时送的格不同（占 9%～47% 的轮次）。
- 三个带前门的臂在工作点即最优时亏损相同（N1 −0.01～−0.03），P(差出 δ) 相同或 R2 略低；全平下写入率都是 3%。
- 相对现行 validate（N1）：R1、R2 在工作点即最优多保住 0.13～0.15 点，宽平台·大、放松更好·大多拿 0.5～1.2 点，但单调·大、窄尖峰·大少拿 0.1～0.6 点；N2 下 R1、R2 在多数大效应曲面落后现行（§4.10 已知的 G1 代价，松侧平台·大 R1 −1.11、R2 −0.55）。不设前门的 R0 在 N0/N1 下小效应曲面比现行少 0.01～0.04 点，其余曲面不差，大效应多拿 0.2～1.4 点。

**本节局限。**
- 口径 2 的判据量压在阈值上；「小 / 大」两档各合并两个幅度，拆开看 A=8 的落差是 −0.31。阈值 0.2 点相对单调·大 R1 的 +1.41 约 14%。
- 「放松更好」的形状是我选的。网格里工作点每个 where 维度只有一档可松，松侧空间只有 15 格、买点最多 1.67×；主版本的紧侧真值很差，对取最大有利。
- 往前段对「比工作点松」的格加了 +1 点幸存者平移（看起来更好），但推荐流程第 6 步的「按上界朝不利方向平移」没有模拟（v5 同）。新曲面上各臂写入的多是松格，写入率与增益对所有臂都偏乐观；臂间对比受影响较小，但 R2 更常送松格，得益可能略多。
- τ̂² 仍是全网格池化，没有「按移动了几个参数分组」（v5 同）。
- 配对差的 MC SE 把同一列内两个幅度当作一个混合总体，和 §4.10 的算法一致。

## 5. 对草案的含义

| 草案条目 | 模拟给出的判断 |
|---|---|
| §3 交叉拟合 = 「股票折 × 时段块」、留一块其余全训 | 有泄漏（§4.3），行情交互越大越乐观；要么改成整年（整时段块）留出或「其它年 ∩ 其它股票」，要么承认它只是按股 bootstrap 的另一种下界。改动是一个块结构参数，属于少量补丁 |
| §3 「平台 vs 峰值两者都跑、取交叉拟合更高」 | 删。选对概率 0.50～0.57，还给报数加 +1～2 点 |
| §3 交叉拟合估计「就是样本外效用的不偏估计」 | 整年留出下平均偏差 −0.1～−0.3（评估的是只用一年训练的流程），但与本次选中点真值的相关 ≤0.28（N1），单次报数不能当「这个点有多好」；诚实只在平均意义上成立 |
| §3 剪枝只做剪枝、不需多重校正 | 仅当剪枝放进交叉拟合每一折时成立（S3） |
| §3 U = (首次穿越率 − 基线)·n/(n+n0) | 压住了薄格赢家诅咒（55%→0～3%），但 U 口径下可得增益同比例变小、仍在噪声以下；它解决「数量没有归宿」，不解决「效应小于噪声」 |
| §4 步 5 往后那段只开一次、非劣效 + 同号 | 这是整条流程里最大的杠杆。换成往前段 + 往后段合并的单侧优效门，在 N0/N1 下各曲面都不差于现行、大效应多拿 0.7～0.8 点；往前段的幸存者偏差在强行情切换（N2）下会让工作点最优时多亏 0.08 点 |
| §5 砍掉「年份取最差、邻域取最差」的红线身份 | 支持：它们只是隐含的门控强度（§4.1），T=2 时邻域分的「近无偏」是巧合（T=3 变 −1.8） |
| unifier 可信度排序 ρ·d̄ 作默认排序 | 不支持作默认：嵌套网格上系统性偏爱近邻/低 SE 格，Q 口径大效应比朴素取最大少 0.3 点、peak 上只拿到 1/3；U 口径持平 |
| 「CV>0 才进验证」门 | 纯风险收益交换：误写减半、大效应收益少 0.2～0.4 点，无增量 |

外推（第③问）的模拟侧证据：在 N1、确认窗 SE 2.7 下，最好的门控流程在「有 4～8 点真改进」时拿到 oracle 的 30～50%，1～2 点时 10～17%，工作点本身最优时亏 0.04～0.11 点；任何「总会换」的规则在工作点最优时亏 1.2～1.9 点。统计意义上的外推提升只在真效应 ≳ 分辨力（约 4 点）时实质存在，且来自门控而不是挑选规则。

## 6. 局限

- 网格只有 100 格，挑选噪声倍数落在 bb_v1 区间低端；更大网格会放大朴素取最大的虚高，但 v1 旧研究显示倍数与格数几乎无关。
- 「改进伴随买点变少」是 v1～v5 曲面的共同特征（mono、peak）；真实改进伴随买点增多时 ρ·d̄ 的偏好反而有利，§4.11 用「放松更好」曲面验证了这一点。
- 时段冲击的形状（局部随机场 + 线性因子）是假设；远格年交互随距离放大到 6～10 点这一点没有 bb_v1 实测锚点。
- 往后段、往前段的行情冲击各自独立抽，没有模拟相邻时段的行情自相关，也没有模拟 40 日前瞻标签在块边界的重叠（purge 只在 S6 用方差放大近似）。
- 截断校正与合并门的 SE 只含按股抽样误差；没有模拟「把年交互方差加进 SE」后的门与校正。
- 幸存者偏差只作用在往前段、且只按「是否比工作点松」一刀切；S5 的相加版更细，但同样是假设量级（π=0.3、H=−4）。
- v2 的 U 口径「+前向窗」行有 bug（往后段年买点数没按 0.3 年折算），已在 v3 修正；本文 U 口径端到端数字只取 v3。v1/v2 的 Q 口径、以及所有无确认窗的行不受影响。
- 平滑先验后验（核平滑）的核是我选的（线性趋势 + 指数），不是经典唯一形式；它没带来增益不代表所有空间先验都无效。
