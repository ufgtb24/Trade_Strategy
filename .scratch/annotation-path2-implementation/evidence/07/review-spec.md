## 处理

- 已修：
  - **(c)1 淡化核对不成立**：先在 e2e 里复现（打开 AAPL 2024-09-09，图窗左边切过 W底 负样本的跨度，副图 bracket 实际画出的项数是 1，应为 2），再把标注图的图窗筛法改成 `weakFilter`（副图在 `render/annotateLanes.ts`，主图在 `KlineChart.vue` 的 annotate 分支）：一段只要有一端在图窗里、或横跨整个图窗就照画。同一个原因还让 06 的「样本日之后暗一档」在图窗没拉到最后一根时整条消失，一并修好。e2e 现在断言 bracket 画出 2 项、暗一档画出 1 项；单测断言副图的筛法。K 线、成交量只有一个 x，两种筛法结果一样。
  - **(a)1** pattern 页 samples 表每行的 `×n` 去掉（它就是页头的数）。
  - **(a)2** 子块写成 `横盘 ⊃ 缩量`（父名、⊃、子名），仍挂在父块里面。
- 没改的，及理由：
  - **(a)1 unsorted 行的 `×n` 不做成能点开**：它数的就是紧挨着列在下面的那几张卡，点开列出的还是这几张。决策票 15 要「凡数样本的数都能点开」，防的是「一个数点不开就是死路，用户得自己去样本表里按条件找」，这一行不是死路。
  - **(a)3 本 pattern 里全没判过的属性不列**：属性一行回答「这个 pattern 的样本里，这个特征的框被判过的属性分布」。词表里别处用过、本 pattern 一次没判过的属性列进来，就把别的 pattern 里加的属性带进了这个 pattern 的 features 区；它在这里没有对象（分母里的框都没判过它）。在本 pattern 里判过的属性，哪怕分子是 0 也照写（如 `true pos 0/3`）。
  - **(b)** 点卡片打开样本、unsorted 下的轨序：保留，理由同报告；新起的界面名列进完成记录。
