## 搜索

```python
规则 = 固定目标_近期范围_参数范围_预算_数量与方向下限_采用与复核安排()
原参数 = 读取现在正式使用的完整参数()
核查买点当天已能知道全部成立条件()
预留最后验证和未来复核的数据()
登记训练数据的读取范围()  # 包括计算后续表现所需的尾部

逐日标签 = 计算允许范围内各股票各日期的前瞻收益与首次穿越()
原参数买点 = 检测并按股票与日期去重(原参数)
共同重抽安排 = 预先抽取股票与连续时段()  # 每组参数使用同一安排
最好候选 = 原参数

for 本次改动 in Optuna建议的参数组合(含原参数, 固定预算):
    参数 = 在完整原参数上只改本次字段(本次改动)
    if 参数不合法或改变评价尺子:
        记录原因并跳过()
        continue
    买点日 = 复用准确缓存或重新检测(参数)
    表现 = 读取这些买点日的缓存标签()
    近期表现 = 只取事先固定的近期训练部分(表现)
    原始空间 = 近期表现中各买点日前瞻收益的中位数()
    方向与机会 = 按四态统计方向并统计可评估买点日数()
    重抽成绩 = []
    for 股票次数, 时段次数 in 共同重抽安排:
        # 这里不再调用检测，更不调用 Optuna。
        重抽成绩.append(按重复次数汇总日空间中位数(近期表现))
    空间评分 = 重抽成绩的偏低位置()  # 当前默认 20% 分位
    记录原始空间_评分_方向_机会_覆盖与失败抽样数()
    if 各项要求通过且原始空间高于原参数:
        最好候选 = 保留空间评分更高的一组(最好候选, 参数)

if 最好候选还是原参数:
    关闭本轮并释放尚未读取的预留数据()
    return 保留原参数
固定唯一候选与本轮规则(最好候选)
```

一天多个事件重复命中仍只算一次，同一事件持续多日则分别算。标签不全的机会另报，不当作零收益或未触线。更早的训练表现另列，不改变近期排名。

## 最后检查与采用

```python
登记这段最后验证数据已经使用()  # 先记账再读取；失败也不能换参数重试
新结果, 旧结果 = 在允许范围评价(固定候选, 原参数)
比较 = 用同一重抽安排比较两组空间中位数()

if 硬要求失败 or 无法评价 or 原始空间没有改善 or 已有明确变差证据:
    结论 = 不采用
elif 证据足够且比较区间低端仍高于零:
    结论 = 确认采用
else:
    结论 = 暂用并按预定日期复核
保存完整新旧参数_结果_证据状态()
在已获授权范围内核对现役文件未变，再写正式参数并记录备份()
```

重复调用检查命令只能读取保存结果，不能重开数据再选一组。只有暂用需要保留本轮预定复核范围；其他结论释放尚未消费的预留范围。

## 暂用到期

```python
确认复核时点已到且完整后续数据已经具备()
登记并只读这次预定的新数据()
重新比较固定候选与原参数()  # 仍不重新选参
if 规则支持确认改善:
    确认采用()
else:
    恢复保存的原参数()  # 包括到期仍不能确认
核对正式文件没有被其他任务改过并记录实际动作()
```

对半分仅用于可选的方法开发比较，不嵌入这条日常流程。若开展，则在一半数据完整搜索、另一半比较，有重抽和无重抽使用相同范围与预算；用来改方法的数据以后不能再称为最终独立验证。

脚本自动执行到出具采用结论；正式文件写入与备份由 skill 按已获授权继续完成。默认不自动创建定时任务，也不承诺无人触发时会自行到期复核。
