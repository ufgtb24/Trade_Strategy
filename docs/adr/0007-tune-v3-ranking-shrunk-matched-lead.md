# v3 排名目标为按证据打折的相对优势

2026-10-06 用户决定：Optuna 的排名分是候选方向成绩比同日普通买入对照（`path2/CONTEXT.md` 词条，同一天 × 当日波动档配对）多出的部分，统计折扣默认开启；搜索、训练入选、最后检查与复核用同一个分。调参要的是在目标内优化「相对普涨的优势」与「证据量」，不是用门槛筛选。

- **只给正的优势打折**：排名分为 `min(Δ, λΔ)`。领先为正时按证据打折，证据越薄折越多；领先为负时照原值。若负值也乘 λ，证据薄、劣势大的候选会被拉近 0、反超为负的现役；误差估不出时 λ=0，正领先记 0、负领先照原值。
- **删除方向的绝对下限**（方向成绩 >0、对同日普通买入对照的差 ≥0）：二选一时，这两道线只会在下跌行情里把好候选和零效应候选一起拦下、留下更差的现役，检验的是「这个 pattern 这段时间值不值得做」而不是「哪套参数更好」。前者改为报告里的醒目提示，由用户决定是否继续用。
- **「不比现役差」在目标上执行**：搜索要求分数高于现役，最后检查要求分差 >0。不另设「领先不低于现役领先」的原值门槛，否则会挡掉买点更多、领先略小但证据更足的候选。
- **择时不进目标**：绝对方向成绩与随机日基线只报告。pattern 只读单只股票，预测不了未来大盘；择时取决于少数几段独立的大盘起伏，一年多的训练期只有十几段，股票池再大也量不准，优化它就是拟合训练期。扣掉买点之后的大盘只去掉学不掉的部分，不缺信息。
- 机会只设相对原参数的两条下限（总数、近期各不少于一半）；买点数不作业务奖励。

代价：排名偏向「比同日普通买入强得多」而非「绝对涨得多」的参数；折扣尺度 τ 未校准，力度待验证；最后检查对零效应改动的暂用率比保留绝对下限时高。取代 [0001](0001-tune-v3-method-development-boundary.md) 中重抽进排名的部分。

实施入口：`.agents/skills/tune-gates-v3/SKILL.md`。已完成合成数据下的行为验证，未据此宣称真实市场效果或优于旧版。
