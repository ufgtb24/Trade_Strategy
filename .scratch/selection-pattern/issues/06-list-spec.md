# 候选名单的规格：看多久、多长、在哪些股票里选

Type: grilling (HITL)
Status: open
Blocked by: 02, 04, 09

## Question

### Purpose

用法定为每天盘后出候选名单、再看图挑；这张票把名单的用法落成判优尺子的具体口径，是盘点现有 pattern 与挑方向的前提。

### 要决定的事

- **看多久**：买点之后关心多长时间的走势（几天 / 几周 / 几个月）——决定首次穿越和前瞻收益的窗口。
- **多长**：名单大概多长才有用（每天几只 / 每周几只 / 每月几只）——太少没得挑，太多看不过来；它也决定买点数，从而决定分辨得出多大的优势（见「这份数据能分辨多大的选股优势」）。
- **在哪些股票里选**：方向已定（2026-10-07，见地图 Notes「目标股票池」）——中小盘、价位偏低，同日对照也只从这个池子里抽。这里要落的是具体口径：价格上限、成交额上下限的默认值（由会话按「目标池里的分辨力和幸存者偏差有多大」的结果推出并标「待验证」，不交给用户定）。要权衡的是：池子越往小、往便宜里收，命中的不同股票越少、分辨力越差，幸存者偏差越重；「幸存者偏差会把哪类 pattern 的成绩抬多高」建议的每天 500 万美元成交额下限会把低于 10 美元的股票砍掉八成以上，与用户的目标冲突。历史上「挑高波动」和「挑低价股」一直没分开（全宇宙收盘价中位约 13.8 美元）。
- **股票池要排除的证券**（2026-10-07，来自「这份数据能分辨多大的选股优势」与「幸存者偏差会把哪类 pattern 的成绩抬多高」）：挂牌债券、票据、优先股一类非普通股（约 150 只，如 OXLCZ、SAY、GJS；它们会让方向成绩白白变好，见 `docs/feature_candidates.md` FC-015），SPAC 单位与认股权证（81 个代码，如 AFJKU、BBLGW）。池子的价格条件按当时价格、不按复权价。
- **推荐的默认池子**（待验证，2026-10-07，来自「目标池里的分辨力和幸存者偏差有多大」）：
  - 只要普通股；
  - 当时价格不超过 20 美元；
  - 20 日成交额中位每天 200 万～1 亿美元。
  - 决策日的 M（20 日真实波幅占收盘价比例的中位数）不低于 1%：用户 2026-10-07 决定，剔除平时几乎不动、价格被钉住的股票，例如等待并购的公司；它们一跳就会冲到大涨段榜首。对照也一起去掉（待验证）。

  剔除规则：
  - 按交易所挂牌名单里的证券全名，剔除票据、债券、优先股、结构化信托、认股权证、单位、权利；
  - 另剔除封闭式基金（约 290 只）和还没完成合并的 SPAC 空壳（85 只）；
  - ADR 和有限合伙普通单位保留。

  在统计上，成交额下限取 100 万到 500 万美元、价格上限取 10 或 20 美元，分辨力和偏差都差不多。真正的取舍在于名单里可挑的票有多少、买卖价差有多大，成绩按收盘价算，没有扣掉价差。

  当时价格要靠拆合股记录还原。数据文件只存复权价，用复权价筛价格，5 年下来约 7% 的股票日会被分错。用户 2026-10-07 定为先不切节点去取，留到实施阶段一次性取；如果决定补退市数据，就由那份数据顺带解决。
- **配套买卖带来的改动**（2026-10-07）：起点用次日开盘价；用户约每周买一只，名单可以更长，并配强弱排序；「看多久」改由配套买卖规则决定，体检尺子的窗口另取默认（待验证）。
- **外部信息带来的改动**（2026-10-07，来自「能接哪些外部信息：从哪来、历史多长、会不会偷看未来、花多少」）：SEC 季报年报封面的流通股数带申报日，能还原当时市值，「中小盘」可以直接按市值划，不必只拿成交额近似；名单截止时刻默认美东当天 20:00 前接收的信息进当天名单、次日开盘买（待验证）。
- **要不要排序**：名单内要不要按强弱排序——要排序，pattern 就得输出一个强弱分。
