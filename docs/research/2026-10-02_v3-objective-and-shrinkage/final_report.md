# v3：业务目标、统计证据与联合评分

日期：2026-10-02。范围：方法研究、代码审计、确定性合成反例；不修改正式算法或 skill，不读取真实验证集。项目内路径均相对 repo root。状态：已完成三位研究员交叉核对与总稿复核，澄清建议已纳入。

## 结论

**Optuna 应优化有统计证据支持的业务表现。业务决定什么更值得做；统计决定观察到的表现值得相信多少。它们不是两个应当各自最大化再加起来的目标。**

不建议把上涨空间、方向、买点数、普通买入优势、bo 优势统一加权相加。建议采用“一个有业务含义、经过证据校正的主分 + 少数不可妥协的要求 + 分开的解释指标”。所有会影响训练候选去留的要求都应逐次反馈给搜索，并在最终训练选参时采用同一口径；不必全部转成无限增大的加分项。

当前尚未定义持仓容量、同时出现多个信号时的选择、退出和成本规则，因此无法唯一确定有限资金的最优交易目标。本轮建议的可用过渡方案是：**以证据校正后的绝对上涨潜力为主分；数量是否足够与方向是否可接受各自处理；两个对照用来估计、解释和检查替代价值。** 不将最大化两种对照差值默认为更客观的选择。该建议是设计方向，不是已经校准或验证过的市场算法。

用户的随机连续窗口、窗口内买点中位数、窗口间中位数，可以保留为“典型时段的典型潜力”口径，但不是统计学唯一正确的目标。时段等权和外层中位数是两个独立选择；前者减少买点密集时期的权重，后者偏重排序居中的时段、淡化少数极好或极差时期。此前只以“符合用户要求”为理由保留这个口径，论证不足。

## 1. 两个维度的关系

有限资金下的终极问题是：按照相同、可执行的买卖和资金规则，哪组参数能更好地使用资金，并满足必要的风险要求。实际策略评估要容纳持仓、交易成本和持有成本，不能仅把逐信号成绩当成资金回报。这里借鉴的是目标分工，不是在推荐引入复杂组合求解器。[Boyd 等作者原文](https://web.stanford.edu/~boyd/papers/cvx_portfolio.html)

| 项目 | 应用上的意义 | 统计上的意义 | 推荐角色 |
|---|---|---|---|
| 上涨空间 | 衡量买入之后的盈利潜力；不代表能够卖在最高点 | 观察值有误差，也受市场环境和波动影响 | 当前可用的主分代理；资金策略明确后应重新对齐真实交易结果 |
| 方向表现 | 描述先向有利还是不利方向走；不是完整盈亏结果 | 比例精度依赖可用结果数及相关性 | 当前作为可接受要求和解释指标；不任意折算成若干点空间 |
| 买点日数量 | 机会不足可能用不满资金；拥挤时额外信号未必能执行 | 更多相关且提供新信息的观察可能提高估计精度 | 应用供给与证据数量分开处理，不无上限奖励原始计数 |
| 不同时段覆盖 | 决定机会是否只集中在少数时段 | 帮助识别结果是否只靠同一段行情 | 证据与适用范围诊断；不自动要求每个月交易 |
| 两种对照 | 区分市场背景、pattern 附加价值与简单方法的替代价值 | 配对比较有助于控制共同环境；对照本身也有误差 | 进入估计和比较；是否是必须达到的要求取决于业务用途 |
| 重抽次数 | 不创造新的可交易机会 | 改善同一历史统计量的数值近似，不增加独立市场历史 | 数值设置，不作为样本规模奖励 |

“从统计上所有指标都越多越好”需要修正：**更多有用信息通常有利于估计；更大的指标值不等于更多信息，也不等于更可靠。** 同一行情反复出现的买点、重叠的未来收益区间和反复抽中的窗口会共享信息。加入不适用于当前市场的旧数据，还可能使估计目标发生偏移。证据足够确认一个坏策略，并不使该策略变好。

资金有限也不自动等于机会越少越好：额外机会可能提供更好的替换选择和分散空间。但它的价值通常会受持仓容量、时间分布和选择规则限制；单纯总数无法表达。空仓可能是正确择时，不应为满足月份覆盖而强迫出手。

## 2. shrinkage_score 实际做了什么

核对 `BreakoutStrategy/mining/threshold_optimizer.py:61`、`:88`、`:97`、`:603` 与 `BreakoutStrategy/mining/pipeline.py:47`：

1. 按因子触发组合分组；过滤数量不足的组合。
2. **先按未经校正的组内标签中位数选前 K 组**。
3. 对选中组计算 `w = n / (n + n0)`、`adjusted = baseline + w × (median − baseline)`，然后求均值返回。
4. 主流程通常 K=1、n0=200；不能将函数默认 K=5、n0=50 或另一入口的 n0=20 误当成实际运行配置。
5. 主流程 baseline 是输入表全部标签的中位数；标准数据生产链来自突破记录，**不是同日、同池普通买入**。n 是组内记录数，也不能自动解释为独立买点日数。

它的可借鉴点是：把“看起来比普通水平好多少”按照证据量回拉，而不是直接给每个买点增加固定奖励。固定中位数和基线时，表现高于基线，n 增大使校正分增大；表现低于基线，n 增大反而使校正分减小。它因此不是数量越多分数必然越高的公式，也不是一律向下扣分的保守下界。

不能直接照搬：原始行数没有处理依赖；n0 没有随目标估计精度自动标定；baseline 有自己的不确定性；中位数的误差不只由 n 决定。代码 docstring 的 James–Stein 名称不能给任意中位数加权式提供该理论的保证。本轮未证明该启发式无效，也未证明它优于其他方法。

另有明确的内部排名问题：raw 中位数选 top K 后才回拉，可能遗漏回拉后分数更高的组。该问题是代码实际顺序与目标排名的差异，不是数据异常。只记录研究发现，本轮不修代码。

## 3. 对照该怎样参与

**纳入搜索考虑、成为最大化目标、成为必须达到的要求，是三件不同的事。**

普通买入采用同日、同一可交易池、相同标签，不特意排除 pattern 命中。它帮助回答“这段表现有多少是市场本来就在涨”。按候选买点日期配比时，普通对照会随候选变化；把它从空间中减掉，会从追求高潜力转向追求扣除市场背景后的选择优势。同日比较仍可能包含股票波动等差异，不是 pattern 附加能力的因果证明。

bo 使用事先固定的简单突破规则。若比较整套方法，可以在相同日历期间各按自己的信号运行；若比较选股效果，则需明确日期和风险条件。二者回答的问题不同，不能混称完全同条件比较。bo 若是资金真正可以转去的替代策略，比较其可执行表现能帮助决定是否值得替换；若仅作诊断，就不能自动成为否决所有候选的门槛。用户尚未授权把 bo 定为唯一替代策略。

| 方案 | 在最大化什么 | 主要问题 |
|---|---|---|
| 绝对空间，经证据校正 | 买到的机会本身预计有多大上涨潜力 | 仍不是实际可兑现收益；可能偏爱上涨背景良好的日期 |
| 相对普通买入的空间，经证据校正 | 在各自所处背景下多挑出了多少潜力 | 可能偏向绝对潜力较低、但背景更弱的日期 |
| 两个对照优势都加上主空间 | 人为规定三种奖励的交换比例 | 重复计算共同成分，单位相同也不代表权重有依据 |
| 多目标保留取舍候选 | 展示哪些候选各有长处 | 最终仍需业务规则挑一个；不会自动消除价值判断 |

示例：A 空间5%、普通买入0%；B 空间12%、普通买入10%。A 的附加优势更大，B 的绝对潜力更大。仅凭“比基线更好”无法判断有限资金应选谁；还取决于可执行收益、风险和机会条件。最大化增量不是错误，但它是改变目标，不能以“更全面”略过这个选择。

若采用 `P + (P−U) + (P−B)`，实际就是 `3P−U−B`。这是具体的偏好公式，不是统计学保证。若被减去的是对所有候选完全相同的一个汇总常数，则减法不改变排名；候选匹配对照会变，或逐窗口做差后再取中位数，则没有这种保证。

两个对照都应报告。对明显被可执行简单方案取代的候选，采用规则应识别它；但不能默认要求每个训练窗口、每种差值都显著为正，那会混淆暂时证据不足与真实不合用。

## 4. 推荐的评分结构及限度

### 4.1 当前可用方向

在未定义资金与退出政策前，明确将主分标为“上涨潜力代理”。随机窗口、内外中位数可暂作清晰的业务聚合偏好；保留时段等权，绝不按窗口买点数再给外层加权。所有候选共用窗口计划，数量按原始股票—日期去重计数，不累计重叠窗口中的重复出现。

推荐研究的联合方式是**证据校正业务量**。示意如下，而非可立即投入市场的已定公式：

```text
每个可评价窗口：
    P_i = pattern 买点日空间中位数
    C_i = 相同日期条件下，未证明 pattern 额外能力时的合理参照
    调整后的窗口空间 = C_i + w_i × (P_i − C_i)
主分 = 各可评价窗口调整后空间的中位数
```

`w_i` 表达该窗口 pattern 与参照差别值得相信多少。不能拿“抽了200次”作证据数，不能把原始行数直接冒充相互独立的观察，也不能仅凭窗口分数起伏来识别估计误差。真实时段差异、抽样误差、近期适用性和有限次抽窗口的数值误差应分别处理。

此式表示校正后的绝对潜力；只取 `w_i × (P_i−C_i)` 则是在优化额外潜力。两者不能交换名称。弱证据往参照靠拢，在低于参照时还会提高观察分，因此不能称为“安全下界”或“保证扣除了运气”。校正后的高分也不能单独证明 pattern 确有附加能力。

参照是否合理、参照误差、同一股票及同一行情内的依赖、校正强度、每窗口是否足够评价，仍须在开发数据中研究。先校正各窗口再汇总与先汇总再校正一般不相等；应预先固定，不能看到排名再选。逐窗口校正值的中位数，并不等于已证明无偏的原始双中位数估计，也不自动等于该目标的后验均值。上述窗口级式子仅是与当前讨论口径对齐的候选架构。

### 4.2 数量、方向、空窗口

- **应用供给**：机会能否满足资金使用需求，应按可执行机会的时间分布判断。若沿用此前最低买点数要求，应明确它只是供给不足的暂定代理；在执行政策明确前，不把这一数字解释为实际资金需求，也不据此要求每个月出手。
- **证据支撑**：反映估计可信程度，可以使表面更高但证据很弱的候选回拉更多；不额外再按 n 线性加分。与应用供给不是同一个下限。
- **方向**：当前仍是必要检查及可接受要求，不随意将一个百分点换成几分空间；更好的方向不是没有业务价值，而是尚无合理交换比例。进入真实资金评估后，上下路径、退出及持有结果共同决定其价值。
- **空窗口**：没有买点时，条件空间没有定义，不能补零空间、补普通买入成绩或重抽到有买点为止。须保留空窗与可评价比例，报告评分适用范围；资金账户评估若政策规定空仓，才可计明确的现金收益。不能将“条件空间未知”混成“实际空仓收益为零”。
- **覆盖要求**：只用于避免结论由极少证据支撑，或落实明确的供给需求。不能因为想覆盖所有月份就奖励强行交易。稀疏但择时合理的策略可能与频繁供给策略不同，需明示适用范围。

### 4.3 Optuna 应收到什么

```text
搜索前：固定业务口径、对照、窗口、证据校正规则、必须达到的要求
每组参数：检测一次并缓存逐日结果
    计算主分、对照结果、方向结果、供给与证据状态
    把主分和各项要求的达标程度一同交给 Optuna
搜索后：只在满足同一套要求的候选里按同一主分选择
    无合适候选则保留原参数或不作采用结论
冻结后：用未参与搜索的数据检验一个候选，不据此重写本轮评分
```

Optuna 4.7 支持逐试验约束反馈，也支持多目标。约束参与搜索不要求把全部指标相加；同时，约束采样不保证所有试验都满足要求，最终必须显式检查可用性。[官方 TPESampler 文档](https://optuna.readthedocs.io/en/v4.7.0/reference/samplers/generated/optuna.samplers.TPESampler.html)、[官方 FAQ](https://optuna.readthedocs.io/en/v4.7.0/faq.html#how-can-i-optimize-a-model-with-some-constraints)

校正强度不能让 Optuna 与 pattern 参数一起自由挑到最有利于抬分的值；搜索轮内应冻结。如要比较评分方法，只用预定开发数据和相同搜索预算。任何训练评分都可能被大量尝试利用其误差；降低评分噪声有帮助，但并不替代最后独立检查。[Cawley 与 Talbot 原文](https://jmlr.org/papers/v11/cawley10a.html)

## 5. 本轮验证了什么

做了代码阅读、官方文档与一手文献核对，以及少量可复核的确定性合成反例。反例证明若干“必然正确”的说法不成立，不是在测试哪种 v3 方法未来赚钱更多。没有跑真实 pattern 调参、没有比较两套 Optuna 的市场成绩、没有读取留着没碰过的数据。

合成结果存 `formula_counterexamples.json`，完整审计见 `formula_audit.md`。核心例子如下，均为人为设定数字；前两个反例统一采用基线10%、n0=200，复制记录例的每条标签固定为20%：

| 反例 | 可复核结果 | 能说明什么 |
|---|---|---|
| 先 raw top1，后回拉 | A:30%且30条，校正12.61%；B:20%且1000条，校正18.33%；代码仍选A | 两阶段排名不一致，确会漏掉校正后最优组 |
| 复制同一30条记录 | 复制1/10/100倍，校正分约11.30%/16.00%/19.38% | 原始计数不能区分新信息与重复信息；不声称真实数据存在复制异常 |
| 相同10%空间，不同背景 | 参照8%/2%，w=.5：校正绝对空间9%/6%，校正额外空间1%/4% | 两类目标可以选相反候选 |
| 外层中位数 | A七期10%、五期0%；B每期6%：中位数选A，均值选B | 时段等权不唯一决定聚合函数；中位数有明确偏好 |

资金路径另有反例：假设净收益七期+3%、五期−20%，其中位数仍为+3%，但累计资金下降；这使用假想净收益，不是项目上涨空间标签。其目的仅是说明中位数不能代替实际资金路径评估。

## 6. 落地前仍需解决，不能伪装已定

1. 有限资金的选择与退出政策，决定终极业务量。目前只能推荐潜力代理，不能承诺最优资金收益。
2. 证据校正的参照、强度与依赖处理；不直接继承 n0=200，也不将重抽窗口数当独立证据。
3. 双中位数与其他时段聚合的取舍；均值更重视总量但也不是天然更稳健。不能仅凭本轮反例就反向宣布均值必胜。
4. 空窗口与证据不足时的结果状态和适用范围；不能偷偷删到只剩容易得高分的窗口。
5. 两对照分别用于什么决策，避免把纯诊断自动升级成替代门槛。

没有达到登记线的真实市场副产品；未向 `docs/feature_candidates.md` 写入方法猜测。研究产物之外没有正式实现变更。
