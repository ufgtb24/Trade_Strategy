# ② 区分度试验报告：实盘是否使用情感分析

**日期**：2026-08-16 · **预注册**：`preregistration.md`（跑前锁定，无事后改切法）
**数据**：bb_v1 eval 窗口内 112 行买点 × Finnhub+EDGAR 采集 × deepseek-v4-flash 逐条标注
**复现**：`repro/prefill_full.py` → `repro/compute_metrics.py` → `repro/analyze_discrimination.py` → `repro/full_scores_*.json` / `full_metrics_*.json` / `discrimination_result_*.json`

---

## 一、决策问题与设计

实盘在 bb 买点确认时能拿到 news_score（买点前 7 天含当日新闻的聚合评分，因果干净）。问题是：
**知道 score 后，交易动作应否改变（负向放弃买点）？** 设计为可判定的三条件（预注册）：
① G_neg(score<-0.15) vs 其余的 fr median 差 bootstrap CI 不跨 0；② FPR_k6 方向一致（G_neg 更低）；
③ 负向率 ≥5%（作用面有意义）。任一不满足 → 不接入。

主指标（用户裁定纪律）：**首次穿越率 FPR_k6**（几何对称阈值，`path2.eval._first_passage_at` 直调，
锚 t=buy_date 行号）+ **fr median**（fr = max(high[t+1..t+40])/close[t]−1，mfr_high 口径单点重算）。
win_rate 废弃。统计 = 点估计 + bootstrap 95% CI（10k，seed=42），不报 p 值。

**口径披露**：eval JSON 的 `returns["40"]` 实为 end_node span 全部买点日 mfr 的**均值**
（`match_forward_returns`），与本试验的单点锚 fr 不同——对齐校验揭示此差异后，
统计统一用单点重算值（与 FPR 同锚、贴实盘决策点）。另注：本试验 FPR 锚为单买点日，
与 2026-08-03 k_scan 的 span 全 bar 池口径不同，绝对值不做跨研究比较。

## 二、样本与执行

- 112 行（buy_date ≥ 2025-09-07 动态标定边界），83 行有新闻覆盖（74%）。
- 全量逐行评分 672s；fr/FPR 重算 110/112 有效（2 行尾窗不足）。
- LLM 失败率 0（v4-flash）。

## 三、结果

### 分组总表（预注册分组）

| 组 | n (%) | fr median [q25,q75] | FPR_k6 (up/down/none) |
|---|---|---|---|
| G_neg (score<−0.15) | **5 (4.5%)** | **0.813** [0.066, 1.040] | 0.500 (2/2/1) |
| G_mid (覆盖,\|score\|≤0.15) | 17 (15.2%) | 0.169 [0.118, 0.375] | 0.222 (2/7/7) |
| G_pos (score>0.15) | 61 (54.5%) | 0.345 [0.093, 0.562] | 0.500 (19/19/23) |
| G_nocov (无覆盖) | 29 (25.9%) | 0.479 [0.111, 0.935] | 0.647 (11/6/11) |

### 主检验：负向闸（G_neg vs 其余全部，实盘闸语义）

| 指标 | rest−neg 点估计 | 95% CI | 预注册条件 | 结果 |
|---|---|---|---|---|
| fr median | **−0.468**（G_neg 反而更高） | [−6.97, +0.35] | CI 不跨 0 | ✗ 跨 0 且**方向与 H1 相反** |
| FPR_k6 | 0.000 | [−0.53, +0.53] | G_neg 更低 | ✗ 无差 |
| 负向率 | 4.5% | — | ≥5% | ✗ |

稳健性（k=4/5 的 FPR 差）：−0.153 / −0.053，均无支持 H1 的方向性证据。

### 附加检验

- **H2（PR 泛正面=出货前兆）**：G_pos−G_mid fr median = +0.176，CI [−0.11, +0.27]——不成立（正向组反而略好，不显著）。
- **覆盖性混杂**：G_nocov−G_cov fr median = −0.209，CI [−0.42, +0.18]——无覆盖组略好但不显著，混杂未证实，也说明「有新闻」本身不带增量。
- **作用面上限**：即使负向组真的更差且全部杀对，全体 fr median 变化上限 = 4.5%×0.47 ≈ **2.1pp**；FPR 变化上限 ≈ 0（点估计为 0）。

### 过程修复记录（试验内部，非数据问题）

- FPR bootstrap 一处实现 bug（有效样本计数把 down 的 0 值漏加，致 f 恒 1、CI 假性全 0）——合成数据复现定位后修复，重跑全量统计；修复前后的分组点估计不受影响（fpr() 组级函数本身正确）。

## 四、判定与实盘建议

**判定：不接入（预注册三条件全部不满足）。**

三层理由（按强度排序）：

1. **作用面先天不足**：负向事件率仅 4.5%——这是 score 分布的结构性质（bb 买点前的新闻池天然偏正面，pilot 15/19 正向的延续）。即使负向组与 H1 方向一致地差，闸对全体组合的影响上限约 2pp fr median / ~0 FPR。一个查询延迟 + LLM 成本 + 复杂度的组件，期望价值上界这么小，工程上就不值得。
2. **无方向证据**：唯一能翻盘的路径（负向组显著更差）在样本内的点估计是**反的**（G_neg fr median 0.81 为四组最高）。n=5 使这谈不上证伪 H1，但足以否定「样本内存在支持接入的证据」。
3. **正交（H3）符合全部观察**：FPR 无差、H2 不成立、覆盖性无差——score 与这两个主指标在该样本内无携带增量信息的迹象。

**复验条件（何时值得再看）**：bb pattern 语义变化使买点前新闻池负向率显著上升（>10%）；或样本自然增长至 G_neg n≥30。在此之前，此结论视为**终局**，news_sentiment 在 path2 主线的集成到此收线——管道与缓存资产（112 行评分、52+ 条标注、EDGAR collector 重写）保留，供将来其他用途（如 8-K 稀释事件标记，§八发现的正交用法）复用。

## 五、Limitations

- 样本期 2025-09..12 单一市场环境；112 行、G_neg 仅 5 行——本试验对「不接入」的支撑主要来自作用面上限论证（结构性的、不依赖显著性），而非组间检验的功效。
- score 出自 deepseek-v4-flash（单一后端、单一时点）；GLM/FinBERT 未测（benchmark 已判其弱于 deepseek 系）。
- FPR 锚为单买点日口径；G_mid FPR 0.222 的异常（9 有效中 2 up）大概率是小样本噪声，不作解读。
