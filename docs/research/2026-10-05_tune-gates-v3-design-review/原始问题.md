# 原始问题（逐字）

> 日期：2026-10-05

v3 skill 是用 codex 设计开发的，现在换作 cc 评审。从第一性原理出发，对于调参这件事，v3 skill 设计是否合理，有什么不足或者需要提升的地方。
注意，关于改进和提升，防止过度设计，之前的版本之所以重新设计就是因为太复杂。
启用 agent team 分析。

## 本对话中此前已形成的背景（供研究锚定，不是用户原话）

- 用户认为旧版 tune-gates 过度设计，「稳健区域 / 取相邻最差」作用有限且挑最差本身也是挑选；评审方同意，v3 已去掉该规则。
- 用户已拍板的业务方向（见 docs/adr/0001–0005 及 2026-10-02 修订）：方向优先（收盘价首次穿越）、按买点日计机会且机会只设下限、近期优先、允许「看起来改善但证据不足」时暂用并到期复核。注意 ADR 0002 标题与正文仍写「上涨空间优先」，已被 10-02 修订取代但未更新。
- v3 在 bottom_burst 上的真实对照（docs/research/2026-10-02_v3-bb-training-calibration）：256 只股票、33 组参数、两次时间拆分；一次选中参数后段失效，一次无候选达标；正式参数未改。
- 旧版在 bb_v1 上没找到稳健区域，已查明根因是参数改动效果小于样本能分辨的差别（约 3.5~4.8 个百分点）。
