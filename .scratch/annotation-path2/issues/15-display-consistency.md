# 界面显示的对称与统一

Type: grilling (HITL)
Status: resolved

## Question

### Purpose

用户靠界面上的计数和说明判断「标注能不能直接变成 pattern、pattern 能不能对回标注」；这张票让这些显示按统一的规律出现，不出现超出用户预期的显示，减少读界面的困扰。

起因（2026-10-30，用户在标注原型 `docs/research/2026-10-28_annotation-web-loop/repro/mock_v4.html` 的 pattern 页 features 节上指出）：
- pos 和 neg 的出现不对称、时有时无：特征块上看得到的 `in 1/3` 只数 pos，点开的两排却同时列 pos 和 neg；属性的 `3/3` 只数 pos，悬停里又写了 neg。
- 悬停挂的位置不统一：「放量」的说明挂在数字 `3/3` 上，「派发」的说明挂在特征名「派发」上。
- 悬停的句式不统一：如 `pos: 3 of 3 judged boxes true⏎neg: 2/2` 与 `0 pos samples have a “派发” box⏎neg: 1/2 have it`。用户要求注释内部 pos 与 neg 对偶，注释之间格式一致。

用户要求检查整个原型的显示：对称、对偶、原则统一，并给出修改方案。

事实依据：`research/15-display-inventory.md`（子代理实跑盘点，50 多处显示、40 条问题，分 A 覆盖不一致 / B 悬停位置 / C 文字格式 / D 时有时无 / E 其他五组，每条带触发状态）。

## Answer

**方向**：显示按统一的规律出现，不出现超出用户预期的元素；拿不准时，按「读完一个数，下一步是打开那些样本看图」取舍（用户 2026-10-30 第一轮选推荐，2026-10-31 由说明书的使用场景印证）。

### 1. 原则

1. **可见计数正负都显示**：每个数写成 `pos k/N · neg m/M`，与点开的列表、页头 `samples pos n · neg m` 一致；悬停只解释怎么数，不重复数字。防的是：看得到的只有 pos、点开却有 neg，读者以为两处说的不是同一件事。neg 的数只说「你挑的负样本里有几个」，悬停不写比率，防的是把用户挑的负样本读成误报率；盲看标记不进 features 区的任何计数。
2. **解释一个数的悬停挂在那个数上**，特征名上的悬停只放定义。防的是：同类信息时而在数字上、时而在名字上。
3. **各级特征块显示同一组元素**，must_not 也显示 `in pos 0/3 · neg 1/2`。挂靠块的 `qualified`：must_not 落成否定边时 = app 在那里看到了它；optional 默认不进 app，没有可算的，写灰字 `—`，元素不藏。防的是：同一位置的元素随级别时有时无。
4. **只数 pos 的数也算 neg 一侧**：`qualified`、`connected` 都给出 neg；会话定级仍只看 pos。防的是：这两处成为唯一不对偶的数，也看不出 app 是不是把 neg 看得像这个 pattern。
5. **数为 0 或没有对象时一律显示，写 0**。防的是：看不到时要猜是 0 还是没算。

### 2. 计数与卡片

1. **一律数样本**：`in`、`qualified`、属性计数、两段之间的计数都是「多少个样本」。一个样本收了几个同名框时，`qualified` 任一个被认出就算；属性任一个 `true` 就算 `true`、都没判算 `null`、其余算 `false`（待验证，见第 4 节）。题视图 q2 的 `×n` 去掉。防的是：同一块里写法相同、单位不同，以及一个框被两个样本收进时重复计数。
2. **汇总写比例，点开分排写个数**：汇总一律 `pos k/N · neg m/M`；点开按同一划分分排、排头写 `pos a · neg b`，各排之和等于分母——`in` / `not_in`；`qualified` / `not_qualified`；属性 `true` / `false` / `null`；两段之间 `connected` / `disconnected` / `not_qualified` / 缺一段。题视图与 features 区共用同一个点开。防的是：两处数字对不上，用户要想「是不是同一件事」。
3. **凡数样本的数都能点开**：页头 `samples`、`match` 行、features 区每个计数（含 must_not 块）、两段之间的 tag；点了就地展开、再点收起。只数框或特征的数（features 页用量、`unmapped n`）不在此列。防的是：一个数点不开就是死路，用户得自己去样本表里按条件找。
4. **样本卡在哪都挂同一组 tag**：判断看缩略图底部 ▲ / △；有 app 时挂差 tag（含 `=`）、match tag，以及「上一版的 match」（结论翻了时）。唯一例外是样本表，行头已写这一行共同的 tag，卡上不重复。主图样本三角下也画 `=`；selection 页选中样本时页头挂它的差 tag 与 match tag。防的是：同一个样本在两处长得不一样。

### 3. 按原则一并处理的事项

同一含义只留一种说法（盘点 C1、C6、C7、C10）；单复数随数变化（C9）；主图上的 tag 和侧栏同样的 tag 带同样的悬停（B7）；没 app 时只在 neg 里出现的特征也列出（A8）；`↓` 有没有 app 都用同一句悬停、条件不满足也画（B6）；`connected` 带分母并计入缺一段（D11）；excluded 理由里不写会过期的数字，由界面现算（E2）；unsorted 页也有 samples 计数行（D8）；字母 a / b / c 一个样本时也标（D14）；selection 框页的 `samples` 字段改名（E4，名字照命名规则起）；features 标签页的计数写明是跨全部图和 pattern 的用量（E3）。盘点见 `research/15-display-inventory.md`。

### 4. 留待实施阶段验证

- **同一样本多个同名框的「任一个」规则**。触发：第一批真实标注里出现一个样本收了两个同名框、且两框判法不同时。判法：会话列出这些样本按「任一个」归到哪一排，请用户看图确认归得对不对（只看方向）。验证前照「任一个」做。不合适就改规则本身，不回头改第 2 节的「一律数样本」。
