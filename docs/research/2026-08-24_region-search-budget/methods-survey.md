## 0. 一页结论（定位已按 pipeline-analyst 的实测重写）

> **勘误（integrator-final，2026-08-25 收口核验）**：本节「≈ 326 ms/股 ≈ 2715 CPU·s ≈ 5.7 min」与「整张网格比现设计的一格还便宜」两处措辞已被最终报告修正——(1) 326 ms 是 §1 算式值且漏了谓词归属项，实测（两次）为 **345 ms/股**；2715 CPU·s 用了 8325 股，按进 detector 的 6720 股为 **2320 CPU·s ≈ 4.8 min @8w**；(2) 现设计一格 ≈ 235 CPU·s（ATR 修后）/ 874（现状），反转全网格是**一格的 9.9× / 2.7×**，是 4096 格的 1/415 / 1/1540，「比一格还便宜」在 CPU 与 wall 口径下都不成立。第 4 条「每 fold 33-65」是 131/4、260/4 的均分估计，实算半年折为 5/42/38/46 与 10/90/67/93（`repro/tight_fold_counts_out.txt`，eval_meta ≈ 70 交易日窗）；与网格同窗（buf250）为 24/49/45/47 与 57/107/78/94、年折 73/92 与 164/172（`repro/audit_tight_fold_oat_out.txt`，独立审核）。详见 `final_report.md` §6.1。

**成本模型换了，统计方法的位置随之换。** pipeline-analyst 证明（`pipeline-structure.md` §B/§C，逐 event 对拍 0 mismatch）：六个「必须真扫」参数里四个（gap_max / min_bos / stop_confirm_bars / big_rise_k）可在一次检测里精确出全部档位，只有 bo 两维（min_relative_height / exceed_threshold）是状态机、每档要重跑 bo；反转循环（每股 load 一次 → bo 按档 → burst 多 g → tb 多 (K,k) → min_bos 事后过滤）把 6 维 4 档 4096 格的成本从「4096 次全宇宙 scan ≈ 40 h」压到 **≈ 326 ms/股 ≈ 2715 CPU·s ≈ 5.7 min wall（8 worker）**——整张网格比现设计的一格还便宜。**这是结构性省，精确等价，与本文任何统计方法无关，且把它们的预算意义几乎全部吸收。**

因此本文的统计 / 算法方法分三个身份：

| 身份 | 方法 | 结论 |
|---|---|---|
| **(A) 结构性省不可用时的退路**（detector 全是 bo 那种状态机、无上游流可复用、或工具必须保持 pattern 无关不许专用多值 detect） | 2 档全因子筛选 → 维度等价检验坍缩 → 补档（§2.4/2.5）；条件性 racing（§2.2） | 6 维 4 档 4096 格 → 约 64 + 12～56 次 scan ≈ 30×；racing 再省 ~25%（仅 266 s/次档或固定开销归零时值得）。最终网格精确；坍缩决定近似 |
| **(B) 全网格算完后的零成本事后分析** | 维度等价检验（§3.1）、选择后校正（§3.2）、平局诊断 | **能进最终推荐的部分**：判哪些维「随便取」（容错 = 全宽）、校正 4096 选 1 的选择偏置、把 r=1 邻域最小与容错宽度报告在坍缩后的子空间上 |
| **(C) 仍按档计价的维的档数控制** | bo 两维的粗到细（§2.5） | 每加一档 +6%；4×4 = 5.7 min 时无所谓，扫到 10×10（35 min）才值得粗到细 |

**对 lead 有决策意义的四条负面发现**（合成实验 + 队友实测）：

1. **平局是常态**。目标函数（fold 最小 × 邻域最小）每格噪声 SE 0.02-0.05，格子间真实差异 0.01-0.03，绝大多数格子统计上不可区分。任何「淘汰式」方法都只能淘汰「明显差」的格子；全网格也区分不了平局，这是数据的诚实读数。
2. **min 算子让子样本上的绝对水平判断系统性偏向「拒绝」**。用「整体 score（min-of-min）对水平线」做早停，10% 股票时假淘汰 34-100%（`racing_sim2`）——不是参数没调好，是 min 统计量在小样本上向下偏置。有效的判据必须是**分量式**（对每个 (邻居, fold) 的单个线性增量做单侧检验，取并集），假淘汰 0-1.3%，代价是淘汰比例只有 12-49%。
3. **scb 维相邻格几乎不相交**（integrator-skeptic 实测 Jaccard 0.074 / 0.025），配对红利在最重要的维上为零；嵌套维（gap_max / min_bos / bo 两参数）Jaccard 0.57-0.83 → 配对方差缩 3.7-11×（公式 §1）。
4. **收紧态下 fold-min 目标不可评估**。最终 where 配置下全网格只剩 131-260 个 match（skeptic 从 scan 文件核实），按半年 4 折每 fold 33-65 个 < 功效线 100；合成实验中该档**64 格无一可评估**（功效线降到 30 也一样）。这与省预算无关，是 region_find 在收紧态的可行性问题，必须由 lead 拍板（宽进底座上算区域、where 作事后维只在 count 允许处收紧；或 fold 改年）。

**多重性取代预算成为主要风险**（§3.2）：4096 格里挑邻域最小最高者，选择偏置量级 σ√(2 ln C_eff) ≈ 0.03 × √(2 ln 40) ≈ 0.08——与要找的效应同量级；推荐用 bootstrap optimism 校正（每副本重选 argmax、回原数据看其增量），零 scan 成本。

## 1. 记号、两套成本模型、两个基准、配对方差

**记号**：`C = Π_d L_d` 格子数；`S` 股票数（全池 8325 只 pkl，命中股 400-2900）；`t_scan` 单次全宇宙 scan（35 s ATR 修后 / 266 s 修前，lead 给定）；`t_fix` 每次 scan 调用固定开销（进程池、导入、落盘；本文以 `f = t_fix/t_scan` 参数化，35 s 档取 0.1）；`φ` 某格评估的股票比例。

**成本模型 M1（现设计：一格一次全宇宙 scan）**：`T = C · t_scan`。
**成本模型 M2（反转循环，pipeline-structure §C.2 实测）**：`T = S · [L + P + N_bo · (B + U + T_tb) + Λ]` = `8325 × [6.8 + N_bo × 19.9 + 0.4] ms`，N_bo = bo 两维档数之积；其余四维加档几乎免费。

**基准 A**：6 维 × 4 档 = 4096 格。M1：39.8 h / 12.6 d。M2：N_bo = 16 → 326 ms/股 → 2715 CPU·s ≈ **5.7 min**（8 worker）。（勘误：实测 345 ms/股 × 6720 股 = 2320 CPU·s ≈ 4.8 min，见 §0 勘误；M1 的 266 s 档为早期记录，本轮实测现状 wall 120～160 s，12.6 d 偏保守约 2.4×）
**基准 B**：3 维 80 格（spec：scb 5 × min_bos 4 × gap_max 4，全在便宜四维里）。M1：47 min / 5.9 h。M2：N_bo = 1 → 27 ms/股 → 225 CPU·s ≈ **0.5 min**。

**可按股分解**：`scan.py::_aggregate_first_passage` 与 pipeline-structure §D 确认四态计数、随机基线、fr 都是逐股 / 逐 match 记录的求和或中位数，无跨股状态；部分股票的结果可精确拼接，同一批股票上的多格天然配对。

**配对方差（统一公式，按维代入实测）**。两格 A、B 共享 match 集 S，各自独占 D_A、D_B。FP 差里共享部分抵消：`FP_A − FP_B = (b − a)·FP_S + a·FP_DA − b·FP_DB`（a、b = 独占占比）。等大小时 a = b，`Var_配对/Var_独立 = a = (1 − J)/(1 + J)`（J = Jaccard）；嵌套（A ⊂ B，w = 1 − |A|/|B| 为 B 的独占占比）时同样得 `w/(2 − w) = (1 − J)/(1 + J)`。整理 integrator-skeptic 更正后的形式：非共享占比 w 时缩减 ≈ 1/w 量级（w = 0.2 → 9×，不是 w² 的 100×——我在初排序消息里写错了一档，本文与合成实验的公式是对的：`(1−w)²(1/n_A+1/n_D)/(1/n_A+1/n_B)` 代入 w_retain = 0.8 得 0.111，与 bootstrap 实测 0.11-0.12 一致）。

| 维（相邻档） | 实测 Jaccard（skeptic） | 结构 | Var_配对 / Var_独立 | 功效增益 |
|---|---|---|---|---|
| gap_max 4↔8↔12↔20 | 0.77-0.83 | 严格嵌套 | 0.09-0.13 | 8-11× |
| min_bos 1↔2 | 0.794 | 严格嵌套 | 0.115 | 8.7× |
| bo exceed 0.003↔0.01 | 0.689 | 近嵌套 | 0.18 | 5.4× |
| bo mrh 0.15↔0.2 / 0.2↔0.3 | 0.751 / 0.571 | 近嵌套 | 0.14 / 0.27 | 7× / 3.7× |
| big_rise_k 3↔5 / 5↔8 | 0.48 / 0.61 | 部分重叠 | 0.35 / 0.24 | 2.9× / 4× |
| **stop_confirm_bars 0↔1 / 1↔2 / 2↔3** | 0.755 / **0.074 / 0.025** | 0↔1 嵌套；其余**互斥** | 0.14 / **0.86 / 0.95** | 7× / **≈1×** |

含义：scb 维每加一档 confirm 点后移、买点窗全换，相邻格是**不同的样本**——配对红利为零，任何跨 scb 档的比较只能靠绝对功效；这也是 r=1 邻域最小在 scb 维上「要求 edge 跨 3 档才有正格」的原因（`racing_sim2` 里宽 2 档的甜点邻域最小全负）。

**目标函数的噪声地板**：每格每 fold count n_f 约 100-700（宽进态）→ SE(FP) = 0.5/√n_f = 0.019-0.05；fold-min（4 折）再邻域-min（2d+1 格）只增不减，且 **min 的期望向下偏置 ≈ −σ·E[max of k normals]** ≈ −1.0σ（k=4）到 −1.5σ（k=7）。任何方法都不能把「区分 0.01 的差异」变便宜；方法只能省「不需要区分」的部分。

## 2. 方法逐条

每法固定给：原理 / 算式（基准 A、B，M1 与 M2 下）/ 假设 / 失效 / 与「找区域」的兼容性 / 现成实现或自研。

### 2.1 阈值型维度 sweep：一次 scan 出多个格子

**原理**。若参数只做过滤或结构可导出（更严 ⊂ 更松、或一次遍历可得全部档位），用最松档跑一次、per-match 记下「它在该维能通过的最严档」，事后任何档位的格子 = 过滤后的 match 集合，逐位精确。

**本流水线的真实判定**（pipeline-structure §B.1，逐 event 对拍）：min_bos ①过滤型、gap_max ②结构型、stop_confirm_bars × big_rise_k ③多值同评型——四维精确；bo 两维 ④状态机、不可。**所以「sweep」不是本文独立的统计方法，它就是 M2 反转循环本身**；我在初排序里按「3 维可 sweep → 64×」估的账被实测取代为「4 维精确多值 + bo 两维每档重跑 → 700-1600×」。

**算式**：M1 视角 `N_scan = Π_{不可 sweep 维} L_d`：基准 A 若只有 min_bos 可事后切 → 1024 次（10 h / 3.2 d）；四维全可 → 16 次（9.3 min / 71 min）。M2 视角即 §1 的 5.7 min。基准 B（三维全在便宜四维里）：M1 只切 min_bos → 20 次（12 min / 89 min）；M2 0.5 min。**精确等价**。

**假设 / 失效**：把「改产物」的参数当过滤参数 sweep → 结果是错的不是近似的（bo 两维若被当过滤型：1-11% BO 差异 + 15% drought 漂移，pipeline-structure §E.1）。防线：pipeline-analyst 的 `multi_value_equiv.py` 差分对拍固化为测试。**兼容性**：完全兼容（全网格、per-match 四态齐全）。**实现**：自研新入口（pipeline-structure §D：小改 label M 提取 + 新反转循环脚本 + 引擎不动）。

### 2.2 以股票为数据流的 racing

**原理**。把「股票」当 racing 的实例流：所有格子先在 φ₁ 股票上评估，按股 cluster bootstrap 估各格统计量，淘汰「确信不在区域内」的格子，幸存者及其 r=1 邻域继续加股票，终态幸存格全宇宙精确。骨架：Hoeffding races（Maron & Moore 1993）、F-Race / irace（López-Ibáñez et al. 2016）、successive halving（Jamieson & Talwalkar 2016）、CVST（Krueger et al. 2015，线性增大的数据子集上序贯检验淘汰，最高 120×）。

**淘汰判据对准什么（回应 skeptic #4）**。目标函数 `score_c = min_{n ∈ N(c)∪{c}} min_f inc_{n,f}`。四种判据在 `racing_sim2` 里对照：

| 判据 | 定义 | 有效性 |
|---|---|---|
| best（整体） | `P_boot(score_c − score_ĉ ≥ −δ) < α`，ĉ = 已见数据点估计最优格 | 找最优平台；配对差抵消部分 min 偏置；**有互斥维时假淘汰 7-21%**（无配对） |
| level（整体） | `P_boot(score_c ≥ −δ) < α` | **无效**：min-of-min 在子样本上向下偏置，假淘汰 34-100% |
| **level_comp（分量式）** | `∃ (n ∈ N(c)∪{c}, f): P_boot(inc_{n,f} ≥ −δ) < α` | **有效**：score_c ≤ inc_{n,f} 恒成立，任一分量确信低于线 ⇒ score 确信低；每个检验是单个线性统计量、无 min 偏置；并集 → 保守 |
| best_comp（分量式） | `∃ (n, f): P_boot(inc_{n,f} − score_ĉ ≥ −δ) < α` | 有效但极保守（score_ĉ 本身偏低） |

「找区域」要的是 **level_comp**：它对准水平线（相对参照增量 ≥ −δ）、保留 CI 跨线的格子，区域边界与容错宽度的数据都还在；best 类判据会把边界一起淘汰（skeptic 的批评成立）。淘汰的传播是对的：c 确信低 ⇒ 所有以 c 为邻居的格子的邻域最小也确信低（分量式判据自动包含）；反向（c 确信高）不能传播，所以 **幸存格 ∪ N(幸存格) 必须同步评估**——这是必需项不是可选项。锚 ĉ 时必须锚固定索引，不能锚每副本内的 max（选择效应会把真最优淘汰，第一版实验踩过）。

**合成实验 2（按 skeptic 要求的真实密度）**：6000 股、match 集中在 10% 股票上（~5000 match，参照 = 全部 match）、3 维 64 格（scb 式互斥维 × gap_max 式嵌套 ρ=0.85 × min_bos 式嵌套 ρ=0.8）、功效线 100/fold、δ=0.01、α=0.02、B=300、15 seed；oracle = 全网格 × 全宇宙。

读数：(a) 有效判据下 10% 股票淘汰 12-27%、50% 淘汰 18-49%，假淘汰 ≤ 1.3%（null 2 折的 5-7% 来自区域只有 3 个贴线格子）；(b) 预算比例（4 阶段 10/25/50/100 + 邻域税）≈ **0.75**；(c) 收紧态无可评估格 → racing 无落点，且这是 region_find 本身的可行性问题（§0 第 4 条）；(d) 半年 4 折比年 2 折少 14/64 可评估格、区域小 2 倍、max 低 0.02——fold 数是功效与时间一致性的直接交换。第一版实验（`racing_sim.py`，均匀嵌套维、无互斥维）的 best 判据预算 0.60-0.98、假淘汰 2-15%，与此一致：**平局多则不省**。

**算式**。预算比例 `ρ = Σ_k |E_k| Δφ_k / C`，E_k = 活跃 ∪ 邻域；实际时间 `T = t_scan · (ρ·C + f·Σ_k |E_k|)`。M1 基准 A：4096 × 0.75 → 30 h / 9.5 d，首阶段 10% 已等于 410 次全 scan——**单独用不推荐**；叠在退路流水线的补档格上（k′=3 → 56 格）省 14 格 ≈ 8 min / 62 min。基准 B：80 × 0.75 = 60 → 35 min / 4.4 h。阶段数权衡（`racing_stages_check.py`）：5 阶段比 3 阶段多省 5-14 个百分点，但固定开销 Σ|E_k| 翻倍（306-371 vs 150-190）；35 s 档 t_fix = 3.5 s 时 5 阶段固定开销 21 min > 节省 7 min，**净亏**；266 s 档净赚约半小时。**M2 下**：格子特异成本 ≈ (U + T_tb)/C ≈ 0，淘汰格子省不到钱；分层写法（skeptic #5）`省 = Σ_stage 淘汰占比_stage × 成本占比_stage`：bo 81%（只有某 bo 档下**全部**格子被淘汰才省，level_comp 下需要该档 4^4 = 256 格全部确信低）、burst+tb 15%、load/label 4%（永不省）→ 期望省 < 5%。**M2 下不做。**

**假设**：严格按股分解（已证）；股票可随机排序（行业簇效应让 10% 阶段代表性偏差，cluster bootstrap 已计入）；t_fix 小。**失效**：平局多不省；t_fix 大净亏；早期阶段投影 count 不稳（严格格子 10% 股票时功效线判定摇摆）。**兼容性**：level_comp 兼容区域交付；best 类不兼容。**实现**：irace（R 4.4.0）/ CVST（R）判据不对口；Optuna `SuccessiveHalvingPruner` 是按 step 剪 trial 的形状；**自研** ~100 行 numpy（`racing_sim2.py::racing_stage_stats` 即原型），挂在反转循环的「按股票子集跑 + 增量合并计数」上。

### 2.3 全局无效性早停（racing 附属，「无区域」裁决加速器）

所有活跃格子都满足 level_comp 淘汰条件 → 判「无稳健区」停止。第一版实验（整体判据）在崩塌场景 100% 触发、预算 0.21，但平台区误触发 5-10%；换分量式判据后误触发应降到 ≤ α（未单独重跑，标 unknown）。定位：只在用户接受「无区域」作终局时启用，α_futility 收紧到 0.005 并要求连续两阶段。M2 下同样无预算意义（5.7 min 全算完更省事），只作诊断口径。

### 2.4 筛选设计 / 维度坍缩：2 档全因子 + 等价检验

**原理**。对 m 个必扫维各取 2 档（最松、最严-仍达功效线）跑 2^m 全因子（m=6 → 64 次）——**无混杂**，主效应与所有阶交互全部可估。分数因子（pyDOE3 `fracfact`/`fracfact_opt`，https://pydoe3.readthedocs.io/en/latest/factorial.html ）或 DSD（`definitive_screening_design`，BSD-3，6 因子 13 次，https://github.com/danieleongari/definitive_screening_design ）省的 48-51 次在 35 s 档只值 30 min，换来的是分辨率 III 下主效应与二阶交互别名（E[β̂_A] = β_A + β_BC）——**毒药闸正是交互效应**（skeptic #4），别名会把交互记到错的维上、或让交叉型交互（一处升一处降）的主效应抵消成「全平」而被筛掉。处理：M1 下直接跑 2^m 全因子（别名保险费 30 min）；M2 下全因子免费。假阴性可见性：不用主效应做筛选，用**逐对对比**——沿维 d 在每个其他维组合下的相邻档配对差都检验（§3.1），交叉型交互表现为异号的逐对差 > 2ε，不会被判平；剩余盲区 = count 低于检验门槛的格子里的交互，**报告「未检验对数」**而不是沉默。

**坍缩判据**：§3.1 的等价检验。合成实验（4 档全因子、35% 股票）：真平坦维判出率 85-100%，强效应维（+14pt）误判 0-5%，单维效应 < 2pt 的弱平台维判平 40-50%——这是 ε 的定义（效应小于 ε 的维在区域意义上就是「随便取」，交付容错 = 全跨度），不是缺陷。

**算式**（M1 退路）：`N = 2^m + (Π_{保留维} L_d − 2^k′)`。基准 A：k′=2 → 64 + 12 = 76（44 min / 5.6 h）；k′=3 → 120（70 min / 8.9 h）；k′=4 → 304（3.0 h / 22 h）。基准 B（m=3，8 次）：坍缩 1 维 → 8 + (20 − 4) = 24（14 min / 106 min）；无坍缩 → 80（无省）。**M2 下**：省的是本来就不贵的东西（5.7 min），却引入近似 → 作为**采样步骤**不做；等价检验保留但换身份为事后分析（§3.1）。

**假设 / 失效**：「两端平 ⇒ 中间平」（嵌套阈值维通常单调或单峰；严端崩塌型被 2 档判为「有害维」不会误坍缩，「两端等、中间凸」型会）；对**互斥维（scb）根本不适用**——相邻档是不同样本，两端无信息可外推到中间；ε 与区域容忍 δ 是两个独立声明量。**实现**：自研 40 行 numpy（`racing_sim.py::flat_dims`）。

### 2.5 多分辨率 / 粗到细

与 §2.4 是同一流水线：2 档全因子 = 粗网格，非平坦维补齐 = 加密。

**充分条件（回应 skeptic #3/#6）**：设 R = fold-min 增量为正的格子集合（邻域最小之前的原始区域）。若 R 含一个各维边长 ≥ h_d 格的轴对齐盒，则步长 h_d 的粗网格至少命中 R 一格（鸽笼：任意 h_d 个连续档里必有一个粗档）。要让 r=1 邻域最小区域非空，R 至少要含一个半径 1 的十字，故实际要求 **h_d ≤ R 在维 d 的最小宽度，且 R 的宽度 ≥ 3**。失效：细长区（某维宽 < h_d）、粗步内的凸起 / 崩塌、两个不相交区（粗网格粘连或漏一）。**退化情形**：整数维档位 ≤ 5（scb 0-4、min_bos 1-4）时「粗」= 两端点、「细」= 全部档，没有中间态，粗到细退化为 §2.4；**互斥维（scb）无平滑性可依**，相邻档之间「没有中间态」意味着粗网格对中间档零信息——粗到细在该维无效。它只对**档位 ≥ 8 的嵌套维**有意义；M2 下这恰是唯一按档计价的 bo 两维：4×4（5.7 min）不值得，10×10（N_bo=100 → 8325 × 2.0 s ≈ 35 min）时先 4×4 粗定位再在区域邻域加密到 ~30 档组合 → ~12 min。区域边界精度：加密必须补全 r=1 邻居（整维补齐或候选区 r=2 邻域），否则邻域最小算不出来。**近似**（边界精度受粗步长限制直至加密）。

### 2.6 自适应水平集估计（straddle / LSE / Bichon / TRLSE）：维持否决，理由翻转

上一轮否决理由：20-40 次预算下代理不可靠、失败自我强化不可见。**翻案条件**（缺一不可，回应 skeptic #5）：
1. 响应面在每个扫描维上空间平滑——嵌套维（相邻 J ≥ 0.6）满足；**互斥维（scb，J 0.07）不满足**，GP 在该维无可插值之物（lengthscale 会坍到 < 1 档，等价于逐档独立）；
2. 格子总数 ≥ 5× LSE 预算（即按格计价且 ≥ 500-1500 格）——M2 下永不成立（格子免费）；M1 下仅 k′ ≥ 5；
3. 初始设计 ≥ 2^k′ 角点 + 中心星（即先做 §2.4 的 2 档全因子）；
4. 失败可见性：推荐格的 r=1 邻域全部真评估并与 GP 预测比对，任一邻居 |GP − 真值| > 2 SE → 判代理失效、退回全网格；交付物永远用真计数（GP 只决定把预算花在哪）。
条件 1 对 scb 不成立、条件 2 在 M2 下不成立 → **否决维持**。此外与目标函数不兼容：r=1 邻域最小 + 按股联合 bootstrap 需要每个邻居的真实四态计数，GP 均值给不了。实现（若条件成立）：Trieste 4.6.0 ExpectedFeasibility（上一轮已核，TensorFlow / Python ≤ 3.12）或 sklearn GP + 20 行 straddle；LSE 文献 https://people.csail.mit.edu/alkisg/files/gotovos13mscthesis.pdf 、https://arxiv.org/pdf/2111.01768 、https://arxiv.org/pdf/2408.03144 。

### 2.7 股票子样本作代理（非自适应）

φ₀ 股票上全网格 → 取候选及邻域 → 全宇宙。预算 `φ₀ + (1 − φ₀)·|候选 ∪ N|/C`；子样本 SE 是全样本的 1/√φ₀（0.2 → 2.24×），δ′ 必须放宽到 δ + 2 SE 差。第一版实验（φ₀=0.2、δ′=0.03）：预算 0.40-0.71，**误丢 oracle 区域 30-65%**，argmax 一致 0.25-0.85——它就是 racing 只跑一阶段就停，全面被支配。基准 A M1：16-28 h；基准 B：~23 min。近似。**不推荐**。

### 2.8 其他

- **Bandit 式区域淘汰**：每批股票同时更新所有 arm（配对），按 arm 分配样本无意义；racing（§2.2）已是本结构下 bandit 的正确形态。
- **共同随机数（CRN）**：配对 = ranking-and-selection 的 CRN 方差缩减，§1 公式是它在集合重叠上的闭式；**切勿**对不同格子用不同股票子集。
- **分层 / 经验贝叶斯 shrinkage**（回应 skeptic 第 7 条）：邻域最小已是保守平滑器（min 的向下偏置 ≈ −1 到 −1.5σ），再叠 James–Stein 型向邻域均值收缩是**双重收缩**：+0.03 的真平台可能被压到线下。**不叠**；若 region_find 出现「小 count 格子当选」的病态，用功效线而不是 shrinkage 处理。
- **多格子共享一次数据加载**：即 M2，pipeline-analyst 已实测。

## 3. 能进最终推荐的事后分析（零 scan 成本，在 M2 全网格产物上做）

### 3.1 维度等价检验（判「随便取」维）规格

- **对象**：每维 d，所有相邻档位对 (c, c + e_d)。统计量 = fold 合并 FP 的配对差 Δ_{c,d}（fold 合并而非 fold-min：平坦性问的是「该维值不值得调」，时间一致性由 region_find 的 fold-min 另管）。
- **重采样**：与 region_find **同一批**按股 cluster bootstrap 副本（联合重采样整张网格），配对差在每副本内算——自动继承 §1 的配对方差缩减。
- **两层判据**：(a) 汇总对比：按 min(count) 加权的 Δ 均值 95% CI ⊂ [−ε, ε]；(b) 逐对：两格 count ≥ n_pair_min（建议 600，全数据时 SE ≈ 0.02 → 配对 CI ± 0.015-0.03）的每一对 95% CI ⊂ [−2ε, 2ε]。两层皆过 → 维 d「在 ε 下平坦」，坍缩到最松档（count 最大），交付「容错 = 全跨度」。
- **ε 取值依据**：研究者声明「小于多少 FP 差异不值得为之调参」，与区域容忍 δ 独立；建议 ε = 0.02（≈ 全数据单格 SE，比 OAT 报「全平」的 0.005-0.01 波动大一档）。
- **多重性**：平坦是**交集**判定（所有对都得过），检验越多越难判平 → 假平坦率不因多重性膨胀；代价是假「不平」（保守方向）。不做 Bonferroni。
- **报告**：每维 (a) 汇总 CI，(b) 检验对数 / 未检验对数（功效不足），(c) max |Δ| 及其 CI，(d) 异号对数（交互指纹）。
- **适用维**：嵌套维；互斥维（scb）逐对差是两个独立样本的差（无配对缩减、CI 宽 √2 倍），仍可检验但功效低。
- **实证**：§2.4 的合成实验数字。

### 3.2 选择后校正（回应 skeptic E）

**问题**：全网格便宜后，「4096 格里挑邻域最小最高者」的选择偏置成为主要风险。独立格子时 E[max_C 噪声] ≈ σ√(2 ln C)：σ = 0.03、C = 4096 → 0.12；嵌套维强相关使有效格数远小（bo/gap/min_bos 维各 ~2 个有效自由度，scb 4-5 档近独立）→ C_eff ≈ 20-60 → **0.07-0.09**。fold-min 与邻域-min 的向下偏置（≈ −1 到 −1.5σ）部分抵消，但两者量级都与真实效应（0.01-0.05）相当，净方向不可事先知道——**必须校正**。

**方案（bootstrap optimism，Efron 1983 / Harrell）**：用 region_find 那批按股 bootstrap 副本：
1. 每副本 b 重选 `ĉ_b = argmax_c score_b(c)`；
2. `optimism_b = score_b(ĉ_b) − score_orig(ĉ_b)`（副本里选中者的副本分数 − 它在原数据上的分数）；
3. 校正分数 `score_orig(ĉ) − mean_b(optimism_b)`，并报告其 bootstrap CI；
4. 同时报告选择频率 `P_b(ĉ_b ∈ ĉ 的 r=1 邻域)`（稳定性）。
**交叉核对**：按股分半交叉拟合（奇数股选格、偶数股评估，互换取平均）——无偏但功效减半，作 sanity 不作主判。这两项与 lead 审视报告 §3.2 的「推荐格子稳定性 + 增量 CI」是同一批副本上的加算，零成本。

### 3.3 平局诊断

报告「与 argmax 统计不可区分（配对差 CI 含 0）的格子集合」及其在各维的跨度——这本身就是区域交付物的一半（容错宽度），也是防止把平局里的随机赢家当发现的口径。

## 4. 叠加与假设冲突（回应 skeptic #7）

**M2（主线）**：`T = S·[L + P + N_bo·(B + U + T_tb) + Λ]`。四维精确多值 = 结构性 sweep；bo 两维粗到细控制 N_bo；racing 无落点（格子特异成本 ≈ 0）；事后分析 §3 零成本。**无冲突**——只有一次遍历，格子集合从头固定。

**M1 退路**：`N = 2^m + (Π_{保留维} L_d − 2^k′)·ρ_racing`，sweep 维完全不进 m。顺序必须是：2^m 全宇宙（精确）→ 等价检验坍缩（定格子集合）→ 补档格上 racing（level_comp，幸存 ∪ 邻域同步；角点已全评估、可作邻居）。**冲突点**：racing 需要固定格子集合，粗到细却在改集合——只要**先定集合再 race** 就无冲突；若在 race 中途加格子，新格子必须在已见全部股票上补评估（成本 φ_seen × 新格子数），等价于回到上一阶段。基准 A 期望路径（m=6、坍缩到 k′=3、ρ=0.75）：64 + 56 × 0.75 = **106 次**（62 min / 7.8 h）vs 4096；k′=2：64 + 12 = 76。
