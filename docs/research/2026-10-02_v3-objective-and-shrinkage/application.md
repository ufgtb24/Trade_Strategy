# 应用目标：有限资金下到底应当让什么变好

日期：2026-10-02。范围：评分设计研究，不修改正式算法，不读取真实验证集。本文件所有项目内路径均相对 repo root。

## 结论

Optuna 应当寻找更值得实际采用的参数。统计可靠性的职责，是帮助我们更准确地判断“值不值得”，而不是把样本数、重抽次数、覆盖月份另列为无限增长的收益来源。合理结构是：**明确一个应用目标，对它的估计作证据校正，再保留少数确实不能接受的底线**。

现阶段没有完整的出场、持仓占用、同日选股与费用规则，因此不能声称任何上涨空间公式已经在优化真实资金收益。我建议当前以“证据校正后的绝对上涨潜力”为明确的代理目标；同日普通买入可帮助校正没有独有优势时应期待多少，固定 BO 用来比较复杂规则是否有必要。不要把两个对照优势都变成无上限的奖励，更不要把机会总数线性相加。

这并不证明外层中位数必须保留。**按时段等权**与**外层取中位数**是两件事：前者消除买点密集时段仅靠数量得到的高权重，后者偏好“多数时段的典型表现”，会忽略少数很差或特别好的时段。外层中位数可以暂作清楚标注的代理，但不是统计学上唯一正确或最全面的目标。

## 两种问题不能混为一件

1. 应用问题：如果这些结果是真的，哪个参数更值得买？
2. 证据问题：这些结果有多大可能只是观察误差，或者来自不适合接下来交易的行情？

例如，真实优势 8% 与真实优势 2%，在相同风险、资金占用、费用和可用机会下，8% 更好。实际观察到 8% 但只有少数相关样本，与 2% 但证据充分，排序可以不同；这是对真实优势的估计变了，并不是样本数本身变成了收益。

更多有效、相关的数据通常有助于判断，但“所有指标在统计上都是越多越好”不成立。重复计算同一批行情、同一天高度联动的股票、加入不相关的旧行情，都不能简单等价为更多有效证据。更高的观察分数也可能只是更大的随机波动；不能把高分与高把握混同。

原始的投资组合研究已明确区分“根据资料形成对未来的判断”与“依据判断选择怎样投资”；交易框架进一步把收益、风险、交易成本与持有成本同时放入决策。这些研究支持上述分层，但没有替本项目确定一种唯一效用函数。[Markowitz 1952 原论文](https://doi.org/10.1111/j.1540-6261.1952.tb01525.x)、[Boyd 等人的多期交易框架](https://stanford.edu/~boyd/papers/cvx_portfolio.html)。

## 哪些东西应奖励，哪些应有边界

| 观察量 | 对应用的意义 | 在评分中的合理角色 |
|---|---|---|
| 真正可执行交易的扣费后结果 | 资金最终得到什么；还必须考虑损失和资金占用 | 完整交易政策确定后的最终业务目标 |
| 前瞻收益 | 固定未来期限内最大上涨幅度，是盈利潜力，并非已经赚到的钱 | 当前可用的业务代理；不能替代出场与损失评估 |
| 首次穿越的方向表现 | 先到上行线还是先到下行线 | 当前可以保留方向底线；没有指定兑现方式时，不能随意换算成一份收益奖励 |
| 真实买点日数量 | 是否有足够机会可以使用资金 | 有用程度受持仓和资金限制；可作不足时的约束，不应无限奖励 |
| 独立时段、股票与相关性结构 | 决定对结论应信多少、能外推到哪里 | 证据校正与诊断，不等于必须每月交易 |
| 超过普通买入的部分 | 同样市场日里，筛选股票是否增加了信息 | 可进入无优势时的回退估计；保留对照报告 |
| 超过固定 BO 的部分 | 更复杂的 pattern 相对简单突破是否有新增价值 | 部署比较或有业务理由的底线；不能默认必须逐月战胜它 |

项目定义见 `path2/CONTEXT.md:141`（前瞻收益）、`:148`（首次穿越）、`:155`（买点）。这里没有把最大上涨幅度改叫实际收益。

“方向高于底线后还要不要继续奖励”没有统计学通用答案。把它只当底线，意味着在底线以上主要比较上涨潜力；把它持续奖励，则意味着愿意为方向更稳而牺牲部分空间。二者都是应用取舍。没有具体交易损益换算依据时，不能发明一个乘数，把两种指标硬拼成仿佛客观的收益。

## 资金有限改变了机会数量的含义

假设只有一个可用持仓位置，持有期间不能买下一只。同一天出现 100 个买点，并不等于能执行 100 笔交易；十个不同可用时点各出现一个买点，可能更有实际用处。反过来，如果已经满仓，有没有额外信号可能完全不影响交易。

因此，真正相关的是“资金空出来时，有没有值得使用的机会”，不只是训练集所有股票×日期的总行数。机会达到需要的程度后，更多信号可能只增加选择余地；如果决策政策会强迫多买，还会增加费用与低质量交易。

有限资金也**不推出必须全年均匀出手**。如果坏行情中没有值得买的股票，空仓可能正确。把月度覆盖率直接当交易底线，会把合理的择时误判为失败。覆盖率可以说明估计覆盖了多少行情，但需要与“业务上必须每月有买点”分开。

若新增机会可以不买，而且旧的机会集合与选股能力完全保留，更多可选项不会缩小可行选择集合。但调参往往会同时替换信号集合、改变质量与分布，因此不能由这个性质推导“更多买点的参数总是更好”。

## 两种对照不能任意相加

同日普通买入回答的是：在相同买入日期与可交易池中，不使用 pattern 筛选是否也有这些上涨潜力。它更接近筛选贡献的解释；它不能证明实际等额购买整个池子的资金收益。

固定 BO 则是一个简单方法。若要比较它是否能替代完整 pattern，最好在相同日历、资金限制、选股与出场政策下比较整套策略。只在 pattern 出手的那些日期比较，会改变问题；逐月都要求 pattern 战胜 BO，也未必是合理的应用要求。

**设置对照，不自动等于必须战胜对照才能采用。** 当前没有证据表明 BO 就是用户实际准备采用的唯一替代方案。如果它是可执行的替代策略，可以比较整体部署效用后决定是否替换；如果它只是能力诊断，应报告比较，不应自动否决。普通同日对照也是如此：没有额外选股优势，不代表择时没有价值；若筛出的日期本身很好，pattern 仍可能有用。原参数的比较也应使用同一业务量，不能在搜索主分之外另塞一个原始空间入选条件。

特别要防止两种改写：

- 只优化相对优势，可能偏爱普通股票很差、pattern 仅稍好一些的日子。绝对潜力很好的日子如果普通股票也很好，反而可能失分。
- 只优化绝对潜力，可能把大盘普涨或更高波动带来的上涨也全部算作 pattern 的能力。

前者不是自动比后者全面，后者也不是天然足够。必须明确当前需要“更大的买入潜力”，还是“更大的独有筛选优势”。当前用户的应用描述更支持前者作为主量，后者参与校正与解释。

基线与候选无关、且只是减去同一个常数时，绝对值与相对值排序一致。这里同日基线会随候选选择的日期改变，且外层中位数不是线性运算，不能套用这个简化。

## 为什么双中位数不是最终裁判

设每个月确实都有买点。A 在七个月的窗口内买点空间中位数为 10%，另外五个月为 0%；B 十二个月均为 6%。外层中位数选 A：10% 高于 6%。但各月等权的平均空间是 A 约 5.83%、B 为 6%。这说明外层取中位数还引入了“多数月份典型值”的偏好，不仅仅是让月份等权。

如果换成真正的周期净收益，A 七个月 +3%、五个月 −20%，B 每月 +2%，周期中位数仍偏爱 A。这并不是当前空间标签的数据实例，而是说明：中位数本身没有阻止少数时段造成很大损失。最大上涨幅度没有直接包含这种损失信息，更不能单靠双中位数完成实盘风险评价。

无买点的窗口另当别论：买点空间未定义，不能把它编成 0。只有在明确交易政策和持币收益后，整个周期的交易结果才可以把空仓记作现金表现。统计口径必须前后一致。

## 当前可落地到设计层的推荐

1. 继续把“买入后的绝对上涨潜力”作为当前唯一主量，明确它只是没有完整交易政策时的代理。
2. 用同日普通对照帮助估计没有足够筛选证据时应期待什么；证据充分才完整保留观察到的超额部分。这样证据通过主分产生连续影响，不必给数量单独加奖励。
3. 固定 BO 与普通对照都在每个候选里计算，让搜索获得完整比较信息；是否作为限制，要有明确应用理由。不能把两项优势都自动当成无限奖励，也不能分别用同一批证据惩罚三次。不采用“两个对照优势都必须显著大于零”的默认否决规则。
4. 真正不可接受的方向退化与机会严重不足仍可作为约束。机会不足应区分统计证据不足与资金可用时没有机会；不要把全面月份覆盖偷偷当成业务目标。
5. 保留“时段等权”的明确含义；外层中位数若暂留，必须说明它选择典型月份，不声称它全面。展示差月份与均值信息，以看清它舍弃了什么，但不临时把这些信息再拼成一份任意加权的新评分。
6. 确定可执行交易政策后，以同资金条件下的扣费后交易效用替换空间代理。届时机会饱和、持仓占用、损失与空仓会自然进入同一个业务量，不必分别发明奖励。

可表达为一类结构，而非已验证的实现公式：

`校正后的应用估计 = 无独有优势时的参照表现 + 可信程度 × 观察到的额外表现`

这里的“可信程度”必须针对真正独立、与接下来用途相关的信息设计和校准。200 次高度重叠的随机窗口不是 200 份独立证据。方向约束和机会约束不因此自动消失；也不能把这条公式叫作已证明最优。

同日背景本身也有误差，不自动就是正确的回退值；需要共同考虑候选与对照估计的相关性。回拉会压低证据薄弱的好成绩，也会抬高证据薄弱的差成绩，因此不能称作只惩罚好运气。若先逐窗校正再取中位数，这是一个新的工程预测分，不是对原始双中位数的无偏修复，也不能在没有模型时称作后验均值。

有限资金本身并不能唯一推出应选绝对潜力：当前推荐还依赖用户改善买入后上涨潜力的应用目的。假设两个候选观察空间都是 10%、可信程度都是一半，而同日背景分别为 8% 和 2%，校正绝对空间分别为 9% 和 6%，校正额外空间分别为 1% 和 4%，排序完全相反。选择绝对空间，就允许强行情中独有筛选价值较小的候选胜出；这是保留择时价值的预期结果，不能再把它解释成“没有消除市场影响，所以统计失败”。

## 与队友的交叉核对

- `objective_statistics` 同意业务目标与证据校正分层；补充回拉估计与取保守下界代表不同决策偏好，不应都包装成客观更全面。一个主量校正一次，避免重复惩罚同样的证据不足。
- `objective_formula` 核实旧公式为 `b + n/(n+n0) × (m−b)`。当 `m<b` 时，更多样本使评分降低，因此该计数是证据权重，而不是“买点越多越好”的直接奖励。
- 双方都确认：候选相关的基线会导致绝对潜力与额外潜力排序不同；没有一条统计原则能代替业务选择。
- 公式研究员已核对双中位数与相对优势排序的反例并通读本报告，无实质异议；统计研究员已核对上述推荐，并指出逐窗校正后的中位数是一种新代理而不是原分的无偏修复，此限定已补入。

## 局限与最容易误读的地方

- 本研究没有比较真实参数、没有形成市场收益结论，没有触发研究副产品登记标准。
- 推荐的是当下可说明白的代理与分工，绝不是已经完成资金配置优化。
- 不把机会数量无限奖励，不等于机会数量不重要；不把 BO 额外优势无限奖励，也不等于忽视 BO 对照。
- 同日普通对照用于证据回退，不代表 pattern 所有市场择时贡献都被证明或保留；它的比较条件必须在实现时写清。
- 保留双中位数只能是暂定的时间偏好，不是数据已经验证它优于其他聚合。
