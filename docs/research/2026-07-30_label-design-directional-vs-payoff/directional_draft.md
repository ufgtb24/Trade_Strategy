# 方向性 label 设计草案 · directional (v3)

> 视角:用户「视角 1 · 方向性」——平等考虑涨跌,评估选股策略对后续方向的预测力。
> 场景:**web UI 人工分析**(用户看 K 线、逐 match 找规律),非 feedback 自动 score。
> 红线:纯分析,不碰正式代码。本文档只放本文件夹。
>
> **v3 修订记录**(吸收 skeptic 第二轮 + decoupling + payoff):
> - **核心主张调整**:v1/v2 主推「端点收益」为方向 label 主体。skeptic 与 decoupling 独立指出「mfr + min_low 双端极值并列」更奥卡姆(同构、零框架成本、不丢过程极值)。第一性原理重审后**被说服**,改为:min_low 为最小起步,端点收益降为可选增强。
> - **σ 中性论证撤回**:skeptic 戳穿「期望中性 ⟹ 剔除波动率」是偷换——单 match 实现值(用户排序看的)方差仍由 σ 支配。per-match label **不承担**剔除波动率的职责,干净解法仍是 feedback 路子(集合级首穿 + 随机日基线 + 披露波动率倍数)。
> - **定位降级**:per-match label 是 triage(补盲 + 个案可见),不是方向预测力的验收指标;后者干净判据是集合级首次穿越,矛盾时信首穿。

---

## 0. 一句话结论(v3)

**(a) 最小起步 = `mfr`(上行极值 max_high)+ `min_low`(下行极值)双端并列**——min_low 是 mfr 的精确镜像(`min(low[t+1..t+N])/close[t]-1`,买点窗逐点均值),零框架成本、与 mfr 同构、纯过程极值(无持有假设),直接补 mfr「只看涨」的盲区。这是把「跌这半轴还回来」最省、最一致的做法。

**(b) 端点收益 `close[t+N]/close[t]-1` 降为可选增强**——它回答 min_low 回答不了的「最终净涨跌」,但隐含「持有到期」假设、定位次于双极值,默认不上。

**(c) per-match label 的定位 = triage(补盲 + 个案可见),不是验收指标**。方向预测力的干净判据是集合级首次穿越(feedback c 项,已存在),per-match label 不评判、只展示,矛盾时信首穿。

**(d) 波动率混淆 per-match label 不剔除**(诚实):双极值/端点收益都去掉 mfr 的选择偏差(max/min 选端),但单 match 实现值的**方差仍由 σ 支配**——排序时「数值极端」的仍系统性是高波动股。干净解法靠 feedback 路子(集合级首穿 + 随机日基线 + 披露波动率倍数),不靠 per-match label。

## 1. 「方向性」与 per-match label 的定位

方向性的第一性问题:价格会不会朝一个方向净位移。但 **per-match label 不负责评判这个**(skeptic 裁定):feedback c 项已实测当前 pattern 方向接近无信息(pk4 首穿 8 单元 7 个低于随机日),且首穿(顺序、与幅度解耦、与随机日比)才是干净的方向检验。per-match 端点收益可因漂移/少数大涨而为正、与首穿矛盾——**矛盾时信首穿**。

所以 per-match label 退到 triage 职责:**补 mfr 的跌盲区 + 让用户在个案 K 线上看见跌**。它的真价值是「补盲 + 可见」,不是「测方向预测力」。据此,mfr 已是上端极值 ⟹ 补盲的最小、最一致改动是镜像加一列下端极值 min_low,而非引入端点收益这个新语义。

## 2. 定义与公式

### 2.1 最小起步:min_low(mfr 的镜像)

```
min_forward_drawdown(match, end_node, df, N):
    ev = match.node_index[end_node]          # 买点窗 [start_idx, end_idx]
    rets = [ float(low.iloc[t+1 : t+N+1].min()) / float(close.iat[t]) - 1.0
             for t in range(ev.start_idx, ev.end_idx+1)
             if t+N < n_bars ]                # t+N 越界跳过,与 mfr 同
    return mean(rets) if rets else None       # ≤0,量「N 日内最大下行幅度」
```

- 与 `path2/eval.py:39` 的 mfr **完全同构**,只把 `high...max()` 换成 `low...min()`。
- 双端并列(mfr, min_low)像 OHLC 的极值切片:上行天花板 + 下行地板,各自保留过程极值、不合成(skeptic 点明:不合成就没有「双极值合成丢顺序」问题)、不丢信息。
- 纯过程极值,**不含持有到期假设**(和 mfr 一样,只看窗口内极值,不指定终点)。
- 逐买点逐点算,支持与 strategy_return 在同一批买点上 2×2 配对(decoupling 要求)。

### 2.2 可选增强:端点收益(净落点)

```
endpoint_return = close[t+N]/close[t] - 1   # 买点窗逐点均值,口径同上
```

- 回答 min_low 回答不了的问题:**最终净涨还是净跌**(min_low 只给下行极值,不给终点)。
- 代价:隐含「持有到期」假设(decoupling 警示:虽 horizon 全局不可调属选股侧,但仍是「一种交易规则的结果」,非完全无假设,语义要讲清)。
- **定位次于双极值**,默认不展示;用户明确要看「净结果」时再上。

### 2.3 XAGE 实测(payoff 跑的硬数据,repro/xage_sim.py)

XAGE `tb_208_213`:mfr +1.3%(盘中摸高),实为暴跌。payoff 实测三个 label:
- **min_low**:窗内最深跌幅(量级接近 context 所述 -83%)。
- **端点收益(directional)**: **−77%**(净落点)。
- **strategy_return(payoff)**: **−8%**(每个进场日早早触发止损,根本没走到到期)。

三个数三种语义,完美例示分工:mfr 只看到 +1.3% 摸高(**盲区**);min_low/端点收益把暴跌还回来(−77% 量级);payoff 因止损只承 −8%(**交易干预截断了裸位移的显示**)。这正是 directional 不可被 payoff 合并的硬证据(见 §7)。

## 3. ★ 波动率:per-match label 不剔除它(诚实表述)

撤回 v1/v2 的「端点收益对 σ 期望中性 ⟹ 剔除波动率混淆」。skeptic 戳穿这是偷换:

- **期望中性只证明集合均值 E[] 不被 σ 抬高**(去掉 max 的选择偏差,这点对)。
- 但用户在 web UI 看的是**单 match 实现值**并按它排序。单 match 实现值 = E + 噪声,噪声**幅度随 σ 放大**。
- 所以高波动股的 min_low / 端点收益**实现值散布更大**:既出大正也出大负。排序时「数值极端」的仍系统性是高波动股——和 mfr 同病,只是从「均值虚高」换成「方差放大致极值更极端」(mfr 两者都有;min_low/端点收益去掉了均值偏置,但保留方差支配)。
- feedback g 项(A.1,R²≈0.92)的内核正是「label 方差由 σ 解释」。min_low/端点收益的方差同样由 σ 解释,系数比 mfr 小但绝不到 0。

**诚实表述**:per-match label(无论 min_low、端点收益、mfr)都**不剔除**波动率尺度。波动率混淆的干净解法仍是 feedback 的路子:
1. **集合级首次穿越**(与幅度解耦、与随机日比)——方向有无优势的唯一干净判据;
2. **随机日/bo_only 基线**(汇总级,扣漂移、扣突破本身贡献);
3. **波动率倍数**(lag 口径)作披露列。
4. per-σ 归一(`label/σ_N`)若做,是**可选披露视角**让用户区分「方向 alpha vs 波动红利」,不进打分(§0 否决把 σ 并进权重)。

per-match label 只负责「补盲 + 可见」,不负责「剔波动率」——这两件事分开,是 v3 的核心修正。

## 4. min_low vs 端点收益:为何 min_low 是最小起步

| | min_low(最小起步) | 端点收益(可选增强) |
|---|---|---|
| 语义 | N 日内最大下行幅度(过程下极值) | N 日净落点 |
| 与 mfr 关系 | 精确镜像、同构 | 不同构(极值 vs 落点) |
| 框架成本 | 零(把 max 换 min) | 新增第三种语义 |
| 过程信息 | 保留(极值) | 丢(只看终点) |
| 持有假设 | 无(纯过程极值) | 有(持有到期) |
| 回答 | 「最惨跌到哪」 | 「最终涨还是跌」 |
| σ 支配 | 是(方差,同 mfr) | 是(方差) |

**为何 min_low 优先**(skeptic+decoupling 汇聚):补 mfr 盲区(看不到跌)的最小、最一致改动是镜像 min_low——它和 mfr 在「过程极值」语义上完全对称,不丢信息、不引入新假设、零框架成本。端点收益是额外语义(净落点),有独到价值(min_low 给不了终点)但隐含持有假设、定位次之,作可选增强。

**不合成**:min_low 与 mfr **两列独立并列**(像 OHLC),不合成单一标量。v1 候选 B 弃掉 min_low 是因「合成丢顺序」——不合成就没这个问题;顺序的评判本来就交给集合级首穿,per-match 层两列各自展示极值即可。

## 5. 与 mfr 的关系:双端极值对称 + 背离即信号

(mfr, min_low) 双端极值对称:上行天花板 + 下行地板。背离即信号:
- `mfr高 + min_low温和` = 真上行(摸高且没怎么跌);
- `mfr高 + min_low深负` = 脉冲后暴跌(XAGE 型:摸 +1.3% 但深跌);
- `mfr低 + min_low深负` = 阴跌;
- `mfr低 + min_low温和` = 横盘(上下都没动)。

这和 payoff §4.3 的「mfr vs payoff gap 诊断」、我和 payoff 共识的「背离即信号」同构——都用两个 label 的背离揭示路径性格。加端点收益(可选)再补「净落点」一维。

## 6. triage 定位 + per-match 可见性的新信息

**triage 而非验收**(skeptic 第 1 点):per-match label 帮用户挑「哪些 match 去看 K 线」、对比涨 match 与跌 match 的形态差异。不评判 pattern 好坏(验收靠 feedback score + c 项首穿闸)。

**漂移张力的回应**(skeptic 第 1 点):单 match 端点收益/min_low 混了「市场漂移」(单 match +0.10 分不清 pattern 选对还是股本就在涨),和 payoff 被批的「联合体」同构。**承认**。但 triage 要的是「发生了什么」(这单之后跌了),不是「为什么」(纯度);纯度诊断(扣漂移)在汇总级配随机日基线做。所以 per-match 层我不称「选股纯度诊断」,只称「方向可见性/补盲」——定位措辞已据此校正。

**新信息**(skeptic 第 4 点):c 项是集合级二值判定不回个案;min_low/端点收益给 per-match 可见性——把涨/跌 match 挑出来并排看 K 线找 sub-pattern,这是集合统计永远给不了的,是 web UI 人工分析的核心动作。

## 7. 与模拟交易 label 的关系:正交,不合并(接受 payoff §6.6)

payoff 主张 `strategy_return`(止损+跟踪止盈),在 §6.6 给三条反对合并 directional 的理由,我**全部接受**,尤其第 2 条 XAGE 实测(directional −77% vs payoff −8%)最有说服力:

- **反对合并理由**(payoff §6.6):① 「端点收益=payoff 到期分支」关系偶发非本质(只在 simulation 有到期分支时成立);② XAGE 实测两者天差地别(−77% vs −8%,绝大多数有干预的 match 上根本不同),并入会丢 −77% 这个选股关键信息;③ directional 本质与交易规则解耦,并入会摧毁该属性(§0 警告的耦合)。
- **边界**(payoff + decoupling):directional = 路径无关的裸位移披露(无干预);payoff = 路径相关的干预读数(止损止盈)。两者是「无关 vs 耦合」的对照,不是父子档。
- **2×2 正交**(decoupling):方向好+实战好=真alpha / 方向好+实战差=路径不可交易 / 方向差+实战好=警报(波动红利) / 方向差+实战差=garbage。「方向差+实战好」这格使 directional 不可被替代:payoff 会用交易技巧掩盖方向缺陷,directional 拆穿它(XAGE 上 payoff 的 −8% 掩盖了裸位移 −77%)。
- **对 payoff 一个修正**:payoff 称 directional「σ 中性/选股纯度尺子」——这是基于我 v2 表述,现按 §3 修正:directional **非** σ 中性(单 match 实现值方差仍被 σ 支配)、单 match 也**非**纯度尺子(混漂移)。但「路径无关 vs 路径相关」的正交、反合并结论**不受影响**——directional 仍是「裸位移披露」,只是不号称剔波动率。

## 8. 风险与取舍

1. **min_low 仍被 σ 支配方差**(同 mfr):不解决,靠集合级首穿+基线+披露。补盲不等于剔波动率。
2. **极值都丢顺序**:mfr/min_low 都是幅度统计。顺序的评判交集合级首穿,per-match 不评判。
3. **端点收益的持有到期假设**:隐含、定位次之,默认不上,用户要「净结果」时才展示。
4. **horizon 敏感**:短/长 horizon 极值/落点可能反转。必须多 horizon 并排。
5. **不重蹈 feedback 否决设计**:不把 σ 归一/止损止盈并进 label 打分;不把高波动降权当缺陷(用户接受敞口)。
6. **循环论证**:min_low/端点收益是未来已实现价格的客观读数,不依赖 pattern 定义;汇总级配随机日基线外生化。安全姿态同 c 项。
