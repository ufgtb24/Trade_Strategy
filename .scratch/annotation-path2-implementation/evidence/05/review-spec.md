# 票 05 独立审查：需求一侧

审查对象：`git diff 5e12c90...33d21a9`（分支 `impl/05-boxes-and-vocabulary`）。审查子代理对照票面、它引用的 spec 条款和共用执行边界，看不到执行过程。以下为原报告。

**票 05 规格审查**

总体上，票里点名的大部分要求都做到了：拖框和改起止（阈值 4 / 5 像素）、在特征轨上拖出的框直接带名、相近的词加粗排前、新词留一格写定义、属性三态、改名、合并前预览、`box×n · attr×m` 带悬停、子框轨、冲突提示一次、指纹不符报出来且图照常显示。vitest 读的是同一份例子 JSON，e2e 也覆盖了验收里那几条。审查中发现的问题如下。

**(a) 缺了或只做了一部分**

1. **拆回只在本页会话里有效。** spec 5.4 写「`merge` 把一个词并进另一个：先预览会改多少个框，可以拆回」。实现里合并前的样子只存在内存（`stores/annotation.ts` 的 `merges`），刷新或换机器就没了，界面悬停也写了 "only within this page session"。存进文件的只是一批框的改写加删词，日后没有一条「合并」记录可以照着拆回。
2. **attach 只能挂一个目标。** spec 5.4 写「也可以给交叠、但没被完全包住的更长的框点上（`attach`）」。`model.ts` 的 `parentRow` 只给最短的那个候选，用户选不了别的框。已经被别的框包住的框只能 `detach`，没法 `attach` 到另一个交叠、更长的框上。
3. **截图证据还没放。** 验收要求「拍截图自查（共用执行边界第 5、6 条）」，边界第 11 条要求截图放进 `evidence/05/`。这个目录目前不存在，截图只在 Playwright 的测试输出目录里。

**(b) 没被要求的行为**

1. **删框会顺手改样本的成员框，且不提示。** `deleteBox` 在同一批里把这个框从样本的成员里拿掉，而本票写明「不做样本，样本在 06」。这和用户故事 15「旧样本的成员冻结」、16「删框前看到会波及哪些样本」相冲突，等于在 06 之前先埋了一个不经提示就改冻结成员的行为。
2. **提前写了样本那部分的前端代码。** 前端 `membership.ts` 实现了 `memberTree`、`skeleton`、`dupFeatures`，也跑了 tree 例子，但 `src` 里没有任何地方调用它们。骨架和 dup 属于 06/07，而票里只说「前端的框套框实现，过 03 的全部相关例子」。
3. **改了平移方式。** annotate 下拖成交量柱变成平移图窗，缩放滑块也一直显示。spec 5.2 只写了成交量柱「不能在上面画框」，没要求改平移。
4. **框上加了 `note` 输入格。** 5.4 和票里都没提这个界面。

**(c) 看似做了，但可能做错**

1. **子框的词显示了 `true`。** spec 5.4 写「在这个特征下画成过子框的词，界面上写「⊂ 词」，不给 `true`」。`BoxPanel` 在框里有子框时会显示一个静态的 `true` 字样（不是按钮，按钮只有 `false`），从字面看和条文相反，需要确认。
2. **选中的框填了浅灰底。** spec 4.4 写「用户的判断不加底」，而选中的框在特征轨和主图上都填了浅灰。如果这只算「选中」的标记、不算来源色，可以接受，需要确认。
3. **K 线区点一下选不中框。** spec 5.4 写「否则算点一下选中」。在特征轨上点一下能选中，但在 K 线区点一下只会取消选中，因为主图上只画被选中的框和正在拖的框，平时不画框。
4. **属性列表的范围比条文宽。** spec 5.4 写「列出这个 pattern 里同名框用过的属性」，现在取的是全部图。还没有 pattern 时这样做说得通，07 接上 pattern 后需要收窄。
