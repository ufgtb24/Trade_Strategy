# 数据和标注在两台机器之间同步

Type: grilling
Status: open

## Question

### Purpose

用户在 pc 和 upc 两台机器上看图、写 app、做检查，这张票保证两台机器上的标注和它对应的数据始终一致。

用户提议用 Syncthing 同步数据和标注；两台机器已在用 Syncthing 同步 `~/.claude/projects`。方向文档第 10 节列了四条要守的：同步截到 2025 年底的副本；完整行情每天被原地改写，下载只在一台、另一台等同步完再做检查（或不同步完整行情）；标注每批一个新文件、文件名带机器名、只新增不改旧文件，并打开文件版本保留；标注记数据指纹。要定：

- 同步哪几个目录、放在哪里（在 git 之外；worktree 里怎么软链过去，和现在的 `datasets/` 一样经 `.worktree-prep`）；
- 完整行情同步不同步，最后检查在哪台机器上做；
- 下载脚本运行时另一台怎么知道数据还没同步完；
- 现有 `outputs/chart_workflow/` 里的旧标注和 pc 上未对过的旧标注怎么处理。
