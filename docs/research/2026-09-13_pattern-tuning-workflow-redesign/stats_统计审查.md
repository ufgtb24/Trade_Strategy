## 0. 结论摘要

1. **样本比表面少一个数量级。** 长表 3522 万行，只对应 94781 个独立的（股，买点日），平均每个复制 372 份。按买点 bar 计时，按股去簇的设计效应是 7~10。功效线 100 个 bar 大约只等于 10~25 个独立观测。【实测 e1 e2】
2. **optimism 0.150 可以事前预测，但不是用 √(2 ln K) 型公式。** 实测的「选择噪声乘数」在 K 从 64 到 265 万的全部网格上只有 0.9~1.7 倍被选格的按股 SE，远低于经典乘数 2.2~5.4。事前上界公式给出 0.13~0.18，覆盖 0.150。噪声地板主要由功效线决定，K 的作用弱得多。【实测 e3，§3】
3. **「没找到稳健区」的主因是效应小于噪声，不是 265 万格。** 相对宽进参照格挪一档，17 个挪档没有一个过去簇 |z|≥1.96。64、648、4096、35 万格的子网格在功效线 100 时，校正后分数全部 ≤0。修正背景 §3.1 的隐含推论。【实测 e3 e4】
4. **「两年方向一致」不是显著性。** 零假设下两年同为正的概率是 25%。生产格上 21 个挪档里两年同正 4 个，零假设期望 5.25 个。【推导 + 实测 e4】
5. **本轮三项定案的证据强度差别很大**（去重口径，2³ 析因，按股去簇）：
   - 突破幅度 0.003→0.0075：+2.85 ± 0.90pt，z 3.18，两年各自 z 2.23 / 2.35，是唯一站得住的一项（按回踩段去重复核：生产点单改动 +3.20 ± 1.02pt，z 3.13，e10）。

   - 确认根数 1→3：+1.37 ± 2.34pt，无。

6. **突破幅度的效应只在闸阵打开时出现。** 在宽进底座上是 +0.06 ± 0.36pt，在生产闸阵上是 +3.13 ± 1.02pt，差中差 z 3.08。只在宽进底座上做两档筛选，会把本轮唯一有效的参数筛掉。【实测 e9，§4.2】
7. **年份依赖只在局部成立。**

   - 宽进底座上，burst 闸族呈现「2024 正、2025 负」，年交互 z −1.6~−2.1。这几道闸彼此相关，不是 5 个独立证据。
   - 「收紧格为正的比例 54% / 20%」不能当证据：这些格共享同一批股票和时间窗。【实测 e4】
8. **边际基线要同时匹配时间，而且时间粒度会改结论。** 宽进 bb_v1 相对随机日基线（按 bar 集合去重，按股 SE）：

   - ATR 层数从 3 到 10、切点全窗统一还是当日横截面，结果变化都 ≤0.3pt。

## 3. 选择偏差的定量模型（任务 1）

### 3.1 打分管线里的噪声

- 每格每折：δ_f = 格的首次穿越率 − 参照格的首次穿越率。
- 格分 s = min_f δ_f；邻域分 s_nb = 自身与 r=1 邻格的 s 取最小；ĉ = 邻域分最高的格。
- optimism = E[ 重抽样数据上 ĉ* 的邻域分 − 原数据上同一格的邻域分 ]。

每格噪声 σ_cl(n) = √( p(1−p) · deff / (n · s_dec) )。其中 n 是含 none 的 bar 数，p≈0.5，定向占比 s_dec≈0.62，设计效应 deff 小格约 5、中大格约 8。

三种力量把经典的极值乘数压低：
1. 两折取最小：尾部概率被平方。
2. 邻格共享大部分样本：邻域最小只削掉邻格之间不共享的那部分噪声。
3. 真实结构：大多数格真的更差，真正参与竞争的格很少。

一种力量抬高它：K 越大，贴着功效线的小格越多。

顺带一个推导【推导】：零效应格的两折最小值期望是 −0.564σ（两个独立 N(0,σ²) 取最小，期望为 −σ/√π），邻域最小还会再往负拉。所以「可评估格里 99.7% 邻域分为负」即便所有真实效应都是 0 也会出现，不能读成「收紧普遍有害」。

### 3.2 经典公式在本轮的检验

- √(2 ln K) · σ_bar(n=100) = 0.05 × 5.44 = **0.27**。
- 两折取最小版 Φ⁻¹(1 − K^(−1/2)) · σ_bar = 0.05 × 3.23 = **0.16**。数值碰巧接近 0.150，但背后是两处错误抵消：σ 漏了设计效应（按股去簇应为 0.13~0.18），乘数又高估了约 3 倍。

独立噪声零假设模拟（格间噪声独立 + 同样的折最小、邻域最小）在所有子网格上给出 −0.002 ~ −0.007，与实测 optimism 的符号都相反。**格间独立这个假设完全错误**，「有效格数」没法按独立格事前估算。【实测 e3】

### 3.4 事前噪声地板公式（给执行端的机械输出）【推导 + bb_v1 标定】

```
floor_上界(n_pl) = 1.4 × √( p(1−p) · deff / (1.2 · n_pl · s_dec) )
  bb_v1 标定：p = 0.5, deff = 5, s_dec = 0.62；把 1.4 换成 1.0 得到区间下沿
  n_pl = 功效线（每折含 none 的 bar 数）
```

| 网格 | 公式区间 | 实测 optimism | 评价 |
|---|---|---:|---|
| 全网格，功效线 100 | 0.13~0.18 | 0.150 | 覆盖 |
| 35 万格，功效线 400 | 0.065~0.091 | 0.092 | 贴上沿 |
| 35 万格，功效线 1600 | 0.032~0.045 | 0.044 | 覆盖 |
| 12 维 × 2 档，功效线 100 | 0.13~0.18 | 0.082 | 保守 1.6~2.2 倍 |
| 648 格 | 0.13~0.18 | 0.043 | 保守 3~4 倍 |

结论：**被选格贴着功效线的大网格上，公式贴合；小网格上它是保守上界。** 64 格和 6 检测参数网格里没有贴功效线的格，公式不适用，此时 n 改用最小的竞争格计数。

**用法**：执行端只拿它当上界。floor_上界 ≥ 关心的最小效应（MEI）时，不许按该功效线扫。反推所需功效线：

```
n_pl ≥ 3.29 / MEI²   （bb_v1 标定常数）
```

| 关心的最小效应 | 每折所需功效线（bar） | 相当于宽进参照格 bar 的比例（24 / 25） |
|---:|---:|---|
| 10pt | 329 | 2% / 2% |
| 5pt | 1317 | 8% / 6% |
| 3pt | 3659 | 22% / 17% |
| 2pt | 8233 | 49% / 39% |

bb_v1 实际找到的效应是 2~3pt 量级（突破幅度 +3.1pt）。在功效线 100 的网格里，噪声地板大约是它的 5 倍。

**适用边界**：
1. 标定只在 bb_v1 本轮长表上做过。换 pattern 时 deff 与 s_dec 要用 e2 脚本重测。
2. 打分规则（两折取最小、r=1 邻域最小）一变，乘数就要重标。
3. 按股 bootstrap 只含个股噪声、不含行情噪声。这里所有 optimism 都是真实外推损失的**下界**（见 §4.3）。

## 4. 两阶段筛选（screening → confirmation）的有效性条件（任务 2）

### 4.1 筛选估计量、SE 与最小可检出效应

**嵌套闸**（紧档是宽档的子集）【推导 + 实测校验】：

```
Δ = p_紧 − p_宽 = (1 − r)·(p_紧 − p_被拦)
SE(Δ) ≈ √( p(1−p) · deff / D_宽 · (1 − r)/r )     r = 紧档保留的定向 bar 比例
```

32 个嵌套挪档上，公式 SE / 实测配对 SE 的中位数是 1.11（范围 0.88~1.66），公式略偏保守。【实测 e4】

**非嵌套**（检测参数）：没有闭式解，用按股配对残差计算，重叠买点自动计入协方差（`e4_oat_folds.py` 里的 `paired`）。

**最小可检出效应**（双侧 5%、功效 80%，p=0.5，deff=8）【推导 e8】：

| 宽档每年定向 bar | r=0.9 | r=0.7 | r=0.5 | r=0.3 | r=0.1 |
|---|---:|---:|---:|---:|---:|
| 10373（宽进参照格） | 1.3pt | 2.5pt | 3.9pt | 5.9pt | 11.7pt |
| 1041（生产格） | 4.1pt | 8.0pt | 12.3pt | 18.7pt | 36.8pt |

含义【推导】：z ∝ (p_紧 − p_被拦) · √(r(1−r))。被拦部分的差不随 r 变时，r=0.5 功效最高，所以**紧档应放在保留 30%~70% 的位置**。极紧档只适合测极端尾部（毒药闸式）效应。修正背景 §3.5 第一步。

### 4.2 本轮数据里效应稀疏性与层次性是否成立

**稀疏性成立**【实测 e4】：
- 宽进底座 17 个挪档，两年合并 |z|>1.96 的是 0 个。
- 生产底座 21 个挪档里有 1 个：跨度 20→10，−2.92pt，z −2.32。
- 大多数参数的效应在最小可检出效应以下。

**「只有主效应显著的参数之间才有交互」这条层次性假设，在「底座选择」上失效**【实测 e7 e9】：
- A / B / C 的 2³ 析因（去重口径）交互都 ≤0.5pt，|z| ≤1.62。
- 但突破幅度 0.003→0.0075 的效应强烈依赖闸阵：

| 底座 | 效应（去重，合并两年） |
|---|---|
| 宽进 | +0.06 ± 0.36pt |
| 只开 distinct_pk≥3 | +0.99 ± 0.56pt |
| 生产闸阵 | +3.13 ± 1.02pt |
| 差中差（生产 − 宽进） | +3.07 ± 1.00pt，z 3.08；两年各自 z 2.21 / 2.19 |

也就是说：在宽进底座上主效应为 0，在工作点上主效应显著。

**设计条件**【判断，置信度高】：
- 筛选在**两个底座**各做一次：宽进底座（看参数自身）和当前工作点（看在闸阵下的效应）。两底座效应之差的 z 作为交互旗标输出。
- 任一底座通过，就进入确认。
- 代价是比较次数翻倍：12 个参数变 24 个对比，Bonferroni 门槛 z 从 2.87 升到 3.08。

### 4.3 同一数据筛选 + 确认、以及折设计的极限

- **赢家诅咒**【推导】：用 z>2 筛出的幸存者，在筛选数据上的效应被高估。真效应为 0 时，幸存者的期望 z 是 φ(2)/(1−Φ(2)) = 2.37。**确认必须换数据。**
- **时间维只有 13 个独立 label 窗**（两年，每窗 40 交易日）【实测 e1】：年折每折 6~7 个窗，半年折每折约 3 个。
- **窗级异质性真实存在**【实测 e2 e4】：38 个挪档里 9 个在 13 窗上 Cochran Q p<0.05，零假设期望约 2 个。异质性集中在大幅改变 match 构成的挪档：最小相对高度、反弹阈值、distinct_pk、跨度 10。定案的四个改动 Q p 在 0.56~0.86、τ=0。（窗内 SE 用按股去簇近似，Q 检验可能偏松，9 个里有一部分可能是这个原因。）⇒ 对这类参数，同窗按股对半分做确认不充分。
- **「两年方向一致」的证据力**【推导】：零假设下同号概率 0.5，同为正 0.25。12 个参数筛一遍，期望 3 个两年同正；49 次查询时「至少一个两年同正」几乎必然。
- **折设计建议**【判断，置信度高】：
  1. 筛选：训练窗内两年合并的按股去簇 z，经 BH（q=0.10，筛选阶段求召回）；同时分年报 z 与年交互 z，|z_int|>2 标旗。
  2. 确认：用时间上不相交的窗（≥1 年）。bb_v1 现实可用的是 2024 年之前，或数据更新后 2026-03 之后。对预先写定的幸存者清单一次性检验，一律单侧、族内 α=0.05，默认 Westfall–Young 逐步 max-T，Holm 备选（§4.6）。
  3. 窗数 <20 时，不做以窗为簇的主 SE，只报异质性旗标。
  4. 半年折只当诊断视图，不当判据。

### 4.4 两档筛选对非单调参数的失效

- **甜点在中间**：宽、紧两端读数可能一样，筛选判「无效应」而删掉。实例：FC-008 的 first_drought 沿阈值轴 U 形（≥13 +0.063 / ≥40 +0.056 / ≥114 +0.108 / ≥144 −0.028）。
- **平台 + 断崖**：生产底座上跨度 20→10 是 −2.92pt，20→30 是 +0.07pt。紧档若选 10，会读成「收紧有害」；选 30，会读成「无效应」。【实测 e4】
- **对策**【判断，置信度高】：对学习端报出甜点或饱和形状的参数，以及探针显示机制上可能非单调的参数，筛选用三档（宽 / 中 / 紧）。判据改为「任一档相对宽档的差超过最小可检出效应且去簇显著」。该参数的对比数翻倍。

### 4.5 筛选阈值不靠拍脑袋

- 幸存判据：按股去簇 z 过 BH（q=0.10，m = 底座 × 参数 × 档位的全部对比数）。
- 每个被删参数都报它的最小可检出效应。「没检出」只能说「效应小于这个值」。
- 买点数的代价不是统计问题，交给人取舍。每个幸存参数报两列：「首次穿越率差 ± SE」与「买点保留比例」。
- 例：整套生产闸阵相对宽进，2024 +7.34 ± 3.91pt，2025 −0.55 ± 3.69pt，合并 z 1.03，只保留 11% 的买点。【实测 e6】

### 4.6 新数据的使用：调参之后一次开窗、一份清单【推导 + 功效估算；判断，置信度中】

**隔离期两个方向都要设**：确认窗与训练窗之间留 label 窗长度（40 交易日）的空档，否则两边 label 共用同一段行情，确认结果偏乐观。
- 往后：训练买点止于 2025-12-31，label 用到约 2026-02-27，所以前向窗买点从 2026-03-02 起；数据到 2026-08-17，买点止于约 2026-06-18。
- 往前：训练买点从 2024-01-01 起，所以往前窗买点止于约 2023-11-03（不是 2023-12）；最早约 2022-09（首部缓冲 250 交易日，数据起点 2021-08-20）。

**两段新数据都只开一次，而且放在调参之后。** 调参之前不打开任何新数据。

反例（本方案要排除的做法）：学习端调参前用往前窗判闸、决定网格准入，调参后再用同一段确认。这时调参结果的闸组成是由这段数据的 label 选出来的；而突破幅度的效应又依赖闸阵（差中差 z 3.16，§4.2），所以连检测参数的确认也会被牵连。

**本轮流程（bb_v1）**：
1. **训练窗**（2024-01-01 ~ 2025-12-31，全部股票）：优势检查；两底座筛选；在役闸只做「删了不亏」检验（§4.7）；联合网格只含检测参数，外加以前已在独立数据上判过「有用」的闸（bb_v1 无）；连筛选一起重做的 bootstrap。
2. **开窗前冻结预注册清单**，写入账本：
   - **确认子族**（单侧，族内 α=0.05，默认 max-T、Holm 备选）：候选配置 K 整体 + 它的每个组成改动 + 预注册的回退配置。组成改动包括检测参数改动，以及经用户确认语义的删闸；删闸按非劣效检验。
   - **闸子族**（闸内 Simes、闸间 BH q=0.05）：K 中保留的在役闸的存在性。条件总体 = 候选配置 K（被判的闸放到机制下限，其余参数取 K 的值），**不是**「确认后实际采纳的配置」。
   - **每道闸只进一个子族**：被提议删的闸只做非劣效，不做存在性检验，两个子族之间没有逻辑依赖。
   - 每项写明预期功效；幸存者偏差敏感性一并预注册（见下）。
3. **开往前窗**（2022-09 ~ 2023-11-03，全部股票，只做配对差），一次。
4. **开前向窗**（2026-03-02 ~ 06-18），一次，核对 K 与各组成改动的非劣效与方向。
5. **判读**：候选按下表处理；闸子族的结论只影响下一轮的网格准入，本轮不据此改参数。开窗之后，任何一项结果都不改变其他项检验什么、在什么总体上检验。
6. **记账**：两段窗对清单里的全部假设、以及由这次结论派生出的任何配置，都记为已烧。下一轮的确认需要 2026-06-18 之后新攒的数据。

**确认族的构成、回退分支与决策映射**（开窗前写死；由执行端落清单）：
- 回退分支为什么必须预先进族：检测参数改动的效应依赖闸阵（突破幅度：只开 distinct_pk≥3 时 +0.99，生产闸阵下 +3.13）。删闸不通过而回退时，检测参数所处的闸阵变了，它在回退配置下的效应要单独检验。
- bb_v1 的确认族，K = 突破幅度 0.0075 + 删峰龄闸，均相对 09-08 之前的生产配置：
  - H1：K 整体优于改前配置（优效）；
  - H2：K 下突破幅度的组成效应，即 K vs「只删峰龄闸」（优效）；
  - H3：K 下删峰龄闸，即 K vs「只改突破幅度」（非劣效，边界 −δ）；
  - H4：回退配置 K'（只改突破幅度）优于改前配置（优效）；
  - H5：回退配置 K''（只删峰龄闸）相对改前配置非劣（非劣效）。
- 决策映射：H1、H2、H3 都通过 → 采纳 K；否则 H4 通过 → K'；否则 H5 通过 → K''；否则维持改前配置。没有这张映射，开窗后在多个通过的配置里挑选，就是在确认窗上做挑选。
- 校正方式：确认假设方向都事先写定，一律单侧，族内总错误率 α=0.05。H1、H2、H4 几乎是同一批数据、高度相关，默认用 Westfall–Young 逐步 max-T（按股 bootstrap，每个副本同时算全部 z 取最大）；Holm 作保守备选。粗算往前窗对突破幅度的检出功效：单检验单侧约 78%，Holm（m=5）首步约 53%，max-T 接近单检验。【推导】
- 前向窗只核对「按往前窗结果、依映射选出的那个配置」。检验内容由事前规则决定，不留挑选自由度。
- 闸子族条件于 K 本身，不条件于最终采纳的配置；峰龄闸在确认族里，所以不进闸子族；闸子族 BH q=0.05（沿用学习端电池关 1 的标准，筛选阶段的 q=0.10 不适用于这里）。
- **描述性读数不进族**：对账第三步的伪闸重放（在往前窗上用突破幅度字段做事后阈值），开窗前在清单里标「描述性，不进任何族」，其结果不改变本轮任何决定。账本记下往前窗对「突破幅度大小」类假设（FC-006 系）已被看过，以后不能再用这段窗确认由它衍生的闸。
- 谁在什么时候定映射：
  - 用户在联合之前定采纳规则。默认规则是按训练窗证据从强到弱，先整套、再逐项退、最后维持现役。
  - 联合之后，系统按规则机械展开成具体映射，开窗前冻结。
  - 「机械」有三个条件：证据强弱的度量事先写定（训练窗上各组成改动在 K 处的段去重、按股去簇 z，平手按参数声明顺序）；展开出的每个配置的假设全部进族；预告的把握按族内校正门槛、并用扣除训练窗选择偏差后的效应计算。
- 停 3 按映射机械给出结论。用户可以整体否决、维持现役，不能换成映射内外的其他配置，也不能只采纳一部分。
  - 否决只减少采纳，不抬高误采纳率。
  - 否决后两段窗照样记为已用，不能改清单重开。
  - 否决理由记入账本。否决若取决于确认窗点估计，多轮下来留下的采纳在效应量上会偏大。

**判读表**（前向核对看两项：非劣效、方向；「主确认」指映射选出的那个配置在往前窗上的检验）：

| 主确认（往前窗，族内校正） | 前向：非劣效不过 | 前向：非劣效过、与训练期同号 | 前向：非劣效过、与训练期反号 |
|---|---|---|---|
| 显著 | 撤回 | 采纳 | 暂定采纳，前向数据攒满 1 年后复验 |
| 不显著 | 撤回 | 暂定采纳，并报告预期功效 | 不写进正式参数；已在正式参数里的维持暂定、不撤回；攒满 1 年后复验 |

反号的证据力【推导】：前向窗 SE 约 2.7pt。真效应为 +3.2pt 时点估计反号的概率约 12%，真效应为 0 时是 50%。所以反号只是中等证据，不足以单独撤回；但主确认也不显著时，就没有独立证据支持写进正式参数。

**各检验的预期功效**（往前窗约 1150 个生产格定向 bar，前向窗约 290 个；按 e10 训练窗实测 SE、以 SE ∝ 1/√bar 换算，假设买点频率不变；双侧 5%、功效 80%）：

| 检验 | 所属子族 | 往前窗 SE | 最小可检出效应 | 备注 |
|---|---|---:|---:|---|
| 突破幅度 0.003→0.0075 | 确认 | ~1.3pt | ~3.7pt | 对 +3.2pt（训练窗点估计，未扣选择偏差，下列功效是上界）功效：双侧单检验约 67%，单侧单检验约 78%，族内 Holm（m=5）首步约 53%；前向窗 SE ~2.7pt、功效约 22% |
| 删峰龄闸（非劣效，δ=2pt） | 确认 | ~1.0pt | — | 真效应 +0.8pt 时通过的概率约 87% |
| 峰龄闸存在性 | 闸（若未提议删） | ~1.0pt | ~2.8pt | |
| distinct_pk 存在性 | 闸 | ~1.4pt | ~3.8pt | |
| 单日跌幅闸存在性 | 闸 | ~1.6pt | ~4.6pt | |
| vol_spike 存在性 | 闸 | ~2.0pt | ~5.6pt | |
| first_drought 存在性 | 闸 | ~2.5pt | ~7.1pt | |

读法：在役闸存在性的最小可检出效应都在 2.8~7.1pt，高于 δ=2pt。按功效预检规则（MDE ≤ δ 才进族），bb_v1 的在役闸在这段窗上**全部判「功效不足」**。所以把往前窗留给调参之后的一次开窗，对本轮闸准入没有实际损失：调参前开，也只能得到「功效不足」，却会烧掉唯一有功效的确认窗。

**幸存者偏差怎么量化（没有退市股对照）**【推导；置信度低】：
- 偏差 ≈ π × (Δ_在池 − Δ_已退市)。π 是窗内买点中属于 2026-08 前已退市股票的比例。
- π 无法从现有池子算出。按价格过滤 [0.5, 30] 的小盘股每年数个百分点的退市率、窗中点到 2026-08 约 3.5 年推算，π 大约 15%~30%【猜测】。
- Δ_已退市 用代理：在训练窗里挑出「日后困境」的在池股票（如 2026-08 收盘 < $1，或窗后跌幅最深的十分之一），算它们的配对差。它与其余股票的差记为 H，则 |偏差| ≲ π·H。
- 预注册规则：π 取 0.3，若 π·H > 1pt（即 H > 3.3pt），往前窗的确认降为「暂定」，以前向窗为准。需要读 pkl 收盘价，放实施阶段做。
- 前向窗几乎没有幸存者偏差，所以判读表里「前向非劣效不过」一律撤回，不看往前窗。

**自动开窗的条件**：预注册（候选、对照、判据、预期功效）写入账本早于开窗，并且功效预告已经告诉用户。「训练窗上几种读数不矛盾」不是统计上的必要条件，可以留作业务门槛。预期功效低于 50% 时，先告诉用户「这次验证大概率给不出结论」。往前窗只能开一次、也不会随时间变长，建议此时打断，由用户决定现在开窗还是把窗留给效应更大的候选。

### 4.7 删闸与「无信号」的判据：非劣效【推导 + 实测 e10】

用户只定一个数 δ（关心的最小改进，默认 2pt），三处共用。「有用」只要求显著且下界 >0，不要求 ≥δ；介于「有用」与「删了不亏」之间的闸一律固定现值、进验证队列。
- **删闸**：Δ(关 − 开) 的单侧 95% 下界 ≥ −δ → 「删了不亏」，可以删；否则固定现值。
- **学习端无信号**：闸效应 CI 上界 < δ → 无信号；CI 同时覆盖 0 和 δ → 分辨不出。
- **优势检查无边际**：上界 < δ。

生产点实测（按段去重，按股去簇，δ = 2pt）：

| 删哪道闸 | 两年合并差 ± SE | 单侧 95% 下界 | 买点×（24 / 25） | 判读 |
|---|---:|---:|---|---|
| 峰龄 60→0 | +0.77 ± 0.76pt | −0.48 | 1.10 / 1.14 | 删了不亏 |
| vol_spike 3→0 | −1.65 ± 1.54 | −4.18 | 1.47 / 1.36 | 不能删 |
| first_drought 40→0 | −1.39 ± 1.93 | −4.56 | 1.75 / 1.82 | 不能删 |
| distinct_pk 3→1 | −1.03 ± 1.05 | −2.76 | 1.32 / 1.20 | 不能删 |
| 单日跌幅 0.2→不设 | −1.00 ± 1.26 | −3.08 | 1.15 / 1.17 | 不能删 |

「买点×」取自 e4 的定向 bar 比例（逐 match 计）。非劣效用 pattern 内原始差（交易上买到的量），不用层匹配差。判为「代理」的闸，若删掉会损失原始首次穿越率，同样不算删了不亏；但固定现值时要注明「效果来自波动率构成，跨年是否稳定需时间不相交验证」，并排进验证清单。δ_NI 取 δ 而不是 δ/2 的理由见 §11.4（与 learner 的第 1 轮分歧）。「不能删」不等于「有用」：这几道闸的效应同样分辨不出，只是分辨力不足以证明删了不亏。

### 4.8 开工前的分辨力 x【推导 + 实测标定】

回答「这份数据大约能分辨出 x 个点以上的差别」：
- **口径**：按股去簇、按回踩段去重。不取时间块（29 天的块短于 label 窗）；时期差异另报。
- **单位**：单个参数改动相对当前工作点的配对差。同时动两个参数时，SE 约放大 1.7 倍（executor 实测 2.19 vs 1.26）。
- **只用优势检查那一次运行即可算，不需要额外扫描**：
  1. 读当前工作点格首次穿越率的水平 SE_level（按股去簇、段去重、两年合并）；
  2. SE_flip ≈ SE_level × √((1 − r̄)/r̄)，r̄ 是一次改动后仍保留的定向 bar 比例。闸类改动的 r̄ 不看 label 直接数；检测参数改动取标定值 0.85；
  3. 筛选用 x = (z_BH + 0.84) × SE_flip，z_BH 是本轮对比数 m 下 BH 第一名的门槛（q=0.10）；只验一个预先写定的改动时，x = 2.8 × SE_flip。
- **bb_v1 数字**：SE_level = 3.01pt（1962 个定向 bar，设计效应 7.2，e10）→ SE_flip ≈ 1.26pt，与 executor 实测单翻转中位 1.26pt 吻合 → m=36 时 z_BH = 2.99，x ≈ 4.8pt；单个预写改动 x ≈ 3.5pt。
- **「时期差异」的读法**【推导，粗算】：13 个窗、窗内 SE 1~7pt 时，Cochran Q 对约 3pt 以下的时期差异几乎没有功效。τ=0 只能说「没看出时好时坏」，不能说「各时期效果一样」。

## 5. 响应面拟合 vs 邻域最小分（任务 3）

【推导 + 实测形状，置信度中高：没有做直接的交叉验证对比】

- **自由度**：k 维二次响应面需要 1 + 2k + k(k−1)/2 个参数。k=2 要 6 个，k=3 要 10 个，k=12 要 91 个。
- **潜在收益有限**：筛选后 k≤3、格数 16~125 时，邻域最小分的选择偏差已经约等于被选格的 1 个 SE（64 格 c=1.16，§3.3）。响应面合并邻格样本，最多能把被选点 SE 再降 √(K/p)≈2.5 倍，而且前提是曲面形状对。
- **实测形状不是二次的**：
  - 跨度：平台 + 10 处断崖。
  - 确认根数：单调。
  - first_drought：U 形，且 ≥144 处断崖。
  - distinct_pk：≥3 以上才有信息，低档无区分力（FC-007）。
  二次曲面会在平台里造出假的内部最优、在断崖处被抹平。这类偏差是 2~4pt 量级，与关心的效应（2~3pt）同阶。
- **更大的误差来源它治不了**：窗间异质性和样本量不足，响应面和邻域最小分都无能为力。
- **结论：不采用。** 真需要平滑时，只考虑逐轴单调约束（保序回归），它和观测到的形状相容、自由度低。筛选后的联合网格继续用邻域最小分，并受 §3.4 的功效线约束。

## 6. 边际基线闸（任务 4）

【实测 e5 e5b。样本来自 2026-09-07 dag-scoring 研究的现存产物：宽进 bb_v1 match 表 + 随机日表（定案前底座），按 bar 集合去重，按股整簇自助】

| 匹配方式 | 2024 Δ ± SE | 2025 Δ ± SE |
|---|---|---|
| 不匹配 | −4.8 ± 1.5pt | +5.0 ± 1.4pt |
| ATR 3 层 | −0.7 ± 1.5 | +6.8 ± 1.4 |
| ATR 5 / 10 层 | −0.4 / −0.5 | +6.7 / +6.5 |
| ATR 3 层 × 同月 | +0.3 ± 1.6 | +2.6 ± 1.4 |
| ATR 3 层 × 同一 40 日窗 | −0.3 ± 1.5 | +2.0 ± 1.4 |
| ATR 3 层 × 同一交易日（全窗统一切点） | +2.7 ± 1.7 | +3.0 ± 1.3 |
| **ATR 3 层 × 同一交易日（当日横截面切点）** | **+2.5 ± 1.5** | **+3.0 ± 1.4** |

- 窗级 Δ（每个 40 日窗内单独算）的窗间 sd 为 5.0 / 5.3pt，远大于按股 SE。
- 按 match 逐行计（不去重）与去重结果相差 ≤0.3pt。

**设计条件**：
1. **估计量**：Δ = 格的首次穿越率 − Σ_s w_s · 基线_s。层 s = 同一交易日 × 当日横截面 ATR% 三分位；w_s = 该格定向 bar（格内去重后）落在层 s 的占比。随机日基线预先算成「交易日 × ATR 层 × 四态」计数表（executor 方案 §4.2 的做法）。
2. **粒度与切点是尺子**【判断，置信度中】：
   - 时间粒度会改结论（2024 年从 −0.3 变到 +2.5）。取同一交易日，理由是 label 窗完全重合，40 日窗仍留有窗内择时。「同日比窗更对」是推导，没有外部真值可对照。
   - ATR 切点口径影响 ≤0.2pt。取当日横截面，这样市场整体波动随时间漂移时，层的含义不变。
   - 两者都进尺子指纹。
3. **不确定性**：主口径是按股整簇自助，pattern 与基线各自重抽。粒度敏感性（窗 vs 日）作为模型不确定性另报一行，两者差值超过 1 个 SE 时在报告里写明。
4. **判读三分支**：
   - 置信下界 >0：有边际，进入调参。
   - 置信上界 < 关心的最小边际：停。
   - 其余：「边际未证实」，调参可以做，但结论必须带上这个标注。
   - bb_v1 宽进（同日匹配）：2025 +3.0 [+0.2, +5.8]，有边际；2024 +2.5 [−0.4, +5.4]，未证实。
5. **产物缺口**：现有 `outputs/tune_gates/bb_v1/main/random_baseline.csv` 只有按股汇总的四态计数，没有日期、没有 ATR%；长表没有买点日 ATR% 列。
6. **三个估计量分工**（按 learner 方案 §2.2 修订本条）：
   - **模式边际**（pattern 有没有底子）：相对随机日基线，同日 × ATR 层匹配。
   - **闸的存在性**（留下 vs 不设，两边同在池内）：池内按 ATR 层（加同一 40 日窗）分层标准化，**不用随机日的层斜率**。池内与随机日的「首次穿越率 vs ATR」斜率不同（learner E3：2024 年随机日三层 0.612 / 0.538 / 0.471，池内 0.441 / 0.503 / 0.490），拿随机日斜率去抵扣会引入偏差。
   - **调参**（交易上买到的首次穿越率）：pattern 内原始差。

   以 distinct_pk≥3 为例，原始差与「各自对随机日层匹配后的差」会不同：

   | 年 | pattern 内原始差（子集 − 宽进） | 对随机日 ATR3 层匹配后的差 | 差额（基线下移） |
   |---|---:|---:|---:|
   | 2024 | +0.050 | +0.065 | −0.015 |
   | 2025 | +0.039 | +0.045 | −0.006 |

## 7. 两端多重性总账（任务 5）

### 7.1 两种错误不是一回事【推导】

- 学习端的 FDR 控制「宣布有信号的特征里，假信号占多少比例」。它管的是**有没有**。
- 执行端的 optimism 衡量「挑出来的那组参数，分数被高估了多少」。它管的是**有多大**。
- 两者不能相加。但在同一份数据上会连乘：特征因为在数据 D 上显著而被选中，阈值又在 D 上挑，最后报告的效应同时带着两次选择的偏差。

### 7.2 用「数据使用台账」取代只数识别次数【判断，置信度高】

- **台账键**：（pattern，股票宇宙，时间窗）。
- **每次动用 label 记一行**：用途（发现 / 筛选 / 挑选 / 确认）、涉及的假设、比较次数。
- **计数规则**：任何可能改变决定的查看都算一次比较，包括单格查询、切片、组合回放。本轮的账：265 万格识别 1 次 + 约 40 次单闸查询 + 9 次组合回放。
- **「已烧」的定义**：某窗对某假设已烧，当且仅当它的 label 参与过该假设的提出、参数取值的挑选、或做不做的决定。
- **确认窗的用法**：只能对一份预先写定的候选清单（m 个）检验一次，族内校正（默认 max-T，Holm 备选）。检验后改了东西再测，就是挑选，这个窗对这批假设随即变成已烧。
- **同窗换股是半新样本**：个股噪声独立，同期行情不独立。只能当筛选内部的交叉校验，不能当确认。

### 7.3 bb_v1 当前账面

- **2024-01 ~ 2026-01 全宇宙**（本轮长表 4036 股）已烧的假设：
  - burst 四闸：FC-007~010 的发现样本 w2024 / w2025 与之同宇宙同窗。
  - 突破幅度、峰龄、跨度、确认根数：本轮定案。
  - FC-008 的 U 形。
- **FC-006**：发现样本是 2000 股的 bo 全流，2021-01 ~ 2026-03，覆盖了全部现有时间。对它来说，只有「其余股票 × 同窗」（半新）或 2026-03 之后的数据可用。
- **FC-003 / FC-005**：发现样本是 2022-09 ~ 2026-06 的五年 bb_v1，同样覆盖 2024~2025。
- **时间上全新的数据**：
  - 2024 年之前：先查 pkl 池的退市股覆盖，幸存者偏差会抬高超跌反弹类 label。
  - 2026-03-02 之后：主目录数据已覆盖到 2026-08-17（executor 实测），扣掉 40 个交易日隔离期后，前向可用 2026-03-02 ~ 06-18。

### 7.4 两端交接规则【判断，置信度高】

- 学习端判「有信号」用的样本，要与执行端定阈值的样本分开。若只能共用，执行端报告必须声明「特征与阈值是在同一样本上选的」，并且只能出候选、不能定案。
- 执行端的切片发现回流学习端时，登记簿条目的「发现样本」写成台账键，学习端据此自动排除该窗。

## 8. 学习端电池用于闸式特征与首次穿越 label 的适用性（任务 6）

1. **label 编码**：分母是 up+down+both，none 必须排除（本轮占 36~38%），不能编成 0。逐 match 的首次穿越份额有 69% 恰好是 0 或 1。【实测 e5】执行端按 bar 汇总成比例（相当于 match 按 bar 数加权），电池按 match 等权，两端对同一特征估的其实是不同的量。应统一为「格内去重后的买点 bar 汇总比例」，电池里用按股去簇的加权比例差或加权回归。
2. **分箱形状**：按中位数判会退化。vol_spike 五分位的中位数，2024 是 [0, 0, 0.5, 1, 0]，2025 是 [1, 1, 1, 1, 0.83]；均值则是平滑的 0.46~0.54。首次穿越 label 下，形状必须改按汇总比例判。【实测 e5】
3. **关 1 测不到切点尾部**：Spearman 测全程单调，闸的信息在切点尾部。实例：宽进底座上 tb.max_day_drop 从「不设」改到 0.2，只拦掉 4% 的 bar，但 2025 年过闸 vs 被拦的差是 +15.9 ± 7.6pt（z 2.1）。全程秩相关会被另外 96% 的无关样本稀释。【实测 e4】闸式特征应增加切点型检验（过闸 vs 被拦的首次穿越率差 + 按股 SE）。扫多个切点时，用最大选择统计量的置换分布做校正。
4. **关 2 偏松**：秩回归的 t 按 match 独立算。match 级按股设计效应约 2（参照格 SE 0.0106→0.0146），所以 |t|≥2 实际相当于去簇后 |t|≥1.4。改用按股簇稳健 SE。【实测 e2】
5. **关 3 每簇留一条，功效太低**【推导 e8】：

   | 效应 | n=13 | n=20 | n=40 | n=300 | n=2000 |
   |---|---:|---:|---:|---:|---:|
   | ρ = 0.1 | 6% | 7% | 9% | 41% | 99% |
   | ρ = 0.2 | 10% | 13% | 23% | 94% | 100% |

   关 3b 的 n 就是桶数，一旦能跑（≥20 桶），几乎必判「不稳」，而这时失败的是检验，不是信号。关 3a 在股数几百时功效约 40%。改为股 × 时间窗的双向簇稳健 SE（窗 ≥20 时）。窗 <20 时，时间维只报异质性旗标，判定写「时间维未定」而不是「不稳」。「不稳」只在去簇后估计显著反号或显著缩水时才判。
6. **条件宇宙**：在「被测闸放到机制下限、其余闸在工作点」的宽进 match 上提取。否则只看得见过闸的那一半。
7. **控制列**：首次穿越率并非完全波动率中性，随机日基线按 ATR 三层分别是 0.551 / 0.503 / 0.477（`docs/research/2026-09-07_dag-scoring-vs-hard-gates/stats_validity.md`）。`c0_atr_pct` 要保留，另外加「同一 40 日窗」分层作控制。§6 显示同期行情是首次穿越率水平的主要混杂。
8. **FDR 族的范围**：每次电池运行内部的 BH 不管跨运行的累计。登记簿逐条跑电池时，累计比较数要记进 §7.2 的台账。

9. **观测单位与加权**：估计量是段去重后按 bar 汇总的合并率（与执行端和交易口径一致），推断按股去簇。learner 的例子按段去重后是「不加权秩回归 t 2.27 → 按买点日加权 + 按股去簇 t 1.24」：这把加权和去簇两件事混在一起比了，报告必须拆开报，并附一行段等权估计作稳健性检查。另注：段口径下 learner 的闸指示变量（distinct_pk≥3 / ≥4、peak_age≥120）双向簇 t 分别为 1.29 / 1.43 / 1.48，新旧两种推断引擎都判不显著——换引擎的理由是不丢样本、如实处理时间维，而不是功效更高（`repro/learner/e1b_output_segment.txt`）。【判断，置信度高】
10. **时间维门槛**：采用 learner 的 T3（逐年同号作过滤 + 股簇显著），另加 40 日窗固定效应；判定标注「时间维未验证」，直到时间上不相交的样本复核过。时间簇 wild bootstrap（13 簇）只照报、不作门槛。
11. **功效线**：「每侧每年 100 计数」不作功效线（100 个 bar ≈ 12~15 个独立观测，单侧率 SE 约 13pt），改为 §4.1 的无 label 功效预检：MDE ≤ δ 才进族，否则标「功效不足」。

### 10.1 [基线口径] 随机日基线必须同日匹配，匹配粒度会改结论
- **口径**：Δ = 宽进 bb_v1 首次穿越率 − Σ_s w_s · 随机日首次穿越率_s。

  - 层 s = 时间单元 × ATR% 三分位，ATR% = `rolling_atr_pct_nanmedian(h,l,c,20)`；w_s = pattern 定向 bar 在层 s 的占比。

  |---|---|---|

  | ATR 三层 × 同一交易日 | +2.5 ± 1.5 | +3.0 ± 1.4 |
