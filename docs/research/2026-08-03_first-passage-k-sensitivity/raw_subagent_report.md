## 4. 结论

**(1) k=2 落在样本健康区 —— 是。**
none 占比温和(bo_only 1.13%、bottom_burst 2.86%、random 1.82%,都 < 3%);有效样本充足(bo_only 17736/18099 = 98%、bottom_burst 678/699 = 97%);both 占比极低(bo_only 0.87%、bottom_burst 0.14%),不会污染 ratio 分母。k=2 同时是有效样本的近峰值点。

**(2) bottom_burst 在任何 k 下都没有方向信号 —— 是。**
全部 5 个 k 下 |pattern ratio − random ratio| ≤ 0.0112,ratio 始终在 0.49~0.52 徘徊,与「先触上行还是下行」的 50/50 随机无异。first_passage 这个指标对 bottom_burst **没有方向预测力**,且这个结论 **与 k 无关** —— 调 k 不会让信号冒出来。bo_only 亦然(高 k 下 |p−r| → 0)。

**这意味着:first_passage 当前对 bbb 不是有效的方向区分量。它没崩、口径健康、k 选得也合理,只是这个量本身在 bbb 买点上不携带方向信息(买点后短期上行/下行触发概率与无条件随机日相同)。**

**(3) k 的推荐区间:k ∈ [1.5, 2.5],默认 k=2.0 完全合理,无需调整。**
- k < 1.5:阈值太窄 → both 占比飙升(k=1 时 bo_only both=735 占 4%)、ratio 被同日双触噪声主导,且 random_ratio 开始偏离 0.5 不可信。
- k > 2.5:none 占比快速增长(bottom_burst @k=3 达 11.87%)、有效样本流失 9%+,样本稀疏使 ratio 不稳。
- k ∈ [1.5, 2.5]:none 温和(<8%)、有效样本近峰值、both 低(<1.7%)、ratio 稳定。k=2.0 是该区间的几何与统计中心。

若一定要在 [1.5, 2.5] 内挑:数据上没有理由偏离 2.0 —— k=1.5/2.0/2.5 三组的 |p−r| 都在噪声内(0.0034~0.0135),结论一致。保持 2.0 默认值即可。

## 5. 大 k 扩展实验(k=3–8)— 推翻 §4(2)的「无方向信号」结论

> 用户纠正:first_passage 是**为方向性设计**的(弥补 forward_return 只看终点、被波动率驱动、不看下跌的缺陷),小 k 阈值太近、噪声穿越淹没方向 drift,**大 k 才能过滤噪声、暴露真正方向运动**。复用同一 dag 复用管道(校验仍 PASS:k=2.0 全部四态逐字复现 baseline),把 k 扩展到 [3,4,5,6,7,8] 全宇宙重跑。

**结论先行:用户对,我之前的「无方向信号」结论错了。** 大 k 下 pattern ratio 系统性偏离 random,且偏离随 k 单调扩大、远超 2σ 显著线。小 k 的「无信号」确实是阈值太近、噪声穿越把方向 drift 淹掉了的假象。

### 5.4 关键结论(覆盖 §4)

1. **用户对,我之前错了**。first_passage **确实有方向信号**,只是 k=1–3 阈值太近,几何对称线 P(1+kM)/P/(1+kM) 太容易被噪声穿越,up/down 计数被同向小幅震荡污染成 ~50/50。**k≥4 起信号系统性冒头**,正是用户预期的「大 k 过滤噪声」。

2. **bottom_burst 在大 k 下有强方向边**:k=6 时 62.3%、k=7-8 趋平于 ~65.6%(即买点后 40 日内先触上行线的概率约 2/3,vs 随机日 ~50%)。这与 bottom_burst 的语义一致——回撤后买点更接近低点、上行空间大于下行。

3. **bo_only 也有方向边但弱得多**(k=8 时 0.541 vs random 0.488)——纯突破无回撤确认,方向性弱于回撤买点。

4. **k 的双中心结论**(覆盖 §4.3 的单中心 [1.5,2.5]):
   - **度量「波动率读数 / 路径无序度」时**(看 none%、both%、ratio 接近 0.5 的程度):k ∈ [1.5, 2.5] 仍合理(none/both 都低、有效样本峰值)。
   - **度量「方向 drift」时**(pattern ratio 偏离 0.5 的程度):**k ∈ [4, 6] 是甜点**——差距已显著超 2σ、有效样本仍 >350、none<45%;再往大 k=7-8 信号仅微增(0.623→0.656)而样本流失加快,边际不划算。
   - 两个用途不可共用一个 k:**当前 default k=2 适合「样本健康/ratio 平稳」类诊断,但若用 first_passage 做方向信号筛选,应切到大 k(4–6)**。

5. **random 的稳健对照价值**:random_ratio 在 k=3–8 全程 0.488–0.510 抖动、无 drift,正好证伪「大 k 自带 up 偏」的度量 artifact 嫌疑——pattern 的偏离是真信号。建议保留 random 对照作为该指标的常驻 sanity check。

### 5.5 §4(2)的勘误

§4(2)原结论「bottom_burst 在任何 k 下都没有方向信号」**作废**。它基于 k=1–3 的扫描,而 k=1–3 恰好是噪声淹没区(阈值窄、both/none 比例极端、ratio 被 50/50 噪声主导);把 k 推到 4+ 后,方向信号清晰浮现且统计显著。这正是用户指出的「阈值太近淹没 drift」的故障模式。

- **bo − random 的 none 差**:稳定在 −2 ~ −3pp(bo 的 none 略少),可能是 bo 买点(突破日)波动率尺度 M 略大于平均、阈值相对更易触;但绝对差很小、形态一致,不影响判断。
- **三条曲线斜率一致**(每加 1 个 k,none% 大约多 8-10pp),是几何阈值 P(1+kM)/P/(1+kM) 随 k 变远的纯数学后果,与「这是个 pattern 买点」无关。

**这条对照的意义(对 §5 的方向信号结论是关键背书)**:有人可能怀疑「大 k 让 pattern ratio 偏离 0.5 是 none 选择偏差导致的存活偏差」——但上表显示 random 在同样的 none 选择强度下(k=8/9/10 都 60-72% 被剔成 none),ratio 仍稳在 0.49-0.51;**只有 pattern 单方面偏离**。如果 none 选择本身带方向偏差,random 应该同步偏离,但它没有。所以 §5 的方向信号结论干净:大 k 下 pattern ratio 的偏离是 pattern 买点真有方向 drift,不是 none 剔除造成的度量 artifact。
