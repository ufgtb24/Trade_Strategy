# payoff · 模拟交易 label 正式立场(收敛定论)

> payoff 角色经四角色多轮交叉 + skeptic 终审 PASS 后的正式收敛版,对齐 directional.md 的处理。**详尽论证、XAGE 实测、扫参敏感性表、交叉验证过程记录见 `payoff_draft.md`**(skeptic 终审引用其行号,保留作溯源)。本文件只给 lead 综合时的定论入口。

## 0. 一句话定论

**`strategy_return` = 「选股 × 固定交易规则」联合体的利润读数,不是选股纯度的尺子。** 定位 = 独立交易层 readout,视觉隔离,**永不进选股 score / 默认排序键 / 自动工作流目标**。

## 1. 不对称是真实的,但属于交易层

真实交易的退出行为对涨跌处理方式不对称:下行止损截断(左尾有界)、上行跟踪逐利(右尾开放)。这是交易变现的物理事实,不是设计偏好。但它量的因此是「变现」不是「方向」——属交易层,与选股层(directional)正交。注意区分两种「非对称」:feedback §0 顺序闸的「路径顺序」非对称属选股层(信号质量);我说的「交易损益」非对称属交易层(变现)。不同层、不同物。

## 2. 端到端类比:评估成立,优化不成立

用户「选股+交易两层网络、利润为输出」的直觉:**形式(联合体 + 输出利润)归属 sim 的评估端;但训练端(梯度反传)在人工 web UI 无对应物**——人不做反传,选股改进靠人看两 label 手动完成。把利润塞进选股目标函数 = 不可微伪梯度 + 归因不可分(单笔盈亏无法干净拆成选股贡献 vs 退出贡献)= feedback §0 的耦合灾难。**所以 sim 是评估端 readout,不是优化目标。** 优化不能端到端(利润塞进选股目标 = 不可微伪梯度 + 归因不可分,必然耦合);评估端可纳入 sim,但**耦合只是被 UI 闸门压低、未消除**——人看 sim 数字手动调 dag 仍是受其影响的无梯度优化,残留耦合须披露(skeptic H9)。诚实表述 =「闸门压低 + 残留披露」,不是「完全不沾耦合」。

## 3. sim 不能当选股尺子(两条独立论证)

**(a) 方向准确率相同,sim 可差很多**:方向预测力相同的两个 pattern,命中的是「平滑趋势股」(跟踪止盈吃满、止损少触,sim 高)还是「尖刺型股」(止损总被打在最低点,sim 低甚至负),sim 天差地别——差额完全来自路径可交易性(交易层),不是选股层。

**(b) 不对称会掩盖选股缺陷**:方向准确率仅 30% 的 pattern,sim 仍可能为正(止损封顶 70% 小亏、尾部红利覆盖)——sim 给虚假安慰,directional 才揭露方向真相。

**XAGE 实测**(repro/xage_sim.py,切窗 2024-09-19..2026-03-08、horizon=40、tb_208_213):mfr **+1.33%**(fantasy)→ directional **−77.00%**(方向真相)→ strategy_return **−8.00%**(8/20/10 先验投影,止损封顶掩盖了 77% 灾难)。三 label 各照亮一个侧面,没有一个「是对的」。

## 4. 与 directional 的关系:正交,既非必要也非充分

| | sim 正 | sim 负 |
|---|---|---|
| **方向好** | 真 alpha(方向能力变现,可信) | 路径不可交易(方向对但尖刺,改 pattern 可交易性) |
| **方向差** | **警报:波动率红利/虚假 alpha** | garbage(弃) |

四个象限各有意义。「方向差+sim 正」只有 directional 能拆穿;「方向好+sim 差」只有 sim 能看到。两 label 互不蕴含(非必要:§3b 已证方向差也能 sim 正;非充分:方向对但路径不可交易 sim 仍负),都需要,**单独看任一都盲**。这是用户「可以做两个版本 label」的正当性所在。

## 5. 参数纪律:外生声明 + 严禁扫参

三参数(stop_loss / take_profit / trailing)是用户风险偏好的**外生声明**,默认 8/20/10,看数据前定死。

**红线(看程序不看值)**:参数选择程序不得在样本上对 sim 做 argmax。两组同值参数,一个从资金管理规则算出(干净),一个试几组选最高(污染)——值同性质不同。连「据结果事后反调」都视为污染(不可审计)。UI 不提供批量扫参入口,可编辑参数旁加反扫参警告。

**报告 sim 必须标清先验**:XAGE sim 随先验波动(5/15/8→−5%、3/0.5/0.5→−0.56%、15/20/10→−15%),但符号稳健为负(skeptic 预测的「紧止盈翻正」实测不成立,因暴跌从首日起)。其他 match 上符号本身可能随先验翻转,故披露先验是普适要求。

## 6. 虚假 alpha 规避:三层,不靠「与 directional 共读」一句

sim 的不对称会造虚假 alpha(方向无优势 + 高波动 + 不对称交易 ⟹ 假阳),是 feedback g 项「score 首先是波动率读数」在交易层的翻版。完整规避三层:

1. **per-match 共读(directional+sim)**:必要,识别肉眼可见背离。但**不充分**(directional 只在集合期望 σ 中性,per-match 实现值方差仍随 σ 放大,两 label per-match 都带噪声)。
2. **集合级统计闸(主力)**:命中集波动率倍数(已测 1.83–2.13×)/ **控 σ 后 sim 条件百分位**(类比 bo_only +72% lift 控 σ 后归零,若 sim 正期望控 σ 后归零即标红)/ 首次穿越(feedback c 项)。**属选股评估层,复用 feedback 体检口径,不进 sim 内部**——sim 自己不加波动率惩罚项(会把选股评估反向塞进交易层 = 再次耦合,feedback §0 同病方向反)。
3. **UI 标注 sim 的波动率暴露**(诚实披露)。

## 7. 最终收敛(吸收 skeptic 终审 + 全队共识)

- **最小集** = `mfr`(保留·§0 背书 + R²=0.92 波动率读数诊断价值)+ `min_low`(新增·最小·与 mfr 同构零框架成本·补 mfr「只看涨」的诚实盲区)+ `sim`(新增·克制 readout)+ 端点收益(暂缓·YAGNI)。
- **优先级**:① **min_low 先做**(最高性价比:零框架成本、补盲区、批量 triage 灾难 match、诚实化「无优势」)> ② **sim 后做、克制定位**(独立交易层 readout、UI 隔离、参数外生固定、禁扫参、必须与 min_low/方向共读)> ③ 端点收益暂缓 > ④ mfr 保留不动。
- **sim 的战略保留(诚实成本,skeptic §7.2)**:web UI 里 K 线本身已展示路径,sim 把路径压成一个数、损失的恰是肉眼能看的细节 ⟹ sim「路径/顺序独有信息」在 UI 场景的增量**最薄**(弱于无 K 线的自动 score 场景);但虚假 alpha / 诱导当尺子 / 参数敏感这些**风险不因有 K 线而减少**。故 sim 值得做(用户要、让「交易层」具体化、给 mfr 现实主义砝码),但 v1 克制:定位「mfr 现实主义砝码 + 个人风险偏好投影」,**不追求独立决策列**,强约束与 min_low/方向共读。
- **min_low 在「现实主义砝码」上比 sim 更诚实**:min_low 报 −83% 裸位移灾难,sim 的 −8% 反而把灾难粉饰成「小亏」——砝码角色 min_low 已胜任,sim 在这点上冗余且更弱。sim 的独特性在「个人风险偏好投影」(用户交易决策辅助),非选股评估。

## 8. H7 框定(最重要,与 skeptic 一致)

**本次 label 设计不是「换把尺子量出 alpha」。** feedback 已证 pattern 方向无优势(c 项)、lift 控 σ 后归零(A.1)、label R²≈0.92≈波动率。新 label(mfr + min_low + sim)的作用有二,且**都是负向的诚实化,不是创造 alpha**:① 止住 mfr 把「无优势」粉饰成「+72%」,让 feedback 负面结论在个案层可见;② 给交易层一个外生投影。**绝不是反转 feedback 结论、绝非新 alpha 来源。** 任何措辞若让用户产生「新 label 可能反转 pattern 评价」的预期,就是给虚假希望、重蹈 feedback §0 警告的「换尺子找 alpha」循环。final_report 须以此为框定,不作脚注。

## 给 lead 的可执行结论

1. **strategy_return 该做,但定位改为「独立交易层 readout」**(原 plan「与 mfr 同级 label」须改),视觉隔离、不进默认选股排名、无「按 sim 选 pattern」入口、参数只联动 sim(eval.py 现有 `match_forward_returns` 不接交易参数,交互不变式几乎免费成立)。
2. **先做 min_low**(性价比最高),sim 排在其后、克制定位。端点收益暂缓。mfr 保留。
3. **全队六点硬共识**(经 skeptic 终审成立):① 两 label 正交共存非串联;② sim 是联合体利润读数非选股尺子;③ 严禁扫参(看程序不看值);④ 原 plan「同级」定位须改;⑤ sim 虚假 alpha 规避是三层(共读 + 集合闸 + UI 标注);⑥ v1 克制(砝码 + 投影,不追独立决策列)。
4. **H7 作框定**:新 label 让既有负面结论更可见 + 交易层投影,不是找 alpha。
