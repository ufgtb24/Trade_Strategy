# 原始问题（用户逐字）

> 来源：会话 `OAT vs multiple` 延续，2026-08-22。

**用户上一轮三个问题的定论**（我作为 lead 的回答，用户已认可并以此为本任务出发点）：
1. OAT 找平台 = 在其他所有变量固定的投影切片中找 → **是**。
2. 其他变量一变，切片就变，原平台不再适用 → **是**（平台漂移，毒药闸实证：宽进底座白过滤、组合收紧后真毒药）。
3. 最终目的是多维优化 → **修正**：最终目的不是多维**最优**，是多维**稳健区**（有体积的连通区域 + 时间一致）。多维优化是敌人——维度越高越容易挑到训练窗偶然好看的点（63 底座 artifact 教训）。

**核心观点链**（用户采纳，作为本任务的理论底座）：
- 一维找平台 → 多维找有体积的稳健区。
- **点可以是偶然的**（训练窗噪声就能造出尖峰），**有体积的连通区域不容易偶然**（要求区域内每个点都好，噪声很难同时抬起一片区域）。
- 区域还要**在时间上一致**（每一年都是这片区域）。
- optuna 的真正价值不是「高效找最优」，而是「高效采样多维空间的形状」——识别哪一片连通区域整体表现好，取区域中心，而非任何单点最优。
- 诚实边界：bb_v1 外推失效根因是突破信号本身无 edge（bo_only=随机基线），调参能做的是「别把外推搞坏」而非「创造外推能力」。杠杆排序：① 信号 edge（feature-study 层）≫ ② 稳健区选点（tune-gates 层）> ③ 优化精度。

**用户逐字原话**：

> 能不能从上述观点出发，重新构思 optuna 的使用用法，目标是：以一种最有利于外推保持成绩的方式在训练集上调参。避免当前 OAT 方法的 的切片漂移。启动新 agent team 研究

## 任务锚点（本 agent team 的研究目标）

重新构思 optuna 的用法，三个硬目标：
1. **最有利于外推保持成绩**（最终目标，贯穿一切）。
2. **避免 OAT 的切片漂移**——上一方案 objective 仍在优化标量（找最优），本任务要把它重构为「区域识别」。
3. 落地为 tune-gates skill 可复用的方法（供后续频繁创建的新 pattern）。

关键要回答的：什么是「有体积的稳健区」、如何用 optuna 采样出空间形状并识别区域（而非优化单点）、区域选点如何最大化外推保持、区域方法是否从机制上根治切片漂移。
