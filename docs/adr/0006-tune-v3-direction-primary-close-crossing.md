# v3 方向优先，收盘价判首次穿越

2026-10-02 决定：v3 的主要成绩是买点日的方向表现——买点后固定观察期内，按收盘价先触上线记 +1、先触下线记 −1、未触线记 0（首次穿越，`path2/CONTEXT.md` 词条），在连续时段内对全部买点求平均，再按近期权重汇总。前瞻收益与盘中回撤只报告，显式写明数值要求时才成为约束。

理由：前瞻收益含波动率，量的是上涨潜力，波动大的参数天然占优；首次穿越的上下线按当日波动尺度对称设定，剥离了波动率，量的是方向。按收盘价判，同一天不会两线都触到，先后总能分清；与盘中判法相比方向结论很少相反，代价是未触线更多。未触线留在分母里：它不是坏数据，也不表示收益为零。

方向成绩不是收益率；实际利润另需卖出规则与交易成本。本决策取代 [0002](0002-tune-v3-upside-primary.md)。

实施入口：`.agents/skills/tune-gates-v3/SKILL.md`。已完成合成数据下的行为验证，未据此宣称真实市场效果或优于旧版。
