# 研究副产品登记簿（feature 候选队列）

> **性质**：跨任务、持久、只追加。与 `docs/research/`（临时、可删）相反——本文件是 feature-study 的假设队列，
> 报告可以丢，登记不能丢。**登记 ≠ 结论**：每条在被换样本验证前，状态一律 `exploratory`。

## 规则

- **登记触发**（写在 CLAUDE.md）：研究任何任务时，凡是**过了预设判据、但不属于本轮主假设**的发现——新变量、方向反了的闸、错的基线——都登记；不限于"上涨规律"。登记前先 grep 本文件防重复。
- **谁关闭**：只由**换了样本**的验证（feature-study / tune-gates）回写状态与报告链接；**登记人不得关闭自己的条目**（发现样本对该条目已烧掉）。
- **不删只压缩**：关闭的条目压成一行移到「已关闭」段；积多了整段挪到 `docs/feature_candidates_archive.md`。**待验证段不删。**
- **自包含**：口径必须写到**公式级**（`pos = close[t]/max(high[t-20..t])`，不是"价格位置"），报告链接失效后仍能判断"新发现是不是它"。（教训：`2026-07-19_tb-geometry-label` 报告已丢，只剩"回撤相对深度"一句，与 `pos` 是否同一个量已无法核对。）
- **合并**：`.gitattributes` 已设 `merge=union`，多分支并行追加不冲突；已有条目不要回头改（改状态走"关闭"流程新写一行）。

### FC-002 · 买点相对近期高点位置 pos
- **口径**：`pos = close[t] / max(high[t-20..t])`（锚**滚动 21 日最高价**，不是形态 peak）
- **方向**：贴近高点 → fr 更高（三分位：深回撤 0.139 / 中 0.345 / 贴近高点 0.559）
- **效应量**：贴近高点−深回撤 Δfr median **+0.420**，CI [+0.125, +0.900]；标记率 33%
- **发现样本**：同 FC-001
- **原构造目的**：为**杀死** FC-001 而造的机械替代解释的操作化（假说：ATR% 高 ⟹ close 在局部高位 ⟹ 分母大 ⟹ fr 天然低），结果方向相反、杀不掉，顺手量了它自己
- **已知纠缠/反驳**：与 FC-001 纠缠；可能只是 **tb 企稳判据松紧的代理**（bb_v1 买点即 tb 节点）——但 FinChannel 实测买点距 burst 终点中位 2 bar、上限 7，tb 已贴上限、无收紧余量，故更可能来自 burst 自身几何。⚠ 与已丢失的 `2026-07-19_tb-geometry-label`（"回撤相对深度主信号 +0.279，26–38% 甜点"）**表面相反、无法核对**：二分 vs 倒 U / 锚点不同 / 测量对象不同，三条理由指向不矛盾但未证实
- **若成立的行动项**：改 pattern 内部（pos 纳入 where / 调 tb 企稳），**不是**外接数据源
- **状态**：`exploratory`
- **发现报告**：同 FC-001；脚本 `repro/atr_mechanical_check.py`

### FC-005 · [bb 特有] 买点前有无 XBRL 财务读数（「财报序列厚度」）
- **口径**：buy_date 前是否存在任何 point-in-time 可见的 XBRL 季度财务值（营收/CFO/净利润任一）；三分 `G_ok`（全有）/ `G_partial` / `G_none`（全无，占 23.8%）
- **方向**：有读数 → FPR 更高
- **效应量**：有 − 无，年 × 波动率层内：FPR k4 **+0.184** [+0.066, +0.301] · k5 +0.201 [+0.061, +0.333] · k6 **+0.236** [+0.084, +0.377]；三 k 同号排除 0；逐年 2023–2026 全正；2024+ 一致 k6 +0.182 [+0.008, +0.350]；作用面 23.8%
- **不是马甲**：G_none 与 G_ok 的 ATR%/pos 几乎同分布（0.079 vs 0.082 / 0.924 vs 0.923）；四层全控 +0.240 [+0.074, +0.412]；只用价格 k6 −0.001、只用成交额 −0.143 都跨 0
- **发现样本**：bb_v1 五年扫描 789 买点 / 481 票（同 FC-003）

### FC-006 · bo 当根「收盘越过前高的幅度」excess_h
- **口径**：`excess_h = close[t] / max(high[t-20 .. t-1]) - 1`（分母窗**不含当根 t**，长度 = bb_v1 的 `bo.total_window=20`）；回归前 winsorize 到 1%/99%
- **方向**：**负** —— 突破幅度越大，未来 40 日 first-passage 方向越偏下行（追高受罚）
- **效应量**：控制 `drought` / `peak_age_max` / `pk_count` / `log M` 后 beta = **−0.269**（因变量 fp_score∈{−1,0,1}，k=5、horizon=40），cluster-robust t：股内簇 **−7.00**、40 交易日桶 **−4.79**（两维同号且 |t|>2）。分箱亦单调：excess_h 高分位组 FP(up−dn) −0.110 vs 低分位组 −0.064。基线对照：全宇宙随机日 FP(up−dn) −0.023（同一 M、同一 k、同一 horizon）
- **发现样本**：bb_v1 现役 bo 流（`peak_measure=high`、`breakout_measure=close`，params.yaml 实参），2000 只股票 / 2021-01-01~2026-03-08 / n=24662 bo（`docs/research/2026-08-31_pk-as-event-and-multi-measure/repro/s5_shared.csv`）
- **原构造目的**：不是找 feature——它是为回答「`shared`（两个 pk_measure 都触发）组的优势是不是只在复读突破幅度」而造的 **measure-free 控制变量**；主假设（多 pk_measure 有无增量）判定为**无**，这个对照变量自己过了线
- **已知纠缠/反驳**：⚠ 与 **FC-002**（`pos = close[t]/max(high[t-20..t])`，方向为**正**：贴近高点 → fr 更高）口径高度相似但**分母窗含当根**、**label 不同**（fr median vs FP 方向）、**样本对象不同**（bb_v1 的 tb 买点 110~112 行 vs bo 全流 24662 行）。两者符号相反，**未核对是否同一个量**——追这条必须先把 (含当根 / 不含当根) × (fr / FP) 四格拆开量，否则会把口径差当成发现。⚠ 同一回归里 `log M` 亦强负（t −10.79 / −5.03），与 FC-001 同向，excess_h 与波动率的分离未做专门检验
- **状态**：`exploratory`（事后、单窗、样本内；发现样本已烧掉，验证须换样本）
- **发现报告**：`docs/research/2026-08-31_pk-as-event-and-multi-measure/q2_measure.md` §2.3 §6；脚本 `repro/s5_shared_is_new_info.py`

### FC-007 · burst 突破的不同 pk 个数 `distinct_pk`（作为方向性特征，非现有闸的复读）
- **口径**：`BurstEvent.distinct_pk` = 簇内各 bo 突破过的 peak 并集大小（`path2/atoms/breakout.py`）。label 锚在 bb_v1 买点 node `tb` 的逐买点日；指标 = 首次穿越率 `up/(up+down)`（horizon=40，几何对称 k），与**按买点日 ATR% 三分层重加权的随机日基线**作差（层匹配是 FC-004 的硬要求）
- **方向**：`distinct_pk` 越大 → 首次穿越方向越偏上行。分箱单调：FPR 0.549（≤2）/ 0.571（=3）/ 0.607（≥4）
- **效应量**：`≥3` 相对层匹配基线 ΔFPR **+0.100** [+0.047, +0.150]，`≥4` **+0.123** [+0.045, +0.193]（2025 窗，按票整簇自助）；**三档 k 同向且 CI 均不跨 0**（≥4：k4 +0.108 [+0.035,+0.178] / k5 +0.123 / k6 +0.138 [+0.052,+0.218]），过最低线。2024 窗三档 k 同样全正（≥3：+0.031/+0.045/+0.047）但 CI 全跨 0
- **不是 `burst_count` 的马甲**：固定阈值 3 的 2×2 里最强格是 **`pk≥3` & `count<3`**（n=648，ΔFPR +0.142 [+0.081,+0.202]），强于 `pk≥3` & `count≥3`（+0.065）与 `pk<3` & `count≥3`（+0.096）——即「bo 少但各吃多个阻力位」最好，与「burst 更长」相反。`burst_count` 自身在 1/2/3 上近乎平（+0.056/+0.076/+0.062）
- **发现样本**：全宇宙 8325 只 pkl，bb_v1 按 `params.yaml` 底座、4 道 burst 闸放到最松的宽进 match（样本单位 = `(symbol, tb_instance, anchor_bo)` 去重后的 match）；`w2025` = 2025-01-01..2026-01-01 n=5846 / 2232 票，`w2024` = 2024-01-01..2025-01-01 n=4357 / 1734 票
- **原构造目的**：不是找 feature——它是「打分制可补偿性」研究里的**四个对照轴之一**（主假设是「高 `vol_spike` 能不能补偿低 `distinct_pk`」，判定为**不能**）。四个量里只有它自己过了线
- **已知纠缠/反驳**：⚠ **低档位切分无区分力**——`≥1→≥2` 那一档几乎没有增量（+0.067 → +0.072），信息集中在 `≥3` 往上；在 `count=2` 层内按阈值 2 切它，2025 窗上反号（+0.070 vs +0.094，CI 重叠）。⚠ 两个窗都是样本内、无预注册 holdout；本轮报了 4 个量 × 2 窗 × 多阈值档，**未做 FDR 校正**。⚠ 只做了 symbol 单维去簇，**未做时间桶去簇**（同期跨股聚集是盲区）。⚠ 2025 窗宽进总体本身就有优势（+0.067）、2024 窗没有（−0.003），跨年落差大于任何单个量的效应
- **若成立的行动项**：现役 `distinct_pk_min=3` 是四道闸里唯一有实证支撑的一道，且有向 4 收紧的余地；交 tune-gates 单闸定阈值
- **状态**：`exploratory`
- **发现报告**：`docs/research/2026-09-07_dag-scoring-vs-hard-gates/stats_validity.md` §2 §6；脚本 `repro/extract_wide.py` + `repro/distinct_pk_check.py`

### FC-008 · [方向反了的闸] bb_v1 现役 `first_drought_min=40` 在 2025 窗上做负功
- **口径**：`bb_v1` params `burst.first_drought_min`，读 `BurstEvent.first_drought`（= 簇首 bo 的 `drought_floor`，`ed9a9a8f` 后语义）。比较「过闸子集」与「一道闸都不设的宽进总体」各自相对**波动率层匹配随机日基线**的 ΔFPR（horizon=40、k=5）

- **状态**：`exploratory`

### FC-009 · [错的目标口径] bb_v1 的 burst 四量在 `forward_return` 上的优势全部是波动率读数
- **口径**：`first_drought` / `distinct_pk` / `vol_spike`(=`max_bar_vol_ratio`) / `peak_age`(=`peak_age_max`) 四个 burst 量，各自与 `median(forward_return)`（`match_forward_returns`，horizon=40，锚 bb_v1 买点 node `tb`）的关系；对照量是同一批样本的**层匹配随机日基线 med_fr**（按买点日 ATR% = `rolling_atr_pct_nanmedian(h,l,c,20)` 三分位分层重加权）与 `median(forward_drawdown)`
- **方向**：**无** —— 原始 med_fr 随四量单调上升，但层匹配基线以**相同斜率**同步上升，作差后全线贴 0 或转负
- **效应量**：`vol_spike` 五分位 med_fr 0.150→0.234（看似单调有利），同分箱的层匹配基线 0.178→0.241、`med_dd` 从 −0.119 恶化到 −0.226；Spearman(`vol_spike`, `|dd|`) **+0.188** > Spearman(`vol_spike`, `fr`) +0.105。`vol_spike × distinct_pk` 2×2 四格的 Δmed_fr = +0.009 / −0.011 / −0.005 / −0.019（2025），全部贴 0 或为负，而未层匹配的原始 med_fr 排序 0.251 > 0.216 > 0.209 > 0.166 看起来完美可加
- **对照**：同一批样本的**首次穿越率**（剥离波动率）上，`distinct_pk` 留下真实优势（FC-007），说明不是「这批样本没信号」，而是 **`fr` 这个口径把波动率成分算进了信号**
- **发现样本**：同 FC-007（全宇宙 8325 只、`w2025` n=5846 / 2232 票、`w2024` n=4357 / 1734 票、宽进 match）
- **原构造目的**：为回答「这四个量能不能加权求和当打分」而必须先验证「它们各自到底是不是利好因素」；`med_dd` 与层匹配基线都是为**反驳**「med_fr 单调上升 = 有利」而造出来的对照，结果反驳成立
- **登记理由**：不是 feature，是**目标口径的负面结论**——记下来防止下次再拿 `median(forward_return)` 当打分/加权/调参的优化目标。在 bb_v1 这批量上，优化 `fr` 中位数等于优化波动率。**任何以 `fr` 为目标的排序、打分、权重拟合都缺乏干净的优化目标；方向性判断必须走首次穿越率。** 与 FC-004（bb vs 基线必须按波动率层匹配）是同一件事的两面：FC-004 管「比较时要匹配」，本条管「匹配之后 `fr` 这个指标在这批量上还剩什么」（答案：不剩什么）
- **已知纠缠/反驳**：⚠ 只在 bb_v1 的 burst 四量上验过，**不是对 `fr` 这个指标本身的普遍否定**——换一批与波动率不相关的特征，`fr` 仍可能有信息。⚠ 层匹配用的是 ATR% 三分位，层数与切点未做敏感性。⚠ 同 FC-007 的四条统计局限（样本内 / 无 FDR / 单维去簇 / 跨年落差）
- **状态**：`方法结论，不进 feature-study`（与 FC-004 同类；待有人在别的特征族上复核后可推广）
- **发现报告**：`docs/research/2026-09-07_dag-scoring-vs-hard-gates/stats_validity.md` §2「分箱形状」§3 判读 4；脚本 `repro/analyze.py` + `repro/factorial_ci.py`
