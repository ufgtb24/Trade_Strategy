> 目标：以外推保持为最终目标，把 optuna 从「优化单标量」重构为「均匀采样 + 事后区域识别」，根治 OAT 切片漂移。

---

## 0. 核心转变（一句话）

上一轮方案的 objective 是「优化一个稳健标量（min-fold FP + 惩罚）→ 找最优点」——**这本质上还是找最优，只是把标量换成了稳健版**。本任务把它改成：

> **不优化任何单点，而是均匀采样整个多维空间 → 在采样点上识别「有体积 + 时间一致」的连通稳健区 → 取区域中心（离边界最远的点）作为推荐。**

optuna 的角色从「引导式搜索器（TPE/NSGA-II）」降格为「均匀采样器（Sobol/QMC）+ trial 管理（并行/结果存储）」。「找区域」这个动作是采样之后的确定性后处理，不在 optuna 内。

## 1. 切片漂移是否被根治（诚实评估）

**根治了什么**：OAT 的缺陷不在「切片」本身，而在「依赖单维投影切片做决策」。参数有交互时，单维切片的位置随其他变量漂移（毒药闸：宽进底座白过滤 → 组合收紧后真毒药），于是单维切片的结论不可迁移。区域方法**不再做单维投影**——它直接在多维空间画高值区，决策对象是「一片连通区域」而非「某维的一段平台」，因此「切片随其他变量漂移导致结论失效」这个问题的**源头（依赖投影）被消除**。

**没根治、但被转换的东西**：区域内部仍然可能有交互——表现为区域形状**细长/弯曲**而非各向同性。沿长轴方向切，切片依然会漂移。区域方法没有消除交互，它做的是把「隐式陷阱」转成「显式可观测的形状」：

| 区域形状 | 机制含义 | 对切片漂移的含义 |
|---|---|---|
| 各向同性（圆/球） | 参数近似独立，无强交互 | OAT 切片本来就够用 |
| 细长（沿对角拉伸） | 参数可互换（一加一减抵消） | 沿长轴切漂移、沿短轴切稳定 |
| 弯曲（非线性交互） | 阈值关系非线性 | 单维切片结论几乎必然误导 |

**结论**：区域方法把「切片漂移」这个**不可见的风险**，转成了「区域形状」这个**可见、可复核、可量化**的东西。这不是根治（交互仍存在），但它是能做到的最好形态——因为交互是参数空间的真实性质，任何方法都不能「消除」它，只能「测量并绕开」它。区域方法选择绕开的方式是：**取离边界最远的中心点，让推荐点在区域形状的容错范围内，交互再怎么漂也漂不出区域**。

## 2. 稳健区的可计算定义 + 识别算法

### 定义
设必须真扫参数空间为 d 维（d ≤ 4），每个点 x 经一次全量 scan 得稳健得分：

```
s(x) = min(各 fold FP(x))           # fold = 训练窗按年切块（fold 在 scan 内，零额外成本）
       − λ·dispersion(各 fold FP)   # 幅度分裂软惩罚（可选）
```
并受硬约束：`total_count(x) ≥ MIN_MATCH`（功效线，不满足的点直接淘汰）、各 fold 相对 baseline 方向一致（不一致淘汰）。

**稳健区** R = 高值点的**连通分量**：`R = { x : s(x) ≥ s̄ }` 中按图连通性聚合出的最大连通块（s̄ = s 的 top-k% 分位或 s*−ε 水平集）。

### 识别算法（事后，确定性）
1. **均匀采样**：Sobol/QMC 序列取 N 点（N ≈ 40~60，覆盖 d≤4 维）；每点一次全量 scan → s(x_i) + fold 明细。
2. **高值集**：取 s(x_i) ≥ 分位数阈值的点。
3. **连通分量**：在高值点间建图（距离 ≤ 采样特征长度视为相邻），找连通分量；或 DBSCAN。每个分量 = 一个候选稳健区。
4. **代表点 = Chebyshev center**（最大内切球中心，即离区域边界最远的点），或退而求形心。**绝不取该区内 s 最大的点**（那又回到峰值）。
5. **区域判据用 inradius（最大内切球半径）而非体积**（formalizer 关键修正）：细长区体积大但薄方向脆弱，一个长轴很长的细长区在短轴方向上一动就掉出区，体积大是假象。inradius 才是「各向都抗漂移」的正确度量。多个候选区按 inradius 排序，交人复核挑机制合理的。

### 时间一致性如何进区域
`s(x) = min-fold` 已经把「单年驱动」惩罚掉了——某点只有某一年好，其 min-fold 必然低，进不了高值集。所以「稳健区」**自动要求每年都足够好**，无需额外约束。

**更强的等价表述（formalizer）**：`{θ : min_y f_y(θ) ≥ τ} ≡ ∩_y {θ : f_y(θ) ≥ τ} = ∩_y R_y`——逐点取各年 min 再 superlevel，数学上等于**各年稳健区的交集**。这比「单点 min-fold」更强：它不仅要求每个点每年都好，还排除「各年好点位置不同、取交集后为空」的情形（即某年 A 区好、另一年 B 区好，但 A∩B=∅ → 没有跨年一致的区域，任何单点推荐都是赌某一年的位置）。交集为空 = 判「无稳健区」，退回 OAT 或承认无跨年 edge。

**弱年主导缓解（开放点）**：min 的绝对值会受各年 baseline 天然高低影响（弱年 FP 天然低 → 搜索全往弱年靠）。用「各年相对 baseline 增量的 min」而非「各年绝对 FP 的 min」，缓解弱年主导——具体 τ 锚点（基线指标 + 边际）与 r_min 阈值留首轮实战校准。

## 3. optuna 用法重构

| 维度 | 上一轮（错误） | 本轮（正确） |
|---|---|---|
| sampler | TPE / NSGA-II（引导式搜索） | **Sobol/QMC 均匀采样** |
| 目标 | 优化稳健标量 | 不优化；采样后事后识别区域 |
| optuna 的角色 | 搜索器 | 采样器 + trial 管理（并行 + 存储） |
| 产出 | top-K 最优点 | 覆盖全空间的采样点矩阵 + fold 明细 |
| 决策 | argmax 附近复核 | Chebyshev center（离边界最远） |

**为什么均匀采样而非引导式搜索**：区域识别需要的是「能刻画空间形状的均匀覆盖」，不是「集中火力逼近最优点」。TPE 会朝最优点收敛、稀疏采样外围，导致高值区的**边界画不准**——而区域识别的核心恰恰是边界。Sobol 序列保证低差异覆盖。

**objective 的角色 = 指标记录器 + 弱引导（optuna-usage-redesign）**：核心是把每点各 fold 的 FP/fr/count **完整存进 `trial.user_attrs`**；返回值（min-fold FP）只让 optuna 框架能跑，**不驱动采样密度**（密度由 QMC 均匀性保证）。功效线不达标 → 返回 `-inf` 硬淘汰坏点。

**采样规模（4 维时 20-40 点不够覆盖 → 先粗扫缩盒）**：d≤3 时 Sobol N=20~40 足够；d=4 时先做**一维粗扫**缩小每个参数的盒子（目的不是选平台、也不怕漂移——缩盒阶段的漂移无害，因为它只是缩小搜索域），再在缩小的盒子里均匀采样 2-3 维 20-40 点。总成本 ≈ 一次粗扫（d×几档）+ 一次均匀采样（20-40 点），与上一轮「20-40 trials」同量级。

**fold 明细的复用**：每次 scan 已产出带时间戳 match，fold-in-scan 分块是免费附赠（上一轮的正确部件，保留）。采样点矩阵的每一行 = 一个参数点 + 各 fold FP/fr/count + 稳健得分。

   b. 均匀采样（Sobol N 点，每点一次全量 scan）→ 采样点矩阵 + fold 明细

## 5. 外推保持机制（为什么取区域中心）

三重机制，都指向「外推时参数空间最优位置会漂移」：

1. **抗漂移（几何）**：外推 = 数据分布漂移 = 稳健区整体平移/变形。区域中心离边界最远，漂移量小于区域半径时推荐点仍在区内，成绩不掉。单点最优则没有这个缓冲——漂移一点点就掉出最优邻域。
2. **时间一致性（统计）**：min-fold 要求「每年都好」，等价于「这片区在训练窗内不同年份的分布下都成立」。一个「跨年成立的区」比「某年特别好的点」更有理由在未见年份成立——这是归纳的根基，不是玄学。
3. **体积约束（反过拟合）**：噪声很难同时抬起一片连通区域（要求区域内每个点都好）。单点可以是噪声尖峰，连通区几乎不可能是——区域的体积本身就是对「偶然最优」的天然正则。

**诚实的边界（保留上一轮）**：这三重机制保证的是「别把外推搞坏」，不保证「创造外推能力」。若信号本身无 edge（bb_v1 的 bo_only=随机基线），再稳的区外推也是平庸——区域方法只是诚实读数，不是点金术。

## 6. 可解释性（区域形状 = 机制信息，不退化成黑盒）

区域方法**反而比单点最优更可解释**：

- **单点最优**：只告诉你「这个点好」，不告诉你为什么、参数敏感不敏感。
- **区域形状**：各维投影跨度 = 每个参数的可活动范围。某维跨度大 = 该参数鲁棒（阈值放哪都行）；跨度窄 = 该参数敏感（要精确）；细长对角 = 两参数可互换。**这本身就是机制诊断**——比单点最优多给出「哪些参数需要精调、哪些可以糙放」的信息。
- **人复核点**：看区域在参数空间的位置是否机制合理（例如「回踩确认窗口越长越好」在机制上应单调，若区域显示非单调就该警惕）。

- objective 只看训练窗 + 同 head_buffer 外推验证；
- 事后可切参数不进多维搜索（零成本切档是 tune-gates 独有优势）。

**推翻（本任务重构的核心）**：
- ~~objective 优化单标量（min-fold FP 字典序）~~ → 改为「均匀采样 + 事后区域识别，取 Chebyshev center」；
- ~~TPE/NSGA-II 引导式搜索~~ → Sobol/QMC 均匀采样；
- ~~top-K 最优点 + 邻域平台复核~~ → 连通稳健区 + 区域中心；

**一句话总结关系**：上一轮把「找最优」做得更稳健（稳健标量 + 完整检测 + 同缓冲外推），本轮把「找最优」这个目标本身换成「找区域」——前者是「更稳的点」，后者是「有体积的区」，只有后者才真正对准「外推保持」。
