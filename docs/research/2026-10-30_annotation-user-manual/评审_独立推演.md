# 评审尺子：从看图直觉到胜过同日普通买入，路上会在哪里失败

critic 第一阶段独立推演，写于读 writer 骨架之前。用词按票 14（sample / positive / negative / box / member box / dag / hit / event / match = hit 与 sample 的比较 / map / mapping）。本文件所有路径相对 repo root。

## 0. 链条与唯一的裁判

直觉 → 在图上画 box、下 sample → 会话 map 成 dag（mapping 记每个特征的级和由谁来认）→ app 在全池产出 hit → hit 与 sample 比（match）→ 盲看随机抽的 hit → 调参 → 最后检查。

只有最后一步判输赢。前面每一步都只能做两件事之一：**让 app 忠实于用户的意思**（不走样），或者**不让训练段上的好看结果混进证据**（不自欺）。说明书里任何一个功能，如果既不服务前者也不服务后者，它和终极任务就没有连接；如果把前者的产出（认出几个、match 几个）说成后者的证据，就是夸大。

## 1. 失败清单与防线

| # | 会怎么失败 | 后果 | 工具在哪一步防、要什么能力 |
|---|---|---|---|
| **A 后见之明混进买入条件** ||||
| A1 | positive 按「后来涨了」下，而不是「当天有这个样子、当时会买」 | app 学到的是训练段赢家的样子，最后检查才暴露，白用一次 | 标注：选中 sample 时 sample date 之后的 K 线暗下来；会话每轮列出没有结构原因而翻过 judgment 的 sample（含盲看揭开前后判断相反的）问「那天看得见吗」 |
| A2 | member box 跨过 sample date，或属性「有 / 没有」靠后面的走势判 | 依据里混进当天看不到的东西，翻成 where 就是偷看未来 | 标注：跨过 sample date 的框不收进并提示（硬规则，票 14）；属性三态里「没看过」不等于「没有」 |
| A3 | negative 的理由是看到跌了才找出来的 | 「不买」的条件在训练段上完美、在新数据上无效 | 定义要求当天看得出；事后才想到的理由当新想法，走盲看或在要用的地方量，不直接进 dag |
| A4 | app 一侧的买点用了确认之前的信息（回顾型事件按起点买） | hit 的收益是不可执行的 | 框架已有：事件在确认根才存在、买点按 app 声明的买点 node 算（`path2/GLOSSARY.md:56`、`:59`）；说明书对懂 path2 的读者点一句即可，不需新功能 |
| **B 在看过的图上自我欺骗** ||||
| B1 | 看着实测值和门槛一张张放宽，让 app 拟合手上那几张 sample | 训练段上全对，新数据无效 | 对照：单张图只给状态（qualified / detected / missing、matched / unmatched），不给数字；只差门槛的按特征汇总留给调参统一定 |
| B2 | 把「positive 里 matched 几个」「特征 qualified k/n」当成 app 有效的证据 | 用户以为 app 好，其实只是 app 按这些图写的，且用户本来就可以看着 app 标 | 说明书必须明说：这些数只说明 app 忠实不忠实，不说明它赚不赚钱 |
| B3 | 反复看训练段成绩、按成绩改结构 | 训练段被当成检查用，凑出来的优势 | 训练段成绩不每轮主动报，只在用户问、准备调参、送最后检查前给；明显为负才主动提醒 |
| B4 | 盲看时看着后续走势点「是」 | 「是」偏向涨了的，app 被改成专挑赢家 | 盲看：后续走势先藏，点完再露；理由在藏着时写 |
| B5 | 调参把 sample 悄悄调丢 | 调参后的 app 已不是用户说的那个 pattern | 调参后逐个报丢了哪几个 sample，用户定接受还是限范围重调 |
| **C 只在少数几张图上成立 / 挑图偏差** ||||
| C1 | 从大涨段清单找图，只看到涨了的；「长得像却没涨」的一半缺失 | app 的 hit 在全池里多数不是用户说的样子，或是但不涨 | 盲看：从整个股票池随机抽 hit，用户标过的股票不抽，比例和 app 将来遇到的一样 |
| C2 | 把 negative 上 app 买了几个当误报率 | negative 是用户专门挑的，分母不代表任何总体；没标的日子不是 negative | 说明书明说；误报只在盲看的随机部分有比例意义 |
| C3 | 铺满时间轴的特征（走势区段等）随手一框也「认出」 | 认出数虚高 | 对照每层配一个底（随便挪位置也认出的比例），高了提醒 |
| C4 | 「取其一」里少见的分支只有一两张图 | 那一支在新数据上没把握，合计数看不出 | 按分支拆开报认出数；盲看给少见分支补抽 |
| C5 | 新并进的特征带进噪声，或其实和已有的说同一件事 | pattern 变松、优势被稀释 | 在要用的地方量：带 / 不带各跑一遍，只看多出来的那批和同日对照比；「看不出」不等于「没用」 |
| C6 | 用户试了很多个 pattern（或很多版本），每个送检一次，总有一个碰巧过 | 「过了」的那个其实是运气 | 最后检查记次数和 app 版本，次数要让用户看得见；次数怎么跨 pattern 数，是待用户拍板的方向（见第 2 节） |
| **D 直觉翻成 dag 时走样（会话误读）** ||||
| D1 | 一个词装两种意思，或改措辞换了意思 | 同名框一半认得出一半认不出，会话误当门槛问题去调 | 词的定义一旦定下不改，意思变了另建一个词；会话发现同名框明显分成两类时提醒 |
| D2 | 会话分不清「取其一」「至少 k 条」「其实是两个 pattern」 | 翻出来是完全不同的 app | 名字第一次出现时写一句定义说意图；骨架不同就分开 |
| D3 | 定级错：背景被预填成必须有、用户没细看就同意；或只在 negative 上出现的不买理由被「不到一半就不放」吞掉 | app 悄悄变严；不买理由没进 dag | mapping 每行可见、可点 ⚑ 改；出现在全部 positive 里又没定义的顶层特征不预填、必须用户选；只在 negative 上出现的特征进定级单子（票 12） |
| D4 | 对照只看特征名、不看属性，画在属性上的理由有没有被接住看不出 | 用户以为一致，其实 mapping 漏了 | 差 tag 把属性级也算进去（票 13） |
| D5 | 会话推错 member box 或角色 | 拿错的依据写 app | 成员默认推断、用户可点进点出；「画了没收」机械标出；推不出的角色在图上问 |
| D6 | detector 的判定口径和用户的框不同（回踩只记企稳段、用户连下跌一起框） | 被误判成「认不出要新写」 | 认不出时会话先排除判定口径问题，再下新写 detector 的结论 |
| D7 | 用户脱离图用语言改 pattern（「底部再深一点」） | 改动没有对应例子，改完查不出对错 | 会话反问「在哪几张图上看到的」，转去标注或指出已有标注；截图也先变成标注 |
| **E 改动没有对应例子，以后被改坏查不出** ||||
| E1 | 后一轮改动把前面已对上的 sample 改坏 | 退化无人察觉 | 每轮全部 sample 重新比；app 改版后旧汇总标过期重出 |
| E2 | app 改版后 sample 归属跟着变 | 旧标注失效 | sample 挂在 pattern 下，不挂 app 版本 |
| **F 最后检查本身不诚实或被误读** ||||
| F1 | 2026 年起的数据被看到或被分析读到 | 唯一的裁判失效 | 数据墙：除最后检查外一律读截到 2025-12-31 的副本 |
| F2 | 送检版本没冻结、没盲看就送 | 白用一次 | 进门清单：版本冻结、无 unmapped、无没答的问题、最后一次结构改动后做过盲看、调参丢的 sample 看过、训练段四样看过 |
| F3 | 把「胜过同日对照」读成「赚钱」，或把择时的运气当本事 | 判错 | 四样成绩只有「比同日普通买入多多少」判输赢，随机日、择时、绝对收益只报不判 |
| F4 | 九个月数据只分辨得出很大的优势，「没过」被读成「没用」 | 放弃有小优势的 pattern，或反复送检 | 说明书要说清这把尺子能分辨多大的差别 |

## 2. 读者以外的东西，我会追着要的

- 上面 B2、C2、F3、F4 是**承诺的上限**：说明书写「强大」时最容易越过它们。凡是训练段上的数（认出数、matched 数、训练段成绩、量特征的结果）都只能当「忠实」或「参考」，不能当证据。
- C6（跨 pattern、跨版本的总送检次数）我认为是方向题：只按单个 pattern 记次数挡不住「试很多个 pattern 挑过了的那个」。票 04 还开着。说明书若写记次数，要说清记的单位；拿不准就交 auditor 列为用户拍板项。
- 词表陷阱（不是说明书的错，但 writer 引用时会踩）：`path2/GLOSSARY.md:95` 的 match 仍是 app 产出的旧义（改名另立、未执行），说明书应照票 14 用 hit；`:124` 训练段仍写 2024-01..2025-12，已定为 2021-10-08～2025-12-31；`:127`～`:139` 的预检段、调试段、尝试、验证段「只判一次」属于已归档的旧 effort，新方向是「没过就回去改结构，再查再记」，不能照抄。
