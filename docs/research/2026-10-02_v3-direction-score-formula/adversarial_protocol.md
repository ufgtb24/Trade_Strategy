# 窗口公式的事前反例协议

日期：2026-10-02。本文在运行本轮窗口合成实验前写定。所有项目内路径相对 repo root。

## 要比较的东西

输入只有完整的合成股票日标签，不读取行情。每个有买点的窗口记录先上 U、先下 D、未触线 V，总数 N=U+D+V。候选的窗口方向值暂采用 z=(U-D)/N；它把先上、先下、未触线分别记作 +1、-1、0，是方向代理而非实际收益。配对普通对照也用同口径，窗口差值记作 delta=z_pattern-z_control。只在已触线中算先上比例 q=U/(U+D)，保留为解释指标，不直接把 q 当完整优化目标。

候选汇总：

1. 按全部买点日直接合并；用于揭示买点密集时段的高权重。
2. 有交易窗口的等权均值。
3. 有交易窗口的等权中位数。
4. 有交易窗口的近期加权均值；半衰期暂取252个交易日，窗口以终点距训练末日的距离加权，属于演示性应用偏好，尚未校准。
5. 作为顺序比较，演示逐窗口按 n/(n+20) 回拉到0后汇总，与先汇总再作一次回拉。20仅是说明不交换性的反例常量，不是建议参数，n也不代表独立证据量。

日历长度504，窗口长21，有效起点0..483。主比较固定随机种子20261002，均匀有放回抽200个起点，所有候选共用；同时算全部484个有效起点作为随机积分参照。增加200→400时，先直接复制原200窗口，检查完全相同的信息不能被解释成证据增加。所有均值对空窗口保留缺失标记，再另报日历覆盖、有效窗口覆盖和真实唯一机会数；不补零、不补对照、不补抽。

## 事前期望与判据

| 场景 | 应满足的事实或希望暴露的问题 |
|---|---|
| 好行情半年买点密集 | 买点池比例可被密集半年支配；窗口等权大幅减弱跨时段的数量权重，但不会删除这半年的真实表现。同期对照同样改善时，配对优势不应凭市场变好而上升。 |
| 稀疏季节性策略 | 无交易窗口不能被伪造为失败，不能仅因少交易月份就强制排除；有交易条件分必须明确不代表全年均匀供给，近期没有机会时不能宣称近期适用已获证明。 |
| 近期变差 | 等权均值对时间顺序不敏感；近期加权均值应优先排列近期更好的候选。此排序来自“近期适用优先”的应用偏好，不宣称统计更客观。 |
| 全空或全未触线 | 全空主分没有定义；有买点但全未触线时 z=0、q无定义，不能把两者当同一种缺失。 |
| 200窗口复制成400 | 所有位置不变的均值/中位数保持不变，独立历史长度不变；若标准误缩为原值1/√2，说明误把重复当证据。 |
| 边缘日期 | 随机合法起点导致边缘日期被覆盖概率低；首尾各1/484，中间21/484。不能宣称这等同于所有交易日等权。 |
| 改善少数差窗口 | 均值随严格正改善上升；中位数允许不动，显示优化平台。这不证明中位数统计错误，只证明它舍弃了哪些变化。 |
| 先校正还是后校正 | 非线性/不同强度的回拉与均值、中位数不一般交换；逐窗口回拉给稀疏时段更重折扣，改变了等权时段目标。 |
| 条件触线比例陷阱 | 相同q但触线率很不同时，q不给区别；z反映期限内净方向标签，但不因此成为真实交易收益。 |

## 不能靠本实验决定的事

- 真实市场里的最优观察期限、窗口长度、半衰期、收缩强度、机会最低数和风险底线。
- 两个候选分别只在不同日期交易时，哪个能带来更高资金收益；缺乏持仓、资金分配和退出规则，不能将空窗罚分假装成真实成本。
- 普通对照优势与绝对方向哪个应作唯一主分；本实验呈现它们的差别，由目标组统一推荐。
- 重叠窗口不是独立样本；本实验不计算市场证据强度，不进行显著性检验，不将200次重抽当作200段独立行情。
- 合成反例只能排除逻辑失真、说明公式偏好，不能宣布某一公式已经验证有效。
