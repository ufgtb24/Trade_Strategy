## 0. 结论先行

**① 有进一步的统一，而且比草案更简。** 草案里承重的「交叉拟合」不再做挑选与报数的核心，只剩整年留出这一种形式，作为开窗前门前沿上的一档可选项。调参收敛成经典的两阶段「选择—确认」设计，只剩三个部件：

1. **选**：训练期两年合并的增益取最大，只留一个候选；
2. **值不值得开窗**：一道开窗前门，严格程度按确认窗有多稀缺来定；bb_v1 这种确认窗不可再生的处境，用「候选的收缩后增益 ρ·d̄ > δ」，不过门就本轮维持现值；
3. **写不写、有多好**：所有没参与过挑选的数据段按精度合并（方差里加上训练期池化的年交互方差），做一次单侧优效检验，过了才写。

过程参数 5 个（δ、α、买点怎么用、档位范围、按股误差的最少股票数），外加一个业务问题「确认窗有多稀缺」（它决定前门取哪一档），**没有任何「规则选项」**。现行流程里六套挑选偏差校正、四套时段稳定检验、平台 / 峰值规则、单翻转剪枝、max-T 族、四格判读表全部退役。

**② 漏洞：草案的方向框架对，但承重件放错了。** 交叉拟合在两年数据上「诚实」和「可用」不能兼得：按草案的「股票折 × 年」切会把同期行情漏进留出块（报数偏高 +2.0～+4.5 点），整年留出诚实了却只剩一个自由度；而且它估的是「挑选流程的平均表现」，不是这次选中的那一点。围绕它打补丁需要 10 条（重要级以上），这已经是「方法不对」的信号。换掉承重件之后，剩下的补丁只有 4 条小的，都不加参数。

**③ 外推：只能在弱意义上提升，上限很小，杠杆在确认窗不在挑选算法。**
- 「任何场景都不比维持现值差」在定理上做不到——工作点本身就是最优时，任何会换参的规则期望都为负。
- 能成立的保证是：真实没有改进的候选被写入的概率 ≤ α（前提是确认窗能代表未来），以及工作点最优时只有很小的有界亏损。
- 模拟里推荐形态相对**现行流程**：N0 / N1 下四类真值曲面都不差，真改进 4～8 点时多拿 0.56～0.74 点，工作点最优时少亏 0.06～0.08 点；N2 下基本持平。
- 能拿到的绝对量：真改进 4～8 点时约为理想值的 30%～50%，1～2 点时 10%～17%。**bb_v1 这类效应小于噪声的 pattern，期望增益约为 0，方法的价值主要是不把噪声写进正式参数。**
- 「这次挑出的点到底有多好」单轮说不出来（任何报数与未来真值的相关 ≤ 0.49），只能做到跨轮次期望意义上的诚实。

**④ 对照本质目标。** 「选出未来最好的点」：在 bb_v1 量级下挑选规则怎么换，选中点的真实增益只差零点几点，所以取最简单的取最大。「诚实说出有多好」：只有和挑选无关的数据能回答，训练期内任何校正都只是逼近——现行流程手上本来就有两段这样的数据，却只让一段决定写不写，再在训练期里堆了十套机制去逼近一个本可以直接量出来的数。**这是补丁感的根源，也是这次简化的出发点。**

## 1. 第一性原理：为什么交叉拟合是错的承重件

调参要回答两个问题：挑哪个点、它有多好。两者需要的东西不同。

**挑点只需要排序。** 训练期数据用于排序没有任何问题，排序被噪声带偏的程度由「效应 vs 噪声」决定，任何挑选规则都改变不了这个比值。模拟里 1～2 点真改进时，朴素取最大 +0.83、草案交叉拟合 +0.72、现行规则 +0.58（理想值 +1.50）；工作点即最优时三者分别亏 −1.85 / −1.52 / −1.23。**规则之间的差别本质上只是「离开工作点的倾向」强弱不同**，是风险曲线上的不同位置，谁也不支配谁。

**说有多好需要一份和挑选无关的数据。** 挑选已经把训练期的噪声「用掉」了，在上面做任何校正（重抽样、邻域取最差、交叉验证），都是在同一份噪声里估计自己有多幸运。交叉拟合试图在训练期内部造出这样一份数据，但：

- **按股票切不出独立噪声**。同一时段所有股票共享行情冲击，未来时段不共享；相关数据上交叉验证无偏的条件（留出块与训练块的相关结构 = 未来与训练的相关结构，Rabinowicz & Rosset 2022）不满足。模拟：草案块结构报数偏高 N1 +2.1 / N2 +4.5 点。
- **按时间切只有两块**。整年留出是诚实的（偏差 −0.1～−0.3），但只有一个自由度，报数与选中点真值的相关 ≤ 0.28，「年份取最差」在内层根本算不出。
- **它估的不是选中的那一点**。交叉验证估的是「这套流程在另一份数据上的平均表现」（Bates, Hastie & Tibshirani 2023）；bb_v1 上各折选中的格稳定性只有 0.04。

而**确认窗天然就是那份数据**：候选在开窗前冻结，确认窗上的估计与挑选独立，不需要任何挑选校正（两阶段选择—确认设计，Sampson & Sill 2005 的结论是只有「把两阶段数据合起来推断」才需要校正）。所以正确的分工是：训练期只管排序，确认窗管写入和报数。交叉拟合夹在中间，两头都做不好，删掉它流程反而更完整。

## 2. 推荐形态

### 2.1 流程

| # | 步 | 做什么 | 停 |
|---|---|---|---|
| 1 | 定义 | 读任何涨跌结果之前冻结进账本：δ（最小关心改进，默认 2 点）；α（能容忍多大概率把一个不比现在好的配置写进去）；买点怎么用（资金不受限 / 同时几个仓位、平均一笔拿多久）；参数范围与档位；按股误差所需的最少股票数；确认窗有多稀缺（决定第 4 步用哪道前门） | **停 1** |
| 2 | 扫描 | 训练期带标签；确认窗只记买点、不算涨跌。检测参数的档位先做无标签预筛：与工作点的买点对称差占比 f < δ 的档，首次穿越率最多也只能差 f，达不到 δ，不扫 | 不停 |
| 3 | 选候选 | 每格两年合并的增益 d̄（相对工作点），在 f ≥ δ 且股票数达标的格里取最大，得唯一候选 θ̂ | 不停 |
| 4 | 值不值得开窗 | 按停 1 定下的确认窗稀缺程度选一道前门（§3.2 前沿表）。确认窗极稀缺（bb_v1 默认）：候选的收缩后增益 ρ(θ̂)·d̄(θ̂) > δ 才开窗，ρ 是跨年可靠度（真实效应方差占两年平均差总方差的比例，由两年配对差跨格估出）；不过门则本轮维持现值、不消耗确认窗。取代现行「预期把握不到一半」的条件停点 | 不过门时通知 |
| 5 | 机制否决 | 用户只能剔除候选（剔除后取下一名，重走第 4 步），不能换候选；每次剔除记一次挑选 | **停 2**（可选） |
| 6 | 确认并写入 | 所有没参与过本 app 挑选的数据段（首轮即往前、往后两段）：①候选属放松方向时，往前那段估计先按幸存者偏差上界朝不利方向平移；②每段方差 = 按股抽样方差 + τ̂²（训练期跨格池化的年交互方差，不去均值，按「移动了几个参数」分组取候选所在组）；③按精度合并。**合并估计的单侧 1−α 下界 > 0，且最近一段点估计 ≥ −δ，才写入；否则维持现值** | **停 3** |
| 7 | 报数 | 账本每轮记原始合并估计 ± 标准误，写不写都记。写入时照报这个数，并注明「过门才写的读数平均偏高」 | — |

### 2.2 相对现行流程的去留

| 现行机制 | 去向 | 理由（详见 §3、§4） |
|---|---|---|
| 筛选 FDR（q）、刚过线、max-T 族 | 删 | 只用确认窗检验唯一候选，不需要多重比较校正 |
| 单翻转剪枝 | 换成无标签预筛 | 读标签的剪枝不进每折就泄漏（零效应虚报 +0.7～+2.8 点）；无标签版不泄漏、不加参数 |
| 年份取最差、邻域取最差 | 删 | 本质是隐含的门控强度；「邻域取最差」的经典出处是防参数落地偏差（Bertsimas et al. 2010），参数精确落地时用不上 |
| 按股 bootstrap 连挑选重做 | 不再用于报数；乐观度校正保留为前门前沿上的一档 | 训练期内的报数与未来真值相关 ≤ 0.49，报数改由确认窗承担 |
| 对半分验证、三分数并列 | 删 | 同上 |
| 年交互 z、时间窗异质性检验、换池旗标 | 删 | 时段稳定由确认窗 + τ̂² + 最近一段兜底承担 |
| 功效线门槛、30 段下限、30%～70% 保留带 | 并入「最少股票数」一条 + 无标签预筛 | |
| 往前那段 max-T + 往后那段非劣效 + 四格判读表 + 暂定采纳 | 合并成一次优效检验 | 现行判读表里往前那段实际不卡写入，它的功效被浪费 |
| 「预期把握 < 50%」条件停点 | 由第 4 步开窗前门取代 | 同一职能，门的区分力已实测 |
| 「买点少三成就问你」 | 删 | 数量进入效用函数（§3.5） |
| 按股去簇噪声模型、账本、冻结清单、确认窗只开一次、停 1 / 停 3、`depends_on`、一致性验证、optuna 红线 | 保留 | 管的是人为泄漏与工程正确性，估计器替代不了 |

## 3. 各部件的依据

### 3.1 选候选：取最大

候选对比（Q 口径，N1，无确认窗，按真值曲面；± 为蒙特卡洛标准误）：

| 排序统计量 | 单调 | 宽平台 | 窄尖峰 |
|---|---|---|---|
| 朴素取最大 | +3.18 | +3.07 | +1.66 |
| 现行规则（两年较差 → 邻域最小） | +2.52 | +2.97 | +0.90 |
| 收缩排序 ρ·d̄ | +1.23 | +2.37 | +0.51 |
| 尖峰加平板收缩 | +2.31 | +3.27 | +0.76 |
| 理想值 | +3.75 | +3.75 | +3.72 |

接上合并确认门后，收缩排序 − 取最大的配对差：单调 −0.49±0.04、窄尖峰 −0.45±0.03、宽平台 +0.35±0.04；U 口径下 ≤ 0.09。收缩排序系统性偏爱离工作点近、配对误差小的格（选中格离工作点档数中位 4，取最大 6，理想 7），而本问题里真改进往往在远处、伴随买点变少。没有处处不差的赢家，取最简单的。

**经验贝叶斯为什么没成为统一核心**：按后验均值挑选，挑中者期望不虚高（Smith & Winkler 2006 命题 2），这在理论上很漂亮；但它的前提（格多且独立、先验设对）在几十个强相关格上都不满足。正态先验遇到稀疏的真效应会过度收缩（真 +3 点只拿到 +0.45，门控 +1.76），尖峰加平板变体在工作点近最优时又亏得更多（−0.71）。它最适合的位置是开窗前门（§3.2），不是排序，也不是写入门。

### 3.2 值不值得开窗：ρ·d̄ > δ

确认窗一开就算用掉，不管最后写不写。写入门只管「写错」，「白开」只有开窗前的门能管。往前那段不会随时间变长，是不可再生的。

各前门的区分力（真有改进时通过率 ÷ 没有改进时通过率，N1）：按股 bootstrap 校正后 > 0 为 2.5、ρ·d̄ > δ 为 2.1、整年留出交叉验证 > 0 为 1.8、留一格交叉验证 1.4、跨年协方差 > 0 约 1.2（工作点最优时开窗 60%，比纯噪声时的 49% 还高）。

推荐形态端到端（v5，部署年增益 / 开窗率；「现行」为现行 validate，模拟里不含其条件停点）：

| 臂 | 噪声 | 全平 | 小效应 | 大效应 | 工作点即最优 |
|---|---|---|---|---|---|
| 不设前门 | N1 | −0.00 / 100% | +0.14 / 100% | +1.87 / 100% | −0.10 / 100% |
| ρ·d̄ > δ 前门 | N1 | −0.02 / 22% | +0.03 / 28% | +1.41 / 59% | −0.03 / 18% |
| bootstrap 校正前门 | N1 | −0.00 / 81% | +0.13 / 87% | +1.84 / 95% | −0.08 / 62% |
| 现行 | N1 | −0.07 | +0.12 | +1.31 | −0.17 |
| 不设前门 | N2 | +0.03 | +0.07 | +1.41 | −0.15 |
| ρ·d̄ > δ 前门 | N2 | −0.02 / 34% | +0.00 / 36% | +1.06 / 57% | −0.08 / 31% |
| 现行 | N2 | −0.08 | +0.16 | +1.25 | −0.19 |

**端到端看，前门是一条「护窗 ↔ 收益」前沿**（N1；工作点即最优时的开窗率 / 部署年增益，以及大效应时的部署年增益）：

| 前门 | 工作点即最优：开窗率 / 增益 | 大效应增益 | 适用 |
|---|---|---|---|
| ρ·d̄ > δ | 18% / −0.03 | +1.41 | 确认窗极稀缺（bb_v1 默认） |
| 整年留出交叉验证 > 0 | 31% / −0.07 | +1.67 | 居中，或先验认为真改进是孤立单点（单维稀疏 +3 保留 74%，收缩门 48%～56%） |
| bootstrap 校正后 > 0 | 62% / −0.08 | +1.84 | 确认窗不紧缺 |
| 不设 | 100% / −0.10 | +1.87 | 确认窗不紧缺 |

（整年留出一行取自 v4，合并门未含 τ̂²；其余取自 v5。）

读法与取舍：
- **只看训练期区分力，排序正好相反**（bootstrap 2.5 最高、收缩门 2.1、整年留出 1.8），但区分力高不等于护窗强：bootstrap 校正门在嵌套结构里几乎不拦。决定用哪道门，要看端到端的开窗率，不是区分力。
- ρ·d̄ > δ 护窗最强，而且复用第 3 步已有的训练期张量，不加机制；阈值就是 δ，读作「收缩后的期望增益够不够抵换参成本」。
- **代价是真实的**：大效应时少拿约 0.46 点，N2 下大效应甚至比现行少 0.19 点。任何前门都只拿收益换安全，没有统计增益。
- bb_v1 推荐收缩门，理由是它的处境：往前那段不可再生，工作点就是 09-08 在同一段训练数据上挑出来的，先验偏「工作点已接近最优」。往后数据攒够、确认窗不再紧缺时，沿前沿往下选。
- 停 1 只需回答一个业务问题「确认窗有多稀缺」，前门由它决定，不另设规则选项。

### 3.3 写入门：合并优效 + 三处补丁

这是整条流程里对外推影响最大的一处，对现行流程同样适用。

**为什么合并。** 往前那段（SE 约 1.3～1.6 点）比往后那段（约 2.7～3.3 点）精度高得多，合并估计里它的权重约 0.81。现行判读表里「往前主确认不显著 + 往后同号」也会暂定写入，等于往前那段不卡写入。理论推算（extrapolation，τ=0）：改成合并优效后，真实零效应被写入的概率 18% → 5%，真 +2.5 点被写入 51% → 57%～69%，两个方向同时变好。

**补丁一：τ̂² 并进方差。** 只有两段时合并相当于 k=2 的元分析：忽略段间行情差异，误写率膨胀（DerSimonian–Laird 在名义 5% 下可超 30%，IntHout 2014）；承认差异、用稳健区间，又宽到无结论（Friede et al. 2017）。唯一出路是事先给定段间差异的量级，本问题里可以从训练期跨格池化借（格级交互自由度多，估计值与真值效果几乎一样）：

| 年交互 | 真实 0 被写入：不补 → 补 | 真 +2.5 点被写入：不补 → 补 |
|---|---|---|
| 0.9 点 | 7.1% → 5.1% | 56% → 48% |
| 2 点 | 14.0% → 5.2%～6.0% | 55% → 35% |

上表是单个候选的解析结果。**在嵌套网格端到端里（v5）只拉回一大半**：纯噪声写入率 N1 12% → 10%、N2 20% → 12%，没到 5%～6%；N2 工作点即最优时从 −0.27 拉回 −0.15（现行 −0.19）；代价是大效应少约一成。拉不回的原因是全网格池化的 τ̂² 低估了被挑中的远处薄格（单年交互 SD 6～10 点），所以**「按移动了几个参数分组池化」是必需的**（v5 模拟用的是全网格池化，分组版未测）。另一个不可检验的前提：训练期两年之间的差异与相隔三年以上的两段确认窗之间的差异同量级，真实差异只会更大。

**补丁二：幸存者偏差平移（保险）。** pkl 只含现存股票，往前那段缺退市股最多。放松闸会多纳入这类买点却看不到它们的结局，检验偏乐观（单个放松类改动、偏差 +1 点时误写约 21%，平移后回到 5.2%）；收紧闸反而偏保守，不平移。挑选后的实测影响很小：取最大多选紧格；U 口径下虽然偏向松格、写入率上升，但多写入的都落在真更好的格上，误写率有无偏差相同。所以它降级为针对放松类改动的保险，成本为零，保留。

**补丁三：最近一段点估计 ≥ −δ 的弱兜底。** 挡住大幅行情断裂，只少约 10% 收益。**不能写成「非劣效下界通过」**：那样真改进被写入的比例从 39% 掉到 18%，比现行（27%）还低。（这组比例统计的是挑选后的格，多为 SE 大好几倍的远处薄格，绝对水平远低于单个预写改动的解析值 69% / 41%，但相对关系一致。）

**写入门的三种写法对照（v4，N1，真增益 ≥ δ 时被写入比例 / 纯噪声写入率 / 部署年增益 小·大·工作点最优）**：只合并优效 39% / 12% / +0.17·+2.05·−0.11；加点估计兜底 35% / 11% / +0.16·+1.85·−0.09；加非劣效下界 18% / 5% / +0.07·+0.94·−0.04；现行 27% / 13% / +0.12·+1.31·−0.17。

### 3.4 报数：原始合并估计，写不写都记

只在过门时才报的读数系统性偏高（Gelman & Carlin 2014：检验功效 0.80 时夸大 1.12 倍，0.06 时 9.7 倍）。模拟里写入时原始合并估计偏高 N1 +6.8 / N2 +9.6 点。

截断正态条件中位无偏校正（Andrews, Kitagawa & McCloskey 2024 的一维特例）按理可以校正，但**实测不采用**：即使 SE 并入 τ̂²，写入时中位数仍偏高 N1 +1.7 / N2 +4.2，均值在刚过线时发散。原因是 τ̂² 是跨格常数，而取最大偏爱的远处薄格年交互可达 6～10 点，被低估。

所以诚实的做法只有一个：账本每轮记原始合并估计 ± SE，不论写否。它在跨轮次期望意义上不偏；单轮报数误差 RMSE 2.5～12.7 点，单轮本来就说不清，停 3 照实说明即可。

### 3.5 数量项：它就是收缩公式，该问的是仓位

草案的效用 U = (首次穿越率 − 基线) × n/(n+n0) 与老框架 `BreakoutStrategy/mining/threshold_optimizer.py` 的收缩分数减基线恒等，也就是 Bühlmann (1967) 可信度 b = n/(n+k)，k = 组内方差 ÷ 组间真值方差。**一个式子装着两种含义**：统计上 n0 是可从数据估的收缩强度（约几千根买点），业务上 n0 是数量换算（约几十笔 / 年 / 仓位），两者差两个数量级。另外草案把极限写反了：n0→∞ 时是按「超额 × n」排序、偏向松闸，n0→0 才只看质量。

统计收缩那一层已经不需要（挑选校正交给确认窗），U 里只留业务那一层，形状由买点怎么用决定：

| 买点怎么用 | 每年价值正比于 | 停 1 该问的 |
|---|---|---|
| 资金不受限，每个买点等额下注 | 超额 × n | 无 |
| 同时 c 个仓位、平均持有 h、满仓放弃 | 超额 × n × (1 − Erlang 阻塞率)；c=1 时恰为 超额 × n/(n + 1/h) | 同时几个仓位、一笔拿多久 |

限定：
- 买点扎堆到达时（普涨日、板块齐动），实际阻塞比公式高，而松闸多出来的买点往往更扎堆，公式会系统性高估松闸。全网格排序用公式，最终候选与工作点这两个配置按真实买点时间线回放仓位。
- 没碰到目标线的买点（none）不进首次穿越率分母，却占着仓位，按仓位计价时要计入占位。
- δ 仍按点定义，使用处按工作点的数量系数换算，避免 δ 的含义随 n 漂移。
- 模拟里数量项把薄格被选中的概率从 55% 压到 0～3%，但**不增加能拿到的增益**：它解决的是「数量没有归宿」这个需求，不解决「效应小于噪声」。

**实现补丁**：层匹配随机日基线在 `region_core` 格张量上按原文算不出（张量没有波动层轴）。改写成逐买点累加「上穿数 − 每个买点查表得到的基线率之和」（间接标准化），张量多一个浮点通道，与现行口径逐位相等。

草案原文还有五个说法需要撤回：交叉拟合估计 = 选中点的样本外效用；时段块分散度可替代时段检验（两块时标准差区间上下界差 72 倍）；往前那段可并入时段块；U 只借数量换算；确认窗读数就是诚实报数。另外草案所说的「交叉拟合」在文献里叫嵌套交叉验证（Stone 1974；Varma & Simon 2006），双重机器学习的 cross-fitting 是另一回事。

## 5. 外推能力的理论分析（第③问）

### 5.1 「提升」的定义

采纳配置在未来时段上相对工作点的真实增益 G：看期望 E[G]、看下尾 P(G < −δ)，外加报出的数与 G 的偏差。对照两个：维持现值（G ≡ 0，完全诚实，效应小于噪声时很难打败）和现行流程。

### 5.2 未来损失的来源

每格相对工作点的配对差 = 真实效应 μ(θ) + 参数 × 行情交互 a_y(θ) + 个股噪声 e。股票再多也平均不掉 a_y，只有时段多了才平均掉；未来会重新抽一个 a。于是损失分四块：选错点（估计噪声）、报数虚高（挑选偏差）、未来行情不同（分布漂移）、人为环节（停点、复用）。**交叉拟合只动第二块，不改变挑到哪个点**，而第二块在推荐形态里已经由确认窗直接消除。

### 5.3 能证明的

1. **与模型无关的保证**：候选在开窗前冻结，写入只用确认窗，所以 P(写入 | 真增益 ≤ 0) ≤ α。前提是确认窗对未来可交换。它会被三件事打折：年交互（名义 5% 在嵌套网格里实为 N1 12%、N2 20%；τ̂² 补丁拉回到 10% / 12%，分组池化应能再收一截但未测）；往前那段的幸存者偏差（平移补丁作保险）；往前那段权重 0.81，保证主要针对 2022–23 的行情。
2. **挑选能抓到的上限**：可交换高斯候选下，取最大抓到的是「超出候选均值那部分理想增益」的 √ρ。ρ 的天花板随时段数上升、不随买点数上升——**股票再多也突破不了年交互的封顶**。再乘确认窗的通过率。
3. **有界小亏**：工作点即最优时，推荐形态每轮亏 0.03～0.15 点（视前门与行情强度），而任何总会换参的规则亏 1.2～1.9 点。
4. **切换门槛的决策论位置**：损失对称时「估计更好就换」渐近最优（Hirano & Porter 2009）；保守门槛只能来自非对称后悔或切换成本。α 对应前者（Tetenov 2012），δ 对应后者，是两个独立参数，不能合一。

### 5.4 不能证明的

1. **逐场景不亏**：工作点本身最优时，任何换参概率 > 0 的规则期望都 < 0。只有「按先验平均不亏」或「有界小亏」两种弱形状可证。
2. **比现行流程更会挑点**：挑选规则之间只是风险曲线上的不同位置，没有支配关系。
3. **单轮说清有多好**：所有报数与未来真值相关 ≤ 0.49（N1），强行情下 ≤ 0.15。
4. **训练期之后的行情切换**：能处理行情噪声的经典方法都要求足够多的可交换时段块，这里只有 2～3 个；年交互标准差用两个时段估，95% 区间上下界差 72 倍，2～3 点的年交互排除不了。「持续两年、之后不再延续的行情」对任何训练期方法都不可检验，只有另一段行情里的确认窗能检，这也是必须保留往前那段的理由（Sullivan, Timmermann & White 1999：数据窥探校正后样本内最好的交易规则，其后样本外照样失效）。

### 5.5 量级与对比（模拟证据）

推荐形态（不设前门，含 τ̂² 的合并门）相对现行 validate 的部署年增益配对差（± MC SE；全平 / 小 / 大 / 工作点最优）：

| 噪声 | 配对差 |
|---|---|
| N0 | 0 / −0.01±0.01 / +0.74±0.05 / +0.06±0.01 |
| N1 | +0.06±0.06 / +0.02±0.03 / +0.56±0.06 / +0.08±0.03 |
| N2 | +0.11±0.13 / −0.09±0.06 / +0.17±0.08 / +0.05±0.05 |

加 ρ·d̄ > δ 前门后：N1 为 +0.04 / −0.09 / +0.11 / +0.15，N2 为 +0.06 / −0.16 / −0.19 / +0.12——更安全、大效应处收益让出。

**结论**：在「真效应接近或超过分辨力（约 4 点）」时，外推提升在统计意义上实质存在，且来自写入门（用上了往前那段的功效），不来自挑选算法；效应小于噪声时，提升约为 0，价值在于少写噪声：全平曲面上的写入率从现行的 13%～14%，降到不设前门 10%～12%、收缩门 3%～5%。**决定上限的是确认窗的精度**：往后那段攒满一年后 SE 从约 2.7 点降到约 1.5 点，门槛随之放宽——长期看，时间是唯一真正的杠杆。

## 7. 局限

- 全部数字来自合成数据：网格 100 格；模拟曲面里「改进」都伴随买点变少（若真实改进伴随买点增多，收缩排序的近邻偏好可能反而有利）；远处格 6～10 点的年交互没有 bb_v1 实测锚点；没有模拟 40 日标签在块边界的重叠与相邻时段的行情自相关。
- 幸存者偏差量级（π = 0.3）是假设值。
- 「取最大 + ρ·d̄ 前门 + 含 τ̂² 合并门 + 幸存者平移」这一完整默认组合里，幸存者平移在 v5 中只按一刀切近似；U 口径下的完整组合没有端到端单测。
- τ̂² 补丁的前提（训练期年间差异与确认窗段间差异同量级）不可检验；嵌套模拟用的是全网格池化，推荐的「按移动参数个数分组池化」没有端到端单测。
- 数量项的仓位回放、间接标准化浮点通道只做了设计与逐位等价论证，没有实现。

## 8. 建议与待拍板

**建议分两步走。**

1. **先改写入门（小改、收益最大、对现行流程直接适用）**：`validate` 的判读由「往前 max-T + 往后非劣效 + 四格表」改为 §2.1 第 6 步（合并优效 + τ̂² + 幸存者平移 + 最近一段点估计兜底），报数改为原始合并估计写不写都记。这一步不依赖其余重构。
2. **再重写决策层**：`screen.py` 退役为无标签预筛；`region_find.py` 的挑选收成「取最大 + ρ·d̄ 前门」；`validate.py` 按「所有未参与挑选的数据段」泛化；`SKILL.md` / `reference.md` 与 `docs/explain/` 下的说明按五步流程重写。长表扫描、格张量、账本、验证守卫、按股 SE 可复用。
3. 草案 `docs/tmp/2026-09-15-tune-gates-第一性原理重构草案.md` 已被本报告取代。

**需要你拍板的：**

1. **买点怎么用**：资金不受限，还是同时拿几个仓位、一笔平均拿多久？这决定数量项的形状（§3.5）。
2. **α**：能容忍多大概率把一个不比现在好的配置写进正式参数（默认 5%）。δ 维持 2 点，两者是独立参数。
3. **确认窗有多稀缺**：它决定开窗前门取前沿上的哪一点（§3.2）。越稀缺，越省窗、但真有大改进时每轮少拿得越多（最严一档少约 0.5 点）。本报告按 bb_v1 的处境推荐最严一档。
4. **是否先在真实长表上做一次校准**：本地没有 bb_v1 长表，校准需要重扫。校准能给出 τ̂²（分组）、ρ、确认窗实际 SE 的真实值，决定 τ̂² 补丁的代价到底多大。
5. **`repro/results/` 下约 160MB 的 parquet 中间结果**：都能重新生成，是否清理。
