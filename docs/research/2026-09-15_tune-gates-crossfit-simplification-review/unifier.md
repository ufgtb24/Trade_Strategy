## 0. 结论先行

**一句话：草案里「交叉拟合」不再做挑选与报数的核心——训练期只负责选出一个候选（两年合并增益取最大），加一个显式的「维持现行参数」出口和一道「值不值得开窗」的前门（停 1 按确认窗有多稀缺选；bb_v1 默认收缩门）；没碰过的两段确认窗按精度合并做一次优效检验，同时负责「写不写」和「它到底有多好」。这是经典的两阶段「选择—确认」设计，比草案少一层机制；它在外推上与「打补丁的交叉拟合」分不出胜负（red-team、extrapolation、simulator 与本文独立得到），胜在更简单。**

**对照现行流程的实测**（simulator v5 嵌套网格，定稿形态 = 维持臂 + 取最大 + 含年交互方差的两段合并门）：部署年增益（全平 / 小效应 / 大效应 / 工作点最优）在中等行情冲击下为 −0.00 / +0.14 / +1.87 / −0.10，现行 validate 为 −0.07 / +0.12 / +1.31 / −0.17；同批配对差在无、中等行情冲击下四类曲面都 ≥ 0（大效应 +0.56～+0.74），强行情冲击下小效应 −0.09±0.06、工作点最优 +0.05±0.05。

1. **草案的 U 就是老框架的收缩分数，也就是精算里的 Bühlmann 可信度。** `BreakoutStrategy/mining/threshold_optimizer.py` 的 `fast_evaluate` 自己写明是 James-Stein 收缩：w·模板中位数 + (1−w)·基线，w = n/(n+n0)；减去基线 = 超额 × n/(n+n0)，与草案 U 同式。n/(n+n0) 的经典出处是 Bühlmann（1967）可信度 b = n/(n+k)，k = 组内过程方差 ÷ 组间真实均值方差，是不依赖分布的最小二乘线性后验；原文 Remark 2 允许把 E[σ²]/n 换成别的 n 的函数，按股成簇时就是 b = n_eff/(n_eff + k)（literature 读原文；Smith & Winkler 2006 式 (6a) 同形）。所以它天生是统计收缩，n0 可以从数据估，不是业务数；草案把它改读成数量换算，是换了解释没换公式。另外草案 §3 把极限写反了：n0→∞ 时 U 按「超额 × n」排序（只看总量），n0→0 才只看质量。业务上的数量换算另有经典形状（仓位受限时的 Erlang 损失成交率，§2.4）。
2. **经验贝叶斯 / 可信度收缩不当排序、不当写入门、不当报数，只剩「确认窗极稀缺时的开窗前门」一个位置。** 当写入门它安全但保守、稀疏真效应时过度压缩（red-team：真 +3 点只拿 +0.45）；当报数偏高（simulator v3：收缩后 > δ 直接换参时，报数比部署年真值高 1.2～2.8 个 δ，工作点最优时最大）；**当排序也不占优**——simulator v3 嵌套网格同批重复的配对差（收缩排序 − 取最大，都接合并门，中等行情冲击，± 为蒙特卡洛标准误）：单调曲面 −0.49±0.04 点、薄样本角尖峰 −0.45±0.03，宽平台 +0.35±0.04，工作点最优 +0.02；U 口径各曲面差 ≤ 0.05～0.09 点。没有处处不差的赢家，按奥卡姆取更简单的取最大。原因是它系统性偏爱配对标准误小的近邻格（选中格离工作点档数中位 4，取最大 6、神谕 7），错过远处真峰。我在独立格玩具里看到的排序增益，在嵌套结构下不成立。当开窗前门，它最护窗、也最伤收益（端到端数字见第 4 条）。
3. **换参门与诚实报数合成一个检验。** 往前那段（配对 SE 1.3～1.6 点）与往后那段（2.7～3.3 点）按精度合并的单侧优效：extrapolation 算得误写零效应从现行门槛的 18% 降到 5%，真 +3.5 点的写入率从 65% 升到 82%～91%。它的合并估计是「选中的这个 θ̂、跨时段、与模型无关」的样本外估计——草案交叉拟合想报而报不准的那个数。它带三处小补丁（§3）：名义 5% 在年交互 0.9 点时实为约 8%，把训练期跨格池化的年交互方差并进标准误；候选是放松方向时，往前那段先按幸存者偏差上界朝不利方向平移；往后那段只设「点估计 ≥ −δ」的弱兜底。报数有显著性过滤的坑：只报写入的会虚高（我的玩具 +1.3～+4 点；simulator v5 合并 SE 已并入年交互方差时，写入时原始估计仍偏高 +5.1 / +6.8 / +9.6 点，对应无 / 中 / 强行情冲击）。截断校正救不回来：中位仍偏高 +0.7 / +1.7 / +4.2，均值发散到 −9.8 / −6.5 / −5.9。所以主报数是事先承诺的「每轮不论写否都记的原始合并估计 ± SE」，写入时注明「以写入为条件，这个数预期偏高」，截断校正值只作参考列（§2.3）。
4. **开窗前门的职能是省确认窗，不是多赚。** 任何前门在期望增益上都没有增量：玩具里叠加整年留出门只把误写率再减半（全零 5.3% → 2.8%），有真改进时收益砍到四到六成；simulator 端到端里加前门后大效应从 +1.02～+1.32 降到 +0.66～+0.99，工作点即最优时从 −0.07～−0.11 收窄到 −0.00～−0.04。但往前那段对一个 app 实际只能用一次，按「每烧一次确认窗的收益」倍数 q1/(π·q1 + (1−π)·q0)（π = 0.2，q1、q0 为真有 / 没有改进时的通过率）算：收缩前门 1.74、按股 bootstrap 校正前门 1.90、整年留出 1.57，「跨年协方差 > 0」0.76——工作点接近最优时以工作点为中心的二阶矩反而更大，是反向信息。**前门是一条「护窗 ↔ 收益」的前沿，停 1 按确认窗有多稀缺选。** 只看训练期区分力（不接确认窗）的排序是 bootstrap 校正 2.5 > 收缩 2.1 > 整年留出 1.8，但端到端（simulator v5 定稿形态、中等行情冲击，red-team 整理）的护窗能力排序反过来：

   | 前门 | 工作点即最优时开窗率 | 工作点即最优时终值 | 大效应终值 |
   |---|---|---|---|
   | 选中格收缩后增益 ρ·d̄ > δ | 18% | −0.03 | +1.41 |
   | 整年留出 > 0 | 31% | −0.07 | +1.67 |
   | 按股 bootstrap 校正后 > 0（现有 `joint_bootstrap` 的乐观度校正） | 62% | −0.08 | +1.84 |
   | 不设 | 100% | −0.11 | +2.05 |

   四档单调排成一条前沿，互不支配。bb_v1 的往前那段不可再生、先验偏「工作点近最优」，默认收缩门；确认窗不紧缺时用 bootstrap 校正门或不设；整年留出居中，且单维稀疏真 +3 的保留率最高（74%，收缩门 48%～56%），先验认为真改进是稀疏单点时选它。simulator v3 里给「收缩排序 + 合并门」叠整年留出门：全平误写 16% → 6%、工作点最优 −0.08 → −0.04、大效应 +1.74 → +1.53；取最大版叠整年留出门的配对差为单调 −0.20、尖峰 −0.16、平台 −0.27、工作点最优 +0.05——前门只换安全、不增收益，这一点对三个统计量都成立。 嵌套交叉验证作为挑选与报数核心的那一层、平台 / 峰值规则比较、对半分验证、四格判读表、往前那段的 max-T 族退役。
5. **v1 里撤回的四处**：①前推滚动起点作为主方案（末折必须封存才能防住停 1 / 停 2 / 工作点复用这些人为环节的泄漏，封存后就退回现行前向窗）；②让往前那段进训练（它当确认窗卡写入的收益远大于让年份块 2→3 的收益）；③「模型成立时换参期望收益永不为负」的保证（只在先验平均、超参数已知时成立，§4）；④经验贝叶斯 / 可信度收缩作为统一核心与排序统计量（§2.1）。

## 1. 草案本身的漏洞

| # | 漏洞 | 性质 | 补丁 |
|---|---|---|---|
| L1 | **交叉拟合块定义泄漏**：留出（股票折 k，年 y）而训练含同年其他股票，同年共有的行情冲击同时进挑选与打分，对时段噪声而言等于样本内。red-team 玩具：纯噪声、年交互 3.5 点时报 +3.41 点（真值 0），工作点近局部最优时符号都反了。**修法是训练 = 其他时段块、全部股票**（股票自身特质与 θ 的交互是可外推的真信号，不是泄漏；可用长表现成的 `fold_6M` 半年块，两侧各隔一个前瞻期）。v1 写的「其他股票 ∩ 其他年份」撤回。另：red-team 更正，bb_v1 生产参数底座上单翻转配对差的年交互 τ≈0、宽进底座约 0.9 点，强的是超额水平的年份差与多闸联动，所以这条泄漏对单翻转只有零点几点，对多闸联合移动才大。simulator 嵌套实测：草案块结构报数 − 部署年真值，中等冲击 +2.0、强冲击 +4.4 点；整年留出与「其他股票 ∩ 其他年份」都在 −0.1～−0.3（诚实略悲观）；「平台 / 峰值两规则取交叉拟合更高者」再加 +1～+1.9 点 | 结构性 | 一行；v2 里交叉拟合不再做核心，只在可选的整年留出前门里出现，已按整时段留出 |
| L2 | **报的是流程不是 θ̂**：交叉拟合估的是挑选流程的平均样本外表现（Bates, Hastie & Tibshirani 2023），bb_v1 选中稳定性 0.04，各折选出的格基本各不相同 | 结构性 | 补不了；v2 用确认窗估计 θ̂ 本身 |
| L3 | **单翻转剪枝在折外**：特征选择放在交叉验证外面的经典泄漏（Ambroise & McLachlan 2002） | 泄漏 | v2 改为不读标签的预筛（§2.5） |
| L4 | **U 的层匹配随机日基线在张量上算不出**：基线要按每格定向买点的「交易日 × 波动层」构成加权，`region_core` 张量没有层轴 | 实现缺口 | 间接标准化，一个浮点通道（§2.4 末）；red-team 核实逐位精确 |
| L5 | **n0 极限写反；U 与收缩同式** | 概念 | 拆开：U 只留业务层「成交率 × 超额」；统计收缩单列（只作开窗前门，§2.1） |
| L6 | **U 隐含未来随机日边际为零；none 占仓位不进分母**，按首次穿越率超额排序 ≠ 按每个仓位期望盈亏排序（仓位受限时变重要） | 口径 | 明示假设；每笔价值写成 2·定向占比·(首次穿越率 − 基线) |
| L7 | **历史时段已被前几轮挑选用过**：工作点就是 2026-09-08 在 2024–2025 上挑的，训练期内任何「新候选 vs 工作点」比较都偏向工作点 | 数据复用 | 不补；v2 的门槛只用确认窗，不受影响 |
| L8 | **草案没有「维持现行参数」一臂与切换判据**（red-team 第 5 条）。red-team 玩具：没有维持臂时全数据 argmax 在 97%～99.8% 的情况下换到更差的点 | 结构性 | v2 显式维持臂 |

术语备注（literature）：草案所说的「交叉拟合」在文献里叫嵌套交叉验证（Stone 1974；Varma & Simon 2006），双重机器学习里的 cross-fitting 是另一回事。

## 2. 七个方向逐一

### 2.1 贝叶斯决策 / 经验贝叶斯（结论：只作确认窗极稀缺时的开窗前门）

**模型**（全在相对工作点的配对差上）：第 y 个年份块上格 θ 的配对差 d̂_y(θ) = μ(θ) + c_y + ξ_y(θ) + ε_y(θ)。μ 为持续效应；c_y 为所有格共有的一项（主要是工作点自己当年的偏离）；ξ 为年份 × 格交互，下一年重抽；ε 为抽样噪声，方差 s_y²（配对差的按股重抽标准误）。

**超参数跨格池化矩估计**（DerSimonian–Laird 随机效应元分析的做法）：
- σ_μ² = 跨格 Cov_θ(d̂_1, d̂_2)，截到一个极小正数（共有项与年交互跨年独立，不贡献协方差）；
- σ_ξ² = max(0, [Var_θ(d̂_1 − d̂_2) − mean_θ(s_1² + s_2²)] / 2)；
- v(θ) = σ_ξ²/Y + mean_y s_y²(θ)/Y，ρ(θ) = σ_μ² / (σ_μ² + v(θ))。

**排序量** d̃(θ) = ρ(θ)·d̄(θ)，先验中心取工作点。σ_μ² 趋于 0 时 ρ ∝ 1/v，排序退化为按精度加权，不会并列。

**与老框架的精确关系**：去掉年份项、噪声方差写成 σ²·deff/n 时 ρ = n/(n + n0)，n0 = σ²·deff/σ_μ²，d̃ = 观测差 × n/(n+n0)，与「超额 × w」同形，只是收缩中心从全体基线换成工作点。老框架是它的特例：n0 手拍，年份项缺失。加上年份项后 ρ 有天花板 σ_μ²/(σ_μ² + σ_ξ²/Y)——买点再多也不能完全信一个格，因为下一年换行情。

**先验中心为什么是工作点**：若写成 d̃ = m + ρ(d̄ − m)（m 为网格均值），共有项 c_y 全额进 m、权重恒为 1，换不换参跟着工作点当年运气走（自测 1 的 E0）。red-team 玩具独立印证：混合场景中心取工作点 +1.45 点、取网格均值 +0.77 点，因为网格均值被一堆差格拉低。等价的经典写法是逐格水平上的两向随机效应（网状元分析处理「多臂共享对照」的做法），自测里与 ρ·d̄ 结果几乎相同，奥卡姆取后者。

**自测 1**（`repro/unifier_eb_sanity.py`：格间独立、两年、两万格、400 次、δ=2 点、工作点比网格均值持续高 1 点；规则为「收缩值 > δ 才换」，**无确认窗**）：

| 场景 | 收缩 ρ·d̄ | 朴素取最大 | 两年取较差 |
|---|---|---|---|
| 效应 < 噪声（持续 1 点、年交互 2 点、噪声 1～5 点） | +0.01（换参率 11%，换参时报数虚高 +2.1） | +0.09（总换，虚高 +11.7） | +0.09（总换，虚高 +10.0） |
| 持续效应 2 点 | +4.37（虚高 +0.5） | +2.99（+10.4） | +2.80（+8.8） |
| 无持续效应 | 0（从不换） | −1.14 | −1.00 |

矩估计 σ_μ²、σ_ξ² 的估 / 真中位 1.00～1.01。这张表的前提是「正态、稠密」效应，恰是收缩最占便宜的场景。

**red-team 的反例（决定了「只排序、不卡门」）**：16 个独立候选、15 个零 + 1 个真 +3 点时，σ_μ² 被摊薄、ρ 很小，「收缩值 > δ 才换」只拿到 +0.45 点，argmax 是 +2.16、整块留出门控是 +1.76。这是线性（James–Stein 型）收缩在稀疏效应下的已知短板；经典修法是尖峰—平板或非参数经验贝叶斯（Johnstone & Silverman 2004；Jiang & Zhang 2009；Koenker & Mizera 2014），但那就不再是一个公式。v2 的最终取舍：收缩值不当写入门、不当排序，只作开窗前门；写不写交给确认窗。（独立格的自测 2 里「收缩排序 + 合并门」在稀疏场景不再过度压缩，但嵌套网格里收缩排序输给取最大，见下。）另一条相关网格上的证据（simulator，12 维相加网格 4095 格）：跨格协方差被移动参数多的大子集主导，σ_μ² 偏大、ρ 偏向 1，初版收缩规则换参时报数虚高 +3.4～+4.8 点——所以收缩值既不能当门、也不能当报数；只作排序时，ρ 整体偏大的后果是排序退化向 argmax，是温和的失效方向。

**simulator 嵌套实测**（`repro/results/report_v2T2.md`：100 格，where 阈值嵌套 + 检测轴相邻共享买点，按股成簇，两年训练，中等行情冲击，目标首次穿越率；表内为不接确认窗时的平稳增益，点）：

| 神谕 | +1.50 | +5.99 | 0 |

接上往后窗后，收缩类规则小效应 +0.02～+0.05、大效应 +0.88～+0.99、工作点即最优 −0.00～−0.01；朴素取最大 +0.10 / +1.12 / −0.11；一倍标准误 +0.05 / +1.32 / −0.05——差距都在零点几点。把往前那段当第三个训练年（`report_v2T3.md`）时收缩类大效应升到 +1.00～+1.08，改善很小。

读法：①收缩值卡门 ≈ 现行规则 > δ 才换：安全、保守，不占优。②只拿收缩后验排序在嵌套网格里**不如**取最大（小效应 −0.11 对 +0.83），与独立格玩具里的增益相反——嵌套格与工作点共享买点，逐格水平的收缩没有用上配对结构；配对版只排序的规则未单测。③simulator 的经验贝叶斯类报数与部署年真值的相关是训练期内所有报数里最高的（无行情冲击 0.80、中等 0.43），但偏高 +1.2～+3.0 点——能排不能报。**判定（simulator v3、v5 后更新）：经验贝叶斯不当排序、不当写入门、不当报数；只作开窗前门，护窗最强、收益代价最大（§0 第 4 条的前沿表），确认窗极稀缺时默认用它。配对版（中心 = 工作点）排序在 v3 嵌套网格里也输给取最大（§0 第 2 条），且系统性选配对标准误小的近邻格——本节原先担心的近邻偏好已坐实。** 薄壳问题（red-team）：同质先验放在配对差上时，全零场景选中薄壳（买点变动 5%）的概率 22%（取最大 3%），白烧确认窗。两个现成手段都能挡：先验改放在「每单位买点变动的质量」d/f 上（降到 0%，不加参数）；或把 §2.5 的无标签预筛扩到 where 档，买点变动 f < δ 的格不进候选——它们连理论上限都过不了 δ 的前门。有真效应时三种排序谁都不支配。另据 extrapolation，U 口径本身已把选中薄样本格的概率从 55% 压到 0～3%，U 目标下可信度排序相对取最大的增益会更小。

**现有机制的归宿**：

| 现有机制 | v2 里的归宿 | 残余 |
|---|---|---|
| 年份取最差 | 默认改为风险中性：年交互方差池化后并进确认窗合并 SE。取最差本身是「对观测到的几个行情取最坏」的分布稳健优化（extrapolation 的定性），是一种风险态度而非估计手段。按全队定稿（`final_report.md` §6）不再保留为停 1 选项：多一个规则选项，而时段稳定已由确认窗、年交互方差与最近一段兜底承担 | 两年里每格只有 1 个自由度，逐格的「行情敏感度」估不出；bb_v1 单翻转层面年交互 τ≈0，影响小 |
| 邻域取最差（平台 / 峰值） | **删除，不是吸收**。它的经典归宿是面向实施误差的邻域最坏情形稳健优化（Bertsimas, Nohadani & Teo 2010，literature 核实），参数精确落地时不需要；它顺带做的「抑制孤立尖峰」由确认窗门接手（孤立尖峰在确认窗里过不了门） | red-team 指出后验不做邻域平滑；带噪声时推荐后验均值最大点是贝叶斯优化的标准做法（Frazier 2018） |
| 功效线 / 可评估门槛 | 由确认窗门接手：样本少 → 合并 SE 大 → 过不了门；另留一条「每格每块至少若干只股票有定向买点」的计算性下限，保证按股标准误可信 | 下限取经典簇稳健误差的簇数下限（约 30～50） |
| 单翻转剪枝 | 统计职能由确认窗门接手；算力职能换成不读标签的预筛（§2.5） | Sclove, Morris & Radhakrishnan（1972）的占优只在平方损失下，对「取最大 + 切换」只作动机 |
| 挑选偏差校正 | 交给确认窗：只检一个冻结的候选，检验水平不需为挑选校正，报数用确认窗估计（§2.3） | 贝叶斯挑选不变性（Dawid 1994）只在先验对时成立，所以不靠它报数 |
| 删闸非劣效 / 收紧优效的不对称 | U 含数量后，放松闸已按数量拿到应得的分，统一用 ΔU 做一次优效检验 | 若用户额外偏好「机制少」，可给删闸降门槛；默认不加 |

**不建议空间平滑**（高斯过程 / 格点马尔可夫随机场）：沿 where 轴的近邻只差一层薄壳，买点几乎相同，平滑是在反复平均同一批数据；要做对还得带上格间噪声协方差，实现复杂度陡增。simulator 的嵌套实测印证：核平滑先验（线性趋势核 + 指数核、按股全协方差、边际似然定超参）小效应时平稳增益 +0.20 点，不如朴素取最大的 +0.37；宽平台大效应时 +3.1 对 +5.1——平滑先验本身没带来增益。

### 2.2 一倍标准误规则

在最优值一倍标准误以内选最简单的（Breiman 等 1984；ESL §7.10）。

- 支持：一个规则就表达了「偏好维持现值」。
- 反驳：①替代不了 δ（δ 是业务量，一倍标准误是噪声量）；②「一倍」无依据，它是「以工作点为中心的尖峰—平板先验 + 换参成本」的频率派近似；③经典写法用水平值的标准误，应当用差值的标准误，且最优点本身被挑选抬高，这把尺子系统性偏松；④Chen & Yang（2021）实测规则里的标准误估计偏差可达 ±50%～100%，以预测为目标时通常不如直接取交叉验证最小值。
- 它和平台规则的正式版是「与最优统计上分不开的集合」（Lei 2020 的 CVC；Hansen, Lunde & Nason 2011 的模型置信集；Hsu 的 MCB），再在集合里按简约挑。
- 决策论上（Hirano & Porter 2009）：对称损失下「估计哪边好就选哪边」渐近最优，保守门槛必须由非对称损失或切换成本推出，不能靠「一倍」拍。

**判定**：不采用。v2 的保守性来自维持臂 + 确认窗优效门（α 有后悔解释，Tetenov 2012），不来自训练期内的集合规则。

### 2.3 诚实报数：哪个工具对

诚实报数分两问：「这一个 θ̂ 有多好」（条件）与「这套流程报的数准不准」（校准）。

| 工具 | 对本问题 |
|---|---|
| Efron 乐观度 / 协方差惩罚（2004） | 目标是固定设计下的样本内误差，不是换一年后的表现；其按股 bootstrap 版对「取最大值」这种只方向可微的泛函不一致（Andrews 2000；Fang & Santos 2019），现行代码已承认只是下界 |
| SURE | argmax 不连续，不能直接用于挑选；可用来定收缩超参数（Xie, Kou & Brown 2012） |
| Tibshirani & Tibshirani（2009）、BBC-CV（Tsamardinos 等 2018） | 修的是「用交叉验证最小值挑超参数」的偏差；v2 训练期内没有交叉验证，用不上 |
| 嵌套交叉验证 | 草案本质就是它；v2 删掉 |
| Andrews, Kitagawa & McCloskey「Inference on Winners」（2024） | 全数据选出的赢家的条件置信区间，目标对得上，但只含抽样噪声、不含年交互；其一维特例（写入条件下的截断校正）在自测里不稳，不采用 |
| **合并确认窗估计** | **推荐**。θ̂ 本身、跨时段、与模型无关 |

**确认窗检验要不要为挑选校正**（literature）：两阶段「选择—确认」设计里，若只用第二阶段的独立数据检验被选中的那一个，挑选只是第一阶段数据的函数，检验水平不需要校正；需要校正的是把两阶段数据合并推断（Sampson & Sill 2005；合并时的条件无偏估计见 Cohen & Sackrowitz 1989、Bowden & Glimm 2008）。v2 的写入门只用确认窗、只检一个候选，所以不做挑选校正；前提是训练期与确认窗之间清除一个前瞻期的标签重叠，且报数不论过没过门都记。

**训练期内的报数为什么不行**（simulator 嵌套框架，目标首次穿越率，相对部署年真值）：现行规则自身的邻域分偏差 N0 −0.4 / N1 +0.0 / N2 +0.8 点，看似诚实，但那是「两年取较差 + 邻域最小」的向下偏差恰好抵掉赢家诅咒，没有原理保证；现行按股 bootstrap 校正后反而偏悲观 1～3 点（「下界」的说法在仿真里不成立）；对半分偏悲观 5.6～7.6 点；草案交叉拟合（原块结构 + 两规则取高）偏乐观 +1.8～+6.3 点。**所有训练期内报数与部署年真值的相关，中等行情冲击下 ≤ 0.34、强冲击下 ≤ 0.15**——真实增益只有 0～3 点时，训练期内说不出「这一轮挑出的点到底有多好」，只能靠确认窗。

**显著性过滤的坑**（自测 2 发现）：合并确认窗估计不论写否都无偏（偏差 −0.04～+0.03 点），但只看写入的那些时虚高 +1.3～+4 点——写入条件本身挑的就是「估计偏高」的那些（Gelman & Carlin 2014 所说的量级错误）。两种经典修法：①事先承诺不论写否都报原始估计与标准误；②写入时报截断正态下的条件中位无偏估计（解 P(X ≤ 估计 | X > z·SE; μ) = 0.5，是 AKM 混合估计的一维特例）。**两者的取舍**（extrapolation、red-team 主张写入时主报②）：用户是在「已经写入」的条件下读数、据此行动的，①只保证跨很多轮平均不虚高，帮不了这一次判断，这个理由成立，但②在实测里做不到（见下）。所以最终取①为主报数——账本每轮（含没写入的）记、停 3 也报——写入时附「以写入为条件，这个数预期偏高」的说明，②只作参考列。自测里②的误差中位数 −0.2～+1.9 点，刚过线时点估计趋于负无穷（均值误差 −3～−156 点）——所以②必须带条件区间一起报，贴近门槛时区间极宽是诚实的表现（AKM）。②只校正确认窗抽样噪声，不含年交互。simulator v3 嵌套实测：写入时原始合并估计偏高 +3.1～+8.6 点；截断校正后无行情冲击时过度（−0.7～−0.8），中、强行情冲击时仍偏高（+1.2～+5.0）。simulator v5 再把年交互方差并进 SE：写入时原始估计偏高 +5.1 / +6.8 / +9.6 点，截断校正后中位仍偏高 +0.7 / +1.7 / +4.2、均值发散到 −9.8 / −6.5 / −5.9——②救不回来。

### 2.4 U 的形状

统计收缩那层已从 U 里拿出（§2.1），U 里只留业务那层，由买点怎么用决定：

| 买点怎么用 | 经典模型 | 每年价值正比于 | 该问用户的量 |
|---|---|---|---|
| 资金不受限，每个买点等额独立下注 | 期望收益线性加总 | e·n | 无 |
| 仓位有限，先到先得，满仓放弃 | Erlang 损失系统（c 个仓位、平均持有 h、到达率 n） | e·n·(1 − B(c, n·h))；**c = 1 时恰为 e·(1/h)·n/(n + 1/h)** | 同时几个仓位、一笔拿多久 |
| 同一笔资金反复周转，看风险调整收益 | 主动管理基本定律（Grinold 1989） | (e/σ)·√(独立买点数) | 无，「独立」按时间去簇 |
| 可加杠杆，看长期增长率 | Kelly | (e/σ)²·独立买点数 | 无 |

（e = 每笔期望盈亏，以止盈止损宽度 k·ATR 为单位；B(c, a) 为 Erlang B 公式。）

- 草案的 n/(n+n0) 按业务读恰是单仓位 Erlang 成交率，n0 = 1/h；同一个式子按统计读是可信度。**一个式子装两种含义，是老框架显得简约、草案又说不清的根源**；两种 n0 的量级也差两个数量级（业务约几十笔 / 年 / 仓位，统计约几千根买点）。
- 草案待拍板第 2 条「按年还是按月」自然消失：真正无量纲的是负载 n·h。
- **成簇到达**（red-team）：买点扎堆在普涨日、板块齐动时，实际阻塞比 Erlang B 高，而松闸多出来的买点往往更扎堆，于是公式系统性高估松闸。峰度法（Hayward 近似 B(c/z, a/z)）只在仓位数不太少、峰度不大时准（literature 读 Li & Whitt 的精度表：峰度 2～3.4 时所需仓位数误差达 2～3 个以上），单仓位远在验证范围外；单仓位应直接用 GI/M/1/1 精确式（拒绝概率 = E[e^{−μA}]，泊松到达时接纳率恰为 n·n0/(n+n0)）。精确做法仍是按真实买点时间线回放 c 个仓位、先到先得，但回放不能后缀累加、会打破张量捷径。取舍：全网格排序用近似，最终候选与工作点用回放。
- **每笔价值口径（L6）**：以 k·ATR 为单位，每笔期望盈亏 ≈ 定向占比 × (上穿概率 − 下穿概率)，相对随机日基线的超额 ≈ 2·定向占比·(首次穿越率 − 基线)。用超额隐含「未来随机日边际为零」，要写明。

**L4 的补丁——间接标准化**：层匹配基线 = Σ_层 w_层·b_层，w_层为本格定向买点落在该层的占比。改写成逐买点累加：首次穿越率 − b(θ) = (Σ 上穿 − Σ_定向买点 b_{层(买点)}) / Σ 定向。第二项是每个买点先查表得到的基线率之和，即流行病学里「观测数 − 期望数」的间接标准化。它与四态通道同构（逐买点加性，同样走包含—排斥去重与后缀累加），张量只多一个浮点通道，与 `edge_core.edge_delta` 的层加权基线逐位相等。唯一改动：`region_core.tensor` 现在对质量做 `np.rint`，浮点通道要绕开取整。

### 2.5 单翻转剪枝：三种理由分开讲

- **统计理由**：剪枝是「先检验、不过就置零、再挑」的预检验做法；本问题实测挑选噪声放大 0.9～1.7、与格数几乎无关，缩小搜索空间省不下多少挑选偏差。统计上不需要。
- **泄漏理由**：只要剪枝读了标签，就必须进每一次挑选（L3）。
- **算力理由**：识别是分钟级，瓶颈在扫描；where 维与过滤型参数事后切几乎免费，**只有检测参数维（每加一维扫描 ×4）有算力理由**。

**收敛**：换成**不读标签的预筛**。检测参数档位上它省扫描；where 档上它不省算力，但把买点变动 f < δ 的格排除出候选，顺带挡住薄壳候选白烧确认窗（§2.1）。用延迟标签模式的无标签扫描（现有 `label_mode="deferred"`）数出每档与工作点的买点对称差占比 f。首次穿越率的变化有精确上界：去掉占比 f 的买点时 |Δ首次穿越率| = f·|留下的 − 去掉的| ≤ f。**f < δ 的档连理论上限都达不到 δ，不扫**。它不读标签、不增参数；上沿（收得太紧、买点太少）由簇数下限与确认窗门处理。

### 2.6 交叉拟合与确认窗合一：前推滚动起点（撤回为非主方案）

**做法**（Dawid 1984 的 prequential 原则；Tashman 2000 的滚动起点评估）：每个时间起点只用之前的数据跑完挑选流程，冻结，在之后那段打分，每段未来数据只打一次分。用现有数据（全部 8325 个 pkl 起于 2021-08-20、止于 2026-08-14～17，只含现存股票；首部缓冲 250 后买点最早约 2022-08）可以排成：{往前段, 2024} 挑 → 2025 打分；{往前段, 2024, 2025} 挑 → 往后段打分。

**撤回理由**：
1. **末折必须封存**（red-team）：跑完一圈就没有没被看过的数据了，停 1 定义、停 2 剔除、上一轮挑选都在机制之外；封存末折之后就退回现行前向窗。
2. **往前那段当门比当训练值钱**（extrapolation 的数字，δ=2 点）：现行写入门槛（往后非劣效 + 同号）误写零效应 18%、真 +2.5 点写入 51%、+3.5 点 65%；改用往前段优效为 5% / 47%～61% / 71%～85%；两段按精度合并优效为 5% / 57%～69% / 82%～91%，两个轴同时占优。让往前段进训练只把年份块从 2 提到 3。附带发现：现行 `validate.interpret` 里「往前窗主确认不显著 + 往后过且同号 → 暂定采纳（写入）」意味着往前窗目前根本不卡写入，它的功效被浪费了。
3. **幸存者偏差是梯度**：pkl 只含现存股票，往前段缺退市股最多，但 2024–2025 同样缺之后退市的股票，不是往前段独有。
4. 不需要股票折这一点仍成立：训练与测试时段不相交时，股票自身特质与 θ 的交互是可外推的信号。

保留为变体：若 `validate.survivorship_bias` 实测往前段的偏差很小，且数据积累到能多封存一段，可以重新考虑。

### 2.7 检测参数（非嵌套）与 where 闸（嵌套）能否统一

- **统计层：本来就统一。** 选候选与收缩前门只需要每格每块的配对差与按股标准误，按股重抽的加权 bincount 对两类轴一视同仁；U 含数量后，删闸与改检测参数都在比 ΔU，不再有优效 / 非劣效两套检验。
- **算力层：不同，也不必统一。** where 维后缀累加一次算出所有档；检测参数每档一次检测。
- **预筛层：一个公式覆盖两类。** §2.5 的上界用「与工作点的买点对称差占比」表述：嵌套时对称差 = 被闸去掉的部分；非嵌套时上界 ≈ 两边独有占比之和。
- **残余差别在机制层**：检测参数会改变买点落在哪根 K 线上（「买得低」「买点窗口变了白拿」这类算术效应），靠停 2 的机制否决与报告里的算术效应归因，统计估计管不了。

## 3. 收敛：v2 推荐形态

**两阶段「选择—确认」：训练期只排序出一个候选，没碰过的数据下结论。**

## 4. 外推理论：能不能在统计意义上提升外推

（与 extrapolation 分工：本节只写统一方案直接推出的结论；可靠度判据的完整推导与核实以 extrapolation 的文档为准。）

**(a) 与模型无关的那部分保证。** 写入门只用确认窗数据、候选在开窗前冻结，所以 P(写入 | θ̂ 的真增益 ≤ 0) ≤ α——**前提是两段确认窗对未来可交换**。自测 2 全零场景误写 5.2%～5.3%，与 α 吻合。这个保证打折的地方（extrapolation 实测）：按精度合并时往前段权重约 0.81，保证的对象主要是「2022–23 行情、幸存股票」上的增益；不把年交互方差并进标准误时，年交互 0.9 点下实际误写约 8.3%、2 点下约 17%；往前段幸存者偏差 +1 点时约 21%（放松方向）、−1 点时约 2.4%（收紧方向）。§3 第 5 步的补丁针对的就是这两项。「持续两年、之后不再延续的行情」对任何训练期方法都不可检验（red-team），只有另一段行情里的确认窗能检，这也是保留两段确认窗的理由。这是 v2 里唯一不依赖先验的外推保证，也是它把门槛放在确认窗上的理由。

**(b) 期望增益由三个因子相乘**：选出的候选真有改进的概率 × 确认窗抓到它的功效 × 改进大小。
- 第一个因子是训练期能做的全部。独立格玩具里可信度排序在「真改进与精度同向」时提高它、反向时降低（Smith & Winkler 的代价面）；simulator v3 嵌套网格里（改进伴随买点变少）可信度排序输给取最大，端到端大效应差 0.3 点，无门时按曲面差 0.7～1.9 点。按 Gu & Koenker（2023），线性效用下按后验均值排序是贝叶斯规则；若目标是「选中的确是真最优」，精度不等时应改按后验尾概率——调参目标属前者。
- 第二个因子受确认窗标准误卡死（合并 SE 1.2～1.4 点、往后段单独 2.7～3.3 点），是所有方案共同的瓶颈（red-team、extrapolation、本文三方独立得到）。
- 所以对「效应 < 噪声」的 pattern（bb_v1 分辨力 3.5～4.8 点、δ = 2 点），任何方法的外推提升都很小；v2 的价值主要在**不把噪声写进正式参数**，而不是多挖出改进。

simulator 嵌套实测同向：加确认窗验证门后，小效应各流程只剩 +0.03～+0.12 点、大效应 +0.9～+1.6 点，流程间差距被压到零点几点；目标换成 U 后，小效应场景里没有任何「总会换参」的流程稳定胜过维持现值。extrapolation 据此判定：打补丁的交叉拟合与收缩方向**在「能否提升外推」这一问上没有胜负**，决定外推效果的是维持臂、写入用什么证据、时间；核心选哪个应按简化与实现稳健性定。v2 正是按这条取舍：保留所有方案都必须有的三样，删掉在外推上分不出胜负、却多一层机制的训练期交叉拟合。训练期内校正得再干净也挡不住行情切换，直接证据是：数据窥探校正后样本内显著的最好交易规则，其后样本外失效（Sullivan, Timmermann & White 1999）。

**对照现行流程（第三问的直接答案）**：simulator v5 的定稿形态（维持臂 + 取最大 + 含年交互方差的两段合并门）与现行 validate 同批配对，无、中等行情冲击下四类曲面都不差于现行（大效应多 +0.56～+0.74 点），强行情冲击下小效应略差（−0.09±0.06）、工作点最优略好（+0.05±0.05）。所以在「未来年与训练期、确认窗在年份 × 参数交互上可交换」的模型里，它在统计意义上提升外推——增量主要来自有真效应时写入把握更高，而不是挑得更准；行情冲击越强，优势越小。

**(c) 模型那部分能说什么、不能说什么。**
- 可交换独立高斯候选下，按均值取最大所抓到的「超出网格均值那部分神谕增益」恰为 √ρ（extrapolation 推导并以 20 万次模拟核实；E[max] 在格数少时应取 J_eff 个标准正态最大值的期望，不用 √(2 ln J)）。ρ 的天花板 σ_μ²/(σ_μ² + σ_ξ²/Y) 不随买点数上升，只随年份块数上升。
- σ_μ² 能从跨年协方差估；**但决定「调参值不值得」的另一半——训练期共有的年份偏移——在 Y = 2 时与持续均值不可分**（extrapolation），只能靠确认窗与时间。所以统一判据是：「调参值不值得跑 = ρ 够不够大（训练期可估）+ 共同年份偏移不致命（训练期不可估）」。它是理论判据，不能当开窗门：跨年协方差不分正负号，工作点接近最优时反而放行更多（§0 第 4 条）。
- v1 写的「模型成立时换参期望收益永不为负」收窄为：**只在先验平均意义下、超参数已知时成立**。逐场景做不到（工作点本身最优时，任何换参概率 > 0 的规则期望都 < 0）；超参数是插值的，经验贝叶斯插值低估不确定性是经典结论（Morris 1983；Kass & Steffey 1989）。
- v1 写的「报数校准性明确改善」收窄为：预测方差在期望意义上包含了年份项，但年份整体偏移那项只有 1～2 个自由度，覆盖率没有保证。v2 因此不把预测区间当门，只作校准旗标。

**(d) 对 bb_v1 的预判**：跨年协方差大概率很小、年份整体偏移大（2025 全网格中位差 −4.8 点）。v2 预计选出一个候选、确认窗大概率不过门、维持现值——这是它**正确地拒绝统计上兑现不了的改动**，对照是 2026-09-08 在样本内 +2.3 / +3.9 点（分辨力以内）就写进了正式参数。
