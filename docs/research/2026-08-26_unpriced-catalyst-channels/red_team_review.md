## 1. 命题是否 well-defined（任务 1）

### 1.1 先拆开两个被混在一起的 claim

用户原话「path2 出信号时，该股存在尚未在价格上被兑现的利好」实际包含两个独立命题：

- **P1（描述性）**：path2 信号点上，某外部利好量 X 的水平高于同类基线。
- **P2（增量性）**：X 在 path2 信号点上携带对未来收益的**增量**信息，超出价格形态已提供的部分。

**P1 可检验但无用**。上一轮就死在这个混淆上：`G_pos` 占 54.5%，「bb 票的新闻普遍偏正面」这个 P1 完全成立，但 P2 完全不成立（fr/FPR 无差、方向还反）。
**任何支流的初稿如果只论证 P1，等于没论证。** 所有判据必须写在 P2 上。

### 1.2 「未兑现」的三种定义，两死一活

| 定义 | 形式 | 裁定 |
|---|---|---|
| **A · 事后式** | 未兑现 = 后来确实涨了 | **伪命题**。把结论塞进定义。隐蔽变体同样致命：用 forward return 参与分组、用「后来暴涨的样本」回溯挑指标或阈值 |
| **B · 落差式** | 未兑现 = 利好强度 S 与已实现涨幅 R 的残差，residual = S − f(R) | 可检验但代价高。f 必须从横截面回归估（否则 S 与 R 单位不可通约）。非循环（只用 t 之前信息），但残差本质 = 「短期反转因子 + 基本面因子」的线性组合，解释性差、工程量大 |
| **C · 事件-反应式** | 未兑现 = **离散利好事件**发生后的**短窗价格反应缺失**（surprise > 0 ∧ CAR[0,+2] ≈ 0 或 < 0），评估窗与事件窗分离 | ✅ **采纳**。非循环、可操作、与用户原话逐字对应（「营收大幅增长，如果股票没有涨」）、有文献对应物（PEAD 的营收分支） |

**裁定 R1-a**：本轮统一采用定义 C。任何支流若无法为自己构造出「事件锚 + 反应窗 + 分离的评估窗」这三件套，须显式说明改用定义 B 并承担其代价，不得滑回定义 A。

### 1.3 被隐藏的接缝：path2 信号点没有事件锚

定义 C 依赖一个**事件时刻**。但 path2 的 bb 买点是价格几何定义的，**与财报日无任何绑定**。从「财报后没涨」到「path2 出信号时未兑现」之间存在一个未验证的时间对齐假设：

> bb 买点必须落在利好事件之后的漂移窗内，命题才接得上。

PEAD 的漂移窗通常是事件后 **60 个交易日**，且强度随时间单调衰减。如果 bb 买点距最近财报的中位数是 40~60+ 个交易日，漂移已过大半，机制上就接不上——**这时候不论营收信号本身多真，在 bb 点上都拿不到剩余**。

**这是本轮成本最低、杀伤力最大的探针**（P0-a）。**我已经跑完了 —— 结果是绿灯，接缝闭合。**

#### 1.3b ✅ P0-a 实测结果（`repro/p0a_filing_distance.py` / `p0a_filing_distance.json`）

对 112 行逐行查 EDGAR submissions，取 `filed ≤ buy_date` 的最近一次定期报告，用 pkl 索引算**交易日**距离：

| 口径 | 结果 |
|---|---|
| 成功 | **106 / 112**（6 行无定期报告：AURFF / CBDL / HAMRF / NPRFF / RSMXF / TBLLF，全是外国 OTC 代码） |
| 距离中位数（全体） | **30 交易日**（mean 58.9，q25 13 / q75 45 / q90 116 / max 1043） |
| ≤20 / ≤40 / ≤60 交易日占比 | 34.9% / **72.6%** / **83.0%** |
| 表单构成 | 10-Q **89** · 20-F 13 · 10-K 4 |

**去掉一个申报节奏 artifact 后，结论更干净**：`>60` 那一档里 **12/18 是 20-F**（外国私人发行人，**只报年报**，距离中位数 123 交易日）——这是申报节奏，不是信号。

> **只看 89 个正常季报（10-Q）申报人**：距离中位数 **28 交易日**，**93.3% 落在 60 交易日内**，80.9% 落在 40 交易日内。
> 剩下 6 个 `>60` 的 10-Q 申报人距上次季报 **132 交易日（≈6 个月）** ⟹ 这不是「离财报远」，是**申报逾期**，本身就是一个红旗。

**⟹ 判定：绿灯，红灯判据（中位数 >60 交易日）远未触发。**
bb 买点在时间上**确实落在 PEAD 漂移窗内**，§1.3 指出的接缝是闭合的。**这实质性地加强了支流 ①**——机制上接得上，不是硬凑。

**顺带的探索性观察（n 小，勿过度解读）**：89 个 10-Q 申报人按距离分档的 fr median 是
`≤20 td: 0.453 (n=32)` / `21-60: 0.381 (n=51)` / `>60: 0.167 (n=6)`。
方向与 PEAD 一致（离财报越近越好），但最远档 n=6、且与「申报逾期」完全混同 ⟹ **不构成证据**，只作为 FinChannel 预注册时的假设来源。

### 1.4 情绪热度的定义困境（单列，因为它没有 C 可用）

热度没有「一致预期」，因而没有 surprise 的自然定义；也没有离散事件锚。可用的只有 abnormal attention（相对自身 baseline 的 z-score，Da/Engelberg/Gao 的 SVI 做法）。

问题在于：**热度与价格是同期强相关的**——热度高就是因为涨了。于是「热度高但没涨」这个格子在数据上极其罕见，落进去的多半是数据错误或未遂的 pump。也就是说，直接照搬定义 C 的框架到情绪上，**目标格子会因为过于稀疏而失去功效**。

情绪支流唯一站得住的「未兑现」读法是**反过来的**，见 §2.3。

## 2. 三支流的选择效应机制判（任务 2）

### 2.0 先把机制说清楚：bb 是一个 collider

上一轮报告把「方向反」归因为「逆势更强选择效应」。用因果图的语言说得更准，且能给出可证伪的预测：

```
    X（外部利好：营收 / 新闻 / 稀释 / 热度）
                 ↘
                  bb 形态成立   ←   U（其他驱动：资金、题材、坐庄、板块 beta）
                 ↗
```

`bb` 同时被 X 和 U 影响 ⟹ bb 是 **collider**。conditioning on bb 会在 X 与 U 之间**人为诱导出负相关**：在 bb 样本内，X 高的票 U 低、X 低的票 U 高。而 fr 由 X + U 共同驱动 ⟹ X 对 fr 的组内效应被系统性抵消，**effect size 衰减、极端时符号反转**。

这比「逆势更强」的叙事强在：它是**确定性的、可预测方向的**，且给出一条可证伪的推论——

> **推论**：任何「是 bb 形成原因之一」的 X，在 bb 样本内测都会出现效应衰减；X 与 bb 的耦合越强，衰减/反转越彻底。

上一轮两条通道（新闻极性、8-K 3.02）**都出现了方向反**，不是两次巧合，是同一个机制的两次实现。这也解释了为什么 8-K 3.02 会变成「公司活跃度标记」——活跃度正是 U 的一个分量。

**推论的实用价值**：X 与 bb 的耦合强度是**可以在跑主试验之前先测的**（全宇宙里算 X 与 P(bb) 的关联）。耦合强 ⟹ 别在 bb 内测。这把一个定性担忧变成了定量前置闸。

### 2.1 ① 营收增长

**耦合路径**：营收好 → 股价涨 → 触发 bo/burst。所以存在耦合，collider bias 存在。

**但强度弱于上一轮的两条通道，理由具体**：

1. **时间尺度错开**。新闻极性的窗口是 buy_date 前 7 天，与 bo/burst 几乎是同一事件的两个投影（耦合近乎 1）；营收是季度量，与 bb 的时间关系松散。
2. **bb 的下游段不吸收营收信息**。bb = bo + burst + throwback 企稳。企稳段（tb）是纯价格几何的，营收信息不通过它。所以吸收是 **partial** 的，不是 total。
3. **有独立于价格的外部标尺**。会计口径不依赖价格生成，而新闻覆盖量/8-K 频率本身就是「活跃度」（≈ U）的直接投影——这才是上一轮真正的结构性缺陷。

**裁定**：营收支流的选择效应风险是**中等且可控**，但**可控性来自设计而非来自量本身**。放在 bb 内测，它照样会被吃掉；放在全宇宙事件锚上测，根本没有 collider。

**最可能逃过的一支 = ①**，理由汇总：(a) 独立外部标尺；(b) 天然事件锚（XBRL 自带 filing date）支持非循环的定义 C；(c) point-in-time 干净、零成本、可全宇宙铺开 ⟹ **唯一能突破 §3 功效天花板的一支**；(d) 有文献先验（Jegadeesh & Livnat 的营收惊喜通道）。

### 2.2 ② 其他财务量

**先回应用户的明确倾向（锚点纪律第 1 条）：用户怀疑净利润不适用——这个怀疑成立，且理由比用户说的更强。**

用户的理由是「高成长股净利润是负的」。负值本身不是障碍（可以用符号、用变化量而非变化率）。真正的障碍是：

> **净利润同比增长率在 0 附近发散**。−0.1 → +0.1 该记 +200% 还是 −200%？分母过零导致比率无定义、排序被噪声完全主导。对微盘/生科票（本样本里 HOWL、CALC 这类），净利润在 0 附近震荡是常态。

这是技术性的、无争议的排除理由。**净利润增长率应排除**；若要用盈利维度，只能用「水平的符号变化」（亏转盈）这种离散标记，或用 scaled 量（净利润/营收）。

**② 的致命问题不是选择效应，是多重检验。** 「有没有其他财务指标也存在利好」在形式上是一道**开放式搜索题**：k 个指标 × 3 个窗口 × 2 个主指标 × 若干阈值，轻易凑出 50+ 个对照。在 §3 的功效条件下（MDE 远大于真实效应），跑 50 个对照几乎必然刷出至少一个「CI 不跨 0」的假阳，而且**没有任何办法事后区分它和真信号**。

**裁定 R5**：② 不作为独立支流跑。降级为 ① 的 secondary 层，且指标集在预注册时锁死为 ≤3 个（推荐：毛利率变化、经营现金流/营收、应收增速−营收增速），**仅在 ① 的 primary 通过后才解锁查看**。

### 2.3 ③ 情绪讨论热度

**这一支的风险最重，而且不是 collider bias，是更硬的东西：信息已被 pattern 的硬闸用掉。**

代码实证（`path2_apps/bb_v1/dag_spec.py:51`、`params.yaml:17`）：

```
("vol_spike", W.attr("max_bar_vol_ratio", ">=", params.burst.vol_spike_min))   # ⑥
burst.vol_spike_min: 10
```

**bb_v1 的 burst 节点硬性要求：至少一根 bar 的成交量 ≥ 63 日均量的 10 倍。**

后果是结构性的：
- 美股微盘不可能在没有注意力冲击的情况下出现 10× 量能尖峰。所以**每一个 bb 样本都已经落在注意力分布的极右尾**。
- 「社交热度」与「异常成交量」是同一个注意力冲击的两个投影，而**成交量那一个已经被写死进 pattern 定义里当硬闸**。
- 组内热度的变异被**上截断**（truncation from above）——不是相关性高的问题，是可用变异被砍掉的问题。

**裁定 R4-③**：直接把「热度水平」当 X 在 bb 样本内测，**先验增量 ≈ 0**，且这个判断不依赖任何新数据，只依赖已有代码。**这条不值得跑。**

> ⚠ **自我更正（代码核实后收窄）**：上面这条**只对 `bb_v1` 成立，对 `bo_only` 池不成立**。
> `path2_apps/bo_only/dag_spec.py` 是**单节点 BODetector、`edges = ()`、无任何 where**；其 `params.yaml` 的 bo 段没有任何量能阈值。
> `path2/atoms/breakout.py` 里 `vol_ratio` / `max_bar_vol_ratio` 只是**被算成 event 属性**（第 133、187-193 行），detector 本身不筛量能——**量能闸写在 dag 的 `where` 里**（`bb_v1/dag_spec.py:51`），属 pattern 语义，不是 path2 固有属性。
> ⟹ 正确表述：**在 bb 样本内**测热度水平不值得跑；**在 `bo_only` 池上**测则完全合法，且那正是 §3.2 裁定「工程闸该在哪测」的池子，样本量还大一个量级（bb 要 bo+burst+throwback 三段全中）。
> 我最初的措辞把一个 pattern 特异的闸当成了通用属性，这是我的错误；保留原文以便追溯。

**但我不把整支流一棍子打死——有一个版本我会替它辩护：**

> **构成比，而非水平。** 在「所有 bb 样本都有 10× 量能」这个既定事实下，真正有变异的是这次量能冲击的**来源构成**：是散户涌入（社交热度同步飙升），还是机构/算法吸筹（成交量爆了但社交面安静）。
>
> 定义 `heat_residual = z(社交热度) − z(异常成交量)`（或热度对成交量回归取残差）。
> 「未兑现」在这个维度上的读法是**反过来的**：**量已经爆了、但人群还没到 ⟹ 散户流入的空间还在。**
> 方向假设是**找低 heat_residual 的 bb 票**，不是找高热度的。

为什么这个版本能逃过 collider：因为 `heat_residual` 与 bb 的硬闸是**负相关或正交**的（硬闸吃的是成交量，残差正是把成交量剔掉之后剩下的部分），所以 conditioning on bb 不会把它吃掉。

**这是我认为情绪支流唯一值得写进方案的形态**，也是唯一同时满足「用户诉求（比新闻覆盖更广、更贴散户情绪）」和「非循环」的构造。

**但它的可行性另有硬伤（见 §4-3）**：社交历史数据的 point-in-time 极难保证，删帖/封号是非随机的、且偏向暴涨样本，**偏差方向朝着假阳**。可行性上这一支最弱。

> ⚠ **后续更正（见 §8.2）**：上面这句「可行性上这一支最弱」是我**基于先验、未经实测**下的判断，后来我实测了 StockTwits，**在数据可得性这一维上被我自己推翻**（公开 API 无需鉴权、可回溯多年、OTC 也有覆盖、自带原生情绪标签；且 `cursor.max` 是全局 message-id ⟹ 可直接跳到目标日期，全宇宙采集成本降到数小时量级）。
> **保留原文不删，以便更正过程可追溯。** 修正后的判断：③ 的拦路虎不再是数据可得性，而是 ① point-in-time 无法保证、② 必须证明控制 `ATR%`/`pos` 后仍有增量。

### 3.1 功效天花板（先看数字，再谈设计）

用真实 fr 经验分布（112 行 `fr_recalc`：median **0.345**、q25 0.102、q75 0.692、q90 1.379、max 7.27）做参数化 bootstrap 功效模拟：

**bb 内部分组（对照组 n_c = 112 − n_t），fr median 的 MDE @power 0.8：**

| n_treat | 最小可检出 Δfr median | 含义（目标组 median 须达到） |
|---|---|---|
| 5 | **+0.52** | 0.345 → 0.87 |
| 15 | **+0.47** | 0.345 → 0.82 |
| 30 | **+0.38** | 0.345 → 0.73 |
| 56（对半分） | **+0.41** | 0.345 → 0.76 |

**FPR_k6 的 MDE @power 0.8**（基线 p=0.500，判定率 60.7%，即 42/112 是 none）：

| n_treat | 最小可检出 Δp |
|---|---|
| 15 | ≈ **+0.40**（0.50 → 0.90） |
| 30 | ≈ +0.35 |
| 56 | ≈ +0.33 |

**关键读法**：
1. **MDE 几乎不随 n_treat 改善**（0.52 → 0.38，n 翻了 11 倍只降 27%）。瓶颈不是分组大小，是 **fr 分布本身的极端右偏**（q90/median ≈ 4×，max = 7.27）。加样本到 112 的两倍也救不了。
2. **任何真实基本面信号的效应量级估计在 0.05~0.20** —— ⚠ **这是本节唯一一个我没有直接实测的数字，必须标注其不确定性**：
   依据是 PEAD 文献中极端 SUE 十分位的 60 日 CAR 漂移约 2~6%，换算到本样本的 fr（40 日 `mfr_high` 口径、微盘、median 0.345）后放大若干倍。
   **这个换算本身是粗略的**：fr 是 max-based 度量、分布极端右偏，与 CAR 不同尺度；微盘的漂移可能显著大于文献均值（信息扩散更慢）。
   **保守读法**：即便把上界放宽到 **0.30**（即文献效应量在本样本上被放大到极限），仍低于 n_treat=15 时的 MDE = 0.47。
   **结论对这个数字不敏感**——要让 112 行分组变得可行，真实效应得达到 **0.4 以上**，那已经是「目标组毛收益整体 ×1.35」的量级，不是一个基本面信号该有的样子。
   ⟹ **MDE 比现实效应大 2~10 倍**（区间反映上述不确定性）。
3. ⟹ **在 112 行上分组测任何新支流，统计上注定得到「CI 跨 0」。** 这不是「本轮可能失败」，是「本轮在这个设计下必然无结论」。

|---|---|

| 200 | 0.63 |

**但要诚实，不要把它说成灾难 —— 我把量也测了**：

|---|---|

**因此真正的威胁不是绝对水平，是差异性幸存（differential survivorship）**，而且方向对用户假设**不利地有利**：

> 「营收高增长 ∧ 股价没涨」这一格，恰恰富集了**有增长无现金 → 增发续命 → 死亡螺旋 → 退市**的公司。
> 这类票被系统性地从数据里删掉了 ⟹ **该格的 fr 被朝着「支持用户假设」的方向高估。**

这不是可以靠加协变量修掉的——缺失数据不在样本里。**唯一诚实的处理是敏感性分析（强制项）**：

> **临界点分析**：假设缺失的退市票全部落在目标格、fr = 退市典型值，
> 问**需要多大比例的缺失质量**才能把结论翻转（CI 从不跨 0 变成跨 0）。
> 报告必须给出这个**临界比例数字**，而不是只在 limitation 里写一句「存在幸存者偏差」。

**判读标准（预注册时定死）**：

| 临界比例 | 判读 |
|---|---|
| < 10% | 结论对幸存者偏差**不稳，不得接入** |
| 10% ~ 30% | 需**外部退市率证据**佐证（该票池的年化退市率 × 从买点到数据快照日的持有期） |
| > 30% | 对幸存者偏差**稳健，可报** |

**我已经把它实现成可抄的模板并跑了 worked example**（`repro/survivorship_tipping_point.py`，

它的 40 日结果一并消失。这个窗口是 **8~11 个月**，对 $2.45 中位价、$1.07M 中位成交额的微盘池，

**方向性说明（重要，防止误伤上一轮结论）**：幸存者偏差只威胁**阳性**结论。
上一轮两条通道的判决是「无差 / 方向反」，补进更差的退市票不会把它们救活

### 4-3 前瞻偏差（point-in-time）
- **财务（最容易写错的一行）**：SEC `companyconcept` 返回的每条 fact 带 `end` / `filed` / `fy` / `fp`。同一个 `end` 期可能有**多条不同 `filed` 的记录**（restatement）。
  必须取 **`filed ≤ t` 的记录中 `filed` 最大的那条**，而不是「该期最新的一条」。
  写错的后果是**朝向假阳**（用了未来修订值）。**代码里加一行 assert：`assert all(f.filed <= t)`。**
- **情绪（防不住，要诚实）**：删帖 / 修订 / 账号封禁导致历史快照 ≠ 当时可见内容，且**删除是非随机的**——pump 帖被事后删得最多，恰好与暴涨样本相关 ⟹ **偏差方向朝向假阳**。
  防御：只用**当时快照**数据源；若用第三方历史 API，必须明确问它是否 point-in-time（多数不是）。防不住就把结论降级，**不要假装防住了**。
- **通用验收**：随机抽 5 个样本手工核对 t 时刻可见性，写进报告。

### 4-4 波动率与市值混杂
- **硬事实**：score 与波动率 R²=0.92，控制波动率后 bo_only lift 归零（memory `project_path2_app_optimization_workflow`）。
- **手段**：**分层，不做回归调整**（波动率-收益关系强非线性，线性调整不干净）。分层变量用买点前 20 日 ATR%（沿用 `rolling_atr_pct_nanmedian`，与 FPR 阈值同源、口径自洽）× 价格档/成交额（微盘常无股本数据，用成交额代理市值）。层内比较，再按层加权合并。
- **验收标准（写死）**：报告必须附**两组的波动率分布对照**。若两组 ATR% 中位数差 > 20%，未分层结果一律作废。
- **免费的稳健性读法**：FPR 的阈值本身是波动率归一的（几何对称 `k·M`），fr median 不是。⟹ **若 fr median 有差而 FPR 无差，优先怀疑波动率残留混杂，而不是「潜力 vs 方向的正交分工」。**

#### 4-4c 自我证伪：我把 §4-4b 拿去证伪了自己，结果比原发现更有价值（`repro/atr_mechanical_check.py`）

我上面提了一个纯机械的替代解释，并按红队纪律自己去测了它。**两步，两个结果，第二步部分推翻了我自己。**

### 4-5 多重检验
- **计数现实**：3 支流 × 若干量 × 3 窗口 × 2 主指标 ⟹ 轻易 50+ 对照。在 MDE ≫ 真实效应的功效下，假阳几乎必然出现。
- **手段（层级门控，不用 Bonferroni）**：Bonferroni 在本功效下会把一切杀光（等于不做）。改用：
  - 每条支流**恰好一个 primary 假设**，跑前写死量、窗口、阈值、方向；
  - secondary（≤3 个）**仅在 primary 通过后解锁查看**；
  - exploratory 结果在报告里**必须标注「不构成证据、仅生成假设」**。
- **廉价的额外多重性控制 —— 符号一致性**：要求同一效应在 `FPR k=4/5/6` + `fr median` 四个近似独立读数上**方向全部一致**（随机同号概率 ≈ 1/8）。
  这个判据**有 teeth**：上一轮 8-K 试验正是死在三窗口符号漂移（d14 +0.20 / d30 −0.36 / d60 −0.08）。
- **样本冻结**：预注册时声明样本边界，不允许「再多跑一个月数据看看」。

### 4-6 作用面上限
- 公式：`Δ_total ≤ 标记率 × Δ_group`。
- **门槛抬高到标记率 ≥ 10%**（上一轮用 5% 太松：4.5% 的负向率导致上限只有 2pp，一个查询延迟 + LLM 成本的组件换 2pp，工程上就不该做）。
- **最省预算的一步**：作用面上限必须在**预注册时**用**预期**标记率算出来。若上限 < 有意义量级，**根本不跑**。

### 4-7 循环定义
- 三种具体形式：① forward return 参与分组；② 用「后来涨了的样本」回溯挑指标/阈值；③ **事件窗与评估窗重叠**（若 CAR[0,+2] 用于分组而 fr 从 t+0 起算，则重叠 3 天）。
- **手段**：**评估窗起点 ≥ 分组窗终点 + 1 个交易日**。fr 的锚必须严格晚于所有分组信息。写进预注册，**并在代码里加一行 assert**。

### 4-8 共线
- **热度 vs 成交量**：报告 `X` 与已用信号的相关。若 |ρ| > 0.6，**必须残差化后再测**（X 对成交量回归取残差），否则测的是已用信息。

### 6.0-bis ⚠ 红队自我更正：正确的 null 是 H0-recent，我的次结论被 FinChannel 驳回（采纳）

**FinChannel 的反驳**：我用的是 **H0-uniform**（财报均匀落在 `[drought_start, buy_date]` 全窗）。
但我们取的是**「最近一次」**财报 = `max(filed ≤ buy_date)`——按季报节奏它**不可能落在全窗任意处**，
只能落在 `[buy_date − P, buy_date]` 内（P = 该票自己的实际申报间隔）。
全窗中位 109 自然日 > 季报间隔 ≈ 91 天 ⟹ 窗口前段有一块**结构上不可能**落进去的区域，
而那块**整个位于旱期内** ⟹ **H0-uniform 系统性高估旱期基率、低估 burst 基率。**

**裁定：他是对的，H0-recent 是正确的 null，我采纳。**
理由（我自己核过的三层）：
1. 令 A = 账龄。在「公司财政日历与形态时钟无关」这个我们真正要检验的零假设下，
   随机观测时点的 **A ~ Uniform(0, P)** ⟹ 落点的支撑集就是 `[buy−P, buy]`，不是全窗。
   **用 P 去界定支撑集不是「把申报间隔的分布和落点分布混为一谈」，恰恰是把前者正确地传导进后者。**
2. 若进一步考虑申报间隔**不等长**（Q4→10-K 的间隔远大于 91 天），更新过程的**后向再生时间**密度是
   `f(a) = P(gap > a)/E[gap]`，随 a **递减** ⟹ 小账龄（更靠近买点、更靠近 burst）的质量**更大**
   ⟹ burst 基率还会**再往上**、lift 还会**再往下**。**他的版本对我仍是偏保守的。**
3. 他用**每票自己的实际间隔** P，比我快速估一个统一 P 更好。

**回应 lead 提的反论**（「形态各段长度本身是随 symbol 变化的随机量，『最近一次』的约束是否真的改变了段占比的期望？」）——
**改变，而且方向是确定的、不会被随机性抹平**，原因是**时序有序 + 截断锚在末端**：

> 形态各段在时间上**有序**：`drought_start → burst → throwback → buy_date`；
> 而截断窗 `[buy−P, buy]` 锚在**末端**（buy_date）。
> ⟹ 被截掉的永远是**最早**那一段，而那一段**整块位于旱期内**。
> - **burst / 回踩**：中位段长 8 + 2 = 10 交易日（≈14 自然日）≪ P≈91 天 ⟹ **完整落在截断窗内，分子不变**；
>   而分母从 W（中位 109）缩到 P（中位 91）⟹ **基率按 W/P 上升**。
> - **旱期**：分子丢掉 `[drought_start, buy−P)` 那块、分母也缩 ⟹ **净份额下降**。
>
> 关键是：对**每一只** W > P 的票，方向都**同号**（burst 升、旱期降）；W ≤ P 的票则不变（无截断）。
> ⟹ 这是一个**非负 / 非正的逐票位移**，**在期望上不可能相互抵消**。
> 数量级对得上：burst 基率 6.8% → 9.8%（×1.44），中位 W/P = 109/91 ≈ 1.20，
> 差额来自 W ≫ P 的那些票（重尾把均值抬得更高）。

**顺带一致性检查**：若 P > W，截断窗会伸到 `drought_start` **之前**，此时最近一次财报会落在
「旱期之前」——他的四分类里这一格确实非空（3/48 = 6.2%），**与 H0-recent 自洽**。

**两个 null 的对照（他的数字，`repro/analyze_baserate_and_g.py`）**：

| 段 | H0-uniform（我的） | **H0-recent（正确）** | 实测 | lift(unif) | **lift(recent)** |
|---|---|---|---|---|---|
| 旱期 | 89.4% | **85.0%** | 77.1% | ×0.86 (p=0.010) | ×0.91 (p=0.096) |
| burst | 6.8% | **9.8%** | 14.6% | ×2.14 (p=0.043) | **×1.49 (p=0.185)** |
| 回踩 | 3.8% | 5.2% | 2.1% | ×0.55 | ×0.40 |

**⟹ 什么变了、什么没变（这两句必须分开写，它们不对称）**：

- **没变（我的主结论，两个 null 下都成立）**：77.1% **不构成**「bb 编码了未兑现利好」的证据——
  它低于基率，且原本就是「无基线的绝对比例」（skill ④ 明令不下结论）。
- **变了（我的次结论，撤回）**：「burst 过表征 ⟹ 该担忧**得到支持**」**不成立**（p=0.185）。

- **两者不对称，别写成一句**：他原来提的是一个**正面主张**（「bb 编码了未兑现利好」），
  证据不成立 ⟹ **主张倒掉**；我提的是**对一个反驳的击败**（「该担忧未被推翻」），
  而「两个方向都没有证据」本身就等于**该担忧仍然开放** ⟹ **这一句仍然成立**。

**最终统一表述（采纳他的措辞 + 我补的第二句）**：
> ① 财报在形态各段的落点与随机放置**无法区分**（H0-recent 下旱期 ×0.91 p=0.096、burst ×1.49 p=0.185）——**两个方向都没有证据**。
> ② 因此：「bb 编码了未兑现利好」**不成立**（其证据是无基线的比例）；「burst 是对财报的反应」这条担忧**仍然开放**（既未被推翻，也未被支持）。

### 6.0a ⭐ 推广纪律（本轮红队最有价值的产出，建议进 final_report）

> **任何形如「X% 的样本落在 Y 里」的陈述，报告时必须同时给出 Y 的基率（时间占比 / 面积占比 / 无条件概率）与 lift = 实测 ÷ 基率。**

与项目废弃 `win_rate` 是**同一条纪律**（高基率下的比例只是基率复读），只是把适用范围
从「**指标**」推广到「**一切比例型陈述**」。skill ④ 已经写了这条思想；本轮的贡献是给出了
一个**它被违反、且违反后结论方向翻转**的真实实例，以及一个可直接套用的算法：

```
基率 = Y 的测度（时间跨度 / 面积 / 计数）÷ 全域测度
lift = 实测比例 ÷ 基率
再算单尾二项 p（H0: p = 基率）
```

**什么还站得住**：「bb 要求财报后至少 40 bar 无突破」是真的，但它是 `params.yaml` 的**定义性推论（同义反复）**，

## 7. 我认为最可能让本轮再次失败的原因

**答案：继续在 112 行 bb 买点样本上分组测试。**

不是「选择效应」也不是「样本太小」——是这**一个动作同时触发两个独立死因**，而且两个都致命：

1. **功效天花板（无解）**：MDE ≈ 0.4~0.5 vs 真实效应 0.05~0.20。这在 112 行上**没有任何设计技巧能救**——它由 fr 分布的极端右偏（q90/median ≈ 4×）决定，加样本到 224 行也只把 MDE 降到 ~0.38。结果预定：CI 跨 0。
2. **collider bias（有解，但解法是换样本）**：bb 是 collider，conditioning on 它会诱导 X ⊥ U 的负相关，系统性衰减甚至反转效应。上一轮两条通道**都**出现方向反，是这个机制的两次实现，不是两次巧合。

**Phase 2 实证追加的第三死因（已在本轮真实发生一次）：基率复读。**
FinChannel 的头号结论「77.1% 财报落在旱期」在基率修正后**低于随机基率**（§6.0）——
这不是假设的风险，是**本轮实际发生的**一次。它与前两条不同：前两条让人测不出/测出假信号，
这一条让人**把一个定义性的同义反复误读成实证发现**，而且极难自查，因为数字看起来很有说服力。
**通用防御**：任何形如「X% 的样本落在 Y 里」的陈述，报告时**必须同时给出 Y 的基率**（时间占比 / 面积占比 / 无条件概率）与 lift。
这正是项目废弃 `win_rate` 的同一条纪律，应当从「指标」推广到**一切比例型陈述**。

**次要但真实的第四风险**：日历不均衡（§4-9，假阳率 52.7%）。它与第一条方向相反——第一条让人**测不出真信号**，这一条让人**测出假信号**。如果本轮换到全宇宙路线拿到了大样本，功效问题解决了，那么**假阳就变成头号威胁**，而营收惊喜与情绪热度都是天然日历聚集的量。**换路线不等于换掉风险，只是换了风险的种类，判据必须跟着换。**

**第三风险（结构性的，不在方法论轴上）**：`pos`（买价贴近近期高点）与 `ATR%` 的效应量级（Δfr ≈ 0.38~0.42）**已经与我们希望从外部信息里榨出的量级同级甚至更大，而它们是零成本的**。
若最后的实证结论是「营收/情绪通道在控制这两个价格量后没有增量」，那**不是本轮失败**，而是一个有价值的正结论：**path2 的改进空间在 pattern 内部（例如收紧 tb 企稳判据、把 `pos` 纳入 where），而不在外接信息源**。

### 8.1 ⚠ SEC 走本机代理会静默失败（FinChannel 必读）

本机环境有 Clash 代理（`HTTP_PROXY=http://127.0.0.1:7897`，`env` 可见）。实测：

| 目标 | 走代理 | 直连（`--noproxy '*'`） |
|---|---|---|
| `https://data.sec.gov/submissions/CIK…json` | **000（失败）** | **200** |
| `https://www.sec.gov/cgi-bin/browse-edgar…` | **000（失败）** | — |
| `https://data.sec.gov/api/xbrl/companyconcept/…` | **000（失败）** | — |
| `https://finnhub.io` | 200 | — |
| `https://api.stocktwits.com/…` | 200 | — |
| `https://example.com` | 200 | — |

Python 端的表现是 `URLError: [SSL: UNEXPECTED_EOF_WHILE_READING]`——**不是超时、不是 403，是 TLS 层直接断**，很容易被误判成「SEC 限流」或「代码写错」而白耗一小时。

**成因**：SEC 封了该代理出口 IP（SEC 对数据中心/VPN 段有长期封锁），不是本地配置错误。
**解法（一行）**：SEC 相关请求全部绕过代理——`curl --noproxy '*'`；Python 用 `urllib.request.build_opener(urllib.request.ProxyHandler({}))`，或设 `NO_PROXY=.sec.gov`。
**顺带确认**：`cache/news_sentiment/ticker_cik.json`（10387 条）对 8325 个 pkl 票的映射率 **100.0%**，对 112 行样本的 82 个 symbol 也是 **100.0%** ⟹ CIK 环节零损耗。

### 8.2 ⭐ StockTwits 可行性：比我预判的好，我推翻自己在 §2.3 的可行性判断

我在 §2.3 写过「情绪支流可行性上最弱」。**在数据可得性这一维上，这个判断被我自己的实测推翻了。**

**三条实测结论**：

**⭐ 关键的成本破局（我额外验证的）**：`cursor.max` 是**全局 message-id，不是 per-symbol 的**。
实测：拿 AAPL 的 id `662794749` 当 `max` 去请求 SPQS / ANVS，都正确返回了 id 更小（更早）的该票消息。

⟹ **不必从"现在"一路翻页回溯到目标日期**。做法变成：
> 一次性用二分搜索标定「全局 message-id ↔ 日期」映射（在一只活跃票上约 20 次请求），
> 之后对任意 (symbol, 买点日) **直接跳到目标日**，只抓窗口内的几页。

成本量级因此从「全宇宙 ≈ 80 万请求 ≈ 6.5 天」降到「≈ 1~4 万请求 ≈ 数小时」。
**⟹ 情绪支流的全宇宙采集从"不可行"变成"可行"。**

| 修好了 | 没修好 |
|---|---|
| 采集成本 / 规模 | **point-in-time**：分页拿到的是**当前仍存在**的消息，删帖/封号后的内容不可恢复，且删除非随机（pump 帖删得最多、恰好与暴涨样本相关）⟹ 偏差方向朝假阳 |

### 9.2 新裁定：条件 B 的口径分歧 —— 「未突破前高」≠「没有涨」（lead 第 4 条）

**事实（FinChannel 已跑完全量，`g` = 财报日→buy_date 累计涨幅，n=48）**：

| 口径 | q25 | **med** | q75 | **\|g\|≤10%** | g>0 |
|---|---|---|---|---|---|
| `g_raw` | +0.381 | **+0.750** | +1.210 | **2.1%** | 93.8% |
| `g_adj`（减同 ATR% 三分位 × 同日历窗、400 只 pkl 的中位收益） | +0.405 | **+0.751** | +1.258 | 4.2% | 95.8% |

减基准前后几乎不变 ⟹ **是个股自身涨幅，不是 beta。**
分段：财报日→burst 起点（旱期段，中位段长 24 td）med **+0.305**，\|x\|≤10% 仅 12.5%；

语义替换的量化：用户原话「没有涨」vs 锁的「未突破前高」，bb 池上**相差中位 +30.5%**，
**只有 12.5%–13.5% 的行真的没涨。**

**⟹ 旱期 = 无突破 ≠ 没涨。** FinChannel 的 H1 把条件 B 定义成**「t 前 40 个交易日内未突破前高」**（几何口径），
用户原话是**「股票没有涨」**（收益口径）。两者存在实质语义差。

**我的评估（三条，对先验判据和两阶段设计都有影响）**：

1. **这改变了「在测什么命题」，不只是改变了口径。** FinChannel 选几何口径的理由是**迁移有效性**
   （bb 的 `first_drought` 就是几何的，b 上估的 f 才能搬到 a），这个理由**成立且重要**。
   但代价是：**阶段 b 测的不再是用户的原命题**。§3.2 我说「回答原命题要换样本」——现在要补一句：
   **换定义同样会换掉命题，B 的口径选择与样本选择是同等级的决策，必须在预注册里显式声明。**
2. **它实质削弱「未兑现」这个前提——但必须精确到「削弱了哪一半」。**
   FinChannel 的推论是「在 bb 买点上从价格路径看，『尚未被价格兑现』不成立」，并说这不否定增量预测力。
   **这个区分成立，但他的措辞还可以更精确一格，我建议这样写**：

   > **`g` ≠ 0 证伪的是「价格没动」，不是「价格没动够」。**
   > 用户原话「股票没有涨」正是**前者**⟹ **用户陈述的前提在 bb 买点上被证伪**（中位已涨 +75%，只有 2.1% 的行 \|g\|≤10%）。
   > 而经济上真正有意义的「未兑现」是**反应不足**（under-response），需要把已实现涨幅与**利好强度**相比才能判定——
   > 这正是 §1.2 定义 B 的落差框架。**`g` 只给了这个比较的一半，另一半（利好强度 f）还没测。**
   > ⟹ PEAD 本身就是「涨了但没涨够」，所以 **D2（增量预测力）完全不受影响**；
   > 被证伪的是**叙事**，不是**可检验命题**。

   ⟹ 报告里必须把这两句分开：**「用户的原话在 bb 上不成立」** 与 **「营收量在 bb 上是否仍有增量」** 是两个独立结论，
   前者已判、后者未测。**把前者写成后者，会把一个尚未验证的通道误判为死亡。**
3. **建议（不推翻 H1，而是加一条对照 + 一条必报项）**：
   - **`g` 必须进模型当分层/协变量**，并检验一条单调预测：**X 的增量效应应随 `g` 增大而衰减**。
     这是「未兑现」叙事最干净的一个证伪测试——若增量效应与 `g` 无关，说明测到的不是「未兑现」而是别的东西。
   - **关于 FinChannel 提出的双口径设计（B 几何 + B' 收益率秩），我的裁定是：不构成多重性，但「只报告不判定」不够，需要补一张预先声明的决策表。**

     **(i) 多重性**：他把 B' 定为**报告项**而非判定项、primary 判定仍只走 B 一条 —— 这个构造**本身是对的**，
     形式上不增加检验次数。**但真正的风险不在检验次数，在「报告自由度」**：若 B 失败而 B' 通过，
     围绕 B' 重写报告的诱惑极大，而那在事后是看不出来的。
     ⟹ **补救（必做）**：预注册里写死一张 **2×2 决策表**，四种组合各自的结论措辞**跑前就定死**——
     `B 过∧B' 过` / `B 过∧B' 不过` / `B 不过∧B' 过` / `都不过`。
     特别是 `B 不过∧B' 过` 这一格必须提前写明它**不能**被表述为「通道有效」，只能表述为
     「用户命题在全宇宙上得到支持，但该结论不可迁移到 bb」。

     **(ii) 更干净的做法（我推荐替换而非并列）**：把「价格反应」从**第二个二值条件**改成**一个连续协变量**——
     即用 `g` 的截面秩，检验 **X 的增量效应是否随 `g` 增大而衰减**。
     好处三条：① 只有一个模型、彻底没有多重性；② **直接检验「未兑现」叙事的核心预测**
     （未兑现 ⟹ 已涨得越多、剩余越少 ⟹ 效应递减），若效应与 `g` 无关，说明测到的根本不是「未兑现」；
     ③ 不浪费变异——二值切分会把 `g` 的三个数量级信息压成一个 0/1。
     **B（几何）保留，但只作为「样本定义条件」以保住向 bb 的迁移有效性，不再兼任「价格没涨」的代理。**
     B' 则降级为**面向用户沟通的描述性切分**（非判定、非分析），因为它是用户原话的忠实实现，报告里需要它来回答用户的问题。

     **(iii) 他那句「『用户命题成立』与『bb 该接入』是可分离的两件事」我完全同意**——
     而且这正是 §3.2 / R6 的**经验实例**：bb 买点 `g` 中位 +75%、系统性不满足 B' ⟹
     B' 版结论在结构上就无法迁移。这条从「设计裁定」变成了「有数据支撑的事实」，建议 final_report 直接引用。
   - **加入我的先验判据（新增 C7）**：**报告必须显式声明 B 的口径；若采用几何口径，
     必须同时报告组内 `g` 的分布；若 `g` 中位数显著 > 0，结论表述中不得出现「股价没涨」这类措辞**
     ——只能说「未突破前高」。这是防止最终报告在语言层面悄悄漂回用户原话、造成过度解读。
