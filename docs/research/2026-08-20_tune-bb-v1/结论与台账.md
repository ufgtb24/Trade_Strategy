# bb_v1 提高外推能力 · 调参全流程结论与台账

> 日期：2026-08-20 ~ 08-21 · 目标：解决「match 不足 → 调参偶然性大」并提高外推能力
> 流程：tune-gates（宽进重扫 → 事后切档 → 组合回放 → 必须真扫 OAT → 外推验证）· 训练窗 [2024-01, 2026-01]
> **核心定论：bb_v1 无可靠 edge 可放大——训练窗收紧增量是 head_buffer 隐式过滤的 artifact；外推失效是突破信号失效，非调参可解。**

---

## 一、起点与 63 底座阶段（第一阶段）

**起点**：收闸 scan `20260818T223413.json`（一年窗 [2025,2026]），**72 match**，fr_med=0.5588——match 不足。

**宽进底座（head_buffer=63）**：`scan-wide.py` → `scan-wide-bb_v1-202401-202601.json`
- 窗 [2024-01, 2026-01]，label_horizon=40，price 0.5-30 / vol≥10000
- 宽进 override：`first_drought_min 40→0`、`distinct_pk_min 3→1`、`vol_spike_min 10→0`、`max_day_drop_pct 0.2→None`；生成侧保持
- **4882 观测**，自检门通过；数据 8325 pkl，0% 退市股覆盖（幸存者偏差确认）

**5 闸平台图（63 底座）**：first_drought 收紧反作用 / distinct_pk fr 平台 [5,6] / vol_spike fr 峰值 15 / peak_age 交集 [125,250] 但分年不一致 / day_drop 看似白过滤。

**组合回放反转**：毒药闸不是白过滤——fd≥20 的毒药样本 FP=0.333 是真坏样本（与 first_drought 交互）。单闸 OAT 交互误判 → 组合回放纠错。

**定案（63 底座）**：B（fd20 毒药 dpk3 vsp10）FP 0.579 / FINAL（+dpk4 vsp15）FP 0.614。

## 二、外推验证与用户批评（关键转折）

**外推（63，窗 [2026-01,08-17]）**：B 22 样本 FP=0.651、A 13 样本 FP=0.600——方向全过。

**用户批评（正确）**：head_buffer=63 漏检 2026-01~02，把这些「坏样本」排除在外推评估 = **选择性使用外推数据**。外推区是 [2026-01-01] 之后全部，不能挑 B 表现好的子窗口。

**前缓冲验证**：head_buffer 63→250，2026-01 事件 0→10，外推样本 22→72。但新增样本 FP=0.38（负 edge）——2026-01 不是「被浪费的好机会」，是「没有好机会」。

## 三、250 完整检测重做（第二阶段，守 skill 红线）

**守纪律**：skill 红线「训练与外推必须同一值」→ 训练底座用 head_buffer=250 重做。

**250 底座**：`scan-wide-bb_v1-202401-202601-buf250.json` → **5552 观测**（63 的 4882 + 完整检测多检出 14%）。

**重大发现（250 完整检测推翻 63 全部收紧结论）**：
1. **收紧降 FP**：全池 FP=0.536 是所有收紧配置的最高点（A 收紧 FP=0.485、B63 FP=0.517 < 全池）。63 底座的「收紧提升」是 head_buffer 隐式过滤 + 样本偏向 2025（有 edge 年）的 artifact。
2. **peak_age/vol_spike 分年方向相反**（2024 收紧升、2025 收紧降）——单年驱动坐实。
3. **2024 年本身无 edge**：250 全池 2024 FP=0.487 <0.5，2025 FP=0.577——训练窗内部 edge 不均匀。
4. **收紧偏向 2024（低 FP 年）→ 整体 FP 被拉低**。

## 四、外推完整定论（250 完整检测）

| 配置 | 外推 FP（250） |
|---|---|
| A 旧 | 0.384 |
| B | 0.424 |
| FINAL | 0.421 |
| **bo_only（单纯突破）** | **0.471** |
| 随机基线 | 0.470 |

**突破信号本身在 2026 外推区无 edge**（bo_only FP 0.471 = 随机基线 0.470）。bb_v1 完整链（0.42）比单纯突破还略差（下游叠加负选择）。训练窗调得多漂亮都救不了外推。

## 五、必须真扫参数 OAT（6 参数 × 4 档，24 档全量 scan）

| 参数 | 结果 | 判定 |
|---|---|---|
| **stop_confirm_bars** 2→3 | FP 0.537→**0.561**，分年 0.507/0.609 **双升** | ✅ **唯一可信增量** |
| min_bos 1→3 | FP 0.548，2024 升 5.2pt / 2025 降 2.3pt | ❌ 分年分裂 |
| min_relative_height | FP 0.532-0.539 全平 | ❌ 无增量 |
| exceed_threshold | FP 0.525-0.543 非单调 | ❌ 无增量 |
| gap_max | FP 0.531-0.541 全平 | ❌ 无增量 |
| big_rise_k | FP 0.537-0.545 非单调 | ❌ 无增量 |

**OAT 收敛**：24 档里只有 stop_confirm_bars=3 有分年一致的 FP 增量（+2.4pt，n 5552→2806）。训练窗无更可靠的 edge 可放大。

## 六、最终定论

1. **bb_v1 没有可靠的 edge 可调参放大**：训练窗（250）里收紧全降 FP、OAT 只有 1 个参数有微增量、2024 年本身无 edge。
2. **外推失效的根因是突破信号失效**（bo_only=随机基线），不是下游参数问题。
3. **63 底座的一整套调参结论是检测 artifact**——head_buffer 隐式过滤制造了「收紧提升 FP」的假象。
4. **调参流程的价值**：完整证明了「bb_v1 在这个调参空间里无 edge 可放大」——「外推平庸=真实 edge 诚实读数」的最完整验证。

## 七、方法论沉淀（全部已写入 tune-gates）

1. 切档先查列分布（peak_age 右缘假象 / first_drought 漏下界）
2. 有交集也要分年验证（peak_age 单年驱动）
3. FP 四态列必须随行
4. 「无增量」先查分布区分空转 vs 无用
5. **单闸 OAT 交互误判 → 组合回放纠错**（毒药闸）
6. **外推窗缓冲双向校验**：①后缓冲（label horizon 截短）②前缓冲（head_buffer 是隐式过滤器，训练与外推必须同一值）
7. **bug 修复**：extract_skeleton.py 的 None-label 误判（窗口末端无 label match 跳过而非失配）
